# MiniMachine 考点覆盖对照

> 把四门课 `LEVELS.md` 末尾「大纲覆盖对照」的每一条，映射到 MiniMachine 的某个阶段和部件，保证 2027 年 408 大纲没有空白。
> 阶段详情见 [LEVELS.md](LEVELS.md)，指令集规格见 [ISA.md](ISA.md)。大纲条目的拆分粒度与各科 `LEVELS.md` 一致。

**「形式」一列的含义**：
- **机器部件**：整机运行时真实存在的模块，用户程序或内核会走到它；
- **trace 场景**：机器提供一个场景脚本，按王道表格格式打印过程（甘特图、置换表、`cwnd` 变化等），用来推演综合大题；
- **旁路实验**：不装进整机主路径，作为可选模式或独立小程序。考纲内但不必做的标「选开」，大纲外的标「选做拓展」（两种标签的定义见 `LEVELS.md` 贯穿设计第 5 节）；
- **卡片**：命名、定义、分类类内容，写进 `00-minimachine/NOTES.md`「概念卡片」下该阶段的「### 阶段 NN」小节，并注明它在机器里对应哪个部件。
