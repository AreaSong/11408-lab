## 07 · 请求分页与页面置换
- **产出**：缺页处理程序（找空闲页框、调入、改页表项、重新执行）；磁盘镜像上的对换区；五种置换算法可切换（OPT、FIFO、LRU、CLOCK、改进型 CLOCK）；页框分配策略；工作集与抖动；伙伴系统管理物理页框；`sbrk` 和 `mmap`
- **小步骤**：① 物理页框：伙伴系统分配与回收，空闲块链用 `lib/02` 的双链表 ② 缺页处理：P = 0 时找空闲页框，没有就置换；从对换区或文件区调入；修改页才写回；改页表项后重新执行 ③ 置换算法：FIFO、OPT（离线，需要整条访问串）、LRU（`lib/02` 双链表加 `lib/16` 散列表）、CLOCK、改进型 CLOCK（用硬件维护的 A、D 位） ④ 页框分配：固定分配局部置换、可变分配全局置换、可变分配局部置换；请求调页与预调页 ⑤ 工作集与抖动：逐步减少页框数，缺页率陡增；在整机上复现 Belady 异常 ⑥ `sbrk` 让堆按需增长；`mmap` 共享映射让两个进程看到同一页框；文件映射先用宿主文件作后备，08 完成后改由 MiniMachine 的文件系统提供
- **通过标准**：给定访问串和物理块数，求缺页次数、缺页率或某次被淘汰的页；某时刻的工作集；缺页中断的处理过程与页表项各字段的作用；改进型 CLOCK 的淘汰顺序
- **选做拓展**：写时复制的 `fork`（共享只读页，写时越权故障里复制）；页面缓冲（空闲页链表与修改页链表）；Slab 分配器
- **选开（考纲内）**：用红黑树管理进程的虚拟内存区间（类似 Linux 的 VMA），按区间起始地址排序：`mmap` 插入区间、缺页时查地址落在哪个区间都查这棵树（`lib/11` 已练；选开前置 `lib/11-rbtree`）
- **前置关卡**：`os/09-contiguous-alloc`、`os/11-demand-paging`、`os/12-page-replace`、`lib/02-linked-list`、`lib/16-hash`；阶段 06
