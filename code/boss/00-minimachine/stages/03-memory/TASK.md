## 03 · 主存与 Cache
- **产出**：主存模块（可配置容量、存取周期、多体低位交叉或高位交叉）；Cache（直接映射、组相联、全相联；LRU、FIFO、随机替换；写回加写分配、写直达加非写分配），指令 Cache 与数据 Cache 分开；CPU 访存都经过 Cache，统计命中率和平均访问时间
- **小步骤**：① 主存：按字节编址、小端；用若干片存储芯片拼出主存，打印每片的地址范围和片选 ② 多体交叉：连续访问时低位交叉的流水时间与带宽，和高位交叉对比 ③ Cache 地址划分（标记 | 组号 | 块内偏移）与查找，三种映射方式可配 ④ 替换算法与写策略：脏位、写回时机；按配置算 Cache 总容量（含标记位、有效位、脏位、替换控制位） ⑤ 接入 CPU：节拍模式下命中 1 拍、缺失按主存周期和块大小计；流水线模式下缺失时阻塞 ⑥ 在整机上复现 `co/06` 的第 ⑥ 步：MM32 程序按行、按列对二维数组求和，打印两种顺序的命中率和平均访问时间
- **通过标准**：主存地址各字段的位数、Cache 总容量、给定数组访问顺序的命中率、平均访问时间、交叉存储器连续访问的时间、存储器扩展的芯片数与地址范围
- **选做拓展**：两级 Cache；硬件预取；进阶可看 MESI
- **选开（考纲内）**：多处理器 Cache 一致性：两颗 MM32 核共享主存，写直达加监听失效，复现 `co/12` 的伪共享；DRAM 刷新造成的访存停顿（`co/05` 第 ① 步已练）
- **前置关卡**：`co/05-memory`、`co/06-cache`；阶段 02
