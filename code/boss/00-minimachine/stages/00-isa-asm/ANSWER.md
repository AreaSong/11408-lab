## 思路

MM32 是 Load/Store 机：运算只碰寄存器，访存只有 `LD`/`ST` 一类。单总线每一拍只能有一个源，所以加法要拆成「rs 送进 Y、rt 与 Y 相加锁进 Z、Z 写回 rd」，做不到单周期。取指对所有指令相同，共 4 拍：PC 送 MAR 并锁住本条地址 IPC，存储器把指令送进 MDR 的同时增量器做 PC+4，MDR 送 IR，最后译码。增量器和存储器走的不是内总线，所以取指第 2 拍的驱动数是 0。

汇编器先把标号记在当前位置计数器上，再回头填位移。分支和 `call` 的操作数是目标地址，位移 = 目标 −（本条地址 + 4）。`[pc+数字]` 里的数字就是位移本身；`[pc+标号]` 里的标号仍是目标地址，汇编器再换成位移。`li` 能放进有符号 16 位时变成一条 `ld rd, #imm`，否则是 `lui` 加 `ori`。`la` 总是这两条，因为地址不一定塞得进 16 位。

标志只在 ALU 写结果时更新。加法的 CF 是最高位进位，OF 是最高位进位异或次高位进位。减法先把减数按位取反再加 1，CF 再把这个进位取反，得到借位。因此 0 减 `FFFFFFFFH` 的和是 1，但 CF=1。逻辑运算把 CF、OF 清 0。移位的 CF 是最后移出去的那一位，移 0 位时 CF 保持原样，OF 清 0。有符号乘只留低 32 位；64 位乘积的高 33 位不全 0 也不全 1 时 OF=CF=1。除法向 0 取整，除数 0 或 `80000000H÷(−1)` 是故障，不写目的寄存器，PC 回到本条。

异常在本阶段只停机：故障把 PC 恢复成 IPC（本条），自陷保留已经加 4 的 PC。不写 EPC，不改用户/内核位，不跳向量表。这些是阶段 01 的隐指令。`SYSCALL`、`BRK`、OF=1 时的 `TRAPV` 都按自陷停机。用户态执行 `HLT` 等特权指令报特权违例，同样停在本条。

## 小步骤对照

1. **编码**：`cpu_enc_*` 按 ISA 的字段位置拼字。`cpu_decode` 要求保留位为 0，无用的寄存器字段也必须为 0，这样每条合法指令只有一种机器码，反汇编才能往返。
2. **两遍汇编**：`asm_layout` 只算地址和指令占几个字；`emit_all` 再编码。`jnz` 先改写成 `jne` 再编码，列表里出现的是 `jne`。
3. **ALU**：`cpu_alu_add` / `cpu_alu_sub`。2024 年第 43 题那两个加数得到 `1FDB9753H`，OF=1，CF=1。2017 年第 44 题的比较 CF=1。2023 年第 16 题 x=10、y=−20 得到 30，OF=0，CF=1，选 B。
4. **寻址**：`cpu_ea` 不碰机器。基址是寄存器加符号扩展位移，变址是零扩展的形式地址加寄存器，相对是（PC+4）加符号扩展位移。直接和变址的形式地址必须落在 `0000H～FFFFH`。
5. **节拍**：`cpu_seq` 给出执行拍，`cpu_step` 前面固定加 4 拍取指。`cpu_bus_drivers` 在每拍之后数驱动。立即数 `ld` 是 4+1=5 拍，寄存器加法是 4+3=7 拍，`hlt` 是 5 拍。
6. **端到端**：1 到 10 求和得到 `r0=00000037H`。`li sp, #0x7000` 后调用函数，返回值在 `r0`，`r7` 回到 `00007000H`。`push` 会展开成 `subi sp, sp, #4`，这条减法会改标志，所以不要指望 `push` 前后标志还在。

## 易错点

1. 相对寻址和分支用的都是已经加 4 的 PC，位移单位是字节。2014 年那种「OFFSET×4」不是 MM32。
2. 减法 CF=1 表示有借位，无符号比较看它；有符号小于看 SF 是否不同于 OF，不看 CF。
3. 全 0 的字是 `NOP`。跑过了 `hlt` 会把后面的 0 当空操作一直执行，所以程序要用 `hlt` 收尾。
4. 故障不写目的寄存器。除法错之后 `r0` 仍是 0，PC 指回除法指令。
5. 直接寻址写 `[0x10000]` 会报超出 16 位。高地址用 `la` 再寄存器间接。
6. 列表第三列是展开后的规范指令，不是用户原来的伪指令文本。手算机器码时看这一列。
7. 本阶段 `PG=1` 也不走页表，地址仍当物理地址。真正的 MMU 在阶段 04，并且默认关闭。

## 概念卡片

1. **单总线为什么不能单周期？** 加法需要两个寄存器先后送到 ALU，还要把结果送回寄存器堆。一条总线同一拍只能有一个输出，这些传送排不进同一拍，所以 CPI 大于 1。
2. **扩展操作码**：主操作码 6 位。`op=0` 再用 6 位 `funct` 区分寄存器运算。短操作码的指令才带 16 位立即数或位移。
3. **取操作数访存次数不含取指**。立即是 0，直接/寄存器间接/基址/变址/相对是 1，一次间接是 2。LEA 不算最后那一次取数；间接 LEA 仍要读一次才能知道 EA。
4. **调用约定**：`CALL` 把返回地址放进 R6，不压栈。栈帧要由被调用者 `push lr`。x86 是硬件压栈，画出来的 `[fp+4]` 位置一样，差别在谁来压。
