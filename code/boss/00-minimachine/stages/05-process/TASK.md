## 05 · 进程与调度
- **产出**：宿主 C 内核的进程管理：PCB、五状态转换、上下文切换（R0~R7、PC、PSW、PTBR）、`fork`（复制地址空间）、`exec`（装入汇编器产出的映像）、`wait`、`exit`；调度算法运行时可切换（FCFS、SJF/SRTN、HRRN、优先级、RR、多级反馈队列），时钟中断驱动抢占；甘特图 trace
- **小步骤**：① PCB 与状态转换，不合法的转换报错 ② 上下文切换：在时钟中断和系统调用返回时换 PCB，同时改 PTBR 并 `TLBFLUSH`；加闲逛进程 ③ `fork`、`exec`、`wait`、`exit` 系统调用，每个进程独立的页表与按 `ISA.md` 第 7 节的地址布局 ④ 调度框架：调度策略做成函数指针表；就绪队列和多级反馈队列各级用 `lib/04` 的循环队列，`sleep` 的定时器用 `lib/09` 的小根堆 ⑤ 调度算法与调度时机：进程结束、阻塞、时间片到、更高优先级到达，分别标出是否引起调度 ⑥ 同时跑几个 CPU 型和 I/O 型的 MM32 用户程序，打印甘特图和周转、带权周转、等待时间表，与 `os/04` 计算器的结果一致
- **通过标准**：给定进程表，求某算法下的平均周转时间和带权周转时间；一段多次 `fork` 的程序打印几次；哪些状态转换可能发生；上下文切换保存了什么
- **选做拓展**：CFS 完全公平调度（按虚拟运行时间排序的红黑树，复用 `lib/11-rbtree`）
- **选开（考纲内）**：两颗 MM32 核的多处理机调度，共享就绪队列与私有队列加负载均衡（`os/05` 第 ④ 步已练）；MM32 用户态的用户级线程库（`os/02` 已练）；进程间通信系统调用：管道、共享内存、消息传递、信号（`os/03` 已练）
- **前置关卡**：`os/02-process-thread`、`os/03-ipc`、`os/04-scheduler`、`os/05-mlfq-smp`、`lib/04-queue`、`lib/09-heap-huffman-ufset`；阶段 04
