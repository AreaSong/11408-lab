## 12 · 传输层与应用层
- **产出**：UDP 与 TCP（连接管理状态机、可靠传输、流量控制、拥塞控制）；`socket` 一组系统调用；DNS 服务器节点；HTTP 服务器与客户端；SMTP 与 POP3
- **小步骤**：① UDP：端口与带伪首部的校验和；`socket`、`sendto`、`recvfrom` 系统调用 ② TCP 连接管理：三次握手、四次挥手的状态机，trace 打印双方状态和序号、确认号 ③ 可靠传输与流量控制：累积确认、超时重传时间（加权平均往返时间）、接收窗口、零窗口与持续计时器 ④ 拥塞控制：每个 RTT 打印 cwnd 和 ssthresh；人为丢包制造超时和 3 个重复 ACK，看慢开始、拥塞避免、快重传、快恢复；发送窗口 = min(接收窗口, 拥塞窗口) ⑤ DNS 与 HTTP：根、顶级、权威 DNS 节点，对比迭代与递归查询的报文数；HTTP 服务器返回文件系统里的网页，比较持久与非持久连接需要的 RTT 数 ⑥ 电子邮件：SMTP 服务器节点收信存入邮箱文件，POP3 取信；非 ASCII 内容用 Base64 编码
- **通过标准**：握手或挥手过程中的序号、确认号与双方状态；某时刻 cwnd 的值、经过多少个 RTT 窗口达到某值；超时重传时间；访问一个网页总共需要多少个 RTT；DNS 查询的报文个数；邮件发送和读取各用什么协议
- **选做拓展**：选择确认（SACK）；把拥塞控制换成 CUBIC 与 Reno 对比
- **选开（考纲内）**：FTP 的控制连接与数据连接（主动、被动模式）；C/S 与 P2P 文件分发时间的实测
