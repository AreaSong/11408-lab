## 09 · 总线、DMA 与 I/O 软件
- **产出**：系统总线（CPU 与 DMA 控制器共享、仲裁、带宽统计、握手 trace）；程序查询、中断、DMA 三种 I/O 方式；I/O 软件四个层次；缓冲；设备分配；SPOOLing 打印
- **小步骤**：① 总线：一种仲裁方式（链式查询、计数器定时查询或独立请求选一种），一次总线事务分别按同步定时和异步全互锁打印握手 trace，统计总线带宽 ② I/O 接口与三种方式：控制台走存储器映射、磁盘走独立端口，对照两种编址；同一任务分别用查询、中断、DMA 完成，统计 CPU 用于 I/O 的时间占比 ③ DMA：在节拍 trace 里显示 DMA 窃取存取周期，传送结束发 IRQ ④ I/O 软件分层与设备分配：用户层 → 设备独立性软件 → 驱动 → 中断处理，trace 一次 `read` 穿过四层；逻辑设备名映射物理设备；SDT、DCT、COCT、CHCT 逐级分配 ⑤ 缓冲：单缓冲、双缓冲的时间线与公式对照，循环缓冲区 ⑥ SPOOLing：多个进程同时打印，作业先进磁盘上的输出井，守护进程逐个送打印机
- **通过标准**：DMA 或中断方式下 CPU 用于 I/O 的时间百分比；单/双缓冲下处理 n 块数据的时间；总线带宽；SPOOLing 的组成与作用；中断响应过程与中断处理过程
- **选做拓展**：两颗 MM32 核共享总线时的仲裁与争用统计
- **选开（考纲内）**：通道与通道程序（`os/15` 概念卡片）
- **前置关卡**：`co/13-bus-io`、`os/15-io`；阶段 08
