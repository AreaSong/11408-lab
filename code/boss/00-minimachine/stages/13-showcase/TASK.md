## 13 · Shell 工具集与开机演示
- **产出**：MM32 用户态运行库与 shell（命令解析、`fork` + `exec` + `wait`、管道、重定向）；文件工具与网络工具；算法工具 `grep`、`sort`、`zip`；综合大题场景脚本；两台机器从开机到互相访问网页的完整演示
- **小步骤**：① 运行库与 shell：MM32 汇编写的启动代码和小库（字符串、打印、数字转换）；shell 解析命令，支持 `|` 和 `>` ② 文件工具：`ls`、`cat`、`mkdir`、`rm`、`ln`、`df` ③ 算法工具（宿主用户程序）：`grep` 用 `lib/06` 的 KMP；`sort` 对放不进内存的大文件做外部排序，`lib/19` 的置换-选择生成初始归并段、败者树多路归并，归并段存在 MiniMachine 的磁盘上，统计读写磁盘的次数；`zip`、`unzip` 用 `lib/09` 的哈夫曼编码 ④ 网络工具：`ping`、`curl`、`mail`，两台机器互访 ⑤ 综合大题场景脚本：按题目参数配置机器、跑一段程序、按王道表格打印 trace（Cache 加地址翻译、PV、文件系统、TCP 组网各至少一个；具体年份和题号由用户核实后填写） ⑥ 开机演示：引导块 → 装入内核 → 挂载根文件系统 → 第一个用户进程 → shell；两台机器开机后 A 用 `curl` 访问 B 的 HTTP 服务器，打印全链路摘要（系统调用、TCP 握手、ARP、帧、DMA、中断）
- **通过标准**：开机演示一次跑通；每个场景脚本打印的关键数字与标准答案一致；`sort` 的读写磁盘次数与外部排序公式一致
- **选做拓展**：C 语言子集编译器，把简单的 C 编译成 MM32 汇编；把时空图、甘特图、cwnd 曲线导出成 HTML；第三台机器做路由器的多跳演示
