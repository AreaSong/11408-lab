# 阶段 13 · 本机 UDP 演示

脚本测试都在一个进程里用模拟时钟。下面这条命令真的走宿主机的 UDP 协议栈，结果和本机有关，所以不放进 `tests/`。

在 `code/` 的构建目录里运行 `minimachine_answer`，输入：

```
udpdemo
```

本机这次的输出是：

```
udpdemo udp bytes=2 text=MM
```

它在 `127.0.0.1` 上打开两个数据报套接字，把两个字节 `MM` 从一个临时端口送到另一个，接收端在 0.2 秒内对上这四个字符。这就是「一根网线是一条 UDP」的最小样子：两个端点、一个数据报、内容原样回来。

它还不是两台独立的 MiniMachine 进程。两台机器的开机和 `curl` 摘要在 `visit` 里，帧并不经过这两个套接字。要把两台整机放进两个进程、用这条 UDP 当网线，还要另做一套进程启动和网卡收发，本阶段没有把它放进必做路径。
