和单关的差别：`lib/06`、`lib/09`、`lib/19` 的程序各自读标准输入。这里只调用它们的函数，命令名让给整机。`lib/19` 的 `exam.c` 没有放进 `DEPS`，不等长段的 WPL 在 `user_sort_wpl` 里按「每次取当前最短的 k 段」重写，口径与那一关的讲解相同。`grep`、`sort`、`zip` 是宿主用户程序：算法在 C 里做，文件只经过 `fs_ns_open` / `read` / `create`，也就是 14～18 号系统调用背后的那一层。

管道没有新的调用号。父 shell 记下有几条命令，就有几次 `fork`、`exec`、`wait`；上一条的输出缓冲区就是下一条的标准输入。参考实现里这个缓冲区在 `user_tool_run`，没有另做 MM32 的管道文件。

## 思路

启动代码只有两条系统调用。`R0 = 1` 是 `write`，`R1` 是标准输出，`R2` 指向 `msg`，`R3` 是 3，送出 `hi\n`。接着 `R0 = 0`、`R1 = 0`，`exit(0)`。`.text` 从 `00001000H` 起，标号 `start` 就是入口。相对寻址和 `la` 仍由阶段 00 的两遍汇编算。

`|` 结束上一条命令。`>` 的下一个词是重定向路径，而且只能出现在最后一条，否则上一条的输出既要进文件又要进管道，接法不唯一。`sh jobs` 只数条数：管道数是命令数减 1，`fork`、`exec`、`wait` 各等于命令数。它不执行命令，所以 `jobs` 行里的 `>` 不会创建文件。

文件工具用的是阶段 08 的根卷。目录项按名字排序后用空格隔开，这样 `ls` 不依赖目录项插进去的顺序。硬链接不占新的索引结点，删掉其中一个名字，链接计数还大于 0，文件还在。`df` 数位图里为 0 的块，以及还没占用的索引结点。空机器数据块从 8 号起空着，一共 24 块；索引结点 0 是根，还剩 31 个。建一个目录、建一个文件之后，用掉 2 个索引结点和 1 个数据块，剩下 `blocks=23 inodes=29`。目录本身不占数据块。

KMP 用从 0 起的 next。2015 的第一次失配记在 `next_i`、`next_j`：主串不动，模式串退到 2。2019 成功时 `pos` 是 3，比较次数含那一次失配，是 10。shell 里的 `grep` 打出匹配行，再打 `host=grep`，表示这是宿主程序，不是又一条系统调用。

置换-选择的例子是工作区 3、输入 `51 49 39 46 38 29 14 61 15 30 1`。第一段 4 个关键字，已经比工作区长：`39 46 49 51`。一共 3 段。归并路数固定为 3，`⌈log3 3⌉ = 1`。生成阶段每个记录读一次、写一次，`gen = 2×11 = 22`。归并阶段套王道估算 `io = 2×n×趟数 = 22`。三段写到 `/s/r0`、`/s/r1`、`/s/r2`，`files` 等于段数。有序结果用败者树归并出来。`ns` 为空时不写文件，公式仍相同。

不等长段不用 `2×n×趟数`。每次取当前最短的 k 段合并，新段长度加入 WPL，读写是 `2×WPL`。9 段那棵树是 223 和 446。二路时最坏比较次数是 `WPL − (段数 − 1)`，2012 的 6 段得到 825，读写仍是 1660。虚段只在 `(r−1)` 除不尽 `(k−1)` 时补，2019 是 2。625 段、5 路正好整除，4 趟，读写 3000000。2024 的冠军是建树之后、还没把段取空时的 `ls[0]`：段号 1，关键字 3。败者树不减少趟数，也不减少 `io`。

哈夫曼仍是权值小的先做左孩子，左分支记 0。2018 的六次权值得到 WPL 80，编码和选项 A 一致。2023 的 WPL 90，除以频次和 36 是 2.5。2014 的 D 用 `code_prefix` 找出 `110` 和 `1100`。2019 的 115 个结点满足 `2n−1`，叶子是 58。`zip` 对正文按出现顺序计频次，编码后再译码，必须和去掉空格后的原文相同。`aba` 里 a 出现两次，b 一次，b 做左孩子记 0，a 记 1，比特串是 `101`，WPL 是 3。

`ping` 的源是 `10.0.0.1/24`，目的是 `10.0.0.2`。同一子网，ARP 问的就是目的地址，不是网关。`curl` 没有引用对象、非持久，握手一个 RTT，请求和响应再一个，共 2。挥手不算在「收完内容」里。`sh mail` 复用阶段 12 的 2012-40：SMTP、SMTP、POP3。

场景不再重算一套口径。Cache 那行先按 10/10/12 拆 `03FFF180H`：虚页号 `3FFFH`，偏移 `180H`，页框 `153H` 拼出 `00153180H`。再用 8 行、直接映射、块 16 字节切这个物理地址。块内 4 位，块号 `15318H`，组号取低 3 位是 0，标记是 `2A63H`。银行家用阶段 06 那张 2012 的表，`k_bank_safe` 给出的序列是 P1 P2 P0 P3 P4，总条数 66。SCAN 用阶段 08 的 `fs_sched`，移动 325。TCP 直接打 2011-39 和 2022-38 的两行。

开机调用 `k_boot`、`k_proc_on`、`k_fs_on`。根卷镜像开头四个字节是 `MMFS`，这就是引导块里能认出的魔数。`k_as_setup` 把 1 号做成正在运行的 init，0 号做成闲逛。`visit` 把这套开机做两遍，表示 A 和 B 各有一台机器；握手用序号 1000 和 5000，第二次是序号 5000、确认号 1001；ARP、一帧、一次 DMA 和 IRQ2 接在同一次 `curl` 上。帧并没有在两台机器的网卡之间真的排队，那些字段是这条访问路径上各层的个数。真的 UDP 数据报只在 `udpdemo` 里发，见实验记录。

## 易错点

1. **`>` 只能放在最后一条。** 放在管道中间，输出就有两个去处。
2. **`sh jobs` 不执行命令。** 它只计数。要创建文件，还得有一条真正的 `echo >`。
3. **硬链接不增加 `df` 里的索引结点。** 删一个名字，另一个还能 `cat`。
4. **目录不占数据块。** 只建目录时 `blocks` 不变。
5. **2015 问的是失配之后的下标，不是成功位置。** 成功位置是后面的 13。
6. **2019 的 10 次含失配。** 只加比成功的 9 次会选 A。
7. **段长不等时不用 `2×n×趟数`。** 9 段若按两趟估是 484，最佳归并树是 446。
8. **2012 的填空是 825，不是 1660。** 1660 是同一棵树的外存读写。
9. **败者树冠军存段号。** 段号 1 和关键字 3 不是同一个数。
10. **虚段余数为 0 就补 0 个。** 2019 的余数是 9，补 2 个。
11. **哈夫曼左右对调，WPL 不变，编码会变。** 这里固定左 0，才能和 2018 的 A 对齐。
12. **平均码长的分母是频次之和。** 2023 是 90/36 = 2.5，不是 16/6。
13. **同一子网 ARP 不问网关。** 下一跳就是 `10.0.0.2`。
14. **一个小网页是 2 个 RTT。** 挥手不计入。
15. **init 是 1，idle 是 0。** 当前进程号是 1，不表示没有闲逛进程。

## 概念卡片参考

- shell 是用户态解释器。它 `fork` 出子进程，`exec` 装入程序，`wait` 收尸。管道和重定向是它在调用前接好的，不是新的处理器指令。
- 宿主用户程序只能经系统调用进内核。`grep`、`sort`、`zip` 重，放在宿主里是为了直接用已经写好的 C 函数；文件内容仍从根卷读出、写回。
- KMP 失配时主串下标不动，模式串退到 next。从 0 起时哨兵是 −1，从 1 起时哨兵是 0，比较次数相同。
- 外部排序的时间主要是内外存交换。增大 k 或用置换-选择减少段数，才能减少趟数。败者树只把选出最小值的比较降到 `⌈log2 k⌉`。
- 哈夫曼树没有度为 1 的结点，n 片叶子共 `2n−1` 个结点。WPL 等于内部结点权值之和。前缀码才能唯一译码。
- 开机顺序是引导块、内核、根文件系统、第一个用户进程。闲逛进程在没有就绪进程时占用 CPU。
- 一次 `curl` 要穿过系统调用、TCP 握手、ARP、帧、DMA 和网卡中断。IRQ2 是这台机器上网卡收帧用的中断号。
