## 11 · 网络层：IP、ARP、NAT 与路由
- **产出**：IPv4 协议栈（首部、校验和、分片与重组、ICMP）；ARP 缓存；路由器节点（多网卡、最长前缀匹配转发表）；NAT 节点；RIP 与 OSPF；DHCP
- **小步骤**：① IP 首部与校验和（复用 `net/01` 的校验和）；按子网划分给每个接口配地址和前缀 ② 转发：最长前缀匹配、TTL 减 1、重算校验和，TTL 为 0 时发 ICMP 超时；用它实现 `ping` 和 `traceroute` ③ ARP：缓存、广播请求、单播响应；跨子网时找下一跳的 MAC ④ 分片与重组：两段 MTU 不同的链路，片偏移以 8 字节为单位，MF 标志 ⑤ 路由协议：RIP 定期交换距离向量（16 表示不可达，断链后看到坏消息传得慢）；OSPF 洪泛链路状态后用 `lib/13` 的 Dijkstra 算路由表 ⑥ NAT 与 DHCP：内网机器经 NAT 路由器访问外网，trace 打印 NAPT 转换表；新机器开机用 DHCP 四步拿到地址
- **通过标准**：子网划分与路由聚合；给定目的地址的下一跳；转发后首部哪些字段改变；分片后各片的长度和偏移；RIP 收到邻居路由表后的更新结果；NAT 转换后的地址和端口
- **选开（考纲内）**：BGP 路径向量（两个 AS 之间）；用 SDN 控制器节点集中算路径并下发流表；IPv6 双栈与地址压缩；组播与组播 MAC 映射；移动 IP 的隧道转发
- **前置关卡**：`net/07-ipv4`、`net/08-forwarding-nat`、`net/09-routing-sdn`、`net/10-bgp-multicast-mip`、`lib/13-graph-app`；阶段 10
