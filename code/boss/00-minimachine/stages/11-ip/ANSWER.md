## 思路

IPv4 地址高 n 位是前缀。网络地址是地址和掩码按位与，广播地址把主机号设成全 1。可分配的是中间那些。`/32` 没有主机位，整份地址就是一台主机。`/31` 只剩全 0 和全 1，408 算可分配 0 个。分类看第一字节，不看前缀。私有地址只有 10/8、172.16/12、192.168/16。172.32 已经出了 /12。

定长划分把主机位再切出子网号。2010 从 /24 收到 /29，子网号 5 位，子网 32 个，每个 6 个。CIDR 不扣全 0、全 1 的子网号。变长划分每次把剩下的一半划出去，2019 的五块最小到 /24，可分配 254。再切一刀就变成 6 块，不再是题目要的 5 块。

聚合找能盖住所有块的最长前缀，再把主机位清 0。2018 四个第三字节的高 3 位相同，加上前面的 16 位是 /19，起点仍是 35.230.32.0。10.0.0.0/24 和 10.0.2.0/24 聚成 /22 时，中间的两块也被盖住，`full=0`。2021 看的是盖住已知块和候选块之后，还剩的洞能不能正好凑成 3 块。`192.168.9.0/26` 和 `128/26` 的最小覆盖是 /24，里面是 4 个 /26，变不成 3 块。

分片在出口，重组在目的主机。MTU 800、首部 20，780 不是 8 的倍数，收成 776。1580 字节的数据报有 1560 字节数据，要 3 片，第 2 片总长度 796、MF 为 1。1500 字节只够 2 片，第 2 片 MF 为 0。DF 为 1 时返回 -2，不切。

转发表留下最长的匹配。默认路由长度是 0，任何更长的前缀都盖过它。2013 的 `194.17.20.200` 既在 /23 里也在 /25 里，走 E0。相等长度不换先写入的那条。

转发先查表。没有匹配就丢，ICMP 类型 3、代码 0。查到了才把 TTL 减 1。减完是 0，不再送，类型 11、代码 0。校验和只盖住首部，字段变了就整份重算。只减 TTL、而且没有进位折回时，校验和正好加 `0x0100`，`66de` 变成 `67de`。2011 还改了源地址，不能靠这一下，重算的结果是 `65e8`。改过的字段用前后两个首部逐段比较，不把答案写死。

ARP 填的是这一跳的 MAC。2011 的目的不在 `10.2.128.0/24`，解析网关 `10.2.128.1`。请求还不知道对方的 MAC，以太网目的是全 1。响应是单播，网关 MAC 是 `00-21-27-21-51-ee`。2024 的 `192.168.3.129` 在 VLAN 3，广播过不去。

基本 NAT 只换 IP。2016 的 `/30` 里 R1 占了 `.9`，R2 是 `.10`，端口 49152 留着。NAPT 的键是地址加端口。第二台主机也用 4000 时，公网这一侧改成 4001，否则回来的分组分不清。2020 是两台路由器各做一次：R3 换源，R2 按静态表换目的。

RIP 先把邻居报的距离加 1，封顶 16。原来的下一跳就是这个邻居，新距离无论好坏都收。别人的路由只有严格更短才换。2016 里 R3 报 16，R1 上次留下的 2 加 1 是 3，所以是 3 而不是 16，也不是原来的 2。坏消息按王道的交替表：不开水平分割 15 轮，开了 2 轮。2024 是同步交换，t=0 就是第一次。`210.2.4.0/24` 接在 R16，60 秒后 R11 才拿到，两条一样长时留下编号更小的 R12。AS4 可能超过 20 台，RIP 到 16 就停，所以内部用 OSPF。15 台路由器把 TTL 减 15 次，发出时至少写 16。

OSPF 用 `lib/13` 的 `dijkstra_run`。`pre[v]` 是父亲。从子网往回走到父亲就是 R1，停住的那台才是下一跳。R1 到 R4 走 R2 是 7，走 R3 是 8，7 更小。四个子网的费用是 1、3、4、8。默认路由写进 LSI，不改这四条更长的前缀。

DHCP 必须按发现、提供、请求、确认。跳过发现直接请求会被拒绝。四步走完才把 `192.168.1.10` 交出去。

`stack` 里主机 `10.0.0.2/24` 访问 `10.1.0.2`。ARP 找的是网关 `10.0.0.1`，不是对端。路由器把 TTL 从 64 减到 63，接口是 E1。1500 字节的数据报在 MTU 800 上切成偏移 0 和 97。去 `8.8.8.8` 没有路由。TTL 为 1 的探测回类型 11。两台内网主机共用 `203.0.113.10` 时，端口是 4000 和 4001。

选开的部分沿用已经核对过的结论。BGP 看见自己的 AS 号就丢。无策略时先比 AS 个数，再比本 AS 内到出口的距离，所以 R14 选 R11、R15 选 R13。IPv6 只压最长的连续 0，一样长压最左边，单独一个 0 写成 `0`。组播 MAC 是 `01-00-5e` 接低 23 位，丢掉 5 位，32 个 IP 共用一个 MAC。移动 IP 的外层目的是转交地址，协议号 4，校验和 `12b9`，减一跳变成 `13b9`。SDN 断掉 S0—S2 之后，下一跳从 S2 改成 S1。数据平面只读已经写下的下一跳，断链本身不算路。

## 对应关卡与差异

| 关卡 | 整机里怎么用 | 差异 |
|---|---|---|
| `net/01` | `ip_header_checksum` | 只拿校验和，不链接那一关的分组构造 |
| `net/07` | 编址、聚合、分片、2012 的五个数 | 输出收成一行。捕获用字段表重算，不重放原始字节 |
| `net/08` | 最长前缀、NAT、ARP、IPv6 | 命令不叫 `map`，那个词是阶段 04 的装页 |
| `net/09` | RIP 的三条规则和 OSPF 的下一跳 | Dijkstra 直接调 `lib/13`。坏消息仍是交替表，2024 仍是同步回合 |
| `net/10` | BGP、组播、移动 IP | 隧道自己组 20 字节外层首部，不再套 `packet_build` 的以太网帧 |
| `lib/13` | `graph_add` 和 `dijkstra_run` | 相等费用不换前驱，和那一关的 `<` 一样 |

## 易错点

1. **片内数据先收到 8 的倍数。** 800−20=780，要用 776。1580 这题会多出第 3 片。
2. **总长度含首部。** 第 2 片是 796，不是 776，也不是 MTU 800。
3. **片偏移的单位是 8 字节。** 776 字节目的偏移是 97。
4. **可分配要减 2。** /29 是 6，/25 是 126。/30 能收广播的主机是 2。
5. **子网号全 0、全 1 都算。** 2010 是 32 和 6，不是 30。
6. **聚合要把主机位清 0。** 四个 /21 的共同前缀是 19 位，起点仍是 35.230.32.0。
7. **同时匹配时留下最长的。** 2013 走 E0，不走先写入的 /23。
8. **默认路由长度是 0。** `8.8.8.8` 只有它匹配，才用 `202.118.2.2`。
9. **到达时的 TTL 要把路径上每一台都减掉。** 2014 是 64−3=61。
10. **只减 TTL 时，校验和加 `0x0100`。** 源地址也改了就必须整份重算。2011 不是 `bb9d`，是 `65e8`。
11. **ARP 解析下一跳。** 2011 找的是网关。请求是广播，响应是单播。
12. **别的 VLAN 进不了 ARP 表。** 2024 的 D 在 VLAN 3。
13. **原下一跳的新距离无论好坏都收。** 2016 是 3，不是 16，也不是 2。
14. **坏消息是 15 轮和 2 轮。** 2024 的 60 秒从 t=0 起，不要再加一个周期变成 90。
15. **`pre[v]` 是父亲。** 下一跳是离开源的第一台。
16. **公网地址加端口不能重复。** 第二台主机的 4000 要让成 4001。2020 的发布地址是 `203.10.2.2:80`。
17. **`::` 只压至少两段的 0。** 一样长时压最左边。`2001::ffff:0:0:1:2` 不能把后面那段 0 压掉。
18. **组播丢掉的是 5 位。** 224.128.1.1 和 224.0.1.1 是同一个 MAC。

## 概念卡片参考

- 网络层负责异构网络互连。路由是控制平面算出来的，转发是数据平面按最长前缀把分组送出去。
- ICMP 装在 IP 里，协议号 1。本阶段实际产生的是类型 3 和类型 11。回显请求是类型 8，应答是类型 0。
- DHCP 用 UDP。服务器端口 67，客户端口 68。发现报文是广播，过不了路由器。
- RIP 是距离向量，直接装进 UDP 端口 520。OSPF 是链路状态，直接装进 IP，协议号 89。BGP 是路径向量，直接装进 TCP 端口 179。
- 直连按王道记 1。16 是不可达，不是 16 跳。
- IPv6 地址是 128 位，是 IPv4 的 2^96 倍。基本首部固定 40 字节，没有首部校验和。Hop Limit 就是原来的 TTL。
- 移动 IP 的归属地址不变。去程由归属代理做 IP-in-IP，外层目的是转交地址。回程用归属地址直接回去，这就是三角路由。
