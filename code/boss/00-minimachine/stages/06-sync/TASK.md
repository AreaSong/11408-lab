## 06 · 同步、互斥与死锁
- **产出**：`TSL`、`XCHG` 自旋锁；信号量系统调用（`sem_create`、`sem_p`、`sem_v`，等待队列在内核）；MM32 用户程序写的经典 PV 问题；银行家算法准入；资源分配图找环的死锁检测与解除
- **小步骤**：① 竞态重现：两个进程对共享页里的计数器各加 N 次，时钟中断随机打断，结果出错 ② 硬件方法：用 `TSL`、`XCHG` 写自旋锁；内核里用关中断保护临界区 ③ 信号量：P 把进程挂进等待队列并阻塞，V 唤醒；打印信号量的值与等待进程数的关系 ④ 经典问题：生产者-消费者、读者-写者、哲学家进餐，用 MM32 程序写各进程；故意把互斥 P 放到同步 P 前面，观察死锁 ⑤ 银行家：进程启动时声明最大需求，每次申请做安全性检查，trace 打印 Work 和 Finish ⑥ 死锁检测与解除：资源分配图化简找环，按撤销代价最小的进程回收资源
- **通过标准**：PV 大题：写出信号量定义（含初值）和各进程的 P/V 代码，在机器上跑通、不死锁、结果正确；当前状态是否安全、安全序列、某个请求能否立即满足；不发生死锁所需的最少资源数
- **选做拓展**：优先级反转与优先级继承；Peterson 算法在流水线和多核下为什么需要内存屏障
- **选开（考纲内）**：管程（一把锁加条件变量的系统调用，`os/06` 第 ⑥ 步已练）
- **前置关卡**：`os/06-mutex`、`os/07-pv-classic`、`os/08-deadlock-banker`、`lib/12-graph-basic`；阶段 05
- **备注**：`lib/12` 与 `lib/13` 都有 `graph.c`，`deps/` 平铺时会互相覆盖，所以本阶段不链接 `lib/12` 的代码，找环按它的思路在资源分配图上重写
