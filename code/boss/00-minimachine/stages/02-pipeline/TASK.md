## 02 · 五段流水线
- **产出**：流水线执行模式：IF、ID、EX、MEM、WB 五段，打印时空图；检测三种冒险，转发、阻塞、冲刷；统计总周期、CPI、MIPS；同一程序在节拍模式和流水线模式下的最终状态一致
- **小步骤**：① 段间寄存器与理想流水：无相关的指令序列，验证总周期 = k + n − 1 ② 数据冒险：检测 RAW，不转发时按「前半拍写、后半拍读」阻塞 ③ 转发，以及转发消不掉的 load-use ④ 控制冒险：预测不转移、EX 段判定、猜错冲刷；可切换为阻塞到 MEM 结束 ⑤ 结构冒险与精确异常：打开「统一存储器」开关观察 MEM 与 IF 相撞；流水线里的缺页、除法错、系统调用按程序顺序处理，后续指令冲刷 ⑥ 对比：同一程序在两种模式下的周期数，算加速比、吞吐率、效率，按给定主频算执行时间和 MIPS（`co/00` 的公式）
- **通过标准**：时空图；哪些指令之间有数据相关、各阻塞几拍、总共多少个时钟周期；把 `co/11` 的真题指令序列改写成 MM32 汇编后，周期数与标准答案一致；CPI、MIPS、加速比的计算
- **选做拓展**：延迟槽；2 位饱和计数器的动态分支预测，比较预测准确率
- **选开（考纲内）**：双发射超标量，观察 CPI 小于 1（`co/11` 卡片、`co/12` 已练）
- **前置关卡**：`co/00-performance`、`co/11-pipeline`；阶段 01
