## 08 · 文件系统与磁盘
- **产出**：用宿主文件当磁盘镜像的磁盘（柱面、磁头、扇区几何与访问时间）；两种文件系统格式：inode 混合索引与 FAT；树形目录、硬链接与软链接、权限位；位示图与成组链接管理空闲块；系统打开文件表与进程打开文件表；VFS 函数指针表；六种磁盘调度；固态盘的 FTL 与磨损均衡
- **小步骤**：① 磁盘模型：块号与（柱面，磁头，扇区）互换，寻道 + 旋转延迟 + 传输时间；请求队列和 FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK ② 格式化：引导块、超级块、空闲空间管理（位示图的行列换算、成组链接的分配与回收）、inode 区、数据区 ③ inode 混合索引（直接、一级间接、二级间接）：最大文件长度，读第 k 个字节要访问几次磁盘 ④ 目录与保护：目录项、路径解析、硬链接计数、软链接；r、w、x 权限检查；大目录用 `lib/15` 的 B+ 树按文件名的散列值建索引；`open` 之后读写不再查目录 ⑤ FAT 与 VFS：同一套 `open`、`read`、`write` 接两个格式；把 FAT 盘挂载到 inode 盘的 `/mnt` 下 ⑥ 固态盘：按页写、按块擦除、FTL 地址映射、动态磨损均衡，统计各块擦除次数
- **通过标准**：最大文件长度、读取某位置要访问几次磁盘；位示图与盘块号换算；成组链接分配后的空闲块状态；某调度算法的磁头移动总道数和访问时间；硬链接与软链接删除后的效果
- **选做拓展**：写前日志与崩溃恢复；磁盘缓存与延迟写
- **选开（考纲内）**：RAID 作为可选的磁盘组织方式：用多块虚拟盘组成 RAID0、RAID1、RAID5，打印条带、镜像、奇偶校验的块布局，计算可用容量与可靠性（口径以王道计组的磁盘阵列为准；RAID 没有在任何关卡里练过，这里是首次练习）
