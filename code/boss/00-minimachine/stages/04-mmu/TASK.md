## 04 · TLB 与两级页表
- **产出**：MMU：TLB（全相联或组相联）加两级页表（10/10/12）的硬件遍历，硬件维护 A、D 位；缺页、越权故障进内核；地址翻译 trace：虚拟地址拆分 → TLB → 页目录项 → 页表项 → 物理地址 → Cache → 主存，每一步打印地址和命中情况
- **小步骤**：① 虚拟地址拆分与页表项格式（`ISA.md` 第 7 节） ② 页表遍历：页目录项地址 = PTBR + DIR × 4，页表项地址 = 页表始址 + PAGE × 4 ③ TLB：查找、装入、替换，进程切换后 `TLBFLUSH` ④ 权限检查与故障：P = 0 产生缺页，W、U 不符产生越权，写 BADVA，EPC 存本条，处理完重新执行（此时内核先用「装入时全部映射好」的最简做法） ⑤ 有效访问时间：区分 TLB 命中、页表命中、缺页三条路径，统计 EAT（`os/10` 第 ④ 步） ⑥ 复现综合题：内核按题目给的页表内容建表，用户程序访问题中的地址，trace 与标准答案逐步对照
- **通过标准**：给定虚拟地址、页表和 TLB 内容，求物理地址以及是否命中 TLB、Cache、是否缺页；页表项的地址；页表共占多少页、顶级页表不超过一页；EAT
- **选做拓展**：带进程标识（ASID）的 TLB，切换进程不必全刷；4 MB 大页（10/22 划分）；反置页表
- **选开（考纲内）**：段式与段页式翻译模式（`os/10` 第 ⑤ 步已练）
