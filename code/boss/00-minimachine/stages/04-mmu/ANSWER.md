## 思路

PSW.PG = 0，或者根本没装 MMU 时，虚拟地址就是物理地址。阶段 02 的精确异常测试只把 PG 置 1，没有装 MMU。那条数据访问仍直接报缺页，取指仍走物理地址，所以旧测试不用改。装上 MMU 并且 PG = 1 之后，取指和数据访问都翻译。向量表仍按物理地址读，`dmem` / `setw` 也仍是物理地址。

翻译顺序和 `co/07`、ISA 第 7 节一样：先查 TLB。命中就拿页框号，不再读主存里的页表。缺失时用物理地址读页目录项，P = 1 再读页表项。这两次不进 TLB，也不进 Cache，避免页表把数据 Cache 的快照弄脏。P = 1 才把这一项装进 TLB，然后用物理地址走阶段 03 的 Cache。查页表多出来的周期加在当前这一拍后面，不另起一行微操作。

页目录放在 PTBR。默认 `00080000H`，后面紧挨着分配二级页表。一页 4 KB，10 位索引正好是 1024 项 × 4 B = 一页，所以顶级页表不会超过一页。表项地址一律是基址 + 下标 × 4。

TLB 不带进程标识。全相联的标记就是 20 位虚页号，组相联的组号是虚页号的低位。空行优先；LRU 命中也刷新，FIFO 只在装入时排队。有效位为 0 的项，标记碰巧相同也不算命中。P = 0 的项不装入快表，缺页要等页表说了才算。`tlbflush` 把全部有效位清掉。改 PTBR 之后硬件不会自动清，内核要自己执行这条指令。命令 `ptbr` 会重建一个空的 TLB。

权限在拿到页框号之后检查。W = 0 时写入是越权，用户态和内核态都算。U = 0 时只有用户态不能访问，内核态可以。检查没过就不改 A、D，也不去碰 Cache。检查过了，硬件把页表项的 A 置 1，写入再把 D 置 1，并写回主存里的那一项。页目录项的 A 本阶段不置。

缺页和越权都是故障：EPC 存本条，BADVA 存出错的虚拟地址，处理完可以从这条重新执行。本阶段还没有请求调页。正常做法是 `map` 或 `ident` 在运行前把要用的页建好。若运行中缺页，而且这条虚拟页登记过 `fix`，内核把它装进页表并返回，`IRET` 之后同一条指令再做一遍。没登记，或者是越权，内核结束进程，不执行 `IRET`，所以停机时 PC 会停在宿主入口，EPC 仍是那条指令。

有效访问时间和 `os/10` 同一口径，快表和内存串行相加。缺页处理时间里已经包含改页表和装入快表，重执行时按快表命中再付一次数据。单级查表 1 次，两级查表 2 次。

## 和关卡的差异

| 关卡 | 整机里怎么用 |
|---|---|
| `co/07` | 一次访存仍是 TLB → 页表 → 物理地址 → Cache。整机的 CPU 固定 4 KB、10/10/12，页表项用 ISA 的 P/W/U/A/D。任意页大小的拆分留给 `geom` |
| `os/10` | 页表页数、顶级不超过一页、表项地址、三条 EAT 用同一套公式。段式和段页式本阶段不做 |

系统调用里的 `read` / `write` 仍按物理地址碰用户缓冲。本阶段用恒等映射时，虚拟地址等于物理地址，所以还能对上。阶段 05 再按当前页表翻译。

## 易错点

- `03FFF180H` 右移 12 位是虚页号 `03FFFH`，不是 `03FFF1H`。`03FFF1H` 是另一项的标记，页框 `0035H`，那是选项 B。有效位为 0 的 `FF180H` 也不能拿来拼地址。
- 2010 年第 29 题问的是页目录项 128。把每一级页表张数加起来是 129，那是另一个数。
- 2013 年第 46 题第（3）问用的是一级页表，下标就是页号 8 和 9。代码页面 2 从 `00901000H` 起，不是第一页的 `00900000H`。
- 2015 年两个地址的高 10 位都是 4，所以只碰一个二级页表。页目录加全部二级页表是 1025 页。
- 缺页时间少算重执行，会得到 100000110，而不是 100000220。两级再多一次页表访问，缺页路径是 100000320。
- 输出固定 8 位十六进制。`00153180H`、`00254362H`、`00101565H` 就是考卷上的 `0153180H`、`254362H`、`101565H`。

## 概念卡片参考

### 卡片一：一次访存的顺序

| 顺序 | 看到什么 | 没命中时 |
|---|---|---|
| 1 | TLB | 接着读页表。有效位为 0 不算命中 |
| 2 | 页目录项、页表项 | P = 0 是缺页，不装入 TLB |
| 3 | 页框号拼页内偏移 | 页内偏移两端一样 |
| 4 | Cache、主存 | Cache 缺失不是异常 |

### 卡片二：页表项

| 位 | 谁写 | 作用 |
|---|---|---|
| P | 操作系统 | 0 则缺页 |
| W | 操作系统 | 0 则写入越权 |
| U | 操作系统 | 0 则用户态不可访问 |
| A | 硬件在访问成功时置 1 | CLOCK |
| D | 硬件在写入成功时置 1 | 换出时要不要写回 |

### 卡片三：有效访问时间

| 路径 | 付什么 |
|---|---|
| 快表命中 | 快表 + 一次内存 |
| 页表命中 | 快表 + 每一级页表 + 一次数据 |
| 缺页 | 上面的查表 + 缺页处理 + 重执行的一次快表命中 |

多级页表让查表次数变多。它不减少页表项总数，也不用来缩短这个平均。

## 回归变更

无。没装 MMU 时，PG = 1 的流水线数据访问仍按阶段 02 直接缺页。`tlbflush` 在没装 MMU 时，节拍明细仍是「阶段00无TLB」。
