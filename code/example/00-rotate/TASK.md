# example/00 · 数组循环左移 · 题目

> 样板关卡：演示一道题的目录结构。本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：`rotate.h` / `rotate.c` 中的函数 `void rotate_left(int *a, int n, int p)`，把数组 `a` 的前 n 个元素原地循环左移 p 位
- **小步骤**：
  ① 先写 `test.c`：用 `test.h` 的 `CHECK_EQ` 写几组「左移前 → 左移后」的检查，此时运行应当失败
  ② 实现 `rotate_left`，让单元测试通过
  ③ 写 `main.c`：按下方「主程序题目」读输入、调用 `rotate_left`、打印结果，让 `tests/` 下的用例全部通过
  ④ 按真题要求写三段式：设计思想、关键代码注释、时间与空间复杂度
- **通过标准**：全部测试通过；时间 O(n)、额外空间 O(1)

每个项目有两个程序：`main.c` 编出的主程序（与项目同名，如 `rotate_first`）和 `test.c` 编出的单元测试（如 `rotate_first_test`）。

## 二、主程序题目

把输入的序列循环左移 p 位后输出。

- **输入**：第一行两个整数 `n p`（1 ≤ n ≤ 10000，0 ≤ p < n）；第二行 n 个整数
- **输出**：一行，左移后的 n 个整数，用一个空格分隔
- **样例**

  输入：
  ```
  5 2
  1 2 3 4 5
  ```
  输出：
  ```
  3 4 5 1 2
  ```

`tests/` 里的每组 `<用例>.in` 都会喂给主程序，输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

## 三、真题题面

### 2010-42（13 分）

设将 n（n > 1）个整数存放到一维数组 R 中。试设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p（0 < p < n）个位置，即将 R 中的数据由 (X₀, X₁, …, Xₙ₋₁) 变换为 (Xₚ, Xₚ₊₁, …, Xₙ₋₁, X₀, X₁, …, Xₚ₋₁)。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
3. 说明你所设计算法的时间复杂度和空间复杂度。

> 程序题目比真题放宽到 n ≥ 1、p ≥ 0，所以测试里多了「不移动」和「只有 1 个元素」两组边界用例。
