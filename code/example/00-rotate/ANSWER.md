## 2010-42 三段式

**1. 设计思想**

把数组看成两段 AB：A 是前 p 个元素，B 是后 n−p 个元素，循环左移 p 位就是把 AB 变成 BA。先把 A 逆置得到 A⁻¹，再把 B 逆置得到 B⁻¹，最后把整个 A⁻¹B⁻¹ 逆置，得到 (A⁻¹B⁻¹)⁻¹ = BA。

**2. 算法实现**：见 `answer/src/rotate.c`，`reverse` 用首尾双指针交换，`rotate_left` 调用三次 `reverse`。

**3. 复杂度**

- 时间：三次逆置分别处理 p/2、(n−p)/2、n/2 次交换，合计约 n 次，O(n)
- 空间：只用一个临时变量，O(1)

## 另一种解法（得分略低）

申请长度为 p 的辅助数组，先把前 p 个存进去，再把后 n−p 个前移，最后把辅助数组接到末尾。时间 O(n)，空间 O(p)。题目要求时间和空间「都尽可能高效」，空间不是 O(1) 的解法拿不到满分，但思路和代码正确仍能拿大部分分数。

## 易错点

1. **三次逆置的区间端点**：A 是 `[0, p-1]`，B 是 `[p, n-1]`。把 A 写成 `[0, p]` 会多吃一个元素。
2. **逆置的顺序可以换，但分界点会变**：先整体逆置得到 B⁻¹A⁻¹，此时前一段长 n−p，所以再分段逆置时分界点是 `n-p` 而不是 `p`。考场上最稳的是「先分段、后整体」，分界点就是 p。
3. **p = 0 或 p = n**：真题保证 0 < p < n，程序题目放宽了，所以要先取模；不取模时 `reverse(a, 0, -1)` 虽然不出错，但读的人要多想一步。
4. **复杂度不要写成 O(p)**：三次逆置总共涉及全部 n 个元素。
