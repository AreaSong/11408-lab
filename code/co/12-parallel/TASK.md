## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每条命令打印一块推导，最后一行以 `结果：` 开头。`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

读命令前用 `prompt("请输入命令（flynn / amdahl / line / simd / mt / 2022-22，Ctrl+D 结束）：")`。读参数前再提示一次。`prompt` 在 `deps/prompt.h`，跑测试时不打印。可以连续输入多条命令，Ctrl+D 结束。参数不合法时向 stderr 报错，并以非 0 退出。

### 公式

- 可并行部分的百分比记为 p（80 表示 80%，不要写成 0.8）。串行部分是 100−p
- 加速比 = 1 / ((1−p) + p/n) = (100×n) / (n×(100−p) + p)。第 00 关的 Amdahl 是「不可改进部分 + 可改进部分 / S」；这里可改进部分分给 n 个核，S 就取 n
- 效率 = 加速比 / n
- 串行部分不是 0 时，n 趋于无穷，加速比趋于 1/(1−p) = 100 / (100−p)。串行部分为 0 时没有这个上界
- 分数先写出代入后的分子和分母，再约成最简。分母为 1 时，结果行只写整数
- 缓存行号 = 地址 / 行大小，行内偏移 = 地址 % 行大小。地址相同是真共享；地址不同但行号相同是伪共享；行号不同则不共享这一行
- SIMD 通道数 = 向量位数 / 元素位数，必须整除。向量指令条数 = ceil(元素个数 / 通道数)。理想加速比 = 元素个数 / 向量指令条数。加速比小于通道数时，要写明最后一条有空通道

### 命令

| 命令 | 输入 | 结果行 |
|---|---|---|
| `flynn map` | 无 | `结果：SISD 对应步骤 1，SIMD 对应步骤 4，MISD 无实验，MIMD 对应步骤 2` |
| `flynn sisd` 等 | `sisd` / `simd` / `misd` / `mimd`，不区分大小写 | `结果：SISD` 或对应的大写名字 |
| `amdahl` | 百分比，以及核数或 `table` | 单个核数：`结果：加速比 …，效率 …，极限 …`。`table` 固定打 1、2、4、8 个核，`结果：1 核 …；2 核 …；4 核 …；8 核 …` |
| `line` | 行大小、地址 A、地址 B。十进制或 `0x` 十六进制，输出里的地址用十进制 | `结果：伪共享` / `结果：真共享` / `结果：不共享` |
| `simd` | 向量位数、元素位数、元素个数 | `结果：通道 …，向量指令 … 条，理想加速比 …` |
| `mt fine` 等 | `fine` / `coarse` / `smt` | `结果：细粒度` / `结果：粗粒度` / `结果：同时多线程` |
| `2022-22` | 无 | `结果：答案` 加选项字母 |

`flynn map` 要写明：步骤 ① 是 SISD，步骤 ④ 是 SIMD，步骤 ② 是 MIMD，MISD 没有实验。四个独立累加器仍是 SISD，不是 SIMD。向量处理器属于 SIMD，多核处理器属于 MIMD。步骤 ③ 的伪共享不是新的一类。

`mt` 各打 4 个周期。细粒度每个时钟周期换一个线程。粗粒度连续执行，遇到 Cache 缺失才清空流水线并切换。同时多线程在同一周期发射两个线程的指令，并且写明它要有超标量的发射槽、不要求有多个核。

百分比不在 0 到 100、核数不是 1 到 4096 的整数也不是 `table`、缓存行大小为 0、向量位数不能被元素位数整除、元素个数不为正、类别认不出，都要报错退出。

### 样例

输入：

```
amdahl 80 4
```

输出：

```
【Amdahl · 多核加速比】
可并行部分 p = 80%
串行部分 1-p = 20%
处理器个数 n = 4 个
第 00 关：新时间 = 不可改进部分 + 可改进部分 / S。这里可改进部分分给 n 个核，S 就取 n
加速比 = 1 / ((1-p) + p/n) = (100×n) / (n×(100-p) + p) = 400/160 = 5/2
效率 E = 加速比 / n = 5/8
n 趋于无穷时，加速比趋于 1/(1-p) = 100/20 = 5
结果：加速比 5/2，效率 5/8，极限 5
```

`amdahl 80 table` 的结果行是 `结果：1 核 1；2 核 5/3；4 核 5/2；8 核 10/3`。串行部分为 0 时，极限写成 `无穷`。

输入：

```
line 128 0 4
```

输出：

```
【缓存行 · 两个地址会不会互相踢】
缓存行 = 128 B
地址 A = 0，行号 = 0，行内偏移 = 0 B
地址 B = 4，行号 = 0，行内偏移 = 4 B
地址不同，行号相同。一致性维护的单位是整行，另一个核上相邻的数据也会被赶出去
程序并没有共享同一个变量，硬件却按共享了一整行来处理，这就是伪共享
结果：伪共享
```

地址相同时，改为「两个地址相同。两个核写的是同一个变量，这是真共享」，结果行是 `结果：真共享`。行号不同时，改为「行号不同。各写各的缓存行，不会因为对方的写而失效」，结果行是 `结果：不共享`。

`simd 128 32 6` 的结果行是 `结果：通道 4，向量指令 2 条，理想加速比 3`，并且要有一句「6 不是 4 的倍数，最后一条向量指令有空通道，加速比小于通道数」。能整除时不要这句。两种情况都要写：实验 ④ 的 NEON float 加法就是 128 bit 向量、32 bit 元素、4 个通道。

## 三、实验程序（`bench.c`）

不读输入，直接跑完四步，打印本机型号、性能核个数、能效核个数和缓存行。时间用 `CLOCK_MONOTONIC` 的墙钟，每种测 3 次取中位数。不要用各线程 CPU 时间相加，那会把多核的同时执行加回成 1 倍。

① 4194304 个 double，元素都是 1。相关链是一个累乘；独立运算是四个累乘，下标每次加 4；数组那组是 `b[i] = a[i] * 1.0000001 + 1`。每种重复 4 遍。这三组都关掉自动向量化和循环展开。打印三段时间和「相关链 / 四累加器」。

② 2097152 个元素，每个元素做 32 次乘加，再重复 4 遍，拆成 1、2、4、8 个线程。线程用用户交互优先级。加速比 = 1 线程的时间 / 这一行的时间。各线程算出的 `b[0]` 要相同。旁边用计算器里的公式打出 p = 100% 和 p = 90% 时 8 核的加速比。

③ 两个线程各把自己的 `int` 加 4194304 次。一次两个 `int` 相距 4 字节，一次相距 128 字节。用宽松次序的原子加，避免数据竞争；独占缓存行的权限仍然会抢。按本机缓存行判断是伪共享还是不共享，并打印相邻时间 / 间隔时间。两个计数都应该等于 4194304。

④ 1048576 个 float，每个做 32 次乘加，重复 4 遍。标量循环关掉自动向量化。NEON 用 128 位寄存器，一次处理 4 个 float。两边的校验要一致。打印标量时间 / NEON 时间。

纳秒数不进 `tests/`。本机一次运行的记录在 `EXPERIMENTS.md`。
