# code/co/ · 计算机组成原理

> 在 MiniMachine 中的角色：**地基**，即数据怎么表示、CPU 怎么执行指令、存储怎么分层。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节。

## 本科目约定
- **默认「🟢 先学会模式 · 两段式推进」优先（见 [TEACHING.md](../TEACHING.md)）**：
  - **第一段（日常闯关 = 只学单一机制）**：每关只搞懂单一核心硬件机制、拿 1 组简单数字手推状态表/算式，再写 `src/` 下最简写的核心计算或状态转移函数并用 `test.c` 断言验证 + 1 次总反讲即标 `✅ 基础已通` 过关；**`TASK.md` 中的 `trace` 打印格式、`main.c` 命令行壳子及跨关综合真题留到板块节点或「🔵 规范化代码模式」**
  - **第二段（板块刷题节点）**：每学完 1 个大板块（见下方进度表中的 `🎯 板块节点` 分隔行），停下来集中手推本板块的 408 历年选择题与综合大题
- **计算器**：手推与推导时**每个数值都带物理单位**
- **模拟器 + trace（仅「🔵 规范化代码模式」要求打印格式）**：在默认「🟢 先学会模式」下只需手推过程表并写核心状态转移函数验证结果；切换到规范化模式时再逐步打印 `trace` 跑 `ctest`
- 看 x86 汇编（真题用 32 位 Intel 语法，此命令只生成汇编、不能链接运行）：`clang -target i386-pc-linux-gnu -m32 -O0 -masm=intel -fno-pic -fno-asynchronous-unwind-tables -S demo.c -o demo.s`

## 考纲约定与易错点（AI 引导时重点核对）
- 性能计算中 K/M/G 是 10³/10⁶/10⁹；存储容量中 K/M/G 是 2¹⁰/2²⁰/2³⁰
- 主存按字节编址还是按字编址，题目必须先确认
- Cache 地址划分：标记 | 组号 | 块内偏移；**总容量要区分是否计入标记位、有效位、脏位、替换控制位**
- IEEE 754 单精度：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数，隐含最高位 1；阶码全 0、全 1 为特殊值
- CF 针对无符号数溢出，OF 针对有符号数溢出；减法时 CF 的含义是借位
- C 语言中 `int` 与 `unsigned` 混合运算时，`int` 先被转换为 `unsigned`
- 相对寻址的有效地址 =（PC 自增后的值）+ 偏移量
- 外部中断在每条指令执行结束时才被检测和响应；DMA 请求在每个存取周期结束时响应
- 所有算式带物理单位
