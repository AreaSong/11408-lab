## 考纲约定与易错点（AI 引导时重点核对）
- Cache 地址划分：标记 | 组号 | 块内偏移；**容量计算要区分是否计入标记位、有效位、脏位**
- 主存按字节编址还是按字编址，题目必须先确认
- IEEE 754 单精度：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数，隐含最高位 1
- 所有算式带物理单位
