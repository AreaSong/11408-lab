## 考纲约定与易错点（AI 引导时重点核对）
- 性能计算中 K/M/G 是 10³/10⁶/10⁹；存储容量中 K/M/G 是 2¹⁰/2²⁰/2³⁰
- 主存按字节编址还是按字编址，题目必须先确认
- Cache 地址划分：标记 | 组号 | 块内偏移；**总容量要区分是否计入标记位、有效位、脏位、替换控制位**
- IEEE 754 单精度：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数，隐含最高位 1；阶码全 0、全 1 为特殊值
- CF 针对无符号数溢出，OF 针对有符号数溢出；减法时 CF 的含义是借位
- C 语言中 `int` 与 `unsigned` 混合运算时，`int` 先被转换为 `unsigned`
- 相对寻址的有效地址 =（PC 自增后的值）+ 偏移量
- 外部中断在每条指令执行结束时才被检测和响应；DMA 请求在每个存取周期结束时响应
- 所有算式带物理单位
