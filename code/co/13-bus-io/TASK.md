## 一、本关任务

- **产出**：总线带宽计算器；一次总线事务的时间；三种 I/O 方式下 CPU 用于 I/O 的时间占比；多重中断执行序列（含屏蔽字）；中断响应 / 处理与 DMA 三段的过程；同步定时和异步握手的状态
- **小步骤**：
  ① 总线带宽，以及突发传送下一次总线事务的时间
  ② 程序查询、程序中断、DMA 三种方式下，CPU 用于 I/O 的时间占比
  ③ 中断响应过程与中断处理过程：中断隐指令做什么，中断服务程序做什么
  ④ 多重中断：根据屏蔽字 trace 打印 CPU 的执行序列
  ⑤ DMA 传送过程：预处理、数据传送、后处理
  ⑥ 同步定时与异步全互锁握手：主设备、从设备各发什么信号、何时等待
- **通过标准**：能算出总线带宽；能算出 DMA 方式下 CPU 用于 I/O 的时间百分比；给定屏蔽字后能说出中断服务程序的完成次序
- **概念卡片**（写进 `NOTES.md`）：总线的组成与分类；I/O 接口的功能和基本结构；I/O 端口的统一编址 vs 独立编址；程序中断 vs DMA

本关有两个程序：`main.c` 编出的主程序（如 `bus_io_answer`）和 `test.c` 编出的单元测试（`bus_io_answer_test`）。

### 单位

- 频率：`Hz`、`kHz`、`MHz`、`GHz`。这里 M = 10⁶
- 时间：`s`、`ms`、`us`、`ns`。`us` 就是微秒
- 传输率：`B/s`、`KB/s`、`MB/s`、`GB/s`。这里 M = 10⁶。`0.5 MB/s` 是 500000 B/s，不是 0.5×2²⁰
- 位宽、字节数、时钟个数、指令数都写数字，不要再带单位

### 命令

题目给的频率是哪一种，决定 `bw` 里「时钟数」和「传送次数」怎么填：

| 题目里的频率 | 时钟数 | 传送次数 |
|---|---|---|
| 时钟频率，每个时钟传 k 次 | 1 | k |
| 时钟频率，m 个时钟才传 1 次 | m | 1 |
| 工作频率、MT/s，或 DDR 这种型号名 | 1 | 1 |

宽度只算数据位。校验位不算。两个方向同时传时双工倍数填 2，否则填 1。

| 命令 | 输入 | 结果行 |
|---|---|---|
| `bw` | 频率 单位 时钟数 传送次数 位宽 双工 通道 | 带宽 |
| `txn burst` | 频率 单位 地址时钟 等待时钟 数据时钟 准备 单位 位宽 字节 | 这一次事务的时间 |
| `txn each` | 频率 单位 次数 地址时钟 等待时钟 数据时钟 准备 单位 位宽 字节 | 全部次数加起来的时间 |
| `poll` | 主频 单位 每次时钟周期 每秒查询次数 | CPU 占比。次数题目已经给了 |
| `query` | 主频 单位 CPI 指令数 传输率 单位 每次字节 | 查询间隔和 CPU 占比 |
| `intr` | 主频 单位 CPI 服务指令数 其他指令数 传输率 单位 每次字节 | 中断方式的 CPU 占比 |
| `fit` | 主频 单位 一次中断的时钟周期 传输率 单位 每次字节 | `可以` 或 `不能` |
| `dma` | 主频 单位 预处理加后处理的时钟周期 传输率 单位 块字节 | DMA 方式的 CPU 占比 |
| `serial` | 起始位 数据位 校验位 停止位 间隔 单位 | 一帧多少位，每秒多少个字符 |
| `task` | 主频 单位 CPI 准备时间 单位 响应周期 服务指令数 第几条启动 字符数 | 任务的时钟周期，以及 CPU 真正占用的时钟周期 |
| `steal` | 字节数 缓冲区位数 | DMA 向 CPU 发了多少次总线请求 |
| `mask` | 个数；一行位序；一行从高到低的处理优先级 | 每个中断源的屏蔽字 |
| `nest` | 个数 服务时间；每个源一行「名字 响应优先级 屏蔽字」；若干「时刻 名字」；最后一行 `.` | 完成次序 |
| `flow` | `multi`、`single` 或 `dma` | 过程的最后一句结论 |
| `wire` | `sync`、`full`、`half` 或 `loose` | 定时方式的名字 |

`nest` 的时间单位自定，程序只比较先后和长短。屏蔽字从左到右对应上面各源的输入顺序，`1` 表示屏蔽。响应优先级的数字越小越先响应。请求一直保持到被响应。服务时间要是正数，请求时刻不能倒退。

频率、次数、位宽不合法，或单位不认识，都向 stderr 报错并以非 0 退出。

### 样例

输入：

```
bw 66 MHz 1 2 32 1 1
```

输出：

```
【总线带宽】
时钟频率 = 66000000 Hz = 66 MHz = 0.066 GHz
每 1 个时钟周期传送 2 次数据，工作频率 = 132000000 Hz = 132 MHz = 0.132 GHz
总线宽度 = 32 位 = 4 B，双工倍数 = 1，通道数 = 1
带宽 = 工作频率 × 一次的字节数 × 双工倍数 × 通道数 = 528000000 B/s = 528 MB/s
带宽只算数据阶段。地址、裁决和等待不计入，所以它是最大传输率
（带宽里的 M、G 是 10^6、10^9，不是存储容量的 2^20、2^30）
结果：528 MB/s
```
