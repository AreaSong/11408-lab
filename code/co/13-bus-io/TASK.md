### 13 · 总线与 I/O 方式
- **产出**：总线带宽计算器；I/O 方式 CPU 占用率计算器（程序查询、中断、DMA）；多重中断执行顺序模拟器（含屏蔽字）；总线定时握手 trace
- **小步骤**：① 总线带宽，以及突发传送下一次总线事务的时间 ② 三种 I/O 方式下 CPU 用于 I/O 的时间占比 ③ 中断响应过程与中断处理过程（中断隐指令做什么、中断服务程序做什么） ④ 多重中断：根据屏蔽字 trace 打印 CPU 的执行序列 ⑤ DMA 传送过程：预处理、数据传送、后处理 ⑥ 同步定时与异步全互锁握手的状态 trace（主设备、从设备各发什么信号、何时等待）
- **通过标准**：真题考法：DMA 方式下 CPU 用于 I/O 的时间百分比、给定屏蔽字后中断服务程序的执行顺序、总线带宽
- **概念卡片**：总线的组成与分类；I/O 接口的功能和基本结构；I/O 端口的统一编址 vs 独立编址；程序中断 vs DMA
