## 思路

一个规格化数写成 `(-1)^s × 1.M × 2^e`。单精度把 `e+127` 放进 8 位阶码，M 的小数部分放进 23 位尾数。最高位的 1 一定在，就不存了，这叫隐含 1（隐藏位）。

阶码全 0、全 1 不表示普通真阶。所以规格化真阶只到 -126～127，偏置取 127，不是普通 8 位移码的 128。

| 阶码 | 尾数 | 含义 | 真值 |
|---|---|---|---|
| 0 | 0 | ±0 | 符号位决定 +0 还是 -0 |
| 0 | 非 0 | 非规格化 | ±0.M × 2^(-126)，没有隐含 1 |
| 1～254 | 任意 | 规格化 | ±1.M × 2^(阶码-127) |
| 255 | 0 | ±无穷 | 上溢用它，不用最大规格化数去凑 |
| 255 | 非 0 | NaN | 不是实数 |

非规格化的真阶是 -126，不是 -127。阶码字段虽然是 0，按规格化公式 `0-127` 去减就会错。最小正规格化数是阶码 1、尾数 0，即 `1.0×2^(-126)`，机器数 `00800000H`。再小一档就是非规格化，最小正数是 `2^(-149)`。

### 编码

先取符号。绝对值换成二进制，写成 `1.M × 2^e`。阶码 = e+127。M 的小数点右边留 23 位，再往右的第一位是舍入位，后面所有位并成粘滞位。

向偶数舍入：

| 舍入位 | 粘滞位 | 留下的最低位 | 动作 |
|---|---|---|---|
| 0 | 任意 | 任意 | 不到一半，不进 |
| 1 | 1 | 任意 | 超过一半，进 1 |
| 1 | 0 | 0 | 正好一半，最低位已是偶数，不进 |
| 1 | 0 | 1 | 正好一半，进 1 使最低位变成偶数 |

进位可能把 `1.111…1` 收成 `10.000…0`，这时右规一位，阶码加 1。阶码超过 254 就是无穷。真阶小于 -126 时，先把数对齐成 `0.M × 2^(-126)` 再舍入，结果是非规格化数或 0。

`-8.25 = -1000.01B = -1.00001 × 2^3`。阶码 = 130 = `10000010`，尾数是 `00001` 后补 0。拼出来 `C1040000H`。`12.1` 的二进制是无限循环 `0011`，舍入位是 1 且后面还有 1，要进位，机器数 `4141999AH`。

### 加减

五步，和王道的口诀一样，舍入用上面的向偶数，不用 0舍1入。

1. 对阶：小阶向大阶看齐，小阶的尾数右移，阶差是多少就移多少。大数不能左移，否则高位会丢。
2. 尾数相加或相减。符号不同就是减。右移丢掉的不足 1 的那些位，减法时要借走，不然尾数偏大。
3. 规格化：和 ≥ 2 就右规，阶码加；和 < 1 就左规，阶码减。左规到真阶 -126 还不够 1，就停，结果是非规格化数。
4. 舍入。正好一半而且最低位已经是 0 时，向偶数不进，0舍1入 会进。`1 + 2^(-24)` 就是这一档，和仍是 1。
5. 判溢出：真阶 > 127 得到无穷；太小则得到非规格化数或带符号的 0。

`1.5+1.5` 的尾数 `1.1+1.1 = 11.0`，右规一位得到 3，机器数 `40400000H`。`40000000H` 是 2，不是 3。两个最大规格化数相加，右规后真阶变成 128，上溢成正无穷 `7F800000H`。

一个操作数是 0，和就是另一个。两个 -0 相加仍是 -0，只要有一个 +0，和就是 +0。无穷加上符号相反的无穷是 NaN。

### 双精度和类型转换

双精度只是把字段加长：阶码 11 位、偏置 1023，尾数 52 位，隐含 1 后有效数字 53 位。规格化真阶 -1022～1023。最小正规格化数 `1.0×2^(-1022)`，机器数 `0010000000000000H`。

32 位 `int` 的有效位最多 31 位，双精度的 53 位盖得住，所以 `int` 转 `double` 不丢。`float` 只有 24 位，`|n| ≤ 2^24` 的整数才能全部精确表示。`16777217 = 2^24+1` 正好在两个可表示值正中间，最低位已是偶数，向偶数舍入成 `16777216`，机器数 `4B800000H`。

`float` 或 `double` 转 `int` 是向零截断，不是四舍五入，也不是向下取整。`1.9` 变成 1，`-1.9` 变成 -1，不会变成 -2。幅度到了 `2^31` 以上，32 位补码放不下；C 语言里这种转换没有定义，程序只报告放不进，不去真的转。

2017 年的 `f2` 就是用 `float` 做 `1+2+…+2^n`。n=23 时和是 24 个 1，float 正好放下，机器数 `4B7FFFFFH`。n=24 时 25 个 1，舍入成 `2^25`。n=126 时结果是 `2^127`，阶码 254，还是有限数；n=127 时是 `2^128`，上溢成正无穷 `7F800000H`。

## 真题核对

题面和答案都已联网核对。计算器用例就是 `tests/` 里的同名文件。

| 题 | 结果 | 选项 |
|---|---|---|
| 2011-13 | -8.25 的机器数是 C1040000H | A |
| 2013-13 | C6400000H = -1.5×2^13 = -12288 | A |
| 2017-43 (1) | n=0 时 `n-1` 变成 2^32-1，无符号比较永远为真。改成 int 后 `n-1=-1`，循环不进 | |
| 2017-43 (2) | 相等。f1 是 00FFFFFFH，f2 是 4B7FFFFFH | |
| 2017-43 (3) | 25 个 1 放不进 24 位有效数字，舍入后 f2 比 f1 大 1 | |
| 2017-43 (4) | 32 个 1 按 int 读是 -1。和 f(n) 相等的最大 n 是 30 | |
| 2017-43 (5) | 7F800000H 是正无穷。不溢出最大 n=126，不舍入最大 n=23 | |
| 2018-14 | 最小正规格化数是 1.0×2^(-126) | A |
| 2023-14 | 80200000H 是非规格化数，-0.01B×2^(-126) = -2^(-128) | A |
| 2024-14 | α 用 32 位整数，β 用双精度。2^40 本身能写成 float，但区间里别的整数会丢 | C |
| 2025-13 | 47300000H = 1.375×2^15 | D |
| 2026-14 | 12.1 舍入后是 4141999AH。41419999H 是没进位的截断 | B |

2013 年的阶码是 `10001100` = 140，真阶 13。尾数 `1.1B` 就是 1.5。漏掉隐含 1 会得到选项里的 0.5。

2023 年阶码全 0、尾数是 `01`。补上并不存在的隐含 1，会得到 -1.01 乘某个 2 的幂；把阶码 0 当成 -127 也是同一类错。选项 B、C 的指数在不同回忆版里有 -126 和 -128 的出入，标准答案是 A。当成 NaN 是 D。

2025 年阶码 `10001110` = 142，真阶 15。尾数 `1.011B` = 1.375。真阶少算 1 会落到 2^14 那两个选项。

## 易错点

1. **偏置是 127，不是 128。** -8.25 的阶码若按 3+128 算，得到 `10000011`，机器数是 C1840000H，就是 2011 年的选项 C。普通移码的偏置 2^(n-1) 在这里不适用，因为全 0 和全 1 被特殊值占掉了。
2. **非规格化数没有隐含 1，真阶是 -126。** 2023 年的 80200000H 不是 -1.01×2^(-127)，也不是 NaN。`0.01 × 2^(-126) = 2^(-128)`。
3. **最小正规格化数是 2^(-126)，最小正非规格化数才是 2^(-149)。** 2018 年的 B、C 把真阶算小了，D 是非规格化数的下限。
4. **向偶数舍入和 0舍1入 只在「正好一半」时分手。** 12.1 的舍入位是 1 且后面还有 1，两种规则都进位，所以 2026 年看不出差别。`1 + 2^(-24)` 才是正好一半、最低位为 0：向偶数保持 1，0舍1入 会变成 `1+2^(-23)`。
5. **右规之后才判溢出。** 两个最大规格化数的尾数和是 `11.111…1`，右规一位后真阶 128，结果是无穷，不是最大规格化数。
6. **3 的机器数是 40400000H。** `1.5+1.5` 右规后是 `1.1×2^1`。`40000000H` 是 `1.0×2^1`，也就是 2。
7. **2009 年第 13 题不是这套格式。** 那题的阶码和尾数都用补码，尾数没有隐含 1，阶码含两位符号。不能把 IEEE 754 的偏置和隐藏位套进去。那题的结果是阶码上溢。
8. **`float` 转 `int` 向零截断。** -1.9 变成 -1。向下取整才会得到 -2。大到 `2^31` 的 float 可以是精确的 2 的幂，但 32 位补码的正数只到 `2^31-1`。
9. **2 的幂能写成 float，不代表那个数量级的整数都能。** 2024 年的 2^40 本身是 `1.0×2^40`，但 2^40-1 需要 40 位有效数字，float 只有 24 位。双精度有 53 位，32 位 int 放不下的 β 用它。α 的 ±2^20 用 32 位整数就够，而且整数运算更快。

## 概念卡片

写进 `NOTES.md`。下面是对照用的，不要抄成自己的复盘。

1. **五种位型**：0、规格化、非规格化、无穷、NaN，各看阶码全 0 / 全 1 和尾数是否为 0。
2. **加减五步**：对阶（小阶右移）、尾数运算、规格化（右规或左规）、舍入、判阶码溢出。
3. **舍入**：默认向偶数。0舍1入、恒置 1、朝 0、朝 ±无穷是另外的规则。正好一半时才和 0舍1入 不同。
4. **转换**：`int`→`double`、`float`→`double` 不丢。`int`→`float` 可能丢精度但不溢出。`float`/`double`→`int` 向零截断，还可能溢出。
