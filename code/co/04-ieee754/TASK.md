### 04 · IEEE 754 浮点数
- **产出**：单精度浮点数编码器和解码器（用 C 的 `union` 对照验证）；浮点加减运算的分步 trace
- **小步骤**：① 编码：符号、阶码（偏置 127）、尾数（隐含 1） ② 解码，包括 ±0、无穷大、NaN、非规格化数 ③ 浮点加减：对阶 → 尾数相加 → 规格化 → 舍入 → 判溢出 ④ 双精度的字段划分，以及 `int`、`float`、`double` 互转时哪些会丢精度
- **通过标准**：真题考法：某个十进制数的 IEEE 754 十六进制表示、给定机器码求真值、float 转 int 时的精度问题
