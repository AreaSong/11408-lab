# co/04 · IEEE 754 浮点数 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：单精度浮点数的编码器和译码器（编码结果用 C 的 `union` 和 `float` 的位型对照）；浮点加减的分步 trace；双精度的字段划分，以及 `int`、`float`、`double` 互转时谁会丢精度
- **小步骤**：
  ① 编码：符号、阶码（偏置 127）、尾数（隐含 1）
  ② 译码，包括 ±0、无穷、NaN、非规格化数
  ③ 浮点加减：对阶 → 尾数相加 → 规格化 → 舍入 → 判溢出
  ④ 双精度的字段划分，以及 `int`、`float`、`double` 互转时哪些会丢精度
- **通过标准**：某个十进制数的 IEEE 754 十六进制机器数、给定机器码求真值、`float` 和 `int` 互转时的精度，都要和标准答案一致

本关有两个程序：`main.c` 编出的主程序（如 `ieee754_answer`），`test.c` 编出的单元测试（`ieee754_answer_test`）。

王道第 2 章：IEEE 754 单精度和双精度、规格化与非规格化、浮点加减的五步。默认舍入是向偶数舍入，和 C 的 `float` 一致。

## 二、主程序题目（`main.c`）

读之前用 `prompt(...)` 提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。

### 写法

- 十进制：可带 `+` 或 `-`，可以有小数点和科学计数法，例如 `-8.25`、`12.1`、`1e-4`。`-0` 和 `0` 不是同一个数。有效数字不超过 18 位，十进制指数在 -45 到 45 之间
- 单精度机器数：`C6400000H` 或 `0xC6400000`，不超过 8 位十六进制

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `enc` | 一个十进制 | 单精度机器数。能精确表示时再给真值 |
| `dec` | 一个单精度机器数 | 真值。规格化数写成 `±1.M×2^阶`，纯 2 的幂可以收成 `±2^k` |
| `add` | 两个数，十进制或机器数都行 | 和的机器数与真值 |
| `sub` | 两个数 | 差的机器数与真值。减法先变成加相反数 |
| `fields` | 无 | 最小正规格化数 |
| `fit` | 两个非负整数 k、m | α 的范围是 ±2^k、β 的范围是 ±2^m 时，各该用 32 位整数还是双精度 |
| `cast` | 一个十进制 | 转到 `float` / `double` 丢不丢精度；浮点转 `int` 时的截断结果，或说明放不进 32 位 `int` |
| `sum` | 一个 n，0 到 200 | 2017 年第 43 题里 `f1(n)`、`f2(n)` 的机器数或是否死循环 |

`enc` 要自己算出符号、阶码和尾数，再用 `union` 和 C 的 `float` 比位型。`add`、`sub` 要把五步都打印出来。无穷和 NaN 不必硬走这五步，写明用的是哪条特殊规则。

### 样例

输入：

```
enc -8.25
```

输出：

```
【单精度编码】-8.25
符号位 = 1（负数）
绝对值的二进制 = 1000.01B
舍入前 = 1.00001000000000000000000|0 × 2^3
竖线左边留下，右边第一位是舍入位，再往后并成粘滞位
舍入：23 位尾数放得下，是精确值
符号位 1，尾数 00001000000000000000000
规格化数。阶码 = 3 + 127 = 130 = 10000010
尾数最高位的 1 被隐含，不占上面这 23 位
机器数 = 1 10000010 00001000000000000000000 = C1040000H
union 对照：和 C 的 float 位型一致
结果：C1040000H，真值 -8.25
```

**2017-43** 已知 f(n) = 2^(n+1) - 1，其二进制是 n+1 个 1。计算 f(n) 的 C 语言函数 f1 如下：

```c
int f1(unsigned n) {
    int sum = 1, power = 1;
    for (unsigned i = 0; i <= n - 1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

将 f1 中的 int 都改为 float，可得到计算 f(n) 的另一个函数 f2。假设 unsigned 和 int 型数据都占 32 位，float 采用 IEEE 754 单精度标准。请回答下列问题。

(1) 当 n = 0 时，f1 会出现死循环，为什么？若将 f1 中的变量 i 和 n 都定义为 int 型，则 f1 是否还会出现死循环？为什么？

(2) f1(23) 和 f2(23) 的返回值是否相等？机器数各是什么（用十六进制表示）？

(3) f1(24) 和 f2(24) 的返回值分别为 33554431 和 33554432.0，为什么不相等？

(4) f(31) = 2^32 - 1，而 f1(31) 的返回值却为 -1，为什么？若使 f1(n) 的返回值与 f(n) 相等，则最大的 n 是多少？

(5) f2(127) 的机器数为 7F800000H，对应的值是什么？若使 f2(n) 的结果不溢出，则最大的 n 是多少？若使 f2(n) 的结果精确（无舍入），则最大的 n 是多少？
