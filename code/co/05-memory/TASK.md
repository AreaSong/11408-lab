### 05 · 半导体存储器、主存与磁盘
- **产出**：存储器扩展计算器；DRAM 刷新计算器；磁盘性能计算器；本机访存延迟台阶测量
- **小步骤**：① DRAM：行列地址复用时的地址引脚数，集中、分散、异步三种刷新方式的刷新间隔与死时间 ② 位扩展、字扩展、字位同时扩展 ③ 片选译码与地址范围（主存和 CPU 之间的连接） ④ 多模块存储器：高位交叉与低位交叉，连续访问的时间与带宽 ⑤ 磁盘：容量、平均存取时间（寻道 + 旋转延迟 + 传输）、数据传输率 ⑥ **写一个按步长和数据量扫描的访存测速程序**，在本机测出 L1、L2 与主存的延迟台阶（本机 L1 数据 Cache 64 KB、L2 4 MB，用 `sysctl hw.l1dcachesize hw.l2cachesize` 核对）
- **通过标准**：真题考法：用某种芯片组成某容量的存储器，求芯片数和某片的地址范围；交叉存储器连续访问的时间；磁盘的平均存取时间
- **概念卡片**：存储器的分类（按介质、存取方式、可改写性）；SRAM vs DRAM；Flash 与 SSD 的读写特性（按页读写、按块擦除、磨损均衡）；DRAM 芯片与内存条的关系
