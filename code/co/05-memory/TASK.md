# co/05 · 半导体存储器、主存与磁盘 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：存储器扩展计算器、DRAM 刷新计算器、磁盘性能计算器，以及一个按步长和数据量扫描的访存测速程序。测速结果随本机和调度到哪类核而变，记在 `EXPERIMENTS.md`，不进 `tests/`
- **小步骤**：
  ① DRAM：行列地址复用时的地址引脚数；集中、分散、异步三种刷新的刷新间隔和死时间
  ② 位扩展、字扩展、字位同时扩展
  ③ 片选译码和地址范围（主存和 CPU 怎么接）
  ④ 多模块存储器：高位交叉和低位交叉，连续访问的时间与带宽
  ⑤ 磁盘：容量、平均存取时间（寻道 + 旋转延迟 + 传输）、数据传输率
  ⑥ 访存测速：用步长把缓冲区拆成结点，随机串成环再追逐指针，看出 L1、L2 和主存的延迟台阶
- **通过标准**：用某种芯片组成某容量的存储器，能算出芯片数和某片的地址范围；能算交叉存储器连续访问的时间；能算磁盘的平均存取时间
- **概念卡片**（写进 `NOTES.md`）：存储器按介质、存取方式、可改写性怎么分类；SRAM 和 DRAM；Flash 和 SSD（按页写、按块擦、磨损均衡）；DRAM 芯片和内存条是什么关系

本关有三个程序：`main.c` 编出的主程序（如 `memory_answer`）、`test.c` 编出的单元测试（`memory_answer_test`）、`scan.c` 编出的测速程序（`memory_answer_scan`）。测速程序会等你输入命令行参数，不读键盘上的题目数据。

王道第 3 章。存储容量里的 K / M / G 是 2¹⁰ / 2²⁰ / 2³⁰；传输率、带宽里的 K / M / G 是 10³ / 10⁶ / 10⁹。先看题目是按字节编址还是按字编址。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每条命令打印一块推导，**每个数都带单位**，最后一行以 `结果：` 开头。`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

读之前用 `prompt(...)` 提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。

### 单位

- 存储容量：`B`、`K`、`KB`、`M`、`MB`、`G`、`GB`。这里 K = 2¹⁰
- 时间：`s`、`ms`、`us`、`ns`。`us` 就是微秒
- 传输率：`B/s`、`KB/s`、`MB/s`、`GB/s`。这里 M = 10⁶
- 频率：`Hz`、`kHz`、`MHz`、`GHz`。这里 M = 10⁶
- 地址：`0B1FH`、`804001AH` 或 `0x804001A`。`bank` 的地址是十进制，不要加 `H`

芯片规格写成「单元数 × 数据位数」。按字节编址、数据总线 8 位时，目标位宽填 8，单元数就是字节数。

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `dram` | 单元数、单位、数据位数 | 行数 r、列数 c、地址引脚、数据引脚、两者之和 |
| `refresh` | 行数、最大刷新间隔、单位、存取周期、单位 | 集中刷新的死时间、分散刷新的系统存取周期、异步刷新的行间隔 |
| `expand` | 目标单元数、单位、目标位宽、芯片单元数、单位、芯片位宽 | 芯片数、扩展方式、组数和每组片数 |
| `locate` | 目标单元数、单位、每组单元数、单位、地址 | 该组最小地址 |
| `mar` | 地址空间、单位 | MAR 的位数。填的是地址空间，不是已经插上的容量 |
| `zone` | 地址线根数、RAM 的份数、ROM 的份数 | ROM 的地址范围。RAM 在低地址，两者把空间占满 |
| `cs` | 地址线根数、片内地址位数、片选约束 | 全译码还是部分译码、第一段范围、共几段。约束从高位写到低位，`x` 表示这根线没参加译码 |
| `bank` | 模块数、地址个数，接着是十进制地址 | 可能冲突的地址对；没有就写没有冲突 |
| `span` | 模块数、总线位数、字节数、起始地址 | 存储周期数。模块数要是 2 的幂，总线位数 = 模块数 × 8 |
| `seq` | 模块数、存取周期、单位、总线周期、单位、字数、每字字节 | 低位交叉和高位交叉的时间 |
| `bw` | 通道数、频率、单位、位宽 | 总带宽，单位 GB/s |
| `sector` | 转速（转/分）、平均寻道、单位、每道扇区数 | 平均存取时间 |
| `read` | 转速、寻道、单位、传输率、单位、数据量、单位、控制器延迟、单位 | 平均存取时间 |
| `cap` | 盘面数、每面磁道数、每道扇区数、每扇区字节数 | 格式化容量 |
| `media` | 转速、每道扇区数、每扇区字节数 | 内部传输率，单位 MB/s |

位宽除不尽、单元数除不尽、地址超出范围、单位不认识，都向 stderr 报错并以非 0 退出。

### 样例

输入：

```
dram 4 M 8
```

输出：

```
【DRAM 行列复用】
单元数 = 4194304 = 4 M = 2^22，数据位数 = 8
行地址和列地址分时复用同一组引脚：先 RAS 送行，再 CAS 送列
地址引脚 = max(行地址位数, 列地址位数)，不是两者相加
引脚要少，行和列就尽量接近；刷新按行做，引脚一样多时取行更少的
采用：2048 行 × 2048 列，行地址 11 位，列地址 11 位，地址引脚 11
数据引脚 = 8，不参加复用
地址不复用时地址引脚是 22，加上数据引脚是 30
结果：r = 2048，c = 2048，地址引脚 = 11，数据引脚 = 8，地址加数据 = 19
```

## 三、访存测速（小步骤 ⑥）

`memory_answer_scan` 不读标准输入。参数是字节数、步长，以及可选的核等级：

```
memory_answer_scan 262144 128 p
memory_answer_scan 65536 128 e
```

`p` 尽量跑在性能核，`e` 尽量跑在能效核。不写就是 `p`。字节数要同时是步长和 128 的倍数，步长至少要放下一个指针。

先用 `sysctl` 看本机 Cache。关卡说明里的 64 KB / 4 MB 指的是 `hw.l1dcachesize` 和 `hw.l2cachesize` 这两项；这台 M4 Pro 上它们是能效核的容量，性能核更大。对照哪一组数，取决于程序钉在哪类核上。本机一次扫描的输出见 `EXPERIMENTS.md`。
