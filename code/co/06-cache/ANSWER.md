LRU 的栈法可以把刚访问的块挪到双向链表表头，淘汰表尾，那就是 `lib/02` 的双链表。计数器法和「越大越新」的时间戳选出的是同一行。考题问的是计数器有几位，所以容量按每行 `log2(路数)` 位算，模拟器里用时间戳，不再依赖链表。

## 思路

先定编址单位。按字节编址时，块内偏移 = log2(块字节数)。按字编址时，块内偏移 = log2(块里的字数)，地址本身就是字地址。

组数 = 行数 / 路数。组号位数 = log2(组数)。标记位数 = 主存地址位数 − 组号位数 − 块内偏移位数。全相联组数是 1，组号 0 位，标记占掉地址里除块内偏移以外的全部。直接映射路数是 1，组号就是行号。

主存块号 = ⌊地址 / 块大小⌋，组号 = 块号 mod 组数。块号的低若干位就是组号，高位是标记。组内用标记比较，还要看有效位：空行不能算命中。

替换只在组内发生。直接映射没有选择。LRU 每次命中或装入都把该行标成最新，牺牲最久没碰的一行。FIFO 只在装入时排队，命中不改变次序。两种算法的命中次数可以一样，换出去的块不同。

写命中：写直达同时改 Cache 和主存，不需要脏位；写回只改 Cache，把脏位置 1，等这一行被换出再写回整块。写缺失：写分配先把块调进来再写；非写分配只改主存，不占 Cache，也不改替换次序。读缺失一律调块。常见搭配是写回 + 写分配、写直达 + 非写分配，四种组合模拟器都能跑。

总容量 = 数据区 + 标记阵列。数据区 = 行数 × 块字节。标记阵列每行 = 标记 + 有效位 + 脏位 + 替换位。有效位总是 1 位。脏位只在写回时为 1。替换位在路数大于 1 且题目要算的时候，是每行 log2(路数) 位。这些位不在主存地址里面，不能从地址位数里减掉。

数组按行优先存放，元素首地址 = 基址 + (行 × 列数 + 列) × 元素字节。按行走，相邻元素差一个元素；按列走，相邻行差「一行的字节数」。这个差如果刚好是若干个主存块，而且块数能被组数整除，整列就挤在同一组里。

## 易错点

1. **2012 年的块内偏移有两套口径。** 题面写块大小为 1 个字，按字编址，块内偏移是 log2(1) = 0 位。4 行、2 路，组数 2，组号是字地址的最低 1 位。0、4、8、2、6 都是偶数，全部进第 0 组。第 0 组只有 2 路，LRU 下只有第 8 次访问（地址 6）命中，共 1 次，对应选项 A。`tests/2012-17.out` 就是这一套。考试分析把 0～1、4～5、8～9 放进第 0 组，2～3、6～7 放进第 1 组，等于字地址的最低 1 位当块内偏移、次低 1 位当组号，一块里就有 2 个字。那样命中发生在第 7 次（地址 8）、第 8 次（地址 6）和第 10 次（地址 8），共 3 次，选项 C，参考答案选 C。王道真题解析按参考答案讲 3 次。教材的一般公式仍是「组号 = 主存块号 mod 组数，块号 = 地址 / 块大小」。本关和 2009-14、2010-44 用同一条公式。考场上这道选择题的参考答案是 C，要能按他们的分组把 3 次算出来。
2. **有效位、脏位都要单独算。** 2015 年能放 4K 字，每字 32 位，一块 4 字，就是 1024 行 × 16 B。标记 18 位，写回再加有效位和脏位各 1 位，每行 148 位，总共 148K 位（K = 2¹⁰）。漏掉有效位是 147K（选项 B），有效位和脏位都漏是 146K（选项 A）。2010 年说不考虑一致性维护和替换算法的控制位，脏位和 LRU 位是 0，有效位还在。8 行 × (64 B + 20 位 / 8) = 532 B。只算数据区会得到 512 B。
3. **替换位不占用主存地址。** 2020 年 8 路，LRU 计数器是每行 log2(8) = 3 位，这 3 位在 Cache 行里，不在 32 位地址里。地址是标记 20 + 组号 6 + 块内偏移 6。组号是 log2(组数)，组数 = 512 / 8 = 64，不是 log2(路数)。把路数当成组号，会得到标记 23 位或别的数。直写没有修改位。
4. **2 路的 LRU 位是每行 1 位，并且乘进行数。** 2018 年 8 组 × 2 路 = 16 行，每行 20 + 1 + 1 + 1 + 32×8 = 279 位，总容量 4464 位 = 558 B。若把这 1 位 LRU 只算在每组上、不乘 2 路，总数对不上 558 B。有效位的作用是指出这一行里的数据是否有效，不是「数据在不在主存」。
5. **`a[k] = a[k] + 32` 访问两次。** 2016 年先读后写。一块 16 B 放 4 个 int，8 次访问里只有第一次读缺失，缺失率 1/8 = 12.5%。只算读、不算写，就变成 1/4 = 25%，那是选项 D。Cache 一共 64 行，数组有 250 块，会周转，但每一块用完就不再用，周转不增加缺失。题面没给首地址，按块对齐来算。
6. **2020 年的起点在块边界上。** 008000C0H 的低 6 位是 0，1024 个 int 占 4096 B = 64 个块。每块第一次读缺失，随后的读和写都命中，缺失 64 次。不是 1024，也不是 2048。
7. **按列可以一次都不中。** 2010 年一行 256 × 4 = 1024 B = 16 个主存块，16 mod 8 = 0，同一列的每一行都映射到同一行 Cache。直接映射只有 1 路，下一行把上一行换掉，刚装进来的另外 15 个 int 也用不上。按行则是每 16 个元素缺 1 次，命中率 15/16 = 93.75%。所以 A 比 B 快。a[0][31] 的地址是 320 + 31×4 = 444，444 / 64 = 6，行号 6。a[1][1] 的地址是 320 + 257×4 = 1348，1348 / 64 = 21，21 mod 8 = 5。
8. **FIFO 命中不刷新次序。** 序列 0、1、0、2 在 2 行全相联里，LRU 和 FIFO 都命中 1 次。LRU 留下块 0 和块 2，FIFO 留下块 2 和块 1。只记命中次数会觉得两种算法一样。
9. **非写分配的第一次写不会把块调进来。** 随后的读仍然会缺失并装入。写回 + 写分配会把脏块一直留到被替换，那时才写回 1 次。写直达每次写都立刻写主存，替换时没有脏块。四条 trace 在 `practice-write` 里。

## 小步骤对应的代码

| 步骤 | 函数 | 在算什么 |
|---|---|---|
| ① | `fields_make`、`show_fields`、`fields_locate` | 组数 = 行数 / 路数。标记 = 地址位数 − 组号位数 − 块内偏移位数。块号 = 地址 / 块大小，组号 = 块号 mod 组数 |
| ② | `cache_access` 在路数为 1 时 | 组里只有一行，缺失就替换它。组号就是行号 |
| ③ | `victim_way`、`touch`、`install` | 空行优先。LRU 在命中和装入时把 stamp 调新，FIFO 只在装入时调。牺牲 stamp 最小的那一行 |
| ④ | `note_write`、`fill_miss` | 写回把脏位置 1，脏行被换出时写回次数加 1。写直达当时写主存。非写分配的写缺失不装入、不改次序 |
| ⑤ | `capacity_make`、`show_capacity` | 每行标记阵列 = 标记 + 有效位 + 脏位 + 替换位。总容量 = 行数 ×（标记阵列 + 块字节 × 8） |
| ⑥ | `walk_run`、`show_walk` | 存放按行优先。按列只改访问次序。按行、按列各从空 Cache 开始，不是跑完按行再接着按列 |

`main.c` 只拆命令。单元测试测的是这些函数，改打印文字时真题的数仍然被 `test.c` 看着。

## 概念卡片参考答案

### 卡片一：三种映射

| | 直接映射 | 组相联 | 全相联 |
|---|---|---|---|
| 主存块能进哪 | 唯一的一行，行号 = 块号 mod 行数 | 唯一的一组，组内任意一行 | 任意一行 |
| 地址字段 | 标记、行号、块内偏移 | 标记、组号、块内偏移 | 标记、块内偏移 |
| 比较器 | 每行一个，而且只比选中的那一行 | 每组路数个 | 每一行一个 |
| 替换 | 没有选择 | 组内 LRU、FIFO 等 | 全部行里选 |
| 冲突 | 多，容易抖动 | 介于两者之间 | 少，硬件贵 |

路数从 1 加到行数，就是从直接映射过渡到全相联。2 路是组相联里最常考的。命中时用标记比较，组号和块内偏移不参加比较。

2020 年第（3）问：00010003H 的块内偏移是低 6 位，组号是中间 6 位，都是 0，所以进指令 Cache 的第 0 组。Cache 起初为空，有效位全是 0，访问缺失。从主存取出该块所在的 64 B，装进第 0 组的任意一行，标记填地址高 20 位，有效位置 1，并改 LRU 位。直写没有修改位。最后用块内偏移 000011B 从这一行取出指令。

### 卡片二：写策略

| | 写直达 | 写回 |
|---|---|---|
| 写命中 | Cache 和主存一起改 | 只改 Cache，脏位置 1 |
| 换出 | 不用写回 | 脏了才把整块写回 |
| 脏位 | 没有 | 有 |
| 常配的写缺失 | 非写分配 | 写分配 |

写分配：写缺失时把主存块调入 Cache，再在 Cache 里写。非写分配：写缺失时只写主存，不调块。读缺失与此无关，仍然调块。

Cache 和主存速度差得不算极端，可以用写直达，少维护脏位。主存和外存差得多，改过的页通常用写回，否则每次存储都去碰磁盘。2016-45 问的就是这件事：直写要同时写快的和慢的，写磁盘比写主存慢得多，所以 Cache 可以直写，改过的页用回写。写回的好处是多次写同一块只在换出时写一次主存；坏处是一致性和替换都要看脏位。
