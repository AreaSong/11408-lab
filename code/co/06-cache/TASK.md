### 06 · Cache 模拟器
- **产出**：Cache 模拟器：支持直接映射、全相联、组相联；LRU/FIFO 替换；写回/写直达；输出每次访问命中还是缺失
- **小步骤**：① 地址划分：标记 | 组号 | 块内偏移 ② 直接映射 ③ 组相联 + LRU（可复用 lib 的双向链表） ④ 写策略与脏位（写命中：写直达、写回；写缺失：写分配、非写分配） ⑤ Cache 总容量计算（含标记位、有效位、脏位、LRU 位） ⑥ **把一段 C 二重循环生成的地址序列喂给模拟器**，比较按行访问和按列访问的命中率
- **通过标准**：真题考法：主存地址的各字段位数、Cache 总容量、给定数组访问顺序求命中率
- **概念卡片**：三种映射方式对比；写策略的搭配
