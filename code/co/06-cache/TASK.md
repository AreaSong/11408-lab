# co/06 · Cache 模拟器 · 题目

## 一、本关任务

- **产出**：Cache 模拟器。支持直接映射、全相联、组相联，LRU / FIFO，写回 / 写直达，写分配 / 非写分配。每次访问打印命中还是缺失
- **小步骤**：
  ① 地址划分：标记 | 组号 | 块内偏移
  ② 直接映射
  ③ 组相联，加上 LRU
  ④ 写策略和脏位。写命中分写直达、写回；写缺失分写分配、非写分配
  ⑤ Cache 总容量（标记位、有效位、脏位、替换位都要分开看）
  ⑥ 把二重循环生成的地址序列喂进模拟器，比较按行访问和按列访问的命中率
- **通过标准**：能算主存地址各字段的位数、Cache 总容量，以及给定数组访问顺序时的命中率
- **概念卡片**（写进 `NOTES.md`）：三种映射方式怎么比；写策略怎么搭配

本关有两个程序：`main.c` 编出的主程序（如 `cache_answer`）、`test.c` 编出的单元测试（`cache_answer_test`）。

王道第 3 章 Cache。主存地址从高到低是**标记、组号、块内偏移**。直接映射的路数是 1，组号就是行号。全相联的路数等于行数，组号是 0 位。先看清按字节编址还是按字编址：块内偏移的单位跟着编址单位走。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每条命令打印一块推导，最后一行以 `结果：` 开头。`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

读之前用 `prompt(...)` 提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。

地址可以写成十进制、`0x` 开头，或末尾加 `H`（如 `008000C0H`）。行数、路数、块大小都要是 2 的幂，路数不能大于行数。不满足时向 stderr 报错并以非 0 退出。

全相联：路数填成和行数一样。直接映射：路数填 1。

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `split` | `byte` 或 `word`、地址位数、块大小、行数、路数 | 标记、组号、块内偏移的位数。`byte` 的块大小单位是字节，`word` 是字 |
| `map` | `byte` 或 `word`、块大小、行数、路数、地址 | 块号、组号（直接映射时写行号）、块内偏移。题目没给地址总位数时用这条 |
| `cap` | 地址位数、行数、块字节、路数、`back` 或 `through`、`lru` / `fifo` / `none` | 标记、有效位、脏位、每行替换位、总容量。按字节编址。`back` 是写回，`through` 是写直达。`none` 表示本题不计替换位 |
| `rate` | 访存次数、缺失次数 | 命中率和缺失率 |
| `trace` | 见下方 | 每次访问的命中或缺失，以及命中次数、写回次数、当时写主存的次数 |
| `loop` | 见下方 | 按行和/或按列的命中率。按行、按列各从空 Cache 算起 |

`trace` 第一行：

```
trace byte 或 word  地址位数  块大小  行数  路数  lru 或 fifo  back 或 through  alloc 或 noalloc
```

下一行是访问次数（1 到 64），接着每行 `R` 或 `W` 再跟地址。题目没给地址有多少位时，填一个装得下这些地址的位数。组号只由块号和组数决定。

`loop` 一行：

```
loop row、col 或 both  read 或 update  地址位数  行数  列数  元素字节  首地址  块字节  Cache行数  路数  lru 或 fifo  back 或 through  alloc 或 noalloc
```

数组按行优先存放。`read` 每个元素读 1 次，`update` 每个元素先读后写。`both` 是先按行再按列。一次访问看的是元素首地址；元素字节要能整除块字节，元素也不能跨在两块上。

替换位按计数器法：路数大于 1 时，每行 `log2(路数)` 位。直接映射没有别的行可换，替换位是 0。写回才有脏位。有效位每行都有。

### 样例

输入：

```
split byte 28 64 8 1
```

输出：

```
【地址划分】
按字节编址，主存地址 28 位
Cache 8 行，每组 1 路，直接映射，块 64 B
组数 = 8 / 1 = 8
直接映射时组号就是行号，主存块只能进这一行
块内偏移 = log2(64) = 6 位
组号 = log2(8) = 3 位
标记 = 28 - 3 - 6 = 19 位
主存地址从高到低：标记 19 位 | 组号 3 位 | 块内偏移 6 位
数据区 = 8 × 64 B = 512 B
结果：标记 = 19 位，组号 = 3 位，块内偏移 = 6 位
```

其余命令的行文以 `tests/` 里同名 `.out` 为准。`trace` 会把被访问的那一组印出来，`*` 是本次访问的路，`脏` 表示写回法下这一行比主存新。

**2010-44**（12 分）某计算机的主存地址空间大小为 256 MB，按字节编址。指令 Cache 和数据 Cache 分离，均有 8 个 Cache 行，每个 Cache 行大小为 64 B，数据 Cache 采用直接映射方式。现有两个功能相同的程序 A 和 B，其伪代码如下所示：

程序 A：

```c
int a[256][256];
int sum_array1()
{
    int i, j, sum = 0;
    for (i = 0; i < 256; i++)
        for (j = 0; j < 256; j++)
            sum += a[i][j];
    return sum;
}
```

程序 B：

```c
int sum_array2()
{
    int i, j, sum = 0;
    for (j = 0; j < 256; j++)
        for (i = 0; i < 256; i++)
            sum += a[i][j];
    return sum;
}
```

假定 int 类型数据用 32 位补码表示，程序编译时 i、j、sum 均分配在寄存器中，数组 a 按行优先方式存放，其首地址为 320（十进制）。请回答下列问题，要求说明理由或给出计算过程。

（1）若不考虑用于 Cache 一致性维护和替换算法的控制位，则数据 Cache 的总容量为多少？

（2）数组元素 a[0][31] 和 a[1][1] 各自所在主存块对应的 Cache 行号分别是多少（Cache 行号从 0 开始）？

（3）程序 A 和 B 的数据访问命中率各是多少？哪个程序的执行时间更短？

**2012-17** 假设某计算机按字编址，Cache 有 4 个行，Cache 和主存之间交换的块大小为 1 个字。若 Cache 的内容初始为空，采用 2 路组相联映射方式和 LRU 替换算法。当访问的主存地址依次为 0，4，8，2，0，6，8，6，4，8 时，命中 Cache 的次数是（ ）。
