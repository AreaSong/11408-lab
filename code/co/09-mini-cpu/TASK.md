# co/09 · 迷你 CPU 与数据通路 · 题目

## 一、本关任务

- **产出**：一台 16 位、按字编址的单总线 CPU。它执行取数、存数、加法、条件跳转和寄存器间接的加法，并按节拍打印微操作和控制信号
- **小步骤**：
  ① 定下指令格式，以及 PC、IR、MAR、MDR、ACC、PSW、暂存器 A、R0～R3
  ② 取指：`(PC)→MAR→主存→MDR→IR`，同时 `(PC)+1→PC`
  ③ 执行取数、存数、加法、跳转。加法要改 PSW
  ④ 每一拍列出控制信号，并检查内总线是不是只有一个输出
- **通过标准**：给定数据通路，能写出一条指令的微操作和控制信号；能说出一条指令至少分几个阶段
- **概念卡片**（写进 `NOTES.md`）：运算器里有什么，控制器里有什么

本关有两个程序：`main.c` 编出的主程序（如 `mini_cpu_answer`）、`test.c` 编出的单元测试（`mini_cpu_answer_test`）。

王道第 5 章中央处理器。玩具机按字编址，取指时 PC 加 1。2015 年那道题的机器按字节编址，顺序执行时 PC 加 2。两套地址单位不要混用。

内总线一个时钟周期只允许一个部件输出。信号名以 `out` 结尾、又不是 `outE` 的，算内总线驱动。`MDRoutE` 走数据总线，`MemR`、`MemW`、`PC+1`、`Add` 都不算内总线驱动。驱动个数大于 1 时，下一行打印冲突。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每次读命令前用 `prompt("请输入命令：")` 提示。`prompt` 在 `deps/prompt.h`，跑测试时不打印。可以连续输入多条命令，Ctrl+D 结束。

`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。参数不合法时向 stderr 报错，并以非 0 退出。

整数可以写成十进制、`0x` 开头，或末尾加 `H`。内存里的值允许是负数，按 16 位补码存。指令里的地址和寄存器编号只写非负十进制。

### 命令

| 命令 | 做什么 | 结果行 |
|---|---|---|
| `prog` | 装入并执行一段玩具程序 | `结果：` 后面有 ACC、访存次数、冲突次数 |
| `2009-44` | 写出 `ADD (R1), R0` 的微操作 | 两种合法节拍数 |
| `2015-43` | 单总线数据通路的结构问题 | 可见寄存器、ALUop 位数、SRop 位数、PC 增量 |
| `2015-44` | 三条指令的机器码，以及两条指令的执行拍数 | 指令条数、三组机器码、两个拍数 |
| `2022-43` | 标志、暂存器、寄存器个数、取指拍数 | SF、寄存器个数、取指时钟周期数 |
| `cycle` | 指令周期有哪些阶段 | 至少几个机器周期 |
| `2009-11` `2010-18` `2011-19` `2016-18` `2016-20` `2019-17` `2021-17` `2021-18` `2023-18` | 对应年份的选择题 | `结果：答案` 加选项字母 |

`prog` 后面先逐行写指令，单独一行 `end` 结束；再逐行写初值，再一行 `end`。初值可以是 `地址 值`，也可以是 `r0` 到 `r3` 再加一个值。

指令（操作码在高 4 位）：

| 指令 | 功能 |
|---|---|
| `nop` | 只做取指。PC 仍要加 1 |
| `lda 地址` | `M[地址]→ACC` |
| `sta 地址` | `ACC→M[地址]` |
| `add 地址` | `ACC+M[地址]→ACC`，并改 PSW |
| `jmp 地址` | `地址→PC` |
| `jz 地址` | ZF=1 时 `地址→PC` |
| `adm 寄存器` | `(R0)+M[(R寄存器)]` 写回那个主存单元，和也留在 ACC |
| `hlt` | 取指之后停机 |

地址是 0～255。主存 256 个字。从 0 号单元开始放指令。超过 32 条指令还没遇到 `hlt` 就停止。

每一拍一行：

```
阶段 C编号 功能 | 细节 | 控制信号 | 内总线驱动 n 个
```

阶段用「取指、译码、执行、访存、写回」这五个名字。每条指令的 C 编号从 1 重新数。一条指令做完打印一行 `状态`。

只有 `add` 和 `adm` 改 PSW。ZF 看结果是不是 0，SF 看结果符号，CF 看无符号进位，OF 看有符号溢出。

### 样例

输入：

```
prog
nop
hlt
end
end
```

输出：

```
模型：16 位字，按字编址，主存 256 字。取指 (PC)+1。单总线同一拍至多 1 个 out
【装入】
M[0] NOP 编码 0000H
M[1] HLT 编码 7000H
【执行】
取指 C1 (PC)->MAR | PC=0 MAR=0 | PCout MARin | 内总线驱动 1 个
取指 C2 M(MAR)->MDR (PC)+1->PC | MDR=0000H PC=1 | MemR MDRinE PC+1 | 内总线驱动 0 个
取指 C3 (MDR)->IR | IR=NOP | MDRout IRin | 内总线驱动 1 个
译码 C4 OP(IR)->CU | IR=NOP | 无 | 内总线驱动 0 个
执行 C5 空操作 | 取指已经把 PC 加 1 | 无 | 内总线驱动 0 个
状态 PC=1 ACC=0(0000H) R0=0 R1=0 R2=0 R3=0 ZF=0 SF=0 CF=0 OF=0 本条访存=1次
取指 C1 (PC)->MAR | PC=1 MAR=1 | PCout MARin | 内总线驱动 1 个
取指 C2 M(MAR)->MDR (PC)+1->PC | MDR=7000H PC=2 | MemR MDRinE PC+1 | 内总线驱动 0 个
取指 C3 (MDR)->IR | IR=HLT | MDRout IRin | 内总线驱动 1 个
译码 C4 OP(IR)->CU | IR=HLT | 无 | 内总线驱动 0 个
执行 C5 停机 | 不再取下一条 | 无 | 内总线驱动 0 个
状态 PC=2 ACC=0(0000H) R0=0 R1=0 R2=0 R3=0 ZF=0 SF=0 CF=0 OF=0 本条访存=1次
【写回的单元】
无
结果：ACC=0(0000H) 访存=2次 冲突=0次
```

空操作自己没有运算，取指仍然访问了一次主存，PC 也加了 1。
