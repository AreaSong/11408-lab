### 09 · 迷你 CPU 与数据通路
- **产出**：一个 5~8 条指令的迷你 CPU 模拟器（取指 → 译码 → 执行 → 访存 → 写回），trace 打印每条指令的微操作序列
- **小步骤**：① 设计指令格式和寄存器（PC、IR、MAR、MDR、ACC、PSW） ② 取指周期：PC → MAR → 存储器 → MDR → IR ③ 执行几条指令（加法、取数、存数、跳转） ④ 单总线数据通路：打印每一步的微操作和控制信号，检查同一时钟周期只有一个部件向总线输出
- **通过标准**：真题考法：给定数据通路图，写出某条指令的微操作序列和控制信号；指令周期分几个阶段
- **概念卡片**：CPU 的功能和基本结构（运算器、控制器包含哪些部件）
