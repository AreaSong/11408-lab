# co/10 · 控制器、异常与中断 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：硬布线控制器的真值表；把同一组控制信号写成微程序，并计算微指令字长和控存容量；一台带除零故障和外部中断的 16 位 CPU，按节拍打印断点
- **小步骤**：
  ① 硬布线：用节拍电位和操作码译码相与，得到每一拍的控制信号
  ② 微程序：把这组信号存成微指令。给定互斥分组、判别位数或后继微指令条数，求操作控制字段、下地址字段、微指令字长和控存容量
  ③ 除零是故障：在本条指令执行过程中响应，断点是本条的地址，处理完要能重新执行
  ④ 外部中断在每条指令执行结束时检查。可屏蔽中断看 IF，不可屏蔽中断不看 IF。响应时关中断、保存断点、把入口送入 PC
- **通过标准**：能算出微指令某个字段的位数；能判断一个事件是故障、陷阱、终止、可屏蔽中断还是不可屏蔽中断，以及什么时候响应、返回到哪里
- **概念卡片**（写进 `NOTES.md`）：硬布线控制器和微程序控制器怎么比；异常与中断怎么分类

本关有两个程序：`main.c` 编出的主程序（如 `controller_interrupt_answer`）、`test.c` 编出的单元测试（`controller_interrupt_answer_test`）。

王道第 5 章。玩具机按字编址，取指时 PC 加 1，操作码编号是本关自己的，不要和第 09 关的编码混用。取指三拍的顺序和第 09 关相同：内总线一个时钟周期只有一个输出，`MDRoutE` 走数据总线，`PC+1` 走增量器。

多重中断的屏蔽字、DMA 传送过程留到第 13 关。这里只做「一条请求在指令边界上进不进得来」。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每次读命令前用 `prompt("请输入命令：")` 提示。`prompt` 在 `deps/prompt.h`，跑测试时不打印。可以连续输入多条命令，Ctrl+D 结束。

`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。命令不合法时向 stderr 报错，并以非 0 退出。

主存 32 个字，指令和数据都是 16 位。操作码在高 4 位，地址在低 8 位。`NOP`、`TRAP`、`HLT`、`IRET`、`FAIL` 不使用地址。

| 指令 | 功能 |
|---|---|
| `NOP` | 只做取指 |
| `LDA 地址` | `M[地址]→ACC` |
| `STA 地址` | `ACC→M[地址]` |
| `ADD 地址` | `ACC+M[地址]→ACC`。先把主存数锁进暂存器 A |
| `DIV 地址` | 除数为 0 时发故障；否则 `ACC/M[地址]→ACC`，商只留整数 |
| `JMP 地址` | `地址→PC` |
| `TRAP` | 陷阱。断点是下一条，然后转到入口 |
| `HLT` | 取指之后停机，不再检查中断 |
| `IRET` | 断点送回 PC，IF 置 1，回到用户态 |
| `FAIL` | 终止。不保存可返回的断点，也不转到入口 |

取指和译码共四拍，对所有指令相同，和操作码无关：

| 节拍 | 动作 | 控制信号 |
|---|---|---|
| T0 | `(PC)→MAR` | `PCout MARin` |
| T1 | `M(MAR)→MDR`，`(PC)+1→PC` | `MemR MDRinE PC+1` |
| T2 | `(MDR)→IR` | `MDRout IRin` |
| T3 | 操作码送控制单元 | 无 |

执行从 T4 开始。`LDA`、`STA` 用到 T6，`ADD` 和除数非 0 的 `DIV` 用到 T7，其余指令只有 T4。除数为 0 时 `DIV` 的 T6 改为 `SavePC IFclr Vec`，没有 T7。`TRAP` 的 T4 也是这三个信号。`IRET` 的 T4 是 `SPCout PCin IFset`。`JMP` 的 T4 是 `IRout PCin`。`NOP` 和 `HLT` 的 T4 无信号。

内总线驱动只数 `PCout`、`MDRout`、`IRout`、`ACCout`、`SPCout`。每一拍这个数只能是 0 或 1。

### 命令

| 命令 | 做什么 | 结果行 |
|---|---|---|
| `wire` | 打印组合逻辑和真值表 | `结果：微命令 22 个` |
| `micro` | 把同一组信号写成微程序，并算字长和控存容量 | 直接编码字长、实际容量、字段编码字长、实际容量 |
| `field a b …` | 字段直接编码。每个数是一组互斥微命令的个数 | `结果：操作控制字段 n 位` |
| `next 指令数 公共条数 每条平均条数` | 断定法的下地址字段 | `结果：下地址字段 n 位` |
| `rom 字长 判别位数 组1 组2 …` | 已知字长，反推下地址，再算控存最大容量 | `结果：下地址字段 n 位，控存最大容量 m 位` |
| `class 名字` | 判断事件类别。名字见下表 | `结果：` 加类别 |
| `fault` `trap` `abort` `irq` `mask` `nmi` | 跑固定场景 | `结果：ACC=… PC=… 断点=… 响应=… 次 IF=…` |
| `2009-17` `2009-19` `2012-18` `2012-22` `2014-18` `2015-22` `2015-24` `2023-21` `2024-13` `2025-16` `2025-22` | 对应年份的选择题 | `结果：答案` 加选项字母 |

`class` 的名字：`div0` 除零，`page` 缺页，`syscall` 系统调用，`bkpt` 断点指令，`hw` 硬件故障，`io` I/O 完成，`nmi` 掉电，`dma` DMA 传送结束，`cache` Cache 缺失。

字段直接编码：每组 n 个微命令要留一个「不发微命令」的状态，字段位数是能表示 n+1 种状态的最少位数。输出里同时给出漏掉这个状态时的位数。

`next` 的微指令总数 = 指令数 × 每条平均条数 + 公共条数。下地址要能区分这么多条微指令。

`rom` 的下地址位数 = 字长 − 操作控制字段 − 判别位数。控存最大容量 = 2^下地址位数 × 字长，单位是位。判别位数按题目已经给出的位数用，不要再对它做一次 log。

`wire` 先逐行打印组合逻辑，再按指令打印真值表。每一拍一行：

```
T<编号> <取指|译码|执行> | <控制信号> | 内总线驱动 <n> 个
```

没有微命令时，控制信号写 `无`。`DIV` 要分「除数非 0」和「除数为 0」两段。

`micro` 每一行：

```
μ<序号> <指令名> <阶段> T<编号> | <控制信号> | 下地址 <下一序号>
```

取指和译码不写指令名。译码的下地址写 `由操作码形成`。`HLT` 的下地址写 `停止`。`DIV` 读完除数的那条，下地址写成 `17（除数为 0 则 19）` 这种样子。然后打印各指令微程序入口，以及直接编码、字段直接编码两种字长和控存容量。字段编码把 5 个内总线输出、`Add`/`Div`、`MemR`/`MemW` 分成三个互斥组，`MDRoutE` 留在直接编码里。判别字段固定 1 位。

场景开头先写标题、初态、要不要外部中断，再按地址列出指令和数据。每条指令以一行 `----` 开始。节拍行是：

```
T<编号> <阶段> <细节> | <控制信号> | 内总线驱动 <n> 个
```

阶段只用「取指、译码、执行」。取指 T1 的 MDR 写成 4 位十六进制加 `H`，数据仍然用十进制。

外部中断若在某条指令执行期间到达，写在该条的 `----` 之后、T0 之前：

```
中断请求到达 | 字地址 <地址> 执行期间 | 可屏蔽
```

不可屏蔽把最后一个词换成 `不可屏蔽`。

一条指令正常做完，且没有待处理的请求：

```
指令结束 下一条字地址 <PC> | 外部中断 无
```

有可屏蔽请求但 IF=0：

```
指令结束 下一条字地址 <PC> | 可屏蔽中断被 IF=0 挡住
```

请求被接受（可屏蔽且 IF=1，或不可屏蔽）：

```
指令结束 响应可屏蔽中断 | 断点 <PC> | 关中断 IF=0 内核态 | 入口 <入口> -> PC
```

不可屏蔽把「可屏蔽」换成「不可屏蔽」。断点是这条指令取指之后的 PC，也就是下一条。接受之后 IF 清 0，PC 改到入口。

除零不走上面的「指令结束」，改走：

```
异常 故障 除零 | 响应在本条指令执行过程中 | 断点 <本条>（取指后 PC 已是 <下一条>） | IF=0 内核态 | 入口 <入口> -> PC
```

断点是 `DIV` 自己的地址。`TRAP`：

```
异常 陷阱 系统调用 | 本条指令主动陷入 | 断点 <下一条> 是下一条 | IF=0 内核态 | 入口 <入口> -> PC
```

`FAIL`：

```
异常 终止 硬件故障 | 响应在译码时 | 不保存返回断点 | 不转到入口 | PC=<本条> IF=0 内核态
```

`HLT` 的 T4 之后另起一行 `停机`，不再检查中断。停机时 PC 已经在取指里加过 1。

六个场景的入口都是字地址 6。程序和数据如下。指令地址和数据地址不能是同一个单元。

| 命令 | 初态 | 程序和数据 | 要看的结果 |
|---|---|---|---|
| `fault` | IF=1，无外部中断 | `0 LDA 20`，`1 DIV 21`，`2 STA 22`，`3 HLT`；入口处 `6 STA 24`，`7 LDA 23`，`8 STA 21`，`9 LDA 24`，`10 IRET`。`M[20]=8`，`M[21]=0`，`M[23]=2` | 先故障，处理程序把除数改成 2 并恢复 ACC 后返回。`DIV` 重执行，商为 4。`ACC=4 PC=4 断点=1 响应=1 次 IF=1` |
| `trap` | IF=1，无外部中断 | `0 LDA 10`，`1 TRAP`，`2 HLT`，`6 NOP`，`7 IRET`。`M[10]=7` | 断点是 2，不是 1。返回后停机。`ACC=7 PC=3 断点=2` |
| `abort` | IF=1，无外部中断 | `0 FAIL` | 不转到入口 6。`PC=0 断点=0 响应=1 次 IF=0` |
| `irq` | IF=1，可屏蔽请求在字地址 1 执行期间到达 | `0 LDA 10`，`1 ADD 10`，`2 HLT`，`6 NOP`，`7 IRET`。`M[10]=5` | `ADD` 先做完，`ACC=10`，然后才响应。断点是 2 |
| `mask` | IF=0，可屏蔽请求在字地址 0 执行期间到达 | `0 NOP`，`1 NOP`，`2 HLT` | 两条 `NOP` 结束时都打印挡住。`响应=0 次 IF=0` |
| `nmi` | IF=0，不可屏蔽请求在字地址 0 执行期间到达 | `0 NOP`，`1 HLT`，`6 IRET` | IF=0 仍然响应。断点是 1，返回后停机 |

### 样例

输入：

```
field 8 4
```

输出：

```
【字段直接编码】
组 8 个微命令：状态数 9，2^3 = 8 不够，2^4 = 16 够，字段 4 位
组 4 个微命令：状态数 5，2^2 = 4 不够，2^3 = 8 够，字段 3 位
操作控制字段 4 位 + 3 位 = 7 位
漏掉不操作状态则是 3 位 + 2 位 = 5 位
结果：操作控制字段 7 位
```

`8` 和 `4` 都是 2 的幂，留不留「不操作」会差位数。`2012-18` 的五组恰好都不是 2 的幂，两种算法位数相同，输出里仍然要两行都写。
