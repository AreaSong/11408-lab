# co/11 · 指令流水线 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：一台 5 段流水线。能画理想流水线的时空图，并算出吞吐率、加速比、效率；能看出结构冒险、数据冒险、控制冒险，并按题目给定的办法插入阻塞或做转发
- **小步骤**：
  ① 各段时间相等、没有冒险：时空图、吞吐率、加速比、效率
  ② 指令和数据共用一个存储器时的结构冒险
  ③ 无转发时的数据冒险：先写后读，以及「同一拍不能又读又写」
  ④ 加上转发。ALU 结果可以提前送走；load 的下一条若在执行段就要用这个数，仍要停 1 拍
  ⑤ 控制冒险：分支一直阻塞到访存段结束；预测不转移；延迟槽
- **通过标准**：给定一段指令，能指出哪些是写后读，各停几拍，整段一共多少个时钟周期
- **概念卡片**（写进 `NOTES.md`）：超标量流水线和动态流水线

本关有两个程序：`main.c` 编出的主程序（如 `pipeline_answer`）、`test.c` 编出的单元测试（`pipeline_answer_test`）。

王道第 5 章。五段固定是 IF 取指、ID 译码并读寄存器、EX 执行或算地址、MEM 访存、WB 写回。只有 load 和 store 在 MEM 段真正访存，运算指令的 MEM 段只是把结果往后送。按序发射：前一条还停在 ID，后一条就不能进入 ID，它的 IF 会重复。

### 命令

| 命令 | 做什么 | 结果行 |
|---|---|---|
| `ideal k n dt 单位` | 理想流水线。`cycle` 表示时钟周期 | `结果：加速比 …，吞吐率 …，效率 …` |
| `freq k n 主频 MHz` | 无阻塞时的吞吐率，主频单位必须写 `MHz` | `结果：吞吐率 …` |
| `clock 段时间… 锁存 单位` | 时钟周期 = 最长段 + 段间锁存 | `结果：时钟周期 …` |
| `pipe 方式` 然后若干指令，单独一行 `.` | 按该方式跑这段指令 | 见下方 |
| `2009-18` 等题号 | 对应年份的题 | 选择题以 `结果：答案` 加字母结束 |

`ideal` 在指令数不超过 6、段数不超过 5 时要印时空图。5 段用 IF、ID、EX、MEM、WB；别的段数用 S1、S2……

流水线方式：

| 方式 | 数据 | 存储器 | 分支 |
|---|---|---|---|
| `half` | 不转发。WB 前半写、ID 后半读，同一拍可以读到刚写回的值 | 指令、数据分开 | 当普通指令 |
| `late` | 不转发。同一拍不能又读又写 | 分开 | 当普通指令 |
| `forward` | 转发 | 分开 | 当普通指令 |
| `branch` | 转发 | 分开 | 下一条要等这条分支的 MEM 结束才取指 |
| `half-branch` | 同 `half` | 分开 | 同 `branch` |
| `struct` | 转发 | 共用一个存储器 | 当普通指令 |
| `predict` | 转发 | 分开 | 预测不转移，EX 段末才知道。实际转移就冲刷已经取进 IF、ID 的指令 |
| `slot` | 转发 | 分开 | 紧跟着的一条是延迟槽，总是执行。ID 段末就能改 PC |

`pipe` 的结果行：

- 一般：`结果：阻塞 n 拍，共 m 个时钟周期`
- `predict`：`结果：冲刷 n 条，惩罚 p 拍，共 m 个时钟周期`
- `slot`：`结果：延迟槽惩罚 p 拍，共 m 个时钟周期`

阻塞拍数 = 实际周期 − 理想周期。理想周期按真正做完的指令数算，被冲刷或被跳过的不算。

### 指令

一行一条。逗号只是分隔。寄存器名字区分不开大小写，`R1` 和 `r1` 是同一个。

| 写法 | 谁写、谁读 |
|---|---|
| `add rd, rs, rt`，以及 `sub` `and` `or` | rd 写，rs 和 rt 在 EX 读。三个都是寄存器 |
| `add rd, rs, 立即数`、`addi rd, rs, 立即数` | rd 写，rs 在 EX 读 |
| `add rs, rd` | 只有两个寄存器时按 2012 年的定义：(rs)+(rd)→rd。rd 既读又写 |
| `sll rd, rs, 立即数` | rd 写，rs 在 EX 读 |
| `shl rd` | rd 左移，rd 既读又写 |
| `load rd, [x]` | rd 写，不读寄存器，MEM 段访存 |
| `load rd, 0(rs)` | rd 写，rs 在 EX 算地址，MEM 段访存 |
| `store rs, [x]` | 不写寄存器，rs 是要存的数，MEM 段访存 |
| `store rs, 0(rt)` | rs 是要存的数，rt 在 EX 算地址 |
| `beq rs, rt, 标号`、`bne` | 不写寄存器，rs 和 rt 在 EX 读。标号写 `not` 表示实际不转移 |
| `nop` | 什么寄存器都不碰 |
| `标号: 指令` | 标号记在这条指令上 |

`predict` 和 `slot` 里，实际转移的标号必须在后面某条指令上出现。`not` 表示沿着顺序往下做。

转发时：ALU 的结果在 EX 段末就可以送给下一条的 EX。load 的数要到 MEM 段末才有；下一条若在 EX 段就要用它（算地址、做运算、做比较），必须再停 1 拍，然后从 MEM/WB 转过去。store 要存的那个数可以晚到 MEM 段才用。不转发时，不管是运算还是 store，都要等数进了寄存器、ID 读得到。

结构冒险只发生在「某条 load/store 正在 MEM」和「另一条正在 IF」同一拍。运算指令的 MEM 不访存，不抢。

### 样例

输入：

```
ideal 5 4 1 cycle
```

输出：

```
【理想流水线】
k = 5 段，n = 4 条，Δt = 1 个时钟周期
各段时间相等，连续流入，没有冒险
流水线时间 Tk = (5 + 4 - 1) × 1 个时钟周期 = 8 个时钟周期
顺序执行 T0 = 4 × 5 × 1 个时钟周期 = 20 个时钟周期
加速比 S = T0 / Tk = 5/2
吞吐率 TP = 4 条 / 8 个时钟周期
最大吞吐率 TPmax = 1 / 1 个时钟周期
效率 E = 有效格 / 总格 = (4 × 5) / (5 × 8) = 1/2
n 很大时加速比接近 5，效率接近 1
时空图
时钟    1    2    3    4    5    6    7    8
I1     IF   ID   EX  MEM   WB
I2          IF   ID   EX  MEM   WB
I3               IF   ID   EX  MEM   WB
I4                    IF   ID   EX  MEM   WB
结果：加速比 5/2，吞吐率 4 条/8 个时钟周期，效率 1/2
```

时空图里空着的格子可以留空格。测试比对时会去掉行尾空白。
