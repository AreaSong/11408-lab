### 01 · 数的编码、对齐与大小端
- **产出**：进制转换器（含小数）；原码、反码、补码、移码互转；符号扩展与零扩展；大端/小端打印；结构体对齐计算器
- **小步骤**：① 二、八、十、十六进制互转，含小数部分 ② 四种编码互转 ③ 表示范围计算 ④ 用 C 的指针逐字节打印内存，**亲眼看本机是小端** ⑤ 对齐：手算几个 `struct` 的大小和各成员偏移，再用 `sizeof`、`offsetof` 验证
- **通过标准**：真题考法：某个数的补码/移码、n 位补码的表示范围、一个 int 在大端/小端机器上各字节的地址、按边界对齐时结构体占多少字节
- **概念卡片**：四种编码的对比（0 的表示、范围、用途）
