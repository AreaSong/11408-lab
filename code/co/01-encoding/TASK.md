# co/01 · 数的编码、对齐与大小端 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：进制转换（含小数）；原码、反码、补码、移码互转；符号扩展与零扩展；大端/小端逐字节打印；按边界对齐计算结构体的大小和成员地址
- **小步骤**：
  ① 二、八、十、十六进制互转，整数用除法取余，小数用乘法取整
  ② 四种编码互转，能处理 0 和最小负数
  ③ 算 n 位整数、定点小数的表示范围
  ④ 给定机器数，按大端或小端列出每个地址上的字节；再用指针看本机内存
  ⑤ 按边界对齐手算结构体，再用本机的 `sizeof`、`offsetof` 核对
- **通过标准**：某个数的补码/移码、n 位补码的表示范围、一个数在大端/小端下各字节的地址、按边界对齐时结构体占多少字节
- **概念卡片**（写进 `NOTES.md`）：四种编码的对比（0 的表示、范围、用途）

本关有三个程序：`main.c` 编出的主程序（如 `encoding_answer`）、`test.c` 编出的单元测试（`encoding_answer_test`）、`native.c` 编出的本机观察程序（`encoding_answer_native`）。最后一个的输出依赖本机，记录在 `EXPERIMENTS.md`，不进 `tests/`。

王道第 2 章的定点数编码，加上第 4 章的数据对齐和大/小端。整数移码的偏置是 2^(n−1)，小数移码的偏置是 1。IEEE 754 阶码的偏置是 2^(k−1)−1，那是第 04 关。

卷面按 32 位机器：`char` 1 字节、`short` 2、`int`/`long`/`float` 4、`double` 8。对齐数等于类型自身的大小，`char` 数组的对齐数仍是 1。结构体大小补到最大对齐数的倍数。本机是 64 位，`long` 和指针是 8 字节，和卷面不一样，以计算器里的 32 位模型为准。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每条命令打印一块推导，最后一行以 `结果：` 开头。`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

读之前用 `prompt(...)` 提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。

### 写法

- 进制只允许 2、8、10、16。机器数写成二进制（必须写满字长，例如 8 位的 `11010011`），或十六进制（`D3H`、`0xD3` 都可以）
- 地址一律十六进制，`C008`、`0xC008`、`0000C008H` 是同一个地址
- 十进制真值可以带负号和一个小数点。`base` 里的负号只表示这个数是负的，不是补码
- 成员赋值：`=273` 是十进制真值，按补码存进该成员；`=12340000H` 是已经编好的机器数。等号两边不要加空格
- `float`、`double` 以及超过 4 字节的成员，这里只接受带 `H` 的机器数

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `base` | 源进制、目标进制、小数最多保留几位、数值 | 转换结果。2/8/16 互转按位分组；从十进制转出用除法取余和乘法取整；转入十进制按权展开 |
| `code int` | 位宽、整数真值 | 原码、反码、补码、移码。表示不了就要写明 |
| `code frac` | 位宽（含符号位）、定点小数真值 | 同上，小数点紧挨在符号位后面 |
| `decode` | `int` 或 `frac`、位宽、`orig`/`ones`/`comp`/`bias`/`unsigned`、机器数 | 真值，以及另外三种编码 |
| `range` | `int` 或 `frac`、位宽 | 无符号、原码、反码、补码、移码的范围 |
| `retype` | 源是 `signed` 还是 `unsigned`、目标是哪一种、源位宽、目标位宽、真值 | 加宽或截断后的机器数和真值。加宽按源类型补位 |
| `extend orig` | 源位宽、目标位宽、原码机器数 | 原码扩展后的机器数。不要把符号位复制到中间 |
| `sum` | 位宽、两个补码机器数 | 低位上的和。最高位进位丢掉，标志位留到下一关 |
| `cmp` | 位宽、x y z 三个机器数 | 按无符号和按补码各自的大小顺序 |
| `endian` | `le`/`be`/`both`、首地址、字节数、机器数，可选一个要查的地址 | 从低地址到高地址的每个字节；查了地址就写出那个字节 |
| `align` | 首地址、`le` 或 `be`，可选 `index <下标>`、`find <字节>`；接着每行一个成员，最后一行 `end` | 每个成员的地址；给了 `find` 就写出该字节的地址；否则如果首地址上有数据，写出那个字节 |

`align` 的下标从 0 开始，和 C 的数组一样。`find` 后面是十六进制字节，`34` 就是 34H。类型可以用 `char`、`short`、`int`、`float`、`long`、`double`，数组写成 `char name[10]`。

位宽 2 到 32。`endian` 的机器数最多 8 字节。

### 样例

输入：

```
base 10 2 8 13.75
```

输出：

```
【十进制转二进制】13.75
整数部分 13，除 2 取余，先得到的余数是低位：
13 ÷ 2 = 6 余 1
6 ÷ 2 = 3 余 0
3 ÷ 2 = 1 余 1
1 ÷ 2 = 0 余 1
余数从下往上读
小数部分 0.75，乘 2 取整，先得到的是高位，最多 8 位：
0.75 × 2 取 1，余 0.5
0.5 × 2 取 1，余 0
正好除尽
结果：1101.11
```

## 四、真题题面

下列各题都是单项选择题。把数代进上一节的命令，结果行应和标准选项一致。

A. x=0000007FH，y=FFF9H，z=00000076H

B. x=0000007FH，y=FFF9H，z=FFFF0076H

C. x=0000007FH，y=FFF7H，z=FFFF0076H

D. x=0000007FH，y=FFF7H，z=00000076H

**2012-13** 假定编译器规定 int 和 short 型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c

```

得到 y 的机器数为（ ）。

A. 0000 7FFAH　B. 0000 FFFAH　C. FFFF 7FFAH　D. FFFF FFFAH

**2012-15** 某计算机存储器按字节编址，采用小端方式存放数据。假定编译器规定 int 型和 short 型长度分别为 32 位和 16 位，并且数据按边界对齐存储。某 C 语言程序段如下：

```c
struct {
    int a;
    char b;
    short c;

record.a = 273;
```

A. 0x00、0xC00D　B. 0x00、0xC00E　C. 0x11、0xC00D　D. 0x11、0xC00E

**2016-14** 某计算机字长为 32 位，按字节编址，采用小端（Little Endian）方式存放数据。假定有一个 double 型变量，其机器数表示为 1122 3344 5566 7788H，存放在 0000 8040H 开始的连续存储单元中，则存储单元 0000 8046H 中存放的是（ ）。

A. 22H　B. 33H　C. 66H　D. 77H

**2020-14** 在按字节编址、采用小端方式的 32 位计算机中，按边界对齐方式为以下 C 语言结构型变量 a 分配存储空间。

A. 2020FE03H　B. 2020FE04H　C. 2020FE05H　D. 2020FE06H

**2021-13** 已知带符号整数用补码表示，变量 x、y、z 的机器数分别为 FFFDH、FFDFH、7FFCH，下列结论中，正确的是（ ）。
