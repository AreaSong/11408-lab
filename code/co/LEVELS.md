# 计算机组成原理 · 关卡任务详情

> 考查范围以 **2027 年 408 统考大纲**为准（与 2026 版无变动），逐条对照见文末「大纲覆盖对照」；具体约定以王道为准。

## 贯穿全程的设计

### 1. 「计算器」对接计算题
计组的大题和选择题大量是**计算**：CPI 与执行时间、Cache 地址划分与命中率、存储器扩展的地址范围、流水线吞吐率、DMA 占用 CPU 的时间比例……
→ 每关都要写一个**带单位的计算器**：输入题目参数，按考纲公式一步步打印推导过程和结果，拿真题数据直接对答案。

### 2. 「模拟器」对接过程题
Cache 命中/缺失序列、流水线时空图、指令执行的微操作序列、多重中断的执行顺序……
→ 这些用**模拟器 + trace 打印**，每一步状态都打出来，和真题答案逐步对照。

### 3. 用 `clang` 看真实汇编
408 会考**读 x86 汇编**（过程调用、栈帧、条件转移），真题用的是 **32 位 Intel 语法**（如 `push ebp`、`mov ebp, esp`）。你的电脑是 arm64，但 `clang` 可以直接生成这种汇编：
`clang -target i386-pc-linux-gnu -m32 -O0 -masm=intel -fno-pic -fno-asynchronous-unwind-tables -S demo.c -o demo.s`
→ 写一段 C，生成汇编，对照着读，比硬看书直观得多。这条命令**只生成汇编、不能链接运行**；后两个选项用来去掉与考题无关的调试伪指令和取地址代码。

### 4. 「概念卡片」对接概念题
存储器分类、CISC 与 RISC、多处理器分类这类内容写不成代码。
→ 每关列出的**概念卡片**写进该关 `NOTES.md` 的「概念卡片」一节：一张卡片 = 一张对比表或一张图。

## 各关详情

### 00 · 性能指标与程序的执行过程
- **产出**：性能计算器：输入主频、CPI、指令条数等，计算执行时间、MIPS、加速比，以及 MFLOPS 到 ZFLOPS 的单位换算；一份"从 `hello.c` 到可执行文件"的实验记录
- **知识点**：冯·诺依曼结构与"存储程序"；硬件五大部件；软件与硬件的关系；主频与时钟周期、CPI、MIPS、CPU 执行时间、吞吐量与响应时间、Amdahl 定律
- **小步骤**：① 基本公式 ② 多类指令加权平均 CPI ③ 改进前后的加速比 ④ FLOPS 系列单位换算（M、G、T、P、E、Z 依次是 10⁶ 到 10²¹） ⑤ 用 `clang -E`、`-S`、`-c` 和链接，分别生成 `.i`、`.s`、`.o` 和可执行文件，用 `nm` 看 `.o` 里哪些符号还没解析，体会编译器、汇编器、链接器各做了什么
- **通过标准**：真题考法：给定各类指令占比与 CPI，求平均 CPI、执行时间或 MIPS（**注意 M 是 10⁶ 而不是 2²⁰**）；高级语言程序转换成机器语言要经过哪几步
- **概念卡片**：冯·诺依曼结构的特点；计算机系统的层次结构；吞吐量 vs 响应时间

### 01 · 数的编码、对齐与大小端
- **产出**：进制转换器（含小数）；原码、反码、补码、移码互转；符号扩展与零扩展；大端/小端打印；结构体对齐计算器
- **小步骤**：① 二、八、十、十六进制互转，含小数部分 ② 四种编码互转 ③ 表示范围计算 ④ 用 C 的指针逐字节打印内存，**亲眼看本机是小端** ⑤ 对齐：手算几个 `struct` 的大小和各成员偏移，再用 `sizeof`、`offsetof` 验证
- **通过标准**：真题考法：某个数的补码/移码、n 位补码的表示范围、一个 int 在大端/小端机器上各字节的地址、按边界对齐时结构体占多少字节
- **概念卡片**：四种编码的对比（0 的表示、范围、用途）

### 02 · 定点运算：加减乘除与标志位
- **产出**：用位运算搭的加法器；补码加减法器，输出结果和 **ZF、SF、CF、OF 四个标志位**；算术移位与逻辑移位；原码一位乘、补码一位乘（Booth）、加减交替法除法的分步 trace
- **小步骤**：① 用位运算写一位全加器，串成 n 位串行进位加法器，再写一个简单 ALU（加、减、与、或） ② 补码加减 ③ 溢出判断（双符号位、最高位进位异或次高位进位） ④ 标志位生成 ⑤ 无符号整数与带符号整数：C 语言中有符号与无符号混合运算、截断与扩展的结果（**真题高频陷阱**） ⑥ 移位运算 ⑦ 原码一位乘、补码一位乘，trace 打印每一步的部分积与乘数 ⑧ 除法（加减交替法），trace 打印每一步的余数与商
- **通过标准**：真题考法：两个数相加后各标志位的值、`unsigned` 与 `int` 比较或转换后的结果、移位后的值、乘除运算某一步的中间结果
- **概念卡片**：串行进位 vs 先行进位；乘法电路和除法电路的基本结构（哪些寄存器、每步做什么）

### 03 · IEEE 754 浮点数
- **产出**：单精度浮点数编码器和解码器（用 C 的 `union` 对照验证）；浮点加减运算的分步 trace
- **小步骤**：① 编码：符号、阶码（偏置 127）、尾数（隐含 1） ② 解码，包括 ±0、无穷大、NaN、非规格化数 ③ 浮点加减：对阶 → 尾数相加 → 规格化 → 舍入 → 判溢出 ④ 双精度的字段划分，以及 `int`、`float`、`double` 互转时哪些会丢精度
- **通过标准**：真题考法：某个十进制数的 IEEE 754 十六进制表示、给定机器码求真值、float 转 int 时的精度问题

### 04 · 半导体存储器、主存与磁盘
- **产出**：存储器扩展计算器：给定芯片规格和目标容量，输出需要的芯片数、扩展方式、每组芯片的地址范围；DRAM 刷新计算器；磁盘性能计算器
- **小步骤**：① DRAM：行列地址复用时的地址引脚数，集中、分散、异步三种刷新方式的刷新间隔与死时间 ② 位扩展、字扩展、字位同时扩展 ③ 片选译码与地址范围（主存和 CPU 之间的连接） ④ 多模块存储器：高位交叉与低位交叉，连续访问的时间与带宽 ⑤ 磁盘：容量、平均存取时间（寻道 + 旋转延迟 + 传输）、数据传输率
- **通过标准**：真题考法：用某种芯片组成某容量的存储器，求芯片数和某片的地址范围；交叉存储器连续访问的时间；磁盘的平均存取时间
- **概念卡片**：存储器的分类（按介质、存取方式、可改写性）；层次化存储器的结构与局部性原理；SRAM vs DRAM；Flash 与 SSD 的读写特性（按页读写、按块擦除、磨损均衡）；DRAM 芯片与内存条的关系

### 05 · Cache 模拟器
- **产出**：Cache 模拟器：支持直接映射、全相联、组相联；LRU/FIFO 替换；写回/写直达；输出每次访问命中还是缺失
- **小步骤**：① 地址划分：标记 | 组号 | 块内偏移 ② 直接映射 ③ 组相联 + LRU（可复用 lib 的双向链表） ④ 写策略与脏位（写命中：写直达、写回；写缺失：写分配、非写分配） ⑤ Cache 总容量计算（含标记位、有效位、脏位、LRU 位） ⑥ **把一段 C 二重循环生成的地址序列喂给模拟器**，比较按行访问和按列访问的命中率
- **通过标准**：真题考法：主存地址的各字段位数、Cache 总容量、给定数组访问顺序求命中率
- **概念卡片**：三种映射方式对比；写策略的搭配

### 06 · 虚拟存储与地址翻译
- **产出**：把 TLB、页表、Cache 串起来的地址翻译器，trace 打印一次访存经过的每一步
- **小步骤**：① 虚拟地址拆分为页号和页内偏移 ② 页表查找 ③ 加入 TLB ④ 物理地址再进 Cache（复用第 05 关）
- **通过标准**：真题考法：给定虚拟地址、页表和 TLB 内容，求物理地址以及是否命中 TLB、Cache、是否缺页
- **概念卡片**：页式、段式、段页式虚拟存储器的基本原理对比
- **备注**：和 OS 第 06 关讲的是同一件事，计组侧重硬件过程，OS 侧重管理策略

### 07 · 指令系统与 x86 汇编
- **产出**：扩展操作码设计验证器；寻址方式有效地址计算器；用 `clang` 生成 32 位 x86 汇编并做阅读笔记
- **小步骤**：① 指令格式：零、一、二、三地址指令 ② 扩展操作码：给定指令字长和各类指令条数，验证编码是否可行 ③ 各种寻址方式的有效地址计算（相对寻址注意 PC 已自增） ④ 写 C 的 `if`、循环、函数调用，生成汇编，标注栈帧变化、参数传递和条件转移所用的标志位
- **通过标准**：真题考法：扩展操作码最多能有多少条指令、某寻址方式的有效地址、读一段 x86 汇编说出它对应的 C 代码或某条指令执行后寄存器的值
- **概念卡片**：指令系统的基本概念（指令集体系结构 ISA）；CISC vs RISC；基址寻址 vs 变址寻址

### 08 · 迷你 CPU、数据通路与异常
- **产出**：一个 5~8 条指令的迷你 CPU 模拟器（取指 → 译码 → 执行 → 访存 → 写回），trace 打印每条指令的微操作序列；加入异常和中断检测
- **小步骤**：① 设计指令格式和寄存器（PC、IR、MAR、MDR、ACC、PSW） ② 取指周期：PC → MAR → 存储器 → MDR → IR ③ 执行几条指令（加法、取数、存数、跳转） ④ 单总线数据通路：打印每一步的微操作和控制信号，检查同一时钟周期只有一个部件向总线输出 ⑤ 微程序控制器计算：给定微命令数、互斥分组和后继地址数，求微指令字长和控制存储器容量 ⑥ 异常和中断：模拟器里加入除零异常和外部中断请求，在每条指令执行结束时检查中断，trace 打印断点保存和跳转
- **通过标准**：真题考法：给定数据通路图，写出某条指令的微操作序列和控制信号；指令周期分几个阶段；微指令字段的位数；某事件属于哪类异常、何时被响应
- **概念卡片**：CPU 的功能和基本结构（运算器、控制器包含哪些部件）；硬布线控制器 vs 微程序控制器；异常与中断的分类（故障、陷阱、终止 vs 可屏蔽、不可屏蔽）

### 09 · 指令流水线与多处理器
- **产出**：5 段流水线模拟器，打印**时空图**；检测数据冒险、控制冒险，并模拟转发和阻塞
- **小步骤**：① 理想流水线的时空图与吞吐率、加速比、效率 ② 结构冒险 ③ 数据冒险检测与阻塞 ④ 加入转发 ⑤ 控制冒险（分支） ⑥（选做）用 `arm_neon.h` 写一个向量加法，和普通循环对比耗时，体会 SIMD
- **通过标准**：真题考法：给定一段指令序列，判断哪些指令之间有数据相关、需要阻塞几个周期、总共需要多少个时钟周期
- **概念卡片**：超标量 vs 动态流水线；SISD、SIMD、MIMD 与向量处理器；硬件多线程（细粒度、粗粒度、同时多线程）；多核处理器与共享内存多处理器 SMP

### 10 · 总线与 I/O 方式
- **产出**：总线带宽计算器；I/O 方式 CPU 占用率计算器（程序查询、中断、DMA）；多重中断执行顺序模拟器（含屏蔽字）
- **小步骤**：① 总线带宽，以及突发传送下一次总线事务的时间 ② 三种 I/O 方式下 CPU 用于 I/O 的时间占比 ③ 中断响应过程与中断处理过程（中断隐指令做什么、中断服务程序做什么） ④ 多重中断：根据屏蔽字 trace 打印 CPU 的执行序列 ⑤ DMA 传送过程：预处理、数据传送、后处理
- **通过标准**：真题考法：DMA 方式下 CPU 用于 I/O 的时间百分比、给定屏蔽字后中断服务程序的执行顺序、总线带宽
- **概念卡片**：总线的组成与分类；总线定时方式（同步、异步、半同步、分离式）；I/O 接口的功能和基本结构；I/O 端口的统一编址 vs 独立编址；程序中断 vs DMA

## 大纲覆盖对照（2027 年 408 大纲 · 计算机组成原理）

> 每个条目后面是落在哪一关；「卡片」表示以概念卡片为主。

- **一、计算机系统概述**：（一）系统的基本组成、硬件的基本结构、软硬件关系 → 00 卡片；工作原理（存储程序、高级语言到机器语言的转换、程序和指令的执行过程） → 00；（二）性能指标（含 MFLOPS 到 ZFLOPS） → 00
- **二、数据的表示和运算**：（一）进位计数制、定点数的编码 → 01；（二）加法器与 ALU、补码加减运算器与标志位、乘除法的基本原理与电路结构 → 02；（三）无符号整数、带符号整数的表示和运算 → 01、02；（四）IEEE 754、浮点加减 → 03
- **三、存储器层次结构**：（一）存储器的分类、（二）层次化存储器的基本结构 → 04 卡片；（三）SRAM、DRAM、Flash → 04；（四）DRAM 芯片和内存条、多模块存储器、主存和 CPU 的连接 → 04；（五）磁盘存储器 → 04，固态硬盘 → 04 卡片；（六）Cache → 05；（七）虚拟存储器（页式、段式、段页式、TLB） → 06
- **四、指令系统**：（一）基本概念 → 07 卡片；（二）指令格式、（三）寻址方式 → 07；（四）数据的对齐和大/小端存放 → 01；（五）CISC 和 RISC → 07 卡片；（六）编译器、汇编器和链接器 → 00，选择、循环、过程调用的机器级表示 → 07
- **五、中央处理器**：（一）CPU 的功能和基本结构、（二）指令执行过程、（三）数据通路、（四）控制器 → 08；（五）异常和中断机制 → 08；（六）流水线、三种冒险 → 09，超标量和动态流水线 → 09 卡片；（七）多处理器的基本概念 → 09 卡片
- **六、总线和输入/输出系统**：（一）总线的基本概念、组成及性能指标、总线事务和定时 → 10；（二）I/O 接口的功能和结构、端口及编址 → 10 卡片；（三）程序查询、程序中断、DMA → 10
