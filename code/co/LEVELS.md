# 计算机组成原理 · 关卡任务详情

## 贯穿全程的设计

### 1. 「计算器」对接计算题
计组的大题和选择题大量是**计算**：CPI 与执行时间、Cache 地址划分与命中率、存储器扩展的地址范围、流水线吞吐率、DMA 占用 CPU 的时间比例……
→ 每关都要写一个**带单位的计算器**：输入题目参数，按考纲公式一步步打印推导过程和结果，拿真题数据直接对答案。

### 2. 「模拟器」对接过程题
Cache 命中/缺失序列、流水线时空图、指令执行的微操作序列、多重中断的执行顺序……
→ 这些用**模拟器 + trace 打印**，每一步状态都打出来，和真题答案逐步对照。

### 3. 用 `clang` 看真实汇编
408 会考**读 x86 汇编**（过程调用、栈帧、条件转移）。你的电脑是 arm64，但 `clang` 可以直接生成 x86 汇编：
`clang -target x86_64-apple-macos -O0 -S demo.c -o demo.s`
→ 写一段 C，生成汇编，对照着读，比硬看书直观得多。

## 各关详情

### 00 · 性能指标计算器
- **产出**：输入主频、CPI、指令条数等，计算执行时间、MIPS、加速比
- **知识点**：主频与时钟周期、CPI、MIPS、CPU 执行时间公式、Amdahl 定律
- **小步骤**：① 基本公式 ② 多类指令加权平均 CPI ③ 改进前后的加速比
- **通过标准**：真题考法：给定各类指令占比与 CPI，求平均 CPI、执行时间或 MIPS（**注意 M 是 10⁶ 而不是 2²⁰**）

### 01 · 数的编码与表示
- **产出**：原码、反码、补码、移码互转；符号扩展与零扩展；大端/小端打印
- **小步骤**：① 四种编码互转 ② 表示范围计算 ③ 用 C 的指针逐字节打印内存，**亲眼看本机是小端**
- **通过标准**：真题考法：某个数的补码/移码、n 位补码的表示范围、一个 int 在大端/小端机器上各字节的地址

### 02 · 定点运算与标志位
- **产出**：补码加减法器，输出结果和 **ZF、SF、CF、OF 四个标志位**；算术移位与逻辑移位
- **小步骤**：① 补码加减 ② 溢出判断（双符号位、最高位进位异或次高位进位） ③ 标志位生成 ④ C 语言中有符号与无符号混合运算的结果（**真题高频陷阱**）
- **通过标准**：真题考法：两个数相加后各标志位的值、`unsigned` 与 `int` 比较或转换后的结果、移位后的值

### 03 · IEEE 754 浮点数
- **产出**：单精度浮点数编码器和解码器（用 C 的 `union` 对照验证）；浮点加减运算的分步 trace
- **小步骤**：① 编码：符号、阶码（偏置 127）、尾数（隐含 1） ② 解码，包括 ±0、无穷大、NaN、非规格化数 ③ 浮点加减：对阶 → 尾数相加 → 规格化 → 舍入 → 判溢出
- **通过标准**：真题考法：某个十进制数的 IEEE 754 十六进制表示、给定机器码求真值、float 转 int 时的精度问题

### 04 · 主存与存储器扩展
- **产出**：存储器扩展计算器：给定芯片规格和目标容量，输出需要的芯片数、扩展方式、每组芯片的地址范围
- **小步骤**：① 位扩展、字扩展、字位同时扩展 ② 片选译码与地址范围 ③ 多模块交叉存储器的带宽计算
- **通过标准**：真题考法：用某种芯片组成某容量的存储器，求芯片数和某片的地址范围；交叉存储器连续访问的时间

### 05 · Cache 模拟器
- **产出**：Cache 模拟器：支持直接映射、全相联、组相联；LRU/FIFO 替换；写回/写直达；输出每次访问命中还是缺失
- **小步骤**：① 地址划分：标记 | 组号 | 块内偏移 ② 直接映射 ③ 组相联 + LRU（可复用 lib 的双向链表） ④ 写策略与脏位 ⑤ Cache 总容量计算（含标记位、有效位、脏位、LRU 位） ⑥ **把一段 C 二重循环生成的地址序列喂给模拟器**，比较按行访问和按列访问的命中率
- **通过标准**：真题考法：主存地址的各字段位数、Cache 总容量、给定数组访问顺序求命中率

### 06 · 虚拟存储与地址翻译
- **产出**：把 TLB、页表、Cache 串起来的地址翻译器，trace 打印一次访存经过的每一步
- **小步骤**：① 虚拟地址拆分为页号和页内偏移 ② 页表查找 ③ 加入 TLB ④ 物理地址再进 Cache（复用第 05 关）
- **通过标准**：真题考法：给定虚拟地址、页表和 TLB 内容，求物理地址以及是否命中 TLB、Cache、是否缺页
- **备注**：和 OS 第 06 关讲的是同一件事，计组侧重硬件过程，OS 侧重管理策略

### 07 · 指令系统与 x86 汇编
- **产出**：扩展操作码设计验证器；寻址方式有效地址计算器；用 `clang` 生成 x86 汇编并做阅读笔记
- **小步骤**：① 扩展操作码：给定指令字长和各类指令条数，验证编码是否可行 ② 各种寻址方式的有效地址计算 ③ 写 C 函数调用、`if`、循环，生成 x86 汇编，标注栈帧变化和条件转移所用的标志位
- **通过标准**：真题考法：扩展操作码最多能有多少条指令、某寻址方式的有效地址、读一段 x86 汇编说出它对应的 C 代码或某条指令执行后寄存器的值

### 08 · 迷你 CPU 与数据通路
- **产出**：一个 5~8 条指令的迷你 CPU 模拟器（取指 → 译码 → 执行 → 访存 → 写回），trace 打印每条指令的微操作序列
- **小步骤**：① 设计指令格式和寄存器 ② 取指周期：PC → MAR → 存储器 → MDR → IR ③ 执行几条指令（加法、取数、存数、跳转） ④ 打印每一步的微操作和控制信号 ⑤（理解层面）硬布线控制器与微程序控制器的区别
- **通过标准**：真题考法：给定数据通路图，写出某条指令的微操作序列和控制信号；指令周期分几个阶段

### 09 · 指令流水线
- **产出**：5 段流水线模拟器，打印**时空图**；检测数据冒险、控制冒险，并模拟转发和阻塞
- **小步骤**：① 理想流水线的时空图与吞吐率、加速比、效率 ② 数据冒险检测与阻塞 ③ 加入转发 ④ 控制冒险（分支）
- **通过标准**：真题考法：给定一段指令序列，判断哪些指令之间有数据相关、需要阻塞几个周期、总共需要多少个时钟周期

### 10 · 总线与 I/O 方式
- **产出**：总线带宽计算器；I/O 方式 CPU 占用率计算器（程序查询、中断、DMA）；多重中断执行顺序模拟器（含屏蔽字）
- **小步骤**：① 总线带宽 ② 三种 I/O 方式下 CPU 用于 I/O 的时间占比 ③ 中断响应过程 ④ 多重中断：根据屏蔽字 trace 打印 CPU 的执行序列
- **通过标准**：真题考法：DMA 方式下 CPU 用于 I/O 的时间百分比、给定屏蔽字后中断服务程序的执行顺序
