## 思路

页式地址从高到低是虚页号、页内偏移。页内偏移的位数 = log2(页字节数)。虚页号 = 虚拟地址位数 − 页内偏移。页框号 = 物理地址位数 − 页内偏移。页框号由主存有多大决定，不由虚拟地址有多长决定。

物理地址 = 页框号拼上原来的页内偏移。存在位为 0 时这一页不在主存，翻译停住，没有物理地址，也不查 Cache。

TLB 是页表项的副本，用 SRAM。查找只用虚页号：全相联时标记就是整个虚页号；组相联时虚页号的低位是组号，高位是标记。有效位为 0 只说明这项空着，即使标记碰巧相同也不算命中，更不能据此判缺页。命中则直接拿到页框号。缺失才去主存查页表；页表命中后，硬件会把这项装进 TLB。

物理地址再按第 06 关拆成标记、组号、块内偏移。Cache 命中要标记相同而且有效位为 1。Cache 缺失只说明这一块不在 Cache 里，页已经在主存。组号和块内偏移如果都落在页内偏移里面，虚地址和物理地址的这几位相同，可以不先知道页框号。

段式：物理地址 = 段基址 + 段内偏移，偏移 ≥ 段长则越界。段页式先看页号有没有超出这一段的页数，再看存在位，最后才是页框号拼页内偏移。

## 易错点

1. **2013 年的虚页号是 03FFFH，不是 03FFF1H。** 页 4 KB，页内偏移 12 位，就是末尾 3 个十六进制数字 180H。虚页号 03FFFH 对上最后一项，有效位 1，页框号 0153H，物理地址 0153180H，选项 A。若把偏移只切掉 8 位，虚页号变成 03FFF1H，会命中页框号 0035H，得到选项 B。有效位为 0 的项不能选 D。
2. **2022 年页表的虚页号是十进制。** 00082840H 的高 20 位是 00082H，等于 130，不是 82。第 130 项存在位 1，页框号 018H，物理地址 018840H，选项 C。82 那一项存在位是 0，查错行会选 D。129 的页框号 180H 会得到选项 B。
3. **2011 年的 Cache 行号是 3，不是 4。** 物理地址 04C60H 的低 5 位是块内偏移，往上 3 位是 011B，行号 3。这一行标记 105H，和 04CH 不同，缺失。第 4 行的标记是 064H，拿去比也会不等，所以行号算错仍可能得到「不命中」，理由里的行号只有 3 是对的。行号从 0 开始。
4. **TLB 有效位为 0 不是缺页。** 标记相同只说明这项曾经可能装过，有效位是 0 就当空项，接着查页表。页表存在位为 1 仍能得到物理地址。缺页只看页表的存在位。`practice-path` 的第一段就是这个顺序。
5. **2018 年第二问不用先翻译。** 页内偏移 12 位，Cache 的组号加块内偏移只有 8 位，落在页内偏移里。0007C260H 的这 8 位给出组号 3。标记还要看页框号，这问没要标记。
6. **TLB 标记来自虚页号，不是页框号。** 2024 年虚页号 32−10=22 位，32 项 4 路是 8 组，组号 3 位，标记 22−3=19。页框号是 30−10=20 位，拿去当标记会得到 20。不减组号会得到 22。2021 年虚拟地址从 30 位加到 32 位，多出的 2 位加在标记上，组号仍是 3 位，所以 TLB 表项增加 2 位。
7. **2021 年换掉的是虚页号 4，不是 12。** 组号 = 虚页号 mod 8。第 4 组先后装入 12 和 4，再次访问 12 时 LRU 把它标成最新，4 变成更旧的。虚页号 20 也进第 4 组，替换 4。别的组都没有超过 2 路。
8. **页表项地址是页号乘页表项的字节数。** 2024 年页 4 MB，偏移 22 位，页号 10 位。12345678H 的页号是 048H。页表项虚拟地址 = B8C00000H + 048H×4 = B8C00120H，物理地址 = 65400000H + 048H×4 = 65400120H。新页框号是 BAB45678H 的高 10 位 2EAH。页表自己的页号是 B8C00000H 的高 10 位 2E3H，对应页表项在 B8C00B8CH，页框号是 65400000H 的高 10 位 195H。乘页大小会偏到别的页去。
9. **2016 年的 H 是块号的高位，不是低位。** 块号 4099 的低 9 位是组号 3，高 9 位是 000001000B，也就是 008H。A 和 B 都是 19，因为全相联 TLB 的标记就是虚页号。D 是 13，因为页是 8 KB。
10. **2011 年第四问的物理地址是 1FBAC。** 页框号 1FH 拼页内偏移 BAC，20 位物理地址写成 1FBACH。括号里的 H 不要再当成一位。题目只问页在不在主存，TLB 命中就已经说明在。

## 概念卡片参考答案

### 卡片一：页式、段式、段页式

| | 页式 | 段式 | 段页式 |
|---|---|---|---|
| 划分 | 页长固定 | 段长按程序的逻辑段，长短不齐 | 先按逻辑分段，段内再分页 |
| 地址 | 虚页号、页内偏移 | 段号、段内偏移 | 段号、页号、页内偏移 |
| 表 | 页表：存在位、页框号 | 段表：段基址、段长 | 段表指出这一段的页表和页数，页表再给出页框号 |
| 越界 | 页号超出页表长度 | 段内偏移 ≥ 段长 | 页号 ≥ 段内页数，或段号超出段表 |
| 缺页 | 存在位为 0 | 段不在主存 | 页的存在位为 0 |
| 碎片 | 页内有内碎片 | 段之间有外碎片 | 主要是页内碎片 |
| 共享 | 按页，可能把无关内容划进同一页 | 按逻辑段，适合共享一段 | 段可以共享，段内仍按页装入 |

物理地址：页式和段页式都是页框号拼页内偏移；段式是段基址加段内偏移。三种都由硬件查表、软件管表。

### 卡片二：一次访存经过谁

顺序是 TLB → 页表 → 物理地址 → Cache。TLB 和 Cache 都在 CPU 一侧，用 SRAM。页表在主存里。缺页才访问磁盘。

| 现象 | 说明 | 下一步 |
|---|---|---|
| TLB 命中 | 这项有效，标记等于虚页号 | 直接拿页框号，不再查页表 |
| TLB 缺失 | 没有可用的项。有效位为 0 也算缺失 | 用虚页号查页表，命中后把该项写入 TLB |
| 存在位为 0 | 缺页 | 交给操作系统调页，然后重新执行这条访存。此时还没有物理地址 |
| Cache 命中 | 物理地址的标记相同，而且有效位为 1 | 从 Cache 取数据 |
| Cache 缺失 | 这一块不在 Cache | 从主存调块。页已经在主存，不是缺页 |

2018 年第（2）问：题图里 TLB 每一项都能比较，是全相联。TLB 要快过主存里的页表，用 SRAM，不用 DRAM。

2024 年第 18 题的结论：MMU 在地址转换里查的是越权、缺页和 TLB 缺失。Cache 缺失要等物理地址已经得到、去取数据时才发生，不在 MMU 的转换过程里。

2016 年第（3）问：缺页开销更大。缺页要访问磁盘，Cache 缺失只访问主存。若答成缺页用软件、Cache 缺失用硬件，也成立。

第（4）问：直写要同时写快的和慢的。Cache 和主存的速度差还允许直写；主存和磁盘差得太多，改过的页用回写，等换出时再写磁盘。第 06 关的概念卡片用的是同一道题。

2024 年第 16 题里，错误的说法是「主存—外存通常采用直接映射」。页可以装进任一空闲页框，这一层是全相联。直接映射会让替换算法没有选择。Cache—主存的交换单位是块，主存—外存的交换单位是页；前者的替换由硬件做，后者由软件做；两层都可以用回写。
