# co/07 · 虚拟存储与地址翻译 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：把 TLB、页表、Cache 串起来的地址翻译器。一次访存要按硬件顺序把每一步打出来
- **小步骤**：
  ① 虚拟地址拆成虚页号和页内偏移
  ② 页表查找。存在位为 0 是缺页
  ③ 加上 TLB。全相联或组相联，命中就不再查页表
  ④ 物理地址再进 Cache，字段划分复用第 06 关
- **通过标准**：给定虚拟地址、页表和 TLB，能求出物理地址，并判断 TLB、Cache 是否命中、是否缺页
- **概念卡片**（写进 `NOTES.md`）：页式、段式、段页式怎么比

本关有两个程序：`main.c` 编出的主程序（如 `vm_translate_answer`）、`test.c` 编出的单元测试（`vm_translate_answer_test`）。

王道第 3 章虚拟存储器。计组看的是一次访存的硬件过程：先查 TLB，没有再查页表，拼出物理地址，再用物理地址查 Cache。缺页交给操作系统，替换策略留到 OS 的分页关。

页内偏移在虚拟地址和物理地址里是同一段，翻译时不改。按字节编址。存储容量里的 K、M 是 2¹⁰、2²⁰，输入时写成字节数，例如 4 KB 写成 `4096`。

输出里的地址写成 `0x` 开头。结果行括号里的 `0153180H` 是考卷写法：末尾的 H 表示十六进制，不是多出来的一位数字。

## 二、主程序题目（`main.c`）

读入命令，直到输入结束。每条命令打印一块推导，最后一行以 `结果：` 开头。`tests/` 里每组 `<用例>.in` 的输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

读之前用 `prompt(...)` 提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。

地址可以写成十进制、`0x` 开头，或末尾加 `H`。页表项里的虚页号如果没写 `H` 或 `0x`，按十进制。页大小、TLB 项数、路数、Cache 行数和块大小要是 2 的幂。不满足时向 stderr 报错并以非 0 退出。

没有 TLB 时，项数和路数都填 `0`。全相联：路数填成和项数一样。直接映射的 Cache：路数填 `1`。

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `page` | 虚拟地址位数、物理地址位数、页字节 | 虚页号、页内偏移、页框号的位数 |
| `cut` | 上面三个数，再加一个虚拟地址 | 虚页号（十六进制和十进制）和页内偏移 |
| `pt` | 三个数、页表项个数，每项「虚页号 存在位 页框号」，最后是虚拟地址 | 命中时的物理地址，或「缺页」 |
| `tlb` | 三个数、TLB 项数、路数 | 标记位数和组号位数 |
| `series` | 虚拟地址位数、页字节、TLB 项数、路数、访问个数，接着每个虚页号 | 被替换的虚页号。TLB 起初为空，替换用 LRU |
| `cfield` | 物理地址位数、Cache 行数、块字节、路数 | 标记、组号、块内偏移的位数 |
| `cset` | `low` 或 `pa`、物理地址位数、页字节、Cache 行数、块字节、路数、地址 | 组号。`low` 表示组号落在页内偏移里，地址可以是虚地址 |
| `band` | 虚拟地址位数、物理地址位数、页字节、TLB 项数、TLB 路数、Cache 数据区字节、块字节、Cache 路数 | A 到 G 的位数。A 虚页号，B TLB 标记，C 页框号，D 页内偏移，E Cache 标记，F 组号，G 块内偏移 |
| `blk` | 物理地址位数、Cache 数据区字节、块字节、路数、主存块号 | 组号，以及标记的二进制 |
| `walk` | 见下方 | TLB 或页表是否命中、物理地址、Cache 是否命中；缺页时不要物理地址 |
| `pte` | 地址位数、页字节、页表项字节、页表虚拟始址、页表物理始址、虚拟地址、缺页处理后的物理地址 | 要改的页表项的虚拟地址和物理地址、新页框号，以及页表自己所在页的页号和对应页表项 |
| `seg` | 段基址、段长、段内偏移 | 物理地址，或「越界」 |
| `segpage` | 页字节、段内页数、页号、页内偏移、存在位、页框号 | 物理地址、「越界」或「缺页」 |

`walk` 的输入：

```
walk 虚拟地址位数 物理地址位数 页字节 TLB项数 TLB路数
给出的 TLB 项个数
组号 路号 有效位 标记 页框号
页表项个数
虚页号 存在位 页框号
cache 行数 块字节 路数
快照条数
组号 路号 有效位 标记
虚拟地址
```

不查 Cache 时，把 `cache` 那一段换成一个词 `nocache`。没给出的 TLB 路和 Cache 行按空项。有效位只能是 0 或 1。存在位为 0 时，后面的页框号不使用。

`series` 把虚页号当成地址、块大小当成 1，用第 06 关的组相联 LRU。组号 = 虚页号 mod 组数。

### 样例

输入：

```
page 32 28 4096
```

输出：

```
【页式地址】
按字节编址，虚拟地址 32 位，物理地址 28 位，页 4096 B
页内偏移 = log2(4096) = 12 位。虚地址和物理地址的这一段相同，翻译时原样留下
虚页号 = 32 - 12 = 20 位
页框号 = 28 - 12 = 16 位。它由物理地址位数决定，和虚拟地址有多少位无关
结果：虚页号 = 20 位，页内偏移 = 12 位，页框号 = 16 位
```
