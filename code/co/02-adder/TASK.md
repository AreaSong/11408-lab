# co/02 · 加法器与定点加减 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

## 一、本关任务

- **产出**：用与、或、异或搭的一位全加器；串成 n 位串行进位加法器，并和 4 位先行进位对照；补码加减法器，输出结果和 ZF、SF、CF、OF；算术移位与逻辑移位
- **小步骤**：
  ① 一位全加器，串成 n 位串行进位加法器，再做加、减、与、或
  ② 补码加减：减法是加上减数的按位取反，最低进位再加 1
  ③ 溢出：双符号位，以及最高位进位异或次高位进位
  ④ 由进位和结果生成 ZF、SF、CF、OF
  ⑤ 有符号与无符号混在一起运算、比较、回绕
  ⑥ 算术移位和逻辑移位
- **通过标准**：两个数相加或相减后各标志位的值、`unsigned` 与 `int` 比较或转换后的结果、移位后的机器数，都要和真题答案一致
- **概念卡片**（写进 `NOTES.md`）：串行进位和先行进位

本关有两个程序：`main.c` 编出的主程序（如 `adder_answer`），`test.c` 编出的单元测试（`adder_answer_test`）。

王道第 2 章：加法器与 ALU、补码加减、溢出和标志位、移位，再加上 C 语言里整型的提升和转换。乘除法是第 03 关，IEEE 754 是第 04 关。

卷面按 32 位：`char` 8 位、`short` 16 位、`int` 和 `unsigned` 32 位。`int` 装得下 `unsigned short` 的全部取值。

### 写法

- 位宽 2 到 32。`cla` 固定 4 位
- 机器数：`0b` 后面刚好写满位宽，例如 8 位的 `0b11011000`；或十六进制，`A3H`、`0xA3` 都可以。输入里不要加空格
- 有符号真值写成十进制，可以带负号，末尾也可以加 `s`
- 无符号真值末尾加 `u`。已经超出该位宽补码范围的正数，必须加 `u`
- 全是 0 和 1、长度又等于位宽的数，不要裸写。机器数用 `0b` 或 `H`，真值加 `s` 或 `u`
- 移位次数从 0 到该位宽，含两端
- 类型名：`char`、`uchar`、`short`、`ushort`、`int`、`unsigned`

### 命令

| 命令 | 输入 | 结果行里要有 |
|---|---|---|
| `fa` | 三个 0 或 1：本位的 a、b，以及低位进位 | 本位和、向高位的进位 |
| `alu` | `add`/`sub`/`and`/`or`、位宽、两个数 | 加减要有机器数、无符号值、补码值、ZF、SF、CF、OF。与、或只写机器数 |
| `cla` | 两个 4 位数 | 4 位和，以及串行进位、先行进位各自的延迟 |
| `shift` | `logic` 或 `arith`，`l` 或 `r`，位宽、数值、移几位 | 移位后的机器数和补码值。算术左移若溢出要写明 |
| `mix` | `cmp`/`add`/`sub`、左类型、左值、右类型、右值 | 比较要写谁大谁小；加减要写运算类型和机器数 |
| `wrap` | `unsigned` 或 `int`，以及 n | n-1 之后，`i <= n-1` 会不会死循环 |
| `fits` | `int` 或 `unsigned`，一个数学值 | 这个值能不能放进该类型；放不下就写出低 32 位按该类型的读法 |
| `cond` | `bgt` 或 `ule` | `bgt` 写出选项字母；`ule` 写出 C、Z、N 三个检测位 |
| `read` | `s` 或 `u`、位宽、机器数 | `s` 按补码读，`u` 按无符号读 |

`bgt` 是无符号大于时转移。`ule` 对应 2013 年第 44 题那种「无符号数比较小于等于时转移」。`fits int` 的输出里能看到 `f(n)=2^(n+1)-1` 装进 `int` 时最大的 n。

延迟用王道的 ty：不算进位产生、进位传递的形成时间，一级与门或一级或门算 1 ty。

### 样例

输入：

```
fa 1 1 1
```

输出：

```
【一位全加器】a=1，b=1，低位进位 c=1
本位和 s = a ⊕ b ⊕ c = 1 ⊕ 1 ⊕ 1 = 1
进位 cout = (a ∧ b) ∨ (c ∧ (a ⊕ b)) = (1 ∧ 1) ∨ (1 ∧ 0) = 1
结果：和 1，进位 1
```
