### 08 · 指令系统与 x86 汇编
- **产出**：扩展操作码设计验证器；寻址方式有效地址计算器；用 `clang` 生成 32 位 x86 汇编并做阅读笔记；同一函数的 i386 与 arm64 反汇编对比
- **小步骤**：① 指令格式：零、一、二、三地址指令 ② 扩展操作码：给定指令字长和各类指令条数，验证编码是否可行 ③ 各种寻址方式的有效地址计算（相对寻址注意 PC 已自增） ④ 写 C 的 `if`、循环、函数调用，生成汇编，标注栈帧变化、参数传递和条件转移所用的标志位 ⑤ 同一个 C 函数分别编译成 i386 和 arm64 的 `.o`，用 `objdump -d` 对比指令长度和访存方式（体会 CISC vs RISC）
- **通过标准**：真题考法：扩展操作码最多能有多少条指令、某寻址方式的有效地址、读一段 x86 汇编说出它对应的 C 代码或某条指令执行后寄存器的值
- **概念卡片**：指令系统的基本概念（指令集体系结构 ISA）；基址寻址 vs 变址寻址
