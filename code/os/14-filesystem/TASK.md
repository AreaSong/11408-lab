## 一、本关任务

- **产出**：四种物理结构的读盘次数；混合索引的最大长度和某字节的读盘次数；位示图换算；成组链接的分配与回收；一块真的写进文件的迷你磁盘；同一套函数指针接上内存文件系统和磁盘文件系统；把第二个文件系统挂到第一个的目录上
- **小步骤**：
  ① `phys`：连续、隐式链接、FAT、单级索引，读第 k 块各几次
  ② `inode`：直接、一级、二级、三级间接。最大文件长度，以及某个字节要读几次盘
  ③ `bitmap` 和 `group`：位示图的字号、位号和盘块号互转；成组链接的栈
  ④ `image`：引导块、超级块、位图、inode 区、数据区写进一个普通文件。内存里放系统打开文件表和进程打开文件表
  ⑤ `roundtrip`：`open` / `read` / `write` / `close` 四张函数指针。内存和磁盘各走一遍，上层不改
  ⑥ `mount`：第二个文件系统挂到第一个的某个目录。`filesystem_answer_host` 再看本机的 `mount` 和 `df`
- **通过标准**：能按 inode 算出最大长度和某偏移的读盘次数；能把位示图的字、位和盘块号换过来；成组链接在「只剩组长块」和「栈满」时的状态对得上；主程序测试全部通过
- **概念卡片**（写进 `NOTES.md`）：
  1. 连续、隐式链接、FAT、索引：能不能随机访问，有没有外部碎片，指针断了会怎样
  2. 磁盘上的顺序：引导块、超级块、空闲空间管理、inode 区、数据区

每个项目有三个程序：`main.c` 编出的主程序（如 `filesystem_first`）、`test.c` 编出的单元测试（`filesystem_first_test`）、`host.c`（`filesystem_first_host`）。`host` 不读键盘，输出随本机挂载变化，不进 `tests/`，记在 `EXPERIMENTS.md`。

### 物理结构

逻辑块从 1 开始数，叫做「第 k 块」。文件控制块已经在内存。`index` 是单级索引，索引块一开始不在内存；放不下一块索引表的大文件用 `inode`，不要用 `phys index`。

| 命令 | 第一次读第 k 块 | 紧接着再读下一块 |
|---|---|---|
| `cont` | 1。地址是算出来的，只读数据块 | 1 |
| `link` | k。指针在块里面，要从第 1 块读到第 k 块 | 1。上一块的指针已经在手里 |
| `fat` | 1。FAT 整表常驻内存 | 1 |
| `fat-disk` | 2。整张 FAT 先读入一次，再读数据 | 1。FAT 留下了 |
| `index` | 2。先读索引块，再读数据 | 1。索引块留下了 |

未加说明的「链接」就是隐式链接，不是 FAT。

```
phys <cont|link|fat|fat-disk|index|all> <k>
```

`all` 打 `cont`、`link`、`fat`、`index` 四行，不打 `fat-disk`。k 是 1 到 1000000。

```
phys kind=link k=5 reads=5 next=1
```

`insert` 把一条已经在内存里的记录插成第 pos 条。文件原来有 n 条，n 和 pos 都从 1 起，pos 不超过 n。每条记录占一块。文件控制块已在内存，改它不计访盘。

- `insert cont <n> <pos>`：可以往前搬，也可以往后搬，取搬得少的一边。次数一样时往前搬。搬一条是读一次、写一次，新记录再写一次。往前搬时起始块号和长度都变；往后搬时只有长度变。
- `insert link <n> <pos>`：不搬别的记录。pos 为 1 时只写新块，改起始块号。否则先读到第 pos−1 块，写出新块，再把改过指针的第 pos−1 块写回。

```
insert cont n=200 pos=30 move=29 dir=head reads=59 fcb=start+length
insert link n=200 pos=30 reads=31
```

`linkmax <块字节> <指针字节>`：隐式链接，指针占给出的字节数，能点名的块数是 2 的「8×指针字节」次方。每块还要扣掉指针自己。指针字节只能是 1 到 4，块必须比指针大。能整除 1GB 时再打 `gb`。

### 混合索引

`inode` 的地址项在索引结点里。索引结点已经在内存，不计入读盘。一个索引块能放的指针个数是块大小除以地址项大小，必须整除。直接、一级、二级、三级的个数都可以是 0。一级可以有多个，2010 年就是 2 个一级间接。

逻辑块从 0 起。`nth` 是从 1 起的「第几块」，等于逻辑块号加 1。

- 落在直接地址：取块号不用再读盘，把数据读进来是 1 次
- 一级：读 1 个索引块才能知道块号，加上数据是 2 次
- 二级：2 个索引块加数据，共 3 次
- 三级：3 个索引块加数据，共 4 次

`inode max` 打最大块数、最大字节数，以及各级容量用 `+` 连起来的式子。某一级是 0 就略去。单位取能整除的最大一档：TB、GB、MB、KB、B。

`inode read` 的偏移按字节编址，从 0 起。超出最大文件是 `result=range`，然后继续。

`inode need` 看一个这么大的文件最后一字节落在哪一级。间接地址用到哪几级写成 `none`、`1`、`1+2` 或 `1+2+3`。0 字节是 `level=empty`、`indirect=none`。超过最大文件同样是 `result=range`。

```
inode max <块大小> <地址项字节> <直接> <一级> <二级> <三级>
inode read <块大小> <地址项字节> <直接> <一级> <二级> <三级> <偏移>
inode need <块大小> <地址项字节> <直接> <一级> <二级> <三级> <文件字节>
```

块大小是 1 到 1048576，地址项字节是 1 到 8，四个个数都是 0 到 64。

```
read off=1234 logical=1 nth=2 level=direct data-reads=1 addr-reads=0
need bytes=6291456 blocks=1536 level=double indirect=1+2
```

`addr-reads` 只算「把块号找出来」要读的索引块。`data-reads` 再加最后那一块数据。

### 位示图和成组链接

`bitmap blocks <磁盘字节> <块字节>`：磁盘字节必须是块的整数倍。一位表示一块。`map-bytes` 是位图的字节数，`map-blocks` 是这些字节占多少块，向上取整。

`bitmap pos <盘块号> <字长> <起点>` 和 `bitmap block <字号> <位号> <字长> <起点>` 互转。字长是 1 到 64。起点只能是 0 或 1，字号、位号、盘块号用同一个起点。

- 起点 0：盘块号 = 字号 × 字长 + 位号
- 起点 1：盘块号 = (字号 − 1) × 字长 + 位号

起点为 1 时盘块号、字号、位号都不能是 0。

```
bitmap block=100 word=4 bit=4
bitmap word=2 bit=5 block=37
```

成组链接的一组最多 100 块。超级块里的栈：下标 0 是栈底，最后一个是栈顶，分配从栈顶拿。`group` 这个结构大约 1.6MB，不要放在函数栈上。

计数大于 1：弹出栈顶，不读盘。计数等于 1，并且栈底那块登记过下一组：先把那块读进栈，再把这块分出去。计数等于 1 但这块没有下一组：它就是最后一块，直接分出去。栈空时分配，打印 `result=none` 后继续。

回收时栈没满就压入。栈已满：把当前栈写进刚回收的块，这块成为新的组长块，栈里只留它。

块号是 0 到 4095。`group stack` 最多 14 个块号，第一个是栈底。一整组用 `group fill`。

```
group cap <一组大小>
group fill <块号> <个数> <第一个> <步长>
group stack <栈底> ... <栈顶>
group total
group alloc
group free <块号>
group show
```

`fill` 从栈底往栈顶排。步长不能是 0。`total` 把内存栈的块数，加上栈底那块里登记的下一组，再顺着下一组的栈底走下去。组长块自己已经算在上一组里，不要再加一次。

```
alloc block=10 read=1 n=3
free block=31 write=1 n=1
stack n=2 bottom=20 top=21
```

本关最后一组的计数就是真实空闲块数，不用 0 号当结束标志。教材图里「N=100 但第一项是 0」时，把这一组看成 99 块。

### 磁盘映像和打开文件表

`image new <路径> <块数>` 格式化并写进这个文件。块大小固定 64 字节，块数 8 到 64。布局是：

| 块号 | 内容 |
|---|---|
| 0 | 引导块，开头是 `L14BOOT` |
| 1 | 超级块 |
| 2 | 位图，一位一块数据块。位 0 是数据区的第一块 |
| 3 到 6 | inode 区。8 个 inode，每个 32 字节 |
| 7 起 | 数据区 |

0 号 inode 是根目录，一开始就占数据区的第一块。根目录一项 16 字节：12 字节名字加 4 字节 inode 号，一块最多 4 个名字。普通文件的 inode 从 1 起取最小空号。文件最多 4 个直接块。

名字和文本只含字母、数字、`.`、`_`、`-`。名字 1 到 11 个字符，文本 1 到 40 个字符，都不能有空格。路径是映像文件在本机的路径，可以含 `/`。

```
image new /tmp/lab14-a.img 32
image open /tmp/lab14-a.img
image layout
create <名字>
write <名字> <文本>
show <名字>
```

`write` 从文件头覆盖，并按新长度截断。`image open` 重新读盘，内存里的打开文件表清空。打不开文件是 `result=io` 并停。

```
layout blocks=32 block=64 file-bytes=2048 boot=0 super=1 bitmap=2 inode=3-6 data=7-31 inodes=8 free=24
create name=a ino=1
write name=a bytes=5 blocks=1
```

`free` 是还没分出去的数据块个数。根目录那一块已经算占用。

进程号 0 到 3，每个进程的 fd 0 到 3。同一个 inode 在系统打开文件表里只有一项，再打开只把引用计数加一。fd 从 0 起取最小空号。打开方式只有 `r` 或 `w`：读打开不能写，写打开不能读，否则 `result=eacces`，偏移不动。偏移从 0 起。读到末尾是 `result=eof`。重名是 `result=exist`。没有这个名字是 `result=no-file`。

```
proc <pid> open <名字> <r|w>
proc <pid> close <fd>
proc <pid> read <fd> <字节数>
proc <pid> write <fd> <文本>
tables
```

```
open pid=0 name=a fd=0 sys=0 refs=1 mode=r
read pid=0 fd=0 n=5 data=hello off=5
sys 0 ino=1 refs=2
fd pid=0 0 sys=0 off=5 mode=r
```

没有表项时，`tables` 打 `sys none` 和 `fd none`。关闭后引用计数到 0，这一项从系统打开文件表拿掉。文件本身还在磁盘上。

### 函数指针和挂载

`roundtrip mem <文本>` 和 `roundtrip disk <路径> <文本>` 用同一段上层代码：按写打开、写入、关闭，再按读打开、读出、关闭。磁盘那次会格式化路径上的新映像。两边都打出刚写进去的文本。

```
roundtrip backend=mem data=hello
roundtrip backend=disk data=hello
```

挂载只有两个文件系统，编号 0 和 1。`mkdir` 和 `file` 的路径只在指定的那个文件系统里找，不跨挂载点。`cat` 从 0 号文件系统的根出发，碰到挂载点就换到 1 号文件系统的根，再继续剩下的分量。

路径以 `/` 开头，不能有空分量，也不能以 `/` 结尾。单独一个 `/` 是根。分量规则和文件名一样。不能把 1 号文件系统挂到 0 号的根上，那是 `result=root`。

```
mount reset
mount mkdir <fs> <父路径> <名字>
mount file <fs> <父路径> <名字> <文本>
mount at <0号文件系统上的目录>
mount show
mount cat <路径>
```

```
step fs=0 name=mnt cross=1
step fs=1 name=a cross=0
cat path=/mnt/a fs=1 data=hi
```

目录打 `dir=1`，不打 data。
