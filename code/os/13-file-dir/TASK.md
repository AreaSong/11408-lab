## 一、本关任务

- **产出**：逻辑结构的平均比较次数；树形目录和打开文件时的读盘次数；硬链接与软链接；两级打开文件表；本机的建立、读写、删除，以及链接和权限
- **小步骤**：
  ① `file_dir_answer_io` 用 `open`、`write`、`lseek`、`read`、`close`、`unlink` 走一遍。打开之后再用文件描述符读，不再把路径交给内核
  ② `asl` / `walk` 把同一批记录按顺序文件、索引文件、索引顺序文件各算一遍平均比较次数
  ③ 目录树：建立、删除、解析路径。`cd`、`open`、`read`、`readpath`、`load` 打印逐级读了几次磁盘
  ④ `file_dir_answer_link` 在本机比较硬链接和软链接的 inode。模拟器里的 `link` / `symlink` / `unlink` 按同样的规则改链接计数
  ⑤ `file_dir_answer_perm` 用 `chmod` 看 r、w、x 对文件和目录各是什么。模拟器里的 `chmod` / `access` 用同一套位，但新建、删除还要父目录同时有 w 和 x
- **通过标准**：能算出顺序文件和索引顺序文件的平均比较次数；能按路径说出打开文件要读几次盘；删掉一个名字之后，硬链接和软链接的结果不同；主程序和三个本机程序的测试全部通过
- **概念卡片**（写进 `NOTES.md`）：
  1. FCB 和 inode。文件名放在哪，权限、地址、链接计数放在哪
  2. 文件保护的三种做法：口令、密码（加密）、访问控制

每个项目有五个程序：`main.c` 编出的主程序（与项目同名，如 `file_dir_first`）、`test.c` 编出的单元测试（`file_dir_first_test`）、`io.c`（`file_dir_first_io`）、`link.c`（`file_dir_first_link`）、`perm.c`（`file_dir_first_perm`）。三个本机程序都不读键盘。它们只打印稳定的结论，不打印 inode 号；某一次运行的 inode 号在 `EXPERIMENTS.md`。

`n` 是 1 到 10000。组数是 1 到 n。关键字是 1 到 n，记录的关键字就是 `1, 2, …, n`，已经按关键字排好。`walk` 的比较次数超过 24 是 `bad-number`。长的平均次数用 `asl`，不要用 `walk`。

路径要么以 `/` 开头，要么相对当前目录。单独一个 `/` 是根。分量只含字母、数字、`.`、`_`、`-`，长度 1 到 15，最多 8 个分量。`.` 和 `..` 只能作为完整的一个分量。不能有空分量，也不能以 `/` 结尾。

### 平均比较次数

比较次数只数关键字比较。按指针把记录取出来，那一次不算比较，也不算在这里。

顺序文件从第 1 条往后比。找关键字 k 要比 k 次。等概率成功查找的平均是 `(n+1)/2`，化成最简分数。

索引文件每个记录一个索引项，索引按关键字有序，用折半。下标从 1 到 n，`mid = (low + high) / 2`，`low`、`high` 都包含。相等就停。平均次数是每条记录的比较次数加起来再除以 n。

索引顺序文件把 n 条切成给定的组数。不能整除时，前面的组各多 1 条。每一组的索引项是这一组的最大关键字。先确定组，再在组里从这条组的第 1 条顺序比。

- `seq`：索引从第 1 组的最大关键字开始顺序比，比到能盖住这条记录的那一组。
- `bin`：在这些最大关键字上做上面的折半，找的是「等于这一组最大关键字」。得到的次数对该组里每条记录都一样，然后再加组内的顺序比较。各组一样大时，这就是索引表的折半成功平均查找长度，加上 `(s+1)/2`，s 是每组条数。

各组不一样大时，`asl isam` 和 `asl all` 的索引顺序两行多一个 `size=`，用 `+` 把各组条数连起来。各组一样大时不印 `size`。

```
seq n=10 cmp=11/2
index n=10 cmp=29/10
isam-seq n=10 groups=3 size=4+3+3 cmp=41/10
isam-bin n=10 groups=3 size=4+3+3 cmp=39/10
```

`walk isam 10 3 seq 6` 的步骤是：

```
step index max=4
step index max=7
step group key=5
step group key=6
walk org=isam-seq n=10 groups=3 key=6 cmp=4
```

折半的步骤用 `step mid=<下标>`。索引顺序并且折半查索引时，用 `step index mid=<下标> max=<最大关键字>`。顺序文件用 `step key=<关键字>`。组内用 `step group key=<关键字>`。

10000 条、100 组那一组在 `tests/practice-asl.out`。

### 目录和读盘

`reset` 之后只有根。根的索引结点号是 0，权限 `755`，链接计数 2（`.` 和 `..` 都指向根）。根的索引结点一开始就在内存。根目录的数据块一开始不在内存。当前目录是根，当前用户号和组号都是 0。

用户号 0 没有超级用户豁免。权限位不让，就是不让。

新建的目录权限 `755`，普通文件 `644`，符号链接 `777`。主人是当时的用户号和组号。新名字的链接计数：目录是 2，普通文件是 1，符号链接是 1。符号链接不增加目标的链接计数。

索引结点号从 1 起，取当前最小的空号。释放之后这个号可以再发给别人。

目录项默认放在父目录的第 0 块。目录默认占 1 块。`blocks` 把目录改成占多块。`place` 把某个名字放到父目录的某一块。块号必须小于父目录的块数，否则 `result=bad-path`。父目录里已有的项落在新块数外面，`blocks` 也是 `bad-path`。

读盘只在 `cd`、`open`、`read`、`readpath`、`load` 上计数，并且打印 `step`。`mkdir`、`create`、`link` 这些只改目录树，不打印读盘。`cache` 和 `uncache` 也不计。

查找一个分量：

1. 当前这一层目录要有 x（搜索）。没有就停，这一层的数据块也不读。
2. 目录数据不在内存：从第 0 块读到放着这个名字的那一块，读到就停。名字不在目录里：这块目录有几块就读几块。
3. `inode` 方案：这个名字对应的索引结点还不在内存，再读一次索引结点。`fcb` 方案：目录项里已经有完整的文件控制块，不再单独读索引结点。
4. 这一截是符号链接，并且这次要跟随：再读符号链接自己的数据块，取出里面的路径，从头解析。相对路径从符号链接所在的目录接着找，不是从当前工作目录。路径已经用 `cache data` 标进内存，就不再读这一块。跟随超过 8 次是 `result=loop`。目标路径不存在是 `result=dangling`。

`cd` 走到的那个目录，索引结点在这次读完之后留在内存。后面的相对路径不用再读它。目录数据不会因为 `cd` 自动留下，除非再 `cache data`。

`open` 跟随到最后，必须是普通文件。读打开要有 r，写打开要有 w。沿途每个目录都要有 x。系统打开文件表里，同一个索引结点只有一项，里面记打开计数、打开时抄下来的权限和块数。再打开只把计数加一。用户打开文件表每个进程一张，fd 从 0 起取最小空号，各自有自己的访问方式和偏移，偏移从 0 起。打开本身不把文件数据读进来。

`read` 只认 fd。这个 fd 必须是读打开的，否则 `result=eacces`，偏移不动。块号从 0 起，必须小于文件块数，否则 `result=range`。数据块不在内存就读 1 次。偏移改成这块的下一块号。不再查目录。

`readpath` 等于再走一遍路径，再读指定的那一块。`load` 走一遍路径，再把每一块都读进来。这两个都要有读权限，也不分配 fd。

根索引结点常驻，所以从根出发时没有 `read-inode path=/`。题目若说根目录的内容已经在内存，先 `cache data /`。这和「FAT 的根目录常驻」不是同一个默认：本关默认只把根的索引结点放在内存。

```
step read-dir dir=/ name=a block=0
step read-inode path=/a
open pid=0 path=/a fd=0 reads=2
```

`fcb` 方案下，同样的打开没有 `read-inode` 那一行。

### 链接、删除、权限

硬链接和旧文件是同一个索引结点，链接计数加一。不能给目录做硬链接，`result=is-dir`。不能给符号链接做硬链接，`result=not-file`。本关只有一个文件系统，硬链接跨不了卷；这条写在 `claim hard-cross` 里。

符号链接是另一个索引结点，链接计数是 1，数据块里存路径。目标当时不存在也可以建，`target-nlink=absent`。

`unlink` 只删这个目录项，并让它指向的索引结点链接计数减一。父目录还在，输出里写 `parent-kept=yes`。不能 `unlink` 目录，用 `rmdir`。链接计数到 0 并且没有进程打开它，文件控制块释放，`fcb=freed`。还开着，`fcb=busy`，等最后一个 `close` 再释放。计数仍大于 0，`fcb=kept`。

`close` 减的是系统打开文件表的打开计数，不减磁盘索引结点的链接计数。计数到 0 才删掉内存里的这一项，`mem=dropped`。没到 0 是 `mem=kept`。链接计数已经是 0 时，这次关闭把磁盘上的索引结点也释放，`disk=freed`；否则 `disk=kept`。

`rmdir` 只能删空目录。空是指里面只剩 `.` 和 `..`。非空是 `result=not-empty`。根是 `result=root`。

权限是三组 rwx，从高到低是主人、同组、其他人。r 是 4，w 是 2，x 是 1。先看是不是主人，再看是不是同组，否则用其他人那一组。

对文件：r 读，w 写，x 执行。对目录：r 列目录，w 增删里面的名字，x 按名字搜索。在目录里 `create`、`link`、`symlink`、`unlink`、`rmdir`、`place`，父目录要同时有 w 和 x。`ls` 要有 r。`open` 沿途要有 x，文件自己要有对应的 r 或 w。

`chmod 100` 这种三位按八进制读。`8` 或其他位数是 `bad-number`。

## 三、本机程序

### `io.c`

不读键盘。在临时目录里建立 `note`，写入 `408-file` 这 8 个字节，`lseek` 回开头再读，再到偏移 4 读出后一半，然后 `close`、`unlink`，再 `open` 一次。

```
write=8
seek0=0
read=408-file
match=yes
seek4=4
tail=file
closed=yes
unlinked=yes
reopen=enoent
```

第二次读用的是已经拿到的描述符。程序印不出内核少查了几次目录，这件事在主程序的 `read` 和 `readpath` 里比。

### `link.c`

不读键盘。建立 `F1`，内容是 `data`。再 `symlink` 出 `F2`，`link` 出 `F3`，然后删掉 `F1`。输出只比较 inode 是否相同、链接计数、删掉目标之后还读不读得到。一次真实的 inode 号记在 `EXPERIMENTS.md`。

### `perm.c`

不读键盘。先把一个普通文件改成 `400`、`200`、`100`，分别试读打开、写打开和 `access` 的执行位。再把一个里面已经有文件的目录改成 `700`、`100`、`400`、`200`、`500`，分别试列目录、按名字打开里面的文件、在里面新建。测完把目录改回 `700` 再删掉。标准输出就是这次在本机上的结果，见 `tests/perm/practice.out`。
