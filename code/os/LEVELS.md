# 操作系统 · 关卡任务详情

## 贯穿全程的设计

### 1. 「模拟器 + 表格」对接过程题
调度甘特图、页面置换过程、磁盘调度序列、银行家算法安全序列……王道和真题都用**表格**来推演。
→ 每个模拟器的 trace 输出都**按王道的表格格式打印**，拿真题数据跑出来的表直接和答案逐行比对。

### 2. 「真实系统调用」对接概念题
进程、线程、信号量、文件 inode 这些概念，在你的 macOS 上都是真实存在的。
→ 部分关卡直接调用真实接口（`fork`、`pthread`、`stat`），**亲眼看到**书上讲的东西，而不只是模拟。

> [!NOTE]
> macOS 不支持匿名 POSIX 信号量（`sem_init`）。第 03 关会**用互斥锁 + 条件变量自己实现 P/V**，这正好能看清信号量的本质。

## 各关详情

### 00 · 系统调用初体验
- **产出**：分别用库函数 `printf` 和系统调用 `write` 输出文字；用 `dtruss`（macOS 版 strace，需要管理员权限）或代码计时观察系统调用的开销
- **知识点**：用户态与内核态、系统调用、中断与异常、库函数与系统调用的区别
- **小步骤**：① `printf` 与 `write` 对比 ② 故意触发一个异常（如除零、访问空指针），观察程序如何被终止 ③ 整理中断、异常、系统调用的对比卡片
- **通过标准**：真题考法：哪些操作需要在内核态执行、某事件属于中断还是异常、系统调用的执行过程

### 01 · 进程与线程
- **产出**：用 `fork`/`exec`/`wait` 创建进程；用 `pthread` 创建线程；对比两者的地址空间是否共享
- **小步骤**：① `fork` 后父子进程各改一个变量，观察互不影响 ② `pthread` 线程改同一个变量，观察共享 ③ 进程状态转换模拟器：输入事件序列，trace 打印每个进程的状态变化
- **通过标准**：真题考法：某代码 `fork` 后共打印几次、哪些状态转换是可能的、线程共享和不共享哪些资源

### 02 · 处理机调度
- **产出**：调度模拟器：FCFS、SJF、SRTN（最短剩余时间优先）、HRRN（高响应比优先）、RR、优先级（抢占/非抢占）、多级反馈队列；输出甘特图、周转时间、带权周转时间、等待时间
- **小步骤**：① FCFS ② SJF 与 SRTN ③ HRRN ④ RR（**新到达进程与时间片用完的进程谁先入队，以王道约定为准**） ⑤ 优先级 ⑥ 多级反馈队列
- **通过标准**：真题考法：给定进程表，求某算法下的平均周转时间、平均带权周转时间，或某时刻正在运行的进程

### 03 · PV 同步
- **产出**：用互斥锁 + 条件变量实现 `semaphore`、`P()`、`V()`；用它解决经典同步问题
- **小步骤**：① 实现信号量 ② 生产者-消费者 ③ 读者-写者（读者优先，再试写者优先） ④ 哲学家进餐（先写出会死锁的版本，再修复） ⑤ 故意把互斥 P 放到同步 P 前面，**亲眼看到死锁**
- **通过标准**：真题 PV 大题考法：给定场景写出信号量定义（含初值）和各进程的 P/V 代码，并用多线程跑通、不死锁、结果正确

### 04 · 死锁与银行家算法
- **产出**：银行家算法（安全性检查 + 资源请求判断）；资源分配图化简与死锁检测
- **小步骤**：① 计算 Need 矩阵 ② 安全性算法，trace 打印每一步的 Work 和 Finish ③ 资源请求算法 ④ 资源分配图化简
- **通过标准**：真题考法：当前状态是否安全、给出一个安全序列、某个请求能否立即满足；不发生死锁所需的最少资源数

### 05 · 连续内存分配
- **产出**：动态分区分配模拟器：首次适应、最佳适应、最坏适应、邻近适应；含回收时的相邻分区合并
- **小步骤**：① 用链表表示空闲分区 ② 四种分配算法 ③ 回收与合并（四种相邻情况） ④ 统计外部碎片
- **通过标准**：真题考法：经过一系列分配和回收后，空闲分区链的状态、某个请求能否满足

### 06 · 分页、分段与地址翻译
- **产出**：逻辑地址到物理地址的翻译器：单级页表、多级页表、TLB、分段、段页式；有效访问时间（EAT）计算器
- **小步骤**：① 单级页表 ② 多级页表（**顶级页表不能超过一页**） ③ 加入 TLB ④ EAT 计算 ⑤ 分段与段页式
- **通过标准**：真题考法：页表项数和页表大小、多级页表需要几级、给定逻辑地址求物理地址、EAT 计算
- **备注**：和计组第 06 关讲的是同一件事，OS 侧重页表结构与管理，计组侧重硬件过程

### 07 · 虚拟内存与页面置换
- **产出**：页面置换模拟器：OPT、FIFO、LRU、CLOCK、改进型 CLOCK；按王道表格格式打印每一步的内存状态和是否缺页
- **小步骤**：① FIFO ② OPT ③ LRU（复用双向链表 + 哈希） ④ CLOCK 与改进型 CLOCK ⑤ **用程序找出 Belady 异常的例子**（FIFO 增加物理块数，缺页反而增多）
- **通过标准**：真题考法：给定访问串和物理块数，求缺页次数、缺页率，或某次访问后被淘汰的页

### 08 · 文件系统
- **产出**：迷你文件系统模拟器：目录树、索引分配（直接 + 一级/二级间接索引）、位示图管理空闲块；最大文件长度计算器
- **小步骤**：① 文件分配方式：连续、链接、FAT、索引的对比 ② inode 多级索引：最大文件长度、访问某个字节需要读几次磁盘 ③ 位示图：盘块号与行列号互转 ④ 用 `ln`、`ln -s` 和 `stat` **在真实文件系统上观察硬链接和软链接的 inode 区别**
- **通过标准**：真题考法：给定 inode 结构求最大文件长度、读取文件某位置需要几次磁盘访问、位示图的行列与盘块号换算

### 09 · 磁盘与 I/O
- **产出**：磁盘调度模拟器：FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK；磁盘访问时间计算器；缓冲区处理时间计算器
- **小步骤**：① 六种磁盘调度，输出访问序列和移动总道数 ② 磁盘访问时间 = 寻道 + 旋转延迟 + 传输 ③ 单缓冲、双缓冲的处理时间 ④（理解层面）SPOOLing、SSD 与磨损均衡
- **通过标准**：真题考法：某调度算法下的磁头移动总道数、读取若干扇区的总时间、单/双缓冲下处理完 n 块数据的时间
