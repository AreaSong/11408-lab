# 操作系统 · 关卡任务详情

> 考查范围以 **2027 年 408 统考大纲**为准（与 2026 版无变动），逐条对照见文末「大纲覆盖对照」；具体约定以王道为准。

## 贯穿全程的设计

### 1. 「模拟器 + 表格」对接过程题
调度甘特图、页面置换过程、磁盘调度序列、银行家算法安全序列……王道和真题都用**表格**来推演。
→ 每个模拟器的 trace 输出都**按王道的表格格式打印**，拿真题数据跑出来的表直接和答案逐行比对。

### 2. 「真实系统调用」对接概念题
进程、线程、信号量、文件 inode 这些概念，在你的 macOS 上都是真实存在的。
→ 部分关卡直接调用真实接口（`fork`、`pthread`、`mmap`、`stat`），**亲眼看到**书上讲的东西，而不只是模拟。

### 3. 「概念卡片」对接概念题
OS 结构、调度层次、设备分配这类内容写不成代码。
→ 每关列出的**概念卡片**写进该关 `NOTES.md` 的「概念卡片」一节：一张卡片 = 一张对比表或一张图。

> [!NOTE]
> macOS 不支持匿名 POSIX 信号量（`sem_init`）。第 03 关会**用互斥锁 + 条件变量自己实现 P/V**，这正好能看清信号量的本质。

## 各关详情

### 00 · 运行环境与系统调用
- **产出**：分别用库函数 `printf` 和系统调用 `write` 输出文字；一张自己程序的内存映像图；链接与装入的实验记录
- **知识点**：内核模式与用户模式、特权指令；中断与异常；系统调用；库函数与系统调用的区别；程序的链接与装入；程序运行时的内存映像
- **小步骤**：① `printf` 与 `write` 对比，用代码计时或 `dtruss`（macOS 版 strace，需要管理员权限）观察系统调用的开销 ② 用空指针访问触发一个异常，观察程序如何被终止（**注意 arm64 上整数除零不会触发异常，结果直接为 0**，这正好说明"异常"由硬件定义） ③ 打印函数、全局变量、未初始化全局变量、`malloc` 得到的指针、局部变量的地址，画出代码段、数据段、BSS、堆、栈的布局 ④ 链接与装入：用 `otool -L` 看可执行文件依赖哪些动态库；同一程序运行两次，比较函数地址，体会运行时重定位
- **通过标准**：真题考法：哪些操作需要在内核态执行、某事件属于中断还是异常、系统调用的执行过程、三种链接方式与三种装入方式的区别
- **概念卡片**：OS 的概念、四个特征与功能；发展历程（批处理、分时、实时）；中断 vs 异常 vs 系统调用；OS 结构（分层、模块化、宏内核、微内核、外核）；操作系统引导过程；虚拟机（第一类、第二类虚拟机管理程序）

### 01 · 进程、线程与进程通信
- **产出**：用 `fork`/`exec`/`wait` 创建进程；用 `pthread` 创建线程；对比两者的地址空间是否共享；四种进程间通信的最小示例
- **小步骤**：① `fork` 后父子进程各改一个变量，观察互不影响 ② `pthread` 线程改同一个变量，观察共享 ③ 进程状态转换模拟器：输入事件序列，trace 打印每个进程的状态变化 ④ 管道：父进程写、子进程读 ⑤ 共享内存：`fork` 前用 `mmap` 建一块 `MAP_SHARED` 的匿名内存，父子都能看到对方写的数据 ⑥ 消息传递：用 `socketpair` 在父子进程间收发结构体消息 ⑦ 信号：用 `sigaction` 注册处理函数，用 `kill` 发信号
- **通过标准**：真题考法：某代码 `fork` 后共打印几次、哪些状态转换是可能的、线程共享和不共享哪些资源、各种进程通信方式的特点
- **概念卡片**：程序 vs 进程 vs 线程；PCB 的内容与组织方式；进程控制原语；内核支持的线程 vs 线程库支持的线程，以及三种多线程模型；四种进程通信方式对比

### 02 · 处理机调度与上下文切换
- **产出**：调度模拟器：FCFS、SJF、SRTN（最短剩余时间优先）、HRRN（高响应比优先）、RR、优先级（抢占/非抢占）、多级反馈队列；输出甘特图、周转时间、带权周转时间、等待时间
- **小步骤**：① FCFS ② SJF 与 SRTN ③ HRRN ④ RR（**新到达进程与时间片用完的进程谁先入队，以王道约定为准**） ⑤ 优先级 ⑥ 多级反馈队列 ⑦ 给模拟器加一个闲逛进程：没有就绪进程时运行它 ⑧ 上下文切换的开销：两个进程用一对管道来回传一个字节 N 次，估算一次切换的耗时
- **通过标准**：真题考法：给定进程表，求某算法下的平均周转时间、平均带权周转时间，或某时刻正在运行的进程；哪些时机会发生调度
- **概念卡片**：调度的三个层次；调度的目标与评价指标；调度时机与调度方式（抢占 vs 非抢占，以及哪些情况不能调度，以王道为准）；内核级线程与用户级线程的调度；多处理机调度；上下文切换要保存和恢复什么

### 03 · 同步与互斥
- **产出**：软件互斥算法（单标志法、双标志法、Peterson）；用 C11 原子操作实现的 TestAndSet 与 Swap 自旋锁；用互斥锁 + 条件变量实现的 `semaphore`、`P()`、`V()`；经典同步问题
- **小步骤**：① 不加任何保护，让两个线程各对同一变量加 100 万次，看结果出错 ② 软件方法：单标志法、双标志先检查、双标志后检查、Peterson，逐个跑，对照各自违反了哪条原则（**arm64 是弱内存模型，不加内存屏障的 Peterson 也可能出错**，加 `atomic_thread_fence` 后再试） ③ 硬件方法：用 `atomic_flag_test_and_set` 实现 TSL 自旋锁，用 `atomic_exchange` 实现 Swap ④ 实现信号量 ⑤ 生产者-消费者 ⑥ 读者-写者（读者优先，再试写者优先） ⑦ 哲学家进餐（先写出会死锁的版本，再修复） ⑧ 故意把互斥 P 放到同步 P 前面，**亲眼看到死锁** ⑨（选做）吸烟者问题
- **通过标准**：真题 PV 大题考法：给定场景写出信号量定义（含初值）和各进程的 P/V 代码，并用多线程跑通、不死锁、结果正确；真题选择题：某软件互斥算法是否满足"空闲让进、忙则等待、有限等待、让权等待"
- **概念卡片**：同步 vs 互斥；临界区访问的四条原则；自旋锁 vs 阻塞式互斥锁；信号量 vs 条件变量（以及管程）

### 04 · 死锁与银行家算法
- **产出**：银行家算法（安全性检查 + 资源请求判断）；资源分配图化简与死锁检测
- **小步骤**：① 计算 Need 矩阵 ② 安全性算法，trace 打印每一步的 Work 和 Finish ③ 资源请求算法 ④ 资源分配图化简
- **通过标准**：真题考法：当前状态是否安全、给出一个安全序列、某个请求能否立即满足；不发生死锁所需的最少资源数
- **概念卡片**：死锁的四个必要条件；预防（破坏哪个条件、代价）vs 避免 vs 检测与解除；死锁 vs 饥饿；不安全状态与死锁的关系

### 05 · 内存管理基础与连续分配
- **产出**：带重定位寄存器和界地址寄存器的地址变换器；动态分区分配模拟器：首次适应、最佳适应、最坏适应、邻近适应；含回收时的相邻分区合并
- **小步骤**：① 逻辑地址到物理地址：重定位寄存器加基址，界地址寄存器判越界（内存保护） ② 用链表表示空闲分区 ③ 四种分配算法 ④ 回收与合并（四种相邻情况） ⑤ 统计外部碎片，并与固定分区的内部碎片对比
- **通过标准**：真题考法：经过一系列分配和回收后，空闲分区链的状态、某个请求能否满足；给定重定位和界地址寄存器的值，判断访问是否越界
- **概念卡片**：逻辑地址空间 vs 物理地址空间；内存保护的两种方式；内存共享；单一连续、固定分区、动态分区对比；内部碎片 vs 外部碎片

### 06 · 分页、分段与地址翻译
- **产出**：逻辑地址到物理地址的翻译器：单级页表、多级页表、TLB、分段、段页式；有效访问时间（EAT）计算器
- **小步骤**：① 单级页表 ② 多级页表（**顶级页表不能超过一页**） ③ 加入 TLB ④ EAT 计算 ⑤ 分段与段页式
- **通过标准**：真题考法：页表项数和页表大小、多级页表需要几级、给定逻辑地址求物理地址、EAT 计算
- **概念卡片**：分页 vs 分段（地址维度、共享与保护、碎片）
- **备注**：和计组第 06 关讲的是同一件事，OS 侧重页表结构与管理，计组侧重硬件过程

### 07 · 虚拟内存与页面置换
- **产出**：请求分页模拟器（含缺页处理）；页面置换模拟器：OPT、FIFO、LRU、CLOCK、改进型 CLOCK，按王道表格格式打印每一步的内存状态和是否缺页；工作集计算器；内存映射文件实验
- **小步骤**：① 请求分页：页表项的状态位、访问位、修改位、外存地址，trace 打印缺页中断的处理流程 ② FIFO ③ OPT ④ LRU（复用双向链表 + 哈希） ⑤ CLOCK 与改进型 CLOCK ⑥ **用程序找出 Belady 异常的例子**（FIFO 增加物理块数，缺页反而增多） ⑦ 工作集：给定访问串和窗口大小，求某时刻的工作集；逐步减少物理块，观察缺页率陡增（抖动） ⑧ 内存映射文件：用 `mmap` 把文件映射进内存，修改内存后检查文件内容
- **通过标准**：真题考法：给定访问串和物理块数，求缺页次数、缺页率，或某次访问后被淘汰的页；某时刻的工作集；改进型 CLOCK 的淘汰顺序
- **概念卡片**：页框分配与置换策略（固定分配局部置换、可变分配全局置换、可变分配局部置换）；调入页面的时机与来源；抖动的原因与对策；影响虚拟存储器性能的因素（页面大小、物理块数、置换算法、程序局部性）

### 08 · 文件与文件系统
- **产出**：迷你文件系统模拟器：超级块、目录树、索引分配（直接 + 一级/二级间接索引）、位示图与成组链接管理空闲块；最大文件长度计算器；真实文件操作的实验记录
- **小步骤**：① 用 `open`、`read`、`write`、`lseek`、`close`、`unlink` 完成一次建立、读写、删除，理解"打开"为什么能省去后续的目录查找 ② 文件物理结构：连续、链接、FAT、索引的对比 ③ inode 多级索引：最大文件长度、访问某个字节需要读几次磁盘 ④ 外存空闲空间管理：位示图的盘块号与行列号互转；模拟成组链接法的分配与回收 ⑤ 树形目录：解析一条路径，统计逐级查找需要读几次磁盘 ⑥ 用 `ln`、`ln -s` 和 `stat` **在真实文件系统上观察硬链接和软链接的 inode 区别** ⑦ 文件保护：用 `chmod` 改权限位，验证 r、w、x 对文件和目录各意味着什么 ⑧ 用 `mount`、`df` 查看本机挂载了哪些文件系统
- **通过标准**：真题考法：给定 inode 结构求最大文件长度、读取文件某位置需要几次磁盘访问、位示图的行列与盘块号换算、成组链接分配后的空闲块状态、硬链接与软链接删除后的效果
- **概念卡片**：文件的逻辑结构（无结构、顺序、索引、索引顺序、散列）；FCB vs inode 与文件元数据；目录的操作；文件系统的全局结构（外存中：引导块、超级块、空闲空间管理、inode 区、数据区；内存中：系统打开文件表、进程打开文件表、目录缓存）；虚拟文件系统；文件系统挂载；文件保护的方式

### 09 · I/O 管理与磁盘
- **产出**：磁盘调度模拟器：FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK；磁盘访问时间计算器；缓冲区处理时间计算器；阻塞与非阻塞 I/O 的对比实验
- **小步骤**：① 六种磁盘调度，输出访问序列和移动总道数 ② 磁盘访问时间 = 寻道 + 旋转延迟 + 传输 ③ 单缓冲、双缓冲的处理时间 ④ 阻塞 vs 非阻塞 I/O：对一个没有数据的管道分别做普通 `read` 和设了 `O_NONBLOCK` 的 `read`，观察区别 ⑤ 用 `ls -l /dev` 找出字符设备（c）和块设备（b）
- **通过标准**：真题考法：某调度算法下的磁头移动总道数、读取若干扇区的总时间、单/双缓冲下处理完 n 块数据的时间
- **概念卡片**：设备的分类；I/O 接口与端口；I/O 控制方式（轮询、中断、DMA、通道）；I/O 软件的四个层次及各自职责；字符设备、块设备、网络设备接口；缓冲区管理（单、双、循环缓冲、缓冲池）；设备分配与回收（DCT、COCT、CHCT、SDT）与设备独立性；SPOOLing；设备驱动程序接口；磁盘的结构、格式化与分区；SSD 的读写性能特性与磨损均衡
