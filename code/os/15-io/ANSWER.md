## 思路

用户进程看到的是「读一块、写一台打印机」。操作系统中间有缓冲区、有一张逻辑设备表，还有一个假脱机守护进程。这三样东西都是为了让 CPU 不要被慢设备拖死，同时不让两个进程的输出缠在一起。

### ① 阻塞、非阻塞、异步是三件事

`io wait` 打的是考纲里的定义。

- 阻塞：数据还没来，进程进入阻塞态，把 CPU 让出去，数据到了再被唤醒。这次 `read` 返回时，数据已经在手里
- 非阻塞：数据还没来，立刻返回 `EAGAIN`，进程仍是运行态。它以后还得再调用一次 `read`，才能拿到数据
- 异步：调用马上返回，数据在完成的时候另发通知。调用者不用停在这一次 `read` 上

管道实验做的是前两种，都是同步 I/O。`host` 里子进程先睡 200 毫秒再写 `ping`。父进程的阻塞 `read` 要等到那一刻，这一次是 202 毫秒，`waited=yes`。同一条没有数据的管道如果设了 `O_NONBLOCK`，`read` 马上返回 -1，errno 是 `EAGAIN`。异步没有放进这次管道实验，定义只在 `io wait async` 里。

### ② 字符设备和块设备看传输单位

`ls -l` 权限串的第一个字母就是类型。`c` 是字符设备，`b` 是块设备。本机 `null` 和 `tty` 是 `c`，`disk0` 是 `b`，`rdisk0` 是 `c`。`rdisk` 是原始设备，按字符流访问同一块盘。考纲说的块设备、字符设备，指的是传输单位是一块还是一个字节，不要拿「这台 Mac 上有没有以 b 开头的行」当成定义。个数会变，记在 `EXPERIMENTS.md`。

按共享属性还有独占、共享、虚拟。打印机独占，磁盘在一段时间内可被多个进程访问、但每一次传输仍然只服务一个进程。虚拟设备就是 SPOOLing 做出来的。按速度还有低速、中速、高速。`card` 把这三轴都列了。

### ③ 时间线先算，公式后归纳

`practice-trace` 里 T=10、M=4、C=6、两块。单缓冲：

| 块 | 输入 | 搬运 | CPU |
|---|---|---|---|
| 1 | 0–10 | 10–14 | 14–20 |
| 2 | 14–24 | 24–28 | 28–34 |

第 2 块不能在第 10 时刻就开始输入，因为唯一的缓冲区要到第 14 时刻才被搬空。第 2 块的搬运也不能在第 24 之前开始，用户区要到第 20 才空，而输入又要到第 24 才结束，取较晚的那个。结束时刻 34。

第 1 块单独做完是 20。两块做完是 34。增量 `avg` 是 14。再多块也是每块再加 14。所以 n 块的结束时刻是

`T + M + C + (n - 1) × (max(C, T) + M)`

双缓冲同一组数：第 2 块在第 10 时刻就送进缓冲区 1，搬运从第 20 开始（用户区刚空，输入也刚结束），CPU 在第 30 结束。增量是 10，等于 `max(C+M, T)`。结束时刻是

`T + M + C + (n - 1) × max(C + M, T)`

`buf.c` 里 `buf_finish` 按上面的资源空闲时刻一步步推，`buf_closed` 用这两个式子。`sim` 和 `total` 必须一样，单元测试在一组 T、M、C、n 上把两边都对过。

`2011-31`：T=100，M=50，C=50，n=10。单缓冲 `200 + 9×150 = 1550`，双缓冲 `200 + 9×100 = 1100`。选 B。

官方解析写成单缓冲 `10×150+50`、双缓冲 `10×100+50+50`。这组数里 T=C，并且 M+C=T，所以和上面的式子是同一个数。T 比 C 大时，单缓冲的「一块间隔」才是 T+M，总数才是 `n×(T+M)+C`。C 比 T 大时，间隔变成 C+M，总数是 `n×(C+M)+T`。

`2013-27` 是单缓冲，T=100，M=5，C=90，n=2。`195 + 105 = 300`，选 C。同一组数的双缓冲是 `195 + 100 = 295`，正好是选项 B。题目写了系统缓冲区和用户区都只有一块。

`practice-cpu`：T=100，M=50，C=200，n=4。单缓冲和双缓冲的增量都是 250，总数都是 1100。CPU 已经比设备慢，多一块缓冲区不再缩短总时间。

`practice-overlap`：T=200，M=50，C=100，n=3。单缓冲 850，双缓冲 750。设备比「搬运加处理」慢时，双缓冲才把间隔压到 T。

`practice-one`：n=1 时两种缓冲的总数都是 T+M+C=200。单缓冲的 avg 仍是 150，双缓冲的 avg 仍是 100。avg 说的是「再来一块要加多少」，不是这一块自己花了多少。

循环缓冲是多块缓冲区围成一圈。`ring` 用块数区分空和满，容量就是能放的块数。`practice-ring` 容量 3，放满 a、b、c 后再放是 `full`；取出 a 再放入 d，顺序变成 b、c、d。留一个空槽也能区分空和满，那样数组要比用户看到的容量多一格，本关不这么做，避免和「有几块缓冲」对不上。

缓冲池是再往上一步：缓冲区不再专属于某一个设备，而是放进空闲队列、输入队列、输出队列，大家来借。`card` 里把它和单缓冲、双缓冲、循环缓冲并列。本关的代码做到循环缓冲为止。

两台机器通信时，单缓冲只能一个方向传完再换方向。要同时双向，每一方都要有收、发两块缓冲。`duplex-needs-two` 因此是 true。

### ④ 分配是改四张表，不是新建进程

`2010-24` 选 C。用户登录、启动程序会创建进程。设备分配只是在系统设备表里找到设备控制表，再顺着控制器、通道往下占。占不到就进那一级的等待队列。不会为此再创建一个进程。

`practice-dev` 里 d0、d1 共用控制器 c0 和通道 ch0。

- A 要 d0：设备、控制器、通道都空，进入 `io`
- B 要 d1：d1 空闲，所以设备先分给 B；c0 还在 A 手里，B 堵在控制器上，d1 仍然算 B 的
- C 要 d0：d0 在 A 手里，C 堵在设备上，什么都还没拿到
- A 做完：先还通道，再还控制器，再还设备。控制器队列的队头是 B，B 补上控制器和通道，进入 `io`。然后才轮到设备队列的 C。C 拿到 d0，但 c0 又被 B 占了，C 改堵在控制器上

教材没有规定这三条队列同时能往下走时先叫谁。本关的约定是：已经占着上游资源的进程先继续。先叫通道队列，再叫控制器队列，最后才把刚空出来的设备给新人。若先把通道给 C，B 会继续占着 d1 和等待位置，通道却被一个刚入场的进程拿走。

`practice-chan` 是另一边：d1 有自己的控制器 c1，只和 d0 抢同一条通道。B 拿到设备和控制器之后堵在通道上。A 归还通道后，B 只补通道，不必再申请一次控制器。

`practice-printer` 是独占设备上的先来先服务。A 占着打印机，B、C 按申请顺序排在设备队列里。A 归还后先叫到 B，C 还在队里。

`practice-logic` 里 A、B 的程序都写逻辑名 `LP`，映射分别指向 p0、p1。两边都能进入 `io`。这就是设备独立性：系统调用里用逻辑设备名（`2009-32` 选 A），物理设备记在进程自己的逻辑设备表里。换一台物理设备，改映射和驱动程序，应用程序不用改。`2020-30` 的 D 说必须改应用程序，所以 D 错。A 成立，是因为设备可以当成特殊文件来打开。

`2023-32` 选 D。分配时要看设备类型、访问权限、现在有没有被占用，以及逻辑名到物理设备的映射。四项都要。

安全分配：进程提出 I/O 之后就阻塞，直到这次 I/O 做完，中间不能再申请别的设备。`ask` 发现进程不是空闲就打 `busy-proc`。不安全分配允许一个进程同时占着多台设备，可能死锁，本关不模拟。

### ⑤ 打印机只交给守护进程

`2016-31` 选 D。SPOOLing 要磁盘上的输入井和输出井，所以要外存。输入进程、输出进程要和用户进程一起在系统里跑，所以要多道程序。独占设备因此可以被多个作业同时「使用」：每个作业以为自己有一台打印机，其实只是往井里写了一份。井和设备之间的搬运由系统进程做，不是由用户作业做。

`spool parts` 的七行就是组成：磁盘上的输入井、输出井，内存里的输入缓冲、输出缓冲，以及输入进程、输出进程。作用是把独占设备变成共享的虚拟设备。

`practice-spool` 容量 3。A、B、C 的作业马上进井。D 来的时候井满了，D 堵在井外面，打印机仍然空闲，谁都没有占着它。`print` 把 j1 经输出缓冲送给守护进程去打，井里空出一格，D 的 j4 才补进来。j1 没打完时再 `print` 得到 `busy`。用户进程的名字只出现在 `owner` 里，表示这份作业是谁提交的。

没有 SPOOLing 时，第二个进程会在 `dev ask` 里堵在设备队列上，直到前一个 `done`。有了输出井，提交在写磁盘时就返回了。

### 控制方式和四个层次

四种方式，CPU 越来越少插手：

| 方式 | CPU | 数据谁搬 | 中断 |
|---|---|---|---|
| 轮询 | 一直看状态寄存器，忙等 | CPU，一个字一个字 | 没有 |
| 中断 | 发完命令就可以去干别的 | 还是 CPU，每来一个字进一次中断 | 每个字 |
| DMA | 只在开始时设置，结束时收尾 | DMA 控制器，设备接口和主存之间，以块为单位 | 每块一次 |
| 通道 | 交出通道程序后不再管中间的块 | 通道，一组块可以不连续 | 整个 I/O 结束一次 |

`2017-32` 选 B，顺序是 ②③①④。先初始化 DMA 并启动磁盘，再把一块传到内存缓冲区，传完 DMA 控制器发中断，然后才执行「DMA 结束」的中断服务程序。CPU 不在块的中间搬每一个字。

`2012-26` 选 A。从上到下是用户级 I/O 软件、设备无关软件、设备驱动程序、中断处理程序。`2011-26` 选 B，是同一条链：用户程序进系统调用（设备无关层），再进驱动程序，设备做完了由中断处理程序收尾。

各层的活：

- 用户层：库函数，以及 SPOOLing 这种放在用户空间旁边的系统服务
- 设备无关层：逻辑名到物理设备、缓冲、分配和回收、保护、屏蔽块大小的差别
- 驱动程序：把「读第几块」变成这台设备的寄存器命令。磁盘的柱面号、磁头号、扇区号在这里算，`2013-25` 选 C
- 中断处理程序：从设备把结果收下，唤醒等这次 I/O 的进程

`2010-32` 选 B。键盘一按键，最先拿到扫描码的是中断处理程序。登录程序和 shell 都要再通过系统调用，从内核缓冲区里读。

`2020-25` 选 D。保存断点（PC）是硬件的中断隐指令。提供中断服务、系统启动时初始化中断向量表，是操作系统。进入中断服务程序之后，操作系统还要保存中断屏蔽字并换上新的屏蔽字，所以 IV 也算操作系统。隐指令本身不做「把屏蔽字存进内存」这一步。

`2022-32` 选 A。厂家按设备特性在驱动里选定一种控制方式，驱动和控制方式有关，A 错。初始化设备、真正的读和写，都在驱动里。驱动执行到一半，设备忙，进程可以进入阻塞态。

`2022-28` 选 D。读文件会等磁盘，申请外设时设备要是被占就会阻塞，`wait` 把信号量减到不够也会阻塞。时间片用完是从执行变成就绪，不是阻塞。时间片在第 4、5 关。

`2015-28` 选 A。内存里的磁盘缓冲区把常用的块留住，下一次不必再启动磁盘，所以减少的是 I/O 次数。寻道时间靠调度，那是第 16 关。可靠性和设备无关也不是开这块缓冲的目的。

驱动程序和内核之间是一张函数表。内核用主设备号找到这张表，用次设备号告诉驱动是同类设备里的哪一台。表里至少有初始化、读、写和中断处理的入口。块设备和字符设备可以走不同的控制方式，字符设备常用中断，块设备常用 DMA。

通道本身还有三种：字节多路通道交叉服务多台低速设备，数组选择通道在一段时间内只为一台高速设备服务，数组多路通道可以连着多台高速设备、但传输时仍只服务一台。本关的分配模型里，一台控制器只指向一条通道，一条通道可以挂多台控制器。

## 易错点

1. **n=1 的总数和 avg 不是同一个数。** 总数是 T+M+C。avg 是「2 块减 1 块」。`practice-one` 里单缓冲总数 200、avg 150。
2. **2011 的简便式只在这组数上和统一式重合。** 单缓冲写成 `n×(T+M)+C`，要求 T≥C。C 更大时要写成 `n×(C+M)+T`。双缓冲写成 `n×T+M+C`，要求 M+C≤T。统一式是上面那两个带 max 的式子。
3. **双缓冲不一定更快。** `practice-cpu` 两边都是 1100。`2013-27` 的 295 是双缓冲，题目是单缓冲，答案是 300。
4. **有的课件把双缓冲的平均时间写成 max(C, T)。** 那是把 M 完全藏进另一侧的画法。按那个算法，2011 的双缓冲会变成 1050，不在选项里。本关和当年答案一致：M 仍算在 CPU 这一侧，平均时间是 max(C+M, T)，最后一块的 M 和 C 都要留下。
5. **非阻塞不是异步。** 非阻塞的进程还是运行态，而且要再读一次才有数据。异步是提交之后就返回，完成时另作通知。
6. **控制器忙的时候，设备已经分出去了。** `practice-dev` 里 B 堵在 c0 上，d1 的 owner 仍是 B。归还时先唤醒 B，再让 C 进来。这个先后是本关的约定，教材没有写死。
7. **分配设备不创建进程，SPOOLing 的守护进程也不是这次分配临时造出来的。** 守护进程是系统里原来就有的。`2010-24` 的 II 不导致创建进程。
8. **换物理设备不改应用程序。** 改的是逻辑设备表和驱动程序。`2020-30` 的错误项是 D。
9. **保存断点的是硬件，保存屏蔽字的是操作系统。** `2020-25` 的 I 不选，II、III、IV 选。
10. **磁盘缓冲区减少的是 I/O 次数，不是寻道时间。** 寻道留给第 16 关。DMA 的数据通路在设备接口和主存之间，那道题在计组（2024 年第 22 题），本关只保留「谁启动、谁被中断、进程会不会阻塞」。

## 概念卡片参考

1. **设备分类**：按传输单位分块设备和字符设备；按共享属性分独占、共享、虚拟；按速度分低速、中速、高速。
2. **控制方式**：轮询是 CPU 忙等、按字搬运；中断是按字通知、CPU 仍搬运；DMA 按块在设备和内存之间搬运，CPU 只在开始和结束时出现；通道执行通道程序，一组块结束才中断一次。
3. **四个层次**：用户级 I/O 软件，设备无关软件，设备驱动程序，中断处理程序。无关层做名字、缓冲、分配和保护；驱动把请求变成具体设备的命令；中断处理负责唤醒。
4. **驱动程序接口**：同一类设备一张函数表，主设备号选表，次设备号选具体设备。表上有初始化、读、写、中断处理。控制方式写在驱动里，和设备特性有关。
