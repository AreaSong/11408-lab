### 15 · I/O 管理
- **产出**：缓冲区处理时间计算器；阻塞与非阻塞 I/O 对比实验；设备分配模拟器；SPOOLing 模拟器
- **小步骤**：① 阻塞 vs 非阻塞 I/O：对一个没有数据的管道分别做普通 `read` 和设了 `O_NONBLOCK` 的 `read`，观察区别 ② 用 `ls -l /dev` 找出字符设备（c）和块设备（b） ③ 单缓冲、双缓冲的处理时间，用时间线模拟验证公式；再实现一个循环缓冲区 ④ 设备分配：建 SDT、DCT、COCT、CHCT 四张表，按"设备 → 控制器 → 通道"逐级分配，trace 打印哪一级阻塞；用逻辑设备名映射到物理设备，体会设备独立性 ⑤ SPOOLing：多个进程同时"打印"，作业先进输出井，再由守护进程逐个送打印机
- **通过标准**：真题考法：单/双缓冲下处理完 n 块数据的时间；设备分配的过程；SPOOLing 的组成与作用
- **概念卡片**：设备的分类；I/O 控制方式（轮询、中断、DMA、通道）；I/O 软件的四个层次及各自职责；设备驱动程序接口
