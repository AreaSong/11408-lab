# code/os/ · 操作系统

> 在 MiniMachine 中的角色：**资源管理者**，负责调度进程、管理内存、管理文件与磁盘。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节。

## 本科目约定
- **默认「🟢 先学会模式 · 两段式推进」优先（见 [TEACHING.md](../TEACHING.md)）**：
  - **第一段（日常闯关 = 只学单一机制）**：每关只搞懂单一内核机制、拿 1 组简单数字手推甘特图/置换表/安全序列，再写 `src/` 下最简写的核心状态转移函数并用 `test.c` 断言验证 + 1 次总反讲即标 `✅ 基础已通` 过关；**`TASK.md` 中的 `trace` 表格打印格式、`main.c` 命令行壳子及跨关综合真题留到板块节点或「🔵 规范化代码模式」**
  - **第二段（板块刷题节点）**：每学完 1 个大板块（见下方进度表中的 `🎯 板块节点` 分隔行），停下来集中手推本板块的 408 历年选择题与综合大题
- **模拟器的 trace 输出（仅「🔵 规范化代码模式」启用）**：规范化模式下按王道的表格格式打印（甘特图、置换表、调度序列）以跑通 `ctest`
- 部分关卡调用真实接口（`fork`、`pthread`、`stat`），观察真实系统的行为
- macOS 不支持 `sem_init`：信号量用 `pthread_mutex` + `pthread_cond` 自行实现
- arm64 是弱内存模型：软件互斥算法（如 Peterson）不加内存屏障可能出错；arm64 上整数除零不触发异常

## 考纲约定与易错点（AI 引导时重点核对）
- PV：同步信号量初值通常为 0、互斥信号量初值为 1；**互斥 P 必须放在同步 P 之后**，否则可能死锁
- 周转时间 = 完成时间 − 到达时间；带权周转时间 = 周转时间 ÷ 运行时间
- RR 中新到达进程与时间片刚用完的进程同时入队时，谁在前按王道约定
- 页面置换的"缺页次数"是否包含初始装入，按题目约定
- 多级页表：顶级页表不能超过一页
- SCAN 要走到磁道端点再折返，LOOK 在最远请求处折返；C-SCAN 返回途中不服务
- 有效访问时间（EAT）要分清 TLB 命中、页表命中、缺页三种路径
- 判断软件互斥算法时，逐条检查空闲让进、忙则等待、有限等待、让权等待四条原则
- 硬链接共享同一个 inode，删除时链接计数减到 0 才真正释放；软链接是一个存放路径的新文件
