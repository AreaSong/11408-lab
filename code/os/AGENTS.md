# code/os/ · 操作系统

> 在 MiniMachine 中的角色：**资源管理者**，负责调度进程、管理内存、管理文件与磁盘。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节。

## 本科目约定
- **模拟器的 trace 输出按王道的表格格式打印**（甘特图、置换表、调度序列），方便和真题答案逐行比对
- 部分关卡调用真实接口（`fork`、`pthread`、`stat`），观察真实系统的行为
- macOS 不支持 `sem_init`：信号量用 `pthread_mutex` + `pthread_cond` 自行实现

## 考纲约定与易错点（AI 引导时重点核对）
- PV：同步信号量初值通常为 0、互斥信号量初值为 1；**互斥 P 必须放在同步 P 之后**，否则可能死锁
- 周转时间 = 完成时间 − 到达时间；带权周转时间 = 周转时间 ÷ 运行时间
- RR 中新到达进程与时间片刚用完的进程同时入队时，谁在前按王道约定
- 页面置换的"缺页次数"是否包含初始装入，按题目约定
- 多级页表：顶级页表不能超过一页
- SCAN 要走到磁道端点再折返，LOOK 在最远请求处折返；C-SCAN 返回途中不服务
- 有效访问时间（EAT）要分清 TLB 命中、页表命中、缺页三种路径
