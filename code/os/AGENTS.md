## 考纲约定与易错点（AI 引导时重点核对）
- PV：同步信号量初值通常为 0、互斥信号量初值为 1；**互斥 P 必须放在同步 P 之后**，否则可能死锁
- 周转时间 = 完成时间 − 到达时间；带权周转时间 = 周转时间 ÷ 运行时间
- 页面置换的"缺页次数"是否包含初始装入，按题目约定
- SCAN 要走到磁道端点再折返，LOOK 在最远请求处折返；C-SCAN 返回途中不服务
- 有效访问时间（EAT）要分清 TLB 命中、页表命中、缺页三种路径
