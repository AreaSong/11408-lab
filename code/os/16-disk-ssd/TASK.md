## 一、本关任务

- **产出**：六种磁盘调度的访问序列和移动总道数；寻道、旋转延迟、传输三段时间；扇区连续编号和交叉编号的连续读时间；SSD 按页写、按块擦，以及不做均衡和动态均衡的擦除次数
- **小步骤**：
  ① `sched`：FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK
  ② `each` / `sum` / `rate` 算访问时间；`layout` 比较扇区交叉编号
  ③ `fmt` 打印三步格式化。`disk_ssd_answer_host` 跑 `diskutil list`，和这三步对看
  ④ `ftl`：写过的页标无效，新数据写到空闲页；没有空闲页就先把有效页抄走，再整块擦除
  ⑤ `wear`：同一个逻辑页反复改写，比较 `none` 和 `dynamic` 各块的擦除次数
- **通过标准**：能按下面的规则算出移动道数和三段时间；能说明写比读慢、磨损均衡摊的是擦除次数的分布；主程序测试全部通过
- **概念卡片**（写进 `NOTES.md`）：
  1. 盘面、磁道、扇区、柱面各是什么，磁盘物理地址由哪三段组成
  2. 同一柱面换磁头还要不要寻道

每个项目有三个程序：`main.c` 编出的主程序（如 `disk_ssd_first`）、`test.c` 编出的单元测试（`disk_ssd_first_test`）、`host.c`（`disk_ssd_first_host`）。`host` 不读键盘，`diskutil list` 的容量和分区个数随本机变化，不进 `tests/`，记在 `EXPERIMENTS.md`。

### 磁盘调度

```
sched <fcfs|sstf|scan|look|cscan|clook> <磁头> <up|down|none> <最大磁道号|none> <请求...>
```

磁头和每条请求是 0 到 1000000。请求 1 到 32 个。`up` 是向磁道号增大的方向，`down` 是向减小的方向。

- `fcfs`、`sstf` 的方向必须是 `none`。FCFS 按给出的顺序。SSTF 每次选距离最小的未服务请求；距离相同取磁道号较小的，磁道号也相同就按到达顺序
- `scan`、`look`、`cscan`、`clook` 的方向必须是 `up` 或 `down`。磁头已经停在的那条请求距离是 0，先服务
- `scan`、`cscan` 必须给出最大磁道号，磁头和请求都要落在 0 到这个号上。当前方向没有未服务请求、另一侧还有时，先走到 0 或最大号。`scan` 然后掉头。`cscan` 再跳到另一端，这段距离计入总道数，方向保持不变，跳回去的路上不服务
- `look`、`clook` 的最大磁道号可以是 `none`。写了数字就只用来检查越界，不拿来当折返点。`look` 在当前方向最后一个请求处掉头。`clook` 从那里直接跳到另一侧最远的请求，这段距离计入总道数
- 另一侧已经没有请求时，停在最后一次服务的磁道上

`order` 只列被服务的请求。`move` 是磁头移过的磁道数，含走到端点和跳回的空跑。

```
sched sstf 50 none none 60 40
```

```
algo=sstf order=40 60 move=30
```

2010-45 的题面写 CSCAN，没有给出磁道端点。本关这一问用 `clook`：从当前方向最远的请求跳到另一侧最远的请求，跳的距离计入寻道。给了 0 到最大号的 CSCAN（2024-32）用 `cscan`。

### 访问时间

时间印成毫秒，三位小数；`round1` 是保留一位、一半向上进位。转一圈的时间或一个扇区的传输时间不能落在整数刻度上时，输出 `bad-div`。

`each` 里每一次访问都付一次寻道、半圈旋转、一个扇区的传输和控制器延迟。`sum` 里 `seek_us` 已经是这批请求的寻道总时间，旋转、传输和控制器延迟按 `count` 次累加。`rate` 只算一次访问，传输时间 = 字节数 / 每秒字节数。这里 1 KB = 10^3 B，1 MB = 10^6 B。

```
each <寻道微秒> <转速> <每磁道扇区数> <次数> <控制器微秒>
sum  <寻道微秒> <转速> <每磁道扇区数> <次数> <控制器微秒>
rate <寻道微秒> <转速> <字节数> <每秒字节数> <控制器微秒>
```

寻道和控制器是 0 到 100000000 微秒。转速是 1 到 1000000。扇区数是 1 到 100000。次数是 1 到 10000。字节数是 0 到 100000000。每秒字节数是 1 到 1000000000。

```
each 0 6000 100 1 0
```

```
seek-ms=0.000 rot-ms=5.000 xfer-ms=0.100 ctrl-ms=0.000 total-ms=5.100 round1=5.1
```

### 扇区交叉

```
layout <每磁道扇区数> <交叉因子> <连续读几个> <处理后转过几个扇区>
```

扇区数是 1 到 64。交叉因子是 0 到 63，并且要小于扇区数。连续读的个数是 1 到扇区数。处理后转过的扇区数是 0 到 64，并且不能大于每磁道扇区数。

逻辑扇区 i 放在物理扇区 `(i × (交叉因子 + 1)) mod 扇区数`。步长和扇区数的最大公约数必须是 1，否则 `bad-div`。磁头一开始停在逻辑 0 的起点，这段初始等待不算进 `ticks`。读一个扇区算 1。读完后磁头已经在下一个物理扇区的起点；处理时间里盘还在转。最后一个扇区读完就停，不再加处理时间。

```
layout 7 0 4 1
```

```
ticks=25 reads=4 wait=18 proc=3
```

### 柱面、磁头、扇区

编号都从 0 开始。每磁道扇区数必须能被每簇扇区数整除，否则 `bad-div`。扇区号是这个簇的第一个扇区。

```
cap <柱面数> <盘面数> <每磁道扇区数> <扇区字节数>
chs <盘面数> <每磁道扇区数> <每簇扇区数> <簇号>
csstf <盘面数> <每磁道扇区数> <每簇扇区数> <磁头所在柱面> <簇号...>
```

`csstf` 先把簇号换成柱面号，再按 SSTF 排这些柱面。同一柱面上有多个簇时，按输入顺序。簇号 1 到 32 个。

```
chs 2 8 2 5
```

```
cyl=0 head=1 sector=2
```

### 格式化三步

`fmt` 固定三行：物理格式化划分扇区，分区写分区表，逻辑格式化建立根目录。安装操作系统是这三步之后的事，在第 01 关。

`card` 固定三行：盘面、磁道、扇区、柱面；物理地址是柱面 + 磁头 + 扇区；同一柱面换磁头不再另计寻道。

### 闪存转换层

```
ftl new <块数> <每块页数> <none|dynamic>
ftl write <逻辑页号> <值>
ftl show
wear <块数> <每块页数> <次数> <none|dynamic>
```

块数、每块页数都是 1 到 4。逻辑页号必须小于块数乘每块页数，值是 0 到 255。`wear` 的次数是 1 到 64，它反复改写逻辑页 0。

页有三种状态：`f` 空闲，`v,逻辑页,值` 有效，`i` 无效。写过的有效页不能改回空闲，再写同一个逻辑页时先把它标成无效，新值写到另一页。

- `none`：空闲页选块号最小的那块。回收时选无效页最多的块，平手选块号最小的
- `dynamic`：空闲页选擦除次数最少的块，平手选块号最小的。回收时选无效页最多的块，平手选擦除次数最少的，再平手选块号最小的

没有空闲页时回收一块：把其中的有效页抄到别的空闲页（抄写计入 `flash`），再把这一块擦成空闲，擦除次数加 1。`host` 只计主机发出的写。`gc` 是擦除次数的合计，和各块 `erase` 加总相同。

### 磁臂粘着

```
stick <fcfs|sstf|scan|cscan> <追加次数>
```

追加次数是 0 到 8。磁头一开始在 50。队列里已经有 50 和 80，50 先到。方向向上，这条演示不用跑到端点。每服务完一次 50，只要追加还没满，就再在队尾放一个 50。`stuck=yes` 表示 80 被服务时，追加的 50 已经全部服务完。
