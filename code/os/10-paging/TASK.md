# os/10 · 分页、分段与地址翻译 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

王道第 3 章，基本分页、多级页表、快表、分段和段页式。计组第 07 关做的是一次访存里 TLB、页表、Cache 的硬件顺序。本关不算 Cache，算页表有多大、要分几级、表项放在哪，以及有效访问时间。

## 一、本关任务

- **产出**：单级页表、多级页表、快表、分段、段页式的地址翻译；有效访问时间计算器
- **小步骤**：
  ① `flat` 做单级页表。页号大于等于页表长度是越界，存在位为 0 是这一页不在内存
  ② `geom` 算页表项数、页表字节数，以及顶级页表不超过一页时最少要几级
  ③ `look` 和 `trace` 加入快表。有效位为 0 的项，页号相同也不算命中
  ④ `path`、`avg`、`rate` 算有效访问时间。分清快表命中、页表命中、缺页
  ⑤ `seg`、`segno`、`segpage` 做分段和段页式
  ⑥ `paging_answer_host` 用 `getpagesize()` 读本机页大小，再代进第 ② 步的公式
- **通过标准**：给定逻辑地址能求出物理地址或指出越界、缺页；能算出页表大小、级数和有效访问时间。主程序测试全部通过
- **概念卡片**（写进 `NOTES.md`）：
  1. 分页和分段。列：地址是几维、大小固定还是可变、程序员看不看得见、碎片在页内还是段间、按什么单位共享
  2. 段页式比前两种多了什么。无快表时访问一次数据要读几次内存

每个项目有三个程序：`main.c` 编出的主程序（与项目同名，如 `paging_first`）、`test.c` 编出的单元测试（`paging_first_test`）、`host.c` 编出的本机页大小（`paging_first_host`）。`host` 的页大小跟机器有关，不进 `tests/`，看 `EXPERIMENTS.md`。

## 二、主程序题目（`main.c`）

每条命令占一行，读到输入结束为止。空行跳过。`#` 开头的行是注释，跳过。命令行每次读取前用 `prompt(...)` 打印「请输入命令，Ctrl+D 结束：」。第一条错误就停，退出码为 1。越界、缺页、快表未命中都是正常翻译结果，退出码仍为 0。

整数可以写成十进制、`0x` 开头，或末尾加 `H`。`H` 是考卷上的十六进制记号，不是多出来的一位。`010` 按十进制读，是 10，不是八进制。

输出里的地址、页框号、偏移，以及 `cut`、`pack`、`dirs` 拆出来的字段，写成 `0x` 开头的十六进制，不补前导 0。考卷上的 `01806008H` 在输出里是 `0x1806008`。页号、下标、个数、位数、时间用十进制。`slot` 的下标也用十进制，输入 `42H` 会印成 `66`。

页字节必须是 2 的幂。一页能放下的页表项个数必须是不小于 2 的 2 的幂，否则 `bad-size`。命令拼错、参数个数不对是 `bad-command`。整数读不出来、位数或存在位不合法、字段装不进给出的位宽、分母为 0、命中数大于分母，是 `bad-number`。一行超过缓冲区是 `bad-line`。未知题号是 `bad-exam`。

| 命令 | 含义 |
|---|---|
| `geom bits <地址位数> <页字节> <页表项字节>` | 按地址位数算单级页表，并给出顶级不超过一页的最少级数 |
| `geom pages <逻辑页数> <页字节> <页表项字节>` | 逻辑页数必须是 2 的幂。页号位数等于这个数的对数 |
| `cut <位宽...> <地址>` | 从高位到低位拆成 2 到 4 段 |
| `pack <位宽...> <值...>` | 按同样的顺序拼回去。值的个数等于段数 |
| `slot <项字节> <表基址> <下标>` | 表项地址 = 基址 + 下标 × 项字节 |
| `join <页字节> <页框号> <偏移>` | 物理地址 = 页框号 × 页字节 + 偏移。偏移必须小于页字节 |
| `span <页字节> <项字节> <逻辑起址> <长度> <装入物理起址> <页表基址>` | 一段连续装入的代码占哪些页。两个起址都要按页对齐，最多跨 8 页 |
| `elem <起始> <列数> <元素字节> <行> <列>` | 行优先。列号必须小于列数 |
| `dirs <目录位> <页号位> <偏移位> <地址1> <地址2>` | 两个地址各落在哪个页目录号，用了几个不同的二级页表 |
| `flat <页字节> <项字节> <页表长度> <页表基址> <页号> <存在位> <页框> <偏移>` | 单级翻译 |
| `two <页字节> <项字节> <目录基址> <目录号> <目录有效> <页表页框> <页号> <页有效> <数据页框> <偏移>` | 二级翻译。页表始址 = 页表页框 × 页字节 |
| `look <页字节> <页号> <偏移> <快表有效> <快表页号> <快表页框> <页表有效> <页表页框>` | 先看快表的这一项，不查 Cache |
| `avg <命中数> <分母> <快表ns> <内存ns> <查表次数>` | 无缺页时的平均有效访问时间，快表和内存串行 |
| `rate <正常次数> <分母> <正常ns> <缺页ns>` | 按缺页率再平均一次。缺页 ns 是一次缺页访问的全部耗时 |
| `path tlb-hit <快表ns> <内存ns>` | 一次快表命中 |
| `path pt-hit <快表ns> <内存ns> <查表次数>` | 快表未命中，页在内存 |
| `path fault <快表ns> <内存ns> <查表次数> <缺页ns>` | 缺页后重新执行那条访存 |
| `seg <基址> <段长> <偏移>` | 一段的地址变换 |
| `seglen <地址位数> <段号位数>` | 最多多少段、最大段长。地址位数是 2 到 63，段号位数更小 |
| `segno <段数> <段号> <段长> <偏移> <基址>` | 先比段号，再比段内偏移 |
| `segpage <页字节> <段内页数> <页号> <偏移> <存在位> <页框> <快表命中>` | 段页式。快表命中只能是 0 或 1 |
| `frag <页字节> <字节数>` | 这些字节占几页，最后一页里没写满的字节数 |
| `share <页字节> <页号A> <页号B> <页框> <偏移>` | 两个逻辑页指向同一个页框 |
| `trace reset <页字节> <快表ns> <内存ns> <缺页ns> <驻留集>` | 清空页表和快表。驻留集是 1 到 32。快表固定 8 项、全相联 |
| `trace map <页号> <页框> <存在位>` | 登记一页。存在位为 1 的页数不能超过驻留集 |
| `trace go <地址>` | 按上面的时间做一次访问 |
| `card` | 按固定顺序打概念卡片 |
| `exam <题号>` | 打印该题选项。题号是 `2009-27`、`2010-29`、`2020-28` |

没执行 `trace reset` 就 `map` 或 `go`，输出 `no-trace`。页号重复是 `duplicate`。页表满 32 页是 `full`。有效页超过驻留集是 `over-resident`。`segpage` 里快表命中写成 1，但页号已经越出段内页数或存在位是 0，输出 `bad-tlb`。

`geom` 的五行：

```
geom mode=bits va=16 page=256 pte=2
offset-bits=8 page-bits=8 pages=256 table-bytes=512
per-page=128 level-bits=7 levels=2
top-bits=1 top-entries=2 top-bytes=4 fits=yes
tables=1+2 pages-used=3
```

`offset-bits` 是页内偏移的位数。`page-bits` 是页号位数。`pages` 和 `table-bytes` 是单级页表全部建出来时的项数和字节数。`per-page` 是一页能放的页表项数，`level-bits` 是它的对数。

级数从低位往高位切：除了最高一级，每一级都取满 `level-bits`。剩下的高位给顶级。能整除时顶级也是满的，`top-bits` 等于 `level-bits`，不是 0。`top-entries` 是顶级的项数，`top-bytes` 是这些项占的字节。`fits=yes` 表示顶级不超过一页。`tables` 从顶级写起，是每一级页表的张数；`pages-used` 是这些张数之和，每张按一页算。逻辑页没全部用到时，低级页表可以不建，这里算的是全部建满。

`flat` 先用页号和页表长度比。页号从 0 起，等于长度已经越界，这时不读页表，也不打印表项地址。存在位为 0 时表项还在，要打印 `pte`。

```
flat page=1 result=ok pte=0x1002 frame=0x7 pa=0x703
flat page=4 result=bound
flat page=8 result=fault pte=0x200020
```

`two` 的目录有效位为 0，只打印页目录项地址，结果是 `fault-dir`。目录有效、页无效，再打印二级页表始址和页表项地址，结果是 `fault-page`。两个有效位都是 1，再打印物理地址。

```
two result=ok pde=0x1004 pt-base=0x2000 pte=0x200c pa=0x9010
```

`look` 只比较给出的那一项快表。有效位为 0 时接着看页表有效位，不能因为页号碰巧相同就判命中或判缺页。命中时用的是命中那一侧的页框。

```
look result=pt-hit frame=0x20 pa=0x20180
look result=tlb-hit frame=0x10 pa=0x10180
look result=fault
```

`avg` 的查表次数是快表未命中时读页表的内存次数，取 1 到 8。单级页表是 1，二级是 2，段页式的段表加页表是 2。快表和内存按串行相加：命中是快表加一次内存，未命中还要加上每一次查表。能整除就印整数，否则印约分后的分数。`rate` 里的缺页时间由调用者给出，程序不再往里面加访问。

```
avg hit=9/10 walks=1 eat=130
avg hit=1/3 walks=1 eat=530/3
path kind=fault ns=100000220
```

`path fault` 的顺序是：快表未命中，读页表，缺页处理，然后重新执行。重新执行时快表已经更新，命中后再访问一次内存。缺页处理时间已经包含更新快表和页表，更新本身不再另加时间。

`seg` 用段内偏移和段长比，等于段长是 `bound`。`segno` 先看段号是否小于段数，再看偏移。`segpage` 的 `visits` 是访存次数：页号越界是 1（段表已经读过），缺页是 2，无快表命中是 3，快表命中是 1。

```
seg offset=999 result=ok pa=0x43e7
seg offset=1000 result=bound
segpage result=pt-hit pa=0x5008 visits=3
segpage result=bound visits=1
```

`trace` 的快表起初是空的，8 项全相联，满了淘汰最久没有再被访问的一项。页表里没有这个页号，是 `bound`，时间为 0，状态不变。存在位为 0 才是缺页。驻留集已满时，淘汰本次访问序列里最久没被用过的有效页；时间戳相同，取页号更小的。还没有被访问过的页，时间戳是 0，比任何一次访问都旧。淘汰后，新页使用被淘汰页的页框。驻留集还没满时，使用 `map` 里写的页框，`victim=-`。

```
go addr=0x2362 page=2 offset=0x362 result=pt-hit frame=0x254 pa=0x254362 ns=210 victim=-
go addr=0x1565 page=1 offset=0x565 result=fault frame=0x101 pa=0x101565 ns=100000220 victim=0
```

`span` 把逻辑起址所在页记为 `which=1`，后面的页序号加 1。连续装入时，第 i 页（i 从 0 起）的物理始址等于装入地址加上 i 个页。`elem` 的下标是行 × 列数 + 列。`frag` 的 `internal` 是最后一页里没写满的字节，长度刚好是整页时为 0。`share` 的两个页号算出同一个物理地址。

（2）数组 `a` 在虚拟地址空间中所占区域是否必须连续？在物理地址空间中所占区域是否必须连续？

（3）已知数组 `a` 按行优先方式存放，若对数组 `a` 分别按行遍历和按列遍历，则哪一种遍历方式的局部性更好？

第（2）（3）问写进答案讲解，程序算第（1）问的地址。
