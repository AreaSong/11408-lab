> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。

> 王道第 2 章 线性表。位序从 1 开始，数组下标从 0 开始。

## 一、本关任务

- **产出**：`src/seqlist.h` / `src/seqlist.c` 里的动态顺序表：初始化、按位插入、按位删除、按值查找、按位取值、容量加倍
- **小步骤**：
  ① 实现上述基本操作。插入、删除要数清元素移动了几次，并能把每一次移动打印出来
  ② 表满时把容量加倍，已有元素保持原顺序；删除后不缩小容量
  ③ 写 `moves.c`：对表长 n，把每个合法位置各做一次插入和删除，统计平均移动次数，和 n/2、(n−1)/2 对照
  ④ 按三段式完成下面两道真题：2011-42 两个等长升序序列的中位数，2013-41 主元素
- **通过标准**：单元测试通过；`moves` 的实测平均次数与公式一致；两道真题的过程和结果与标准答案一致
- **概念卡片**（写进 `NOTES.md`）：静态顺序表 vs 动态顺序表；插入、删除的平均移动次数

每个项目有五个程序：`main.c` 编出的主程序（与项目同名，如 `seqlist_first`）、`test.c` 编出的单元测试（`seqlist_first_test`）、`moves.c`（`seqlist_first_moves`）、`median.c`（`seqlist_first_median`）、`majority.c`（`seqlist_first_majority`）。

约定：

- 逻辑位序从 1 开始。过程行里的 `data[j]` 是从 0 开始的数组下标，位序 i 对应下标 i−1
- 初始容量 4。`length == capacity` 时先把容量乘 2，再插入；删除不缩容
- 按值查找返回第一个相等元素的位序，没有则返回 0
- 插入的合法位序是 1 ≤ i ≤ length+1，删除和按位取值是 1 ≤ i ≤ length。非法操作打印 `fail`，表不变

## 二、主程序题目（`main.c`）

从空表开始，读入若干条命令，对同一张顺序表执行。每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。

- **命令**（读到输入结束为止）：
  - `insert i e`：在位序 i 插入元素 e
  - `delete i`：删除位序 i
  - `find e`：按值查找 e
  - `get i`：读取位序 i
- **输出**：
  - 插入或删除引起元素搬家时，每次搬家单独一行：`move data[目的] <- data[来源]`（下标从 0 开始）。从后往前搬的顺序要反映在行序里
  - 这次插入触发了扩容时，在 `ok` 行之前另起一行：`grow 旧容量 -> 新容量`
  - 成功的插入：`ok insert i=<i> e=<e> moves=<搬家次数> length=<长度> cap=<容量> [<元素，空格分隔>]`
  - 成功的删除：`ok delete i=<i> e=<被删元素> moves=<搬家次数> length=<长度> cap=<容量> [<元素>]`
  - 查找：`ok find e=<e> pos=<位序>`，找不到时 pos 为 0
  - 取值：`ok get i=<i> value=<值>`
  - 非法位序：`fail insert i=<i> e=<e>`、`fail delete i=<i>` 或 `fail get i=<i>`
- **样例**

  输入：
  ```
  insert 1 10
  insert 2 30
  insert 2 20
  delete 1
  ```
  输出：
  ```
  ok insert i=1 e=10 moves=0 length=1 cap=4 [10]
  ok insert i=2 e=30 moves=0 length=2 cap=4 [10 30]
  move data[2] <- data[1]
  ok insert i=2 e=20 moves=1 length=3 cap=4 [10 20 30]
  move data[0] <- data[1]
  move data[1] <- data[2]
  ok delete i=1 e=10 moves=2 length=2 cap=4 [20 30]
  ```

`tests/` 里的每组 `<用例>.in` 都会喂给主程序，输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

## 三、移动次数程序（`moves.c`）

- **输入**：若干行，每行一个整数 n（1 ≤ n ≤ 2000），读到输入结束为止
- **输出**：每行

  `n=<n> insert total=<插入搬家总次数> trials=<n+1> avg=<实测平均> expect=<n/2> delete total=<删除搬家总次数> trials=<n> avg=<实测平均> expect=<(n-1)/2>`

  平均次数保留一位小数。插入要把位序 1 到 n+1 各做一次（含表尾），删除要把位序 1 到 n 各做一次。只数元素搬家，容量加倍时的复制不算
- **样例**

  输入：
  ```
  5
  ```
  输出：
  ```
  n=5 insert total=15 trials=6 avg=2.5 expect=2.5 delete total=10 trials=5 avg=2.0 expect=2.0
  ```

`tests/moves/` 里的用例喂给这个程序。

## 四、中位数程序（`median.c`）

读两个等长升序序列，用折半找出它们的中位数，并打印每一轮留下的区间。

- **输入**：第一行正整数 n（1 ≤ n ≤ 100000）；第二行升序序列 A 的 n 个整数；第三行升序序列 B 的 n 个整数。升序允许相邻元素相等
- **输出**：
  - 还没缩到各剩 1 个元素时，每一轮一行。两段中位数不等：

    `round <轮次> len=<当前段长> A[<左>..<右>] mid=<A 的中位数> <或> B[<左>..<右>] mid=<B 的中位数> -> A[<新左>..<新右>] B[<新左>..<新右>]`

    下标从 0 开始，轮次从 1 开始。`<` 或 `>` 表示两个中位数的大小关系，箭头右边是这一轮保留的区间
  - 两个中位数相等时只打印当前段，不再打印箭头：

    `round <轮次> len=<段长> A[<左>..<右>] mid=<值> == B[<左>..<右>] mid=<值>`
  - 最后一行：`median=<中位数>`。n 为 1 时没有 round 行
- **样例**

  输入：
  ```
  5
  11 13 15 17 19
  2 4 6 8 20
  ```
  输出：
  ```
  round 1 len=5 A[0..4] mid=15 > B[0..4] mid=6 -> A[0..2] B[2..4]
  round 2 len=3 A[0..2] mid=13 > B[2..4] mid=8 -> A[0..1] B[3..4]
  round 3 len=2 A[0..1] mid=11 > B[3..4] mid=8 -> A[0..0] B[4..4]
  median=11
  ```

`tests/median/` 里的用例喂给这个程序。

## 五、主元素程序（`majority.c`）

- **输入**：第一行正整数 n（1 ≤ n ≤ 100000）；第二行 n 个整数
- **输出**：按候选计数打印过程，最后一行是结果
  - 开始：`pick candidate=<第一个元素> count=1`
  - 与候选相同：`i=<下标> a=<当前值> vote count=<加 1 后的计数>`
  - 与候选不同，且减 1 后仍大于 0：`i=<下标> a=<当前值> cancel count=<减 1 后的计数>`
  - 减到 0：当前元素改当新候选，计数记回 1：`i=<下标> a=<当前值> replace candidate=<新候选> count=1`
  - 扫完后再数一遍：`verify candidate=<候选> times=<真实出现次数>`
  - 最后一行：`majority=<主元素>`；没有主元素时为 `majority=-1`
  - 下标 i 从 0 开始，第一行 pick 对应 i = 0，循环从 i = 1 打印
- **样例**

  输入：
  ```
  8
  0 5 5 3 5 7 5 5
  ```
  输出：
  ```
  pick candidate=0 count=1
  i=1 a=5 replace candidate=5 count=1
  i=2 a=5 vote count=2
  i=3 a=3 cancel count=1
  i=4 a=5 vote count=2
  i=5 a=7 cancel count=1
  i=6 a=5 vote count=2
  i=7 a=5 vote count=3
  verify candidate=5 times=5
  majority=5
  ```

`tests/majority/` 里的用例喂给这个程序。

## 六、真题题面

### 2011-42（15 分）

一个长度为 L（L≥1）的升序序列 S，处在第 ⌈L/2⌉ 个位置的数称为 S 的中位数。例如，若序列 S1 = (11, 13, 15, 17, 19)，则 S1 的中位数是 15。两个序列的中位数是含它们所有元素的升序序列的中位数。例如，若 S2 = (2, 4, 6, 8, 20)，则 S1 和 S2 的中位数是 11。现有两个等长升序序列 A 和 B，试设计一个在时间和空间两方面都尽可能高效的算法，找出两个序列 A 和 B 的中位数。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
3. 说明你所设计算法的时间复杂度和空间复杂度。

### 2013-41（13 分）

已知一个整数序列 A = (a0, a1, …, an−1)，其中 0 ≤ ai < n（0 ≤ i < n）。若存在 ap1 = ap2 = … = apm = x 且 m > n/2（0 ≤ pk < n，1 ≤ k ≤ m），则称 x 为 A 的主元素。例如 A = (0, 5, 5, 3, 5, 7, 5, 5)，则 5 为主元素；又如 A = (0, 5, 5, 3, 5, 1, 5, 7)，则 A 中没有主元素。假设 A 中的 n 个元素保存在一个一维数组中，请设计一个尽可能高效的算法，找出 A 的主元素。若存在主元素，则输出该元素；否则输出 −1。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
3. 说明你所设计算法的时间复杂度和空间复杂度。
