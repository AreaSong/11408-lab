## 概念卡片

### 1. 静态顺序表 vs 动态顺序表
| 对比项 | 静态顺序表（定长数组 `data[MaxSize]`） | 动态顺序表（指针 `int *data` + `malloc/realloc`） |
|---|---|---|
| **空间分配** | 编译期固定大小，装满即溢出，无法扩展 | 运行期在堆上按需申请，表满时用 `realloc` 容量加倍并搬家 |
| **物理特征** | **两者底层都必须是「一大块连续内存」**（支持随机存取 `O(1)`，絕不是像链表那样零散挂钩） |

### 2. 顺序表基本操作代价与移动次数
| 操作 | 合法位序范围（从 1 起算） | 挪动方向与代码核心 | 平均移动次数 | 时间复杂度 |
|---|---|---|---|---|
| **按位插入 `insert`** | `1 <= i <= length + 1`（可插表尾） | **从后往前**退位：`data[j] = data[j - 1]` | **`n / 2`**（最少 0 次、最多 `n` 次） | `O(n)` |
| **按位删除 `delete`** | `1 <= i <= length` | **从前往后**填坑：`data[j - 1] = data[j]` | **`(n - 1) / 2`**（最少 0 次、最多 `n - 1` 次） | `O(n)` |
| **按位取值 `get`** | `1 <= i <= length` | 直接算下标：`return L->data[i - 1]` | `0` | **`O(1)`**（随机存取） |
| **按值查找 `find`** | — | 从 `0` 到 `length - 1` 顺序扫描，找到返回位序 **`i + 1`**，找不到返回 `0` | — | `O(n)` |

- **核心认知与易错点复盘（摘自对话与 `Lab随笔.md`）**：
  - **`&` 与 `*`（发件与收件）**：调用处写 `&L` 是把本地结构体 `L` 的真实内存地址发过去；函数头写 `SeqList *L` 是声明收件人 `L` 是一个指针（地址纸条）。不加 `&` 和 `*` 则会复制一份新结构体，改不到原表。
  - **`.` 与 `->`**：手里拿的是结构体本体时用 `.`（东西就在手边，如 `L.length`）；手里拿的是指针地址时用 `->`（顺着快递地址去找，如 `L->length`，等价于 `(*L).length`）。
  - **位序 vs 下标**：位序是人类口语从 `1` 开始数，C 数组下标从 `0` 开始数；所以按位取值用 `i - 1`，按值查找返回位序用 `i + 1`。
  - **踩坑留痕**：`seqlist_delete` 循环起点曾误敲成 `for (int j = 1; ...)`（应为 `j = i`），导致删除第 2 位时把第 1 位元素意外覆盖，在 `test.c` 补上 `CHECK_EQ(seqlist_get(&L, 1), 10)` 后定位并修复。
  - **`.h` 与 `.c` 编译链接（`Lab随笔.md` 原文心得摘录）**：
    - `.c` 是函数实现（源文件），`.h` 是函数声明（头文件，相当于点菜菜单，`#include` 本质是在编译前把声明复制粘贴过来）。
    - C 分两步：① **编译期**单兵检查单个 `.c` 语法与声明；② **链接期**把所有 `.o` 拼起来找真正的函数符号。
    - 在整个编译链接生成的最终程序里，全局公开符号表中同一个函数名只能有且仅有一个；仅在本 `.c` 内使用的私有函数不放进 `.h`，并在 `.c` 中加 `static` 关键字隔离。
