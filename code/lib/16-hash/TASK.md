## 一、本关任务

- **产出**：除留余数法；开放定址法（线性探测、平方探测、双散列）和拉链法；自动计算查找成功和查找失败的 ASL；改变装填因子，对照近似公式和某一张具体表
- **小步骤**：
  ① 线性探测。trace 打出每次插入走过的地址
  ② 平方探测（王道的正负双向，以及只加平方）和双散列
  ③ 拉链法。同义词串成一条链
  ④ 计算查找成功和查找失败的 ASL。失败的分母按王道取散列函数的取值个数
  ⑤ 改变装填因子。同一组关键字放大表，以及用公式比较相同装填因子、不同记录数
- **通过标准**：单元测试通过；`tests/2010-41.out` 的 `slot`、`success`、`fail`、`den`，`tests/2018-9.out` 和 `tests/2019-8.out`、`tests/2023-9.out` 的 `value` 与 `letter`，`tests/2024-42.out` 的 `hit` 与 `miss stop`，`tests/2011-9.out` 和 `tests/2025-9.out` 的 `letter`，`tests/practice-alpha.out` 里两组相同装填因子的 `formula_succ`，与程序一致
- **概念卡片**（写进 `NOTES.md`）：开放定址法和拉链法在聚集、删除上的差别；ASL 和装填因子的关系，以及它和「某一张具体表」的差别

每个项目有两个程序：`main.c` 编出的主程序（如 `hash_first`）、`test.c` 编出的单元测试（`hash_first_test`）。算法都在主程序里，没有第二个带 `main` 的文件。

约定：

- 表长 m 是 1 到 64，下标从 0 起。模 p 是 1 到 m。乘数 a 是 1 到 1000000。加数 b 默认 0，用 `bias` 改，范围同样是 0 到 1000000。关键字是 0 到 1000000 的整数。一条建表命令最多 64 个关键字
- 散列函数是除留余数法：H(key) = (a × key + b) mod p。探测在整张表上取模，模的是表长 m，不是 p
- 线性探测的增量是 0, 1, 2, …，地址 (H + i) mod m。表里只要还有空位，这条序列一定能走到
- `quad` 是王道的平方探测：先 +1²，再 −1²，再 +2²，再 −2²，k 从 1 试到 m−1。已经探过的地址跳过。`qpos` 只加 k²，没有负向，用来对 2024 年的题面。两种都不保证走遍全表
- 双散列：H₂(key) = q − (key mod q)，q 是 1 到 m−1。第 i 次探测的地址是 (H + i × H₂) mod m。序列一旦回到已经探过的地址就停。H₂ 和 m 不互质时，表没满也可能插不进去
- 拉链法用头插。插入前先沿链查有没有同一个关键字。链上从前往后是后插入的在前
- 开放定址的空位打印成 `-`，删除标记打印成 `#`。`del` 把找到的关键字改成 `#`，查找遇到 `#` 要继续走。`erase` 直接置成 `-`，探测链会在这里断开。拉链法的 `del` 把结点摘掉；对拉链法 `erase` 会失败
- 查找成功的 ASL：每个已存关键字的比较次数之和，除以关键字个数 n。比较次数含命中的那一次。没有关键字时成功 ASL 无定义
- 查找失败的 ASL：只对散列地址 0, 1, …, p−1 平均，分母是 p，不是表长 m，也不是 n。开放定址从该地址走到空位，空位那一次也算，`#` 不算空位。拉链法默认只数关键字比较，一条链的失败次数等于链长，空链是 0。`asl null` 再给每个散列地址加 1，表示把走到空指针也算进去。双散列的下一步依赖具体关键字的 H₂，不能只按地址平均，失败 ASL 记为依赖关键字，用 `miss` 看某一个
- 装填因子 α = n / m。`theory` 打的是等概率、散列均匀时的近似公式，不是某一张表的实测：
  - 线性探测，成功 ½(1 + 1/(1−α))，失败 ½(1 + 1/(1−α)²)，都打成分数
  - 平方探测和双散列，成功 −(1/α) ln(1−α)，保留四位小数；失败 1/(1−α)，打成分数
  - 拉链法，成功 1 + α/2，打成分数；失败 α + e^(−α)，保留四位小数
  - 开放定址在 n ≥ m 时公式无定义。平方探测和双散列在 n = 0 时也无定义
- `grow` 用关键字 1, 2, …, n，a = 1，b = 0，散列函数是 key mod p。n 是 1 到 64，m 是 1 到 64，p 不能大于 m。双散列不能用 `grow`
- 分数都约成最简。一行一条命令。读到输入结束就退出，退出码 0。空行跳过。失败时这条命令不再打别的内容；建表插到一半失败时，已经放进去的关键字保留，并照常打出当前表
- 一行超过 4095 个字符是 `fail long`。一行里的词超过 80 个，或命令的词个数不对，是 `fail format`

| 输出 | 含义 |
|---|---|
| `fail format` | 词的个数不对，或某个词不是整数 |
| `fail range` | 表长、模、乘数、加数、关键字或个数越界，或模大于表长 |
| `fail dup` | 关键字已经在表里 |
| `fail full` | 开放定址的探测序列上没有可放的位置 |
| `fail empty` | 还没有表，却要查找、删除或计算 |
| `fail miss` | 要删的关键字不在表里 |
| `fail kind` | 这个命令不能用在当前这种表上 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令 |

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（linear / quad / qpos / double / chain / bias / find / miss / del / erase / asl / runs / show / theory / grow / match / clash / improve，一行一条，Ctrl+D 结束）：`

建表之后先打每个关键字的插入过程，再打整张表。线性探测的样例：

```text
linear 5 5 1 1 6
```

```text
ins 1 h=1
path 1:-
put 1 cmp=1
ins 6 h=1
path 1:1 2:-
put 2 cmp=2
kind=linear
m=5 p=5 a=1
slot - 1 6 - -
n=2
alpha=2/5
success=3/2
fail=8/5
den=5
```

`h` 是散列地址。`path` 里每个 `地址:内容` 是插入时走到这一格时的样子，空位是 `-`。`put` 是最终放下的下标，`cmp` 是以后查找这个关键字要比较的次数。`slot` 从下标 0 写到 m−1。`den` 是失败 ASL 的分母，也就是模 p。`alpha`、`success`、`fail` 都是约分后的分数。

拉链法的插入过程换成：

```text
ins 14 h=1
path -
front cmp=1
```

`path` 是查重时比过的关键字，空链写成 `-`。`front` 表示新关键字插在链头，以后查找它自己比 1 次。整张表按桶打印，桶里从链头写到链尾：

```text
bucket 1 79 27 1 14
```

空桶是 `bucket 1 -`。b 不为 0 时，表头那一行在 `a` 后面多一个 `b=4`。双散列多一个 `q`。双散列的失败 ASL 写成 `fail=depend`。

### `bias b`

后面的建表都用这个加数，直到下一条 `bias`。打出 `bias=4`。

### `linear m p a k1 k2 ... kn`

### `quad m p a k1 ... kn`

### `qpos m p a k1 ... kn`

### `double m p a q k1 ... kn`

### `chain m p a k1 ... kn`

清空当前表，按这个方法把关键字依次插入。`quad` 是双向平方，`qpos` 只加平方。

### `find k` / `miss k`

在当前表里查。开放定址命中打 `hit pos=下标 cmp=次数`，失败打 `miss stop=空位或-1 cmp=次数`。拉链法没有下标，命中是 `hit cmp=次数`，失败是 `miss cmp=次数`。

### `del k` / `erase k`

`del` 在开放定址上打删除标记，输出 `mark 下标`；在拉链法上摘掉结点，输出 `drop cmp=次数`。`erase` 只用于开放定址，把那一格直接置空，输出 `wipe 下标`。

### `asl` / `asl null`

再打一遍成功 ASL、失败 ASL 和分母。`null` 只改变拉链法：每个散列地址的失败次数加 1。开放定址打 `null=off` 或 `null=open`，数字不变。拉链法打 `null=off` 或 `null=on`。

### `runs`

开放定址上，非空格子（含 `#`）沿表绕一圈的最长连续段。拉链法不能用。

### `show`

把当前表的汇总再打一遍，格式和建表结束时一样。

### `theory linear|quad|qpos|double|chain n m`

只算公式，不建表。n 是 0 到 10000，m 是 1 到 10000。

```text
theory linear n=7 m=10
alpha=7/10
formula_succ=13/6
formula_fail=109/18
```

开放定址的公式无定义时，这两行换成一行 `formula=invalid`。

### `grow linear|quad|qpos|chain p n m`

用关键字 1..n 建一张表，打实测 ASL，再打同一组 n、m 的公式。插不进去时只打 `fail full`。

### `match success|fail 分子 分母  ... `

四个选项按 A 到 D 的顺序，每个选项是一个分数，写成两个整数。先打约分后的 `value`，再打对上的 `letter`。四个都对不上是 `letter=none`。双散列不能拿 `fail` 来对。2018 年的 1.5、1.6、2、3 写成 `3 2  8 5  2 1  3 1`。2019 年的 4、5.25、6、6.29 写成 `4 1  21 4  6 1  44 7`，其中 6.29 是 44/7 保留两位。2023 年的 1、1.6、1.8、2.2 写成 `1 1  8 5  9 5  11 5`。

### `improve`

固定实验，对应 2011 年第 9 题的三条措施。先比线性探测公式在 n=7、m=10 和 n=7、m=20 的成功 ASL。再拿关键字 1..7、表长 13、模 7，分别用 a=1 和 a=7 做线性探测。最后用 a=7 的同一组关键字比较线性探测和拉链法的失败 ASL。I 表示「增大装填因子」这条措施成立，II、III 同理。选项是 A 仅 I、B 仅 II、C 仅 I 和 II、D 仅 II 和 III。

### `clash`

固定实验，对应 2025 年第 9 题。表长 5、模 5，先放 0、5、10，再放 15：线性探测是否还能找到空位，双向平方和只加平方是否也还能。另用一张表看线性探测会不会撞上非同义词，双向平方会不会先撞上同义词。四条叙述里只有一条成立时打出对应字母。
