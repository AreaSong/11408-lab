## 一、本关任务

- **产出**：简单选择、堆排序、归并、基数排序，每种都能按趟打印序列；一张九种排序的时空与稳定性汇总表
- **小步骤**：
  ① 简单选择。每一趟在未排序区间里找最小关键字，和区间开头交换
  ② 堆排序。先按第 09 关的规则建成大根堆，再一趟趟把堆顶换到当前堆尾
  ③ 归并。自底向上，段长 1、2、4、…；也可以把若干段已经有序的序列从左往右合并
  ④ 基数。最低位优先，基数 10，每一位做一次稳定的分配和收集
  ⑤ 统计本关与第 17 关每种排序的比较次数、移动次数
  ⑥ 汇总表：最好、平均、最坏时间，辅助空间，稳定性。表上的稳定性要用程序在具体序列上验一遍
- **通过标准**：单元测试通过；下面这些用例的序列、计数和 `letter` 与程序一致
  - `tests/2009-10.out` 的 `insert=possible`，另外三行是 `no`，`letter=B`
  - `tests/2012-10.out` 的 `select_always=yes`、`quick_always=yes`、`heap_always=yes`，希尔和归并是 `no`，`letter=A`
  - `tests/2013-11.out` 第二趟是 `7 110 911 114 119 120 122`，`letter=C`
  - `tests/2015-9.out` 只有 `radix_move` 的 `same=yes`，`letter=C`
  - `tests/2016-11.out` 的 `method=merge`、`letter=D`
  - `tests/2017-10.out` 的 `faster=yes`、`less_space=no`、`letter=B`；`tests/2017-11.out` 的 `letter=D`
  - `tests/2019-7.out` 的 `letter=D`，`tests/2020-11.out` 的 `fewer_cmp=yes`、`fewer_move=no`、`letter=A`
  - `tests/2021-10.out` 的 `before=301`、`after=892`、`letter=C`
  - `tests/2022-10.out` 的 `out 1 2 3 4 5`、`letter=A`；`tests/2022-11.out` 的 `letter=D`
  - `tests/2024-9.out` 的 `heap 20 19 15 5 8 12`、`letter=B`；`tests/2024-10.out` 的 `cmp=5`、`letter=C`
  - `tests/2025-10.out` 的 `select_worst` 等于 `select_cap`，`letter=D`
- **概念卡片**（写进 `NOTES.md`）：九种排序的时间、空间、稳定性；第 k 趟之后选择、归并各自留下什么外形；稳定性只看最终次序

每个项目有两个程序：`main.c` 编出的主程序（如 `sort_select_merge_radix_first`）、`test.c` 编出的单元测试（`sort_select_merge_radix_first_test`）。算法都在主程序里，没有第二个带 `main` 的文件。

约定：

- 关键字个数 n 是 1 到 16。关键字是 −1000000 到 1000000 的整数，可以重复。基数排序只接受非负整数，负数是 `fail range`，序列保持原样
- 打印出来的序列下标从 0 起。堆在程序内部从 1 起存放，打出来的 `at` 已经换成从 0 起，王道的位置号比这里大 1
- 比较次数：每做一次关键字比较记 1。基数排序取出某一位不算比较，所以 `cmp=0`。移动次数：每做一次记录赋值记 1。一次交换是 3 次赋值
- 相等关键字原来的下标记在 `ord` 里。最终序列里，相等关键字的 `ord` 仍然从小到大，才是稳定
- 一行一条命令。读到输入结束就退出，退出码 0。空行跳过。失败时这条命令不再打别的内容
- 一行超过 4095 个字符是 `fail long`。一行里的词超过 80 个，或命令的词个数不对，是 `fail format`
- 试卷上的 `007` 这里印成 `7`。位数看这一组里最大的关键字，不足的高位当作 0

| 输出 | 含义 |
|---|---|
| `fail format` | 词的个数不对，或某个词不是整数，或分段符用错 |
| `fail range` | 关键字个数、关键字、趟数越界，或基数排序遇到负数 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令或题号 |

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（select / heap / merge / radix / fit / runs / stable / count / table / exam，一行一条，Ctrl+D 结束）：`

简单选择的样例：

```text
select 3 1 2
```

```text
pass 1 at=0
1 3 2
pass 2 at=1
1 2 3
cmp=3
move=6
stable=yes
```

`at` 是这一趟放好最小值的下标。第 k 趟的 `at` 是 k−1，也就是未排序区间的开头。`cmp` 只由下标决定。`stable` 看相等关键字的原来次序还在不在；这组数没有重复关键字，所以是 `yes`。

堆排序的样例：

```text
heap 3 1 2
```

```text
build
3 1 2
heap09=yes
pass 1 at=2 key=3
2 1 3
pass 2 at=1 key=2
1 2 3
cmp=3
move=6
stable=yes
```

`build` 是初始大根堆，不算排序的第一趟。`heap09=yes` 表示这些关键字和第 09 关 `heap_build` 的大根堆一致。`pass` 里的 `at` 是刚放好的当前最大值的下标，`key` 是这个最大值。打出的序列含已经就位的后缀。

归并和基数的完整过程见 `tests/practice-merge.out`、`tests/practice-radix.out`。短样例：

```text
merge 4 3 2 1
```

```text
pass 1 width=1
3 4 1 2
pass 2 width=2
1 2 3 4
cmp=4
move=16
stable=yes
```

```text
radix 21 12
```

```text
pass 1 digit=1
21 12
pass 2 digit=10
12 21
cmp=0
move=8
stable=yes
```

`width` 是这一趟合并前每一段的长度。`digit` 是这一位的权，个位是 1，十位是 10。

### `select k1 ... kn`

清空计数，做简单选择。严格小于才更新最小下标，相等时留下先出现的那个。每一趟最多交换一次。n−1 趟都要做完。每一趟打 `pass`、`at` 和整段序列，最后打 `cmp`、`move`、`stable`。n = 1 时打 `sorted` 和这一个关键字。

### `heap k1 ... kn`

先建大根堆，再做堆排序。下标从 1 起：右孩子的关键字严格大于左孩子才走向右边，相等的孩子留在左边；父亲不小于选中的孩子就停。建堆从 ⌊n/2⌋ 收到 1。排序的一趟是把下标 1 和当前堆尾交换，堆的长度减 1，再对变短的堆筛选。共 n−1 趟。

### `merge k1 ... kn`

自底向上的二路归并。段长从 1 开始，每趟翻倍，直到段长不小于 n。一段和它右边那段合并；右边不够一整段时，有多少并多少；右边已经没有元素时，这一段留在原地，本趟不搬。关键字相等时先取左边。写进辅助数组再写回，一段参与合并的长度为 L 时，移动 2L 次。

### `radix k1 ... kn`

最低位优先，基数 r = 10。最大关键字有几位就做几趟，至少 1 趟。每一位用计数排序，从后往前把记录放进结果，效果和队列先进先出相同。每一趟每个记录先写进辅助数组、再写回，移动 2n 次。

### `fit k a1 ... an`

只看序列的外形，判断它有没有可能是第 k 趟的结果。k 是 1 到 n。

| 行 | 成立的条件 |
|---|---|
| `bubble` / `select` | 前 k 个是最小的 k 个并且非降，或者后 k 个是最大的 k 个并且非降 |
| `insert` | 前 k+1 个已经非降 |
| `merge` | 每 2^k 个关键字是一段非降序列，最后一段可以更短 |

不成立打 `no`，不能排除打 `possible`。四个选项按 2009 年第 10 题：A 起泡，B 插入，C 选择，D 二路归并。只有插入不能排除、另外三个都不成立时打 `letter=B`，否则 `letter=none`。起泡和简单选择的外形条件相同，所以这两行总是一样的。

### `runs` 用 `/` 把若干段隔开

每一段自己已经非降。从左往右，每次把当前结果和下一段合并，打 `step`、这一步的 `cmp` 和合并后的关键字。最后再打总的 `cmp`。只有一段时不打 `step`，直接打关键字和 `cmp=0`。空段、末尾多一个 `/` 是 `fail format`。关键字总数超过 16 是 `fail range`。

### `stable` / `count` / `table`

这三条命令不带参数。

- `stable`：九种排序各用一组带重复关键字的序列。`key:ord` 里的 `ord` 是排序前的下标。希尔那一组先打 `gap=2`
- `count`：三行数据。`up` 是 `1 2 3 4 5`，`down` 是 `5 4 3 2 1`，`classic` 是 `49 38 65 97 76 13 27 49`。每种排序打 `cmp` 和 `move`。起泡用第 17 关的 `sink`
- `table`：九行 `best`、`avg`、`worst`、`space`、`stable`、`live`。`stable` 是教材上的结论，`live` 是 `stable` 命令那组序列的实测。两者一致时 `live_ok=yes`。另起两行写快排最坏的栈空间，以及基数排序这份数组实现实际占用的空间

### `exam <题号>`

题号不认识是 `fail unknown`。各题打出的计数和 `letter` 以 `tests/<题号>.out` 为准。
