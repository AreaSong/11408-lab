# lib/07 · 二叉树与遍历 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 5 章。二叉树的孩子分左右，不能交换。先序、中序、后序、层次是四种走法；先序加中序、后序加中序能把树还原回来，先序加后序一般不能。

## 一、本关任务

- **产出**：二叉树的顺序存储和二叉链表；先序、中序、后序、层次遍历（递归和非递归）；由遍历序列构造二叉树
- **小步骤**：
  ① 性质计算器。非空二叉树满足 `n = n0 + n1 + n2` 和 `n0 = n2 + 1`。完全二叉树还能由结点总数定出 `n0`、`n1`、`n2` 和高度，编号从 1 起时孩子是 `2i`、`2i+1`
  ② 顺序存储和二叉链表互相转换。顺序存储靠下标算孩子，空洞要占位置；二叉链表在结点里记下左右孩子
  ③ 递归遍历，以及用第 03 关顺序栈做的非递归遍历。先序、中序、后序三种都要
  ④ 用第 04 关循环队列做层次遍历，并判断是不是完全二叉树
  ⑤ 由先序加中序建树，由后序加中序建树。再造一组先序、后序相同但树不同的例子
  ⑥ 算法题：2014-41 求叶子的带权路径长度，2017-41 把表达式树写成带括号的中缀表达式
- **通过标准**：单元测试通过；上面两道算法题按三段式写完，并用程序里的数据验证；2009-5、2011-4 的结点数，2011-5 的中序，2017-4 的条件，都和真题答案一致
- **概念卡片**（写进 `NOTES.md`）：树和二叉树差在哪里；满二叉树和完全二叉树差在哪里

每个项目有两个程序：`main.c` 编出的主程序（与项目同名，如 `binary_tree_first`）、`test.c` 编出的单元测试（`binary_tree_first_test`）。

约定：

- 根在第 1 层。空树高度是 0，只有根的树高度是 1。`n` 个结点的二叉树，最矮是 `floor(log2 n) + 1`，最高是 `n`
- 完全二叉树、顺序存储的编号从 1 起。`i` 的左孩子是 `2i`，右孩子是 `2i+1`，双亲是 `floor(i/2)`。`2i` 或 `2i+1` 大于 `n` 就没有这个孩子
- 2022-41 的数组从 0 起，左孩子是 `2i+1`，右孩子是 `2i+2`，双亲是 `floor((i-1)/2)`，空位用 `-1`。程序在顺序存储里把两套编号都打出来。空位在输出里写成 `#`，和 `-1` 是同一个位置
- 先序建树的字符串里，`#` 表示空孩子。每个结点都带着两个孩子位置，叶子是「字符后面紧跟 `##`」。字符是除空格和 `#` 以外的单个可见字符
- 权值是非负整数。先序读权值时，空孩子仍写成 `#`
- 表达式树的词可以长到 9 个字符。`#` 仍是空孩子。单目减号的左孩子是 `#`
- `n0`、`n1`、`n2` 是度为 0、1、2 的结点数。`?` 和 `-1` 都表示这个量未知
- 非递归遍历打印的栈、队列里，每一项是 `编号:字符`。编号是建树时分配的，从 1 起，不是顺序存储的 `2i` 那套下标
- 一行一条命令。一行里命令读完之后还剩的内容，按该命令自己的规则处理

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（prop / range / full / cbt / most / seq / link / shape / walk / prein / postin / prepost / wpl / infix / exam，一行一条，Ctrl+D 结束）：`

读到输入结束就退出，退出码 0。参数个数不对，或者该是整数的词不是整数：往标准输出打 `fail format`，继续读下一条。测试数据里两种行都有。

`link`、`prein`、`postin`、`seq` 成功之后，当前这棵树留着，后面的 `shape` 和 `walk` 用它。失败则当前树清空。

### `prop <n> <n0> <n1> <n2>`

四个数都可以是 `?`。按非空二叉树的两个等式能定出来的，打 `status=unique` 和那一组数，再打两行验算 `n=n0+n1+n2`、`n0=n2+1`。

定不出唯一解、但解的个数有限：`status=range`，然后 `count` 以及 `n0`、`n1`、`n2` 的最小最大，再一行 `parity opposite`（`n` 和 `n1` 的奇偶性相反）。

还缺一个可以随便取的量：`status=free`，打出已经固定的量和一个例子。

等式冲突：`status=conflict`，`reason` 是 `parity`、`n0=n2+1`、`empty` 或 `none`。`n` 为 0 或给出的 `n0` 为 0，算 `empty`。

`prop 3 ? 0 ?` 的输出：

```
prop n=3 n0=? n1=0 n2=?
status=unique
n=3 n0=2 n1=0 n2=1
check 3=2+0+1
check 2=1+1
```

`n` 未知、只知道 `n0=2` 时解不唯一，见 `tests/practice-prop.in`。

### `range <n>`

`n >= 1` 时打最矮和最高，以及 `formula min=floor(log2 n)+1 max=n`。`n = 0` 时两行高度都是 0。

### `full <h>`

高度 `h`（根在第 1 层）的满二叉树最多结点数，以及第 1 层到第 `h` 层各有多少个结点。`h` 从 1 到 20。`full 3` 的 `max=7`。

### `cbt <n>` 和 `cbt <n> <i>`

`n >= 1` 个结点的完全二叉树。先打编号公式，再打 `n1`、`n0`、`n2`、`height`。`last_branch` 是 `floor(n/2)`，`leaves` 是 `n - last_branch`。

高度至少为 2 时再打最下一层结点数 `bottom`、这些结点的双亲个数 `parents`、倒数第二层里的叶子 `prev_leaves`，以及 `leaf_sum`。`leaf_sum` 必须和 `n0` 相同。

给出 `i` 时多打这个结点的两套下标。没有的孩子、双亲、兄弟写成 `-`。`side` 是 `root`、`left` 或 `right`。`cbt 10 6` 见 `tests/practice-prop.in`。`i` 不在 `1..n`：这一行是 `fail i`，前面的统计照常打。

### `most <层号> <该层叶子数>`

层号从 1 起，根是第 1 层。完全二叉树这一层恰好有这么多叶子时，整棵树最少、最多各有多少结点。层号 1 到 20，叶子数至少 1，并且不能超过这一层最多能放的结点数，否则 `status=reject`。

`width` 是这一层满的时候有多少个位置，`branch` 是这些位置里不是叶子的个数。`short` 是树就停在这一层时的结点数。`branch` 为 0 时没有更高的树，`tall=0`。否则打满到这一层的结点数、再往下一层最少和最多的孩子数。`tests/practice-prop.in` 里有第 6 层 8 个叶子，最多 111、最少 39。

### `seq <词>...`

从下标 1 起的顺序存储。每个词是一个字符或 `#`。`#` 是空洞，中间的空洞必须写出来，末尾的 `#` 可以不写。根是空洞，或者某个结点的双亲位置是空洞：`fail hole`。词不是单个字符：`fail char`。

输出先打结点数、最后一个下标、`waste`（空洞个数），再打两套公式。每个实有结点两行：`i1=` 用从 1 起的编号，`i0=` 用从 0 起的编号。孩子位置上是空洞就写成 `下标:#`，数组里没有这个位置就写成 `-`。

最后一行 `linked pre=... in=... post=...`，是同一棵树改成二叉链表之后的三种遍历。右斜的三结点 `seq A # B # # # C` 见 `tests/practice-seq.in`。

### `link <先序串>`

用先序串建成二叉链表，成功时 `link ok n=<结点数> root=<根字符>`。串在中途用完：`fail short`。串还有多余字符：`fail extra`。整棵树是空的（只有一个 `#`）：`fail empty`。

### `shape`

打印当前树。还没有树：`fail empty`。第一行的 `null` 是空着的孩子指针个数，`width` 是最宽一层的结点数，`complete` 为 1 表示完全二叉树。

接着是 `pre=`、`in=`、`post=`，一行 `check n0=n2+1 ok=1` 或 `ok=0`，再一行这些标志：

- `pre_eq_in`：先序串和中序串是否相同
- `no_left`：没有任何结点有左孩子
- `no_right`：没有任何结点有右孩子
- `nonleaf`：非叶结点个数
- `nonleaf_deg1`、`nonleaf_deg2`：每个非叶结点是不是都恰有 1 个、或都恰有 2 个孩子。没有非叶结点时，这两个都是 1
- `all_deg1`、`all_deg2`：是不是每个结点（含叶子）的度都是 1、或都是 2

最后一行 `seq1` 是按完全二叉树编号摊开的顺序存储，`waste` 是空洞数。树太斜、下标超过 63：这一行改成 `seq1 fail size`。

**样例**

输入：

```
link AB##C##
shape
```

输出：

```
link ok n=3 root=A
shape n=3 n0=2 n1=0 n2=1 null=4 height=2 width=2 complete=1
pre=ABC in=BAC post=BCA
check n0=n2+1 ok=1
pre_eq_in=0 no_left=0 no_right=0 nonleaf=1 nonleaf_deg1=0 nonleaf_deg2=1 all_deg1=0 all_deg2=0
seq1 1:A 2:B 3:C waste=0
```

`ABD##E##C##` 的 `shape` 和整段 `walk` 在 `tests/practice-walk.in`。

### `walk`

对当前树打印递归过程、非递归过程和层次遍历。还没有树：`fail empty`。

递归每种遍历都有 `enter`、`visit`、`leave`。先序的 `visit` 在进入左右子树之前，中序在两者之间，后序在两者之后。三种序列各收成一行 `rec_pre`、`rec_in`、`rec_post`。

非递归：

- 先序：弹出就访问，然后先压右孩子、再压左孩子。`push=` 按压入顺序列出孩子字符，没有孩子是 `-`。栈从栈底打到栈顶
- 中序：结点非空就压栈并走向左孩子；栈顶弹出时访问，再走向右孩子
- 后序：沿左孩子一路压栈。栈顶的右孩子若存在并且还没访问过，就转向右孩子；否则弹出并访问
- 层次：队列里一层的结点连续出队。出队时把左右孩子中非空的入队。`width` 是各层 `count` 的最大者

完全二叉树：空孩子也入队，打印成 `0:#`。出队遇到空结点之后，若再出队到非空结点，打 `reject`，`complete=0`。一直到队列空都没有这种事，`complete=1`。

五结点那棵树的每一步在 `tests/practice-walk.out`。先序第一行是 `pre step=1 id=1 pop=A visit=A push=C,B stack=[5:C 2:B]`，栈顶是 `B`。

### `prein <先序> <中序>` 和 `postin <后序> <中序>`

两条串等长，字符互不重复，并且用到的是同一批字符。每次确定一个根，打一行 `split root=<字符> left=<中序左段> right=<中序右段>`，空的一段写成 `-`。成功后 `built n=<结点数> root=<根>`，这棵树成为当前树。

字符非法或重复：`fail char`。两串对不上：`fail mismatch`。结点太多：`fail size`。`ABDECF` 配 `DBEACF` 见 `tests/practice-build.in`。

### `prepost <先序> <后序>`

列出同时满足这两条序列的每一棵树。`shape` 里 `A(B,C)` 表示左右孩子都有，`A(,B)` 表示只有右孩子，`A(B,)` 表示只有左孩子，叶子只写字符。每棵树一行 `tree <序号> shape=... in=...`，序号从 1 起。最后 `unique=1` 或 `unique=0`。

两条串用的字符集合不同：`fail set`。集合相同但一棵树也拼不出来：`fail mismatch`。串长超过 6：`fail size`。`AB` 对 `BA` 有两棵，`ABC` 对 `BCA` 只有一棵，见 `tests/practice-build.in`。

### `wpl <权值或 #>...`

先序读入，空孩子是 `#`。叶子才把 `weight * edge` 加进去。`edge` 是从根到该结点的边数，根是 0。同一行的 `level` 是层次，根是 1，只打印，不参与相乘。非叶打 `inner`，它的权值不加入。最后一行 `wpl=<和>`。

样例这棵树的叶子是 5、1、3：

```
wpl 4 2 5 # # 1 # # 3 # #
```

```
rule path_edge root=0 level root=1 use=edge
inner weight=4 edge=0
inner weight=2 edge=1
leaf weight=5 edge=2 level=3 add=10
leaf weight=1 edge=2 level=3 add=2
leaf weight=3 edge=1 level=2 add=3
wpl=15
```

只有一个结点时也要写出两个空孩子：`wpl 7 # #`，和是 0。串提前结束：`fail short`。还有多余的词：`fail extra`。权值不是非负整数：`fail format`。

### `infix <词或 #>...`

先序读入表达式树。按中序输出，非根的非叶结点在左右子树外面加一对括号。根的 `deep` 是 1。`deep>1` 才打括号。叶子只输出词。左孩子为空就什么都不输出，再输出本结点的词。最后一行 `infix <字符串>`。

`*` 的左子树是 `+`，右子树是 `*`，后者的右孩子是单目 `-`：

```
infix * + a # # b # # * c # # - # d # #
```

结果是 `infix (a+b)*(c*(-d))`。另一棵树得到 `(a*b)+(-(c-d))`，过程在 `tests/2017-41.out`。

### `exam <题号>`

题号是 `2009-5`、`2011-4`、`2011-5`、`2017-4`、`2014-41`、`2017-41`。输出就是对应 `.out` 文件。不认识的题号：`fail unknown exam <题号>`。

`tests/` 里的每组 `<用例>.in` 都会喂给主程序，输出必须与同名 `.out` 一致（行尾空白和首尾空行会被忽略）。

### 失败输出

拒绝后继续读下一条命令，退出码仍是 0。

- 没有当前树却执行 `shape` 或 `walk`：`fail empty`
- 不认识的命令：`fail unknown <命令名>`

### 2017-41（15 分）

请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。例如，当下列两棵表达式树作为算法输入时，输出的中缀表达式分别为 `(a+b)*(c*(-d))` 和 `(a*b)+(-(c-d))`。

二叉树结点的定义如下：

```c
typedef struct node {
    char data[10];   /* 存储操作数或操作符 */
    struct node *left, *right;
} BTree;
```

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

> 第一棵树的根是 `*`，左子树是 `a+b`，右子树是 `c*(-d)`，其中 `-` 是单目减号，左孩子为空。第二棵树的根是 `+`，左子树是 `a*b`，右子树是 `-(c-d)`。试卷上的负号就是这里的减号 `-`。
