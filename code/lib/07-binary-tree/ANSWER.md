> 王道第 5 章。二叉树和普通的树不一样：每个结点最多两个孩子，而且左右不能对调。先序、中序、后序都是「处理根」和「走两边子树」的不同次序。层次遍历用队列，一层一层走。中序负责把左右子树切开，所以它配上先序或后序就能把树还原；先序配后序还缺这一刀。

## 思路

### 两个等式，空树除外

非空二叉树的边数是 `n - 1`，也等于 `n1 + 2*n2`。结点数又是 `n0 + n1 + n2`。两式相减得到 `n0 = n2 + 1`。空树没有根，边数公式不能写成 `n - 1`，所以不要把 `0 = 0 + 1` 套到空树上。

由此还能看出 `n` 和 `n1` 的奇偶性相反：`n = 2*n2 + 1 + n1`，前半段是奇数。`n` 是偶数时 `n1` 必须是奇数，`n` 是奇数时 `n1` 必须是偶数。`prop 2 ? 0 ?` 没有解，`reason=parity`，因为 2 和 0 同为偶数。

只知道 `n` 时解有很多个。`n0` 最少是 1（一条链），最多是 `ceil(n/2)`。完全二叉树把 `n1` 收成 0 或 1，解才唯一：`n` 为偶数则 `n1 = 1`、`n0 = n/2`；`n` 为奇数则 `n1 = 0`、`n0 = (n+1)/2`。

`test.c` 用固定种子长出 30 棵树，每棵都检查 `n0 = n2 + 1`，并且空着的孩子指针是 `n + 1` 个。`n` 个结点有 `2n` 个指针域，其中 `n - 1` 个指向孩子，剩下 `n + 1` 个为空。这 `n + 1` 个空链域是下一关线索二叉树要用的。

### 2011-4：768 个结点，叶子 384，选 C

`n = 768` 是偶数，所以 `n1 = 1`，`n0 = 384`，`n2 = 383`。高度 `floor(log2 768) + 1 = 10`。

另一条算法不先用奇偶：完全二叉树按层编号之后，叶子是编号 `floor(n/2) + 1` 到 `n`。`floor(768/2) = 384` 是最后一个分支结点，叶子个数是 `768 - 384 = 384`。

最下一层还可以单独数。前 9 层满，有 `2^9 - 1 = 511` 个结点，第 10 层有 `768 - 511 = 257` 个。这 257 个全是叶子，它们的双亲有 `ceil(257/2) = 129` 个，都在第 9 层。第 9 层共 256 个结点，其中 `256 - 129 = 127` 个自己就是叶子。叶子合计 `257 + 127 = 384`。

选项 A 的 257 只是最下一层。选项 B、D 是在 257 或 384 上多加了 1。

### 2009-5：第 6 层 8 个叶子，最多 111，选 C

完全二叉树的叶子只出现在最下两层。第 6 层已经有叶子，树高只可能是 6 或 7。要结点数最多，就取高度 7。

高度为 7 时，前 6 层必须是满的，共 `2^6 - 1 = 63` 个。第 6 层有 32 个位置，其中 8 个是叶子，剩下 24 个各有 2 个孩子，第 7 层 48 个。总数 `63 + 48 = 111`。若最后那个分支结点只带 1 个孩子，第 7 层是 47 个，总数 110，比 111 少，不是「最多」。

高度停在 6 时，前 5 层满，有 31 个，第 6 层恰好 8 个结点，总数 39。这是最少，不是最多，选项 A 就是这个数。

选项 D 的 119 等于 `2^7 - 1 - 8`。满的 7 层是 127 个，少掉的不是那 8 个叶子本身，而是这 8 个叶子若还往下长会多出来的 16 个孩子。`127 - 16 = 111`。

`most 1 1` 只有根这一个叶子，最少最多都是 1。第 6 层若 32 个全是叶子，`branch = 0`，树不能再高。

### 编号从 1 起，2022 从 0 起

`cbt 10 6` 里，结点 6 的双亲是 `floor(6/2) = 3`，`2*6 = 12` 已经超过 10，所以它是叶子。6 是偶数，是双亲的左孩子，右兄弟是 7。

同一点换成从 0 起的下标是 5。双亲 `(5-1)/2 = 2`，也就是从 1 数的结点 3。左孩子 `2*5+1 = 11`，右孩子 `2*5+2 = 12`，都超出了 0 到 9 的范围。

右斜的三结点 `A → B → C` 在顺序存储里占下标 1、3、7，数组要开到 7，空洞有 4 个。`seq` 打出 `left1=2:#`，表示下标 2 这个位置空着。同一关系从 0 起是下标 0、2、6。2022-41 判断二叉搜索树时用的就是这套从 0 起的下标，空位写成 `-1`。树形没有变。

二叉链表不靠这个公式。`link A#B#C##` 得到三个结点，每个结点自己的 `right` 指向下一个。`shape` 再把它摊回顺序存储，才会重新出现下标 7 和那些 `#`。

### 递归看 visit 的位置，非递归看栈里剩谁

`ABD##E##C##` 这棵树是：

```text
      A
     / \
    B   C
   / \
  D   E
```

先序是「访问、左、右」，序列 `ABDEC`。中序是「左、访问、右」，序列 `DBEAC`。后序是「左、右、访问」，序列 `DEBCA`。层次是 `ABCDE`，最宽的一层有 2 个结点。叶子是 D、E、C 三个，度为 2 的是 A、B 两个，`3 = 2 + 1`。空链域 6 个。它是完全二叉树，但不是满的：满的三层要 7 个结点。

非递归先序每次弹出就访问，并且先压右孩子再压左孩子。访问 A 之后栈是 `[C B]`，栈顶是 B，下一轮才会先走到左子树。先压左再压右的话，下一轮弹出的是右孩子，先序就错了。

非递归中序一路向左压栈，左边空了才弹出访问，然后转到右孩子。D 在 B 的左边，所以 D 比 B 先访问。栈里留着的是还没访问的祖先。

非递归后序也是先沿左边压栈。看栈顶时，右孩子若存在而且不等于「刚访问过的那个结点」，就转到右孩子，先不弹出。否则弹出并访问，同时把这个结点记成刚访问过的。没有这个记号，刚从右边回来还会再走进右孩子。

层次遍历用循环队列。出队访问，非空的左孩子、右孩子依次入队。队列里连续的一段就是一层，这一段的长度就是该层宽度。

判断完全二叉树时，空孩子也入队。一旦出队过空结点，后面就不该再出队到实结点。`AB#E##C##` 是 A 的右孩子 C、B 的右孩子 E，B 没有左孩子。层序把这个空位排在 E 的前面，所以会先看到空、再看到 E，`complete=0`。顺序存储里这个空位就是下标 4 的 `#`，E 落在下标 5。

### 2017-4：先序和中序相同，当且仅当没有左孩子，选 B

先序是「根，左，右」，中序是「左，根，右」。任何一个结点只要有左子树，这棵左子树的结点在中序里排在根前面，在先序里排在根后面，两条序列就不会相同。

反过来，每个非叶结点都只有右孩子时，两种走法都变成「根，然后右子树」。右斜链 `A#B#C##` 的先序和中序都是 `ABC`。

四个选项：

- A 只有左子树。左斜链 `ABC####` 的先序是 `ABC`，中序是 `CBA`，并不相同
- B 只有右子树。上面的右斜链满足，而且「有左孩子」必然使两条序列不同，所以这个条件正好
- C 结点的度均为 1。左斜链的非叶结点度也是 1，但序列不同。另外叶子的度是 0，若把这句话理解成每一个结点，任何有叶子的树都不满足
- D 结点的度均为 2。`AB##C##` 的根度是 2，先序 `ABC`、中序 `BAC`，不相同。右斜链能让序列相同，可那些非叶结点的度是 1 不是 2

只有一个结点时，先序和中序都是这一个字符。它没有非叶结点，「所有非叶结点都只有右子树」这种说法空着也成立。`all_deg1` 仍是 0，因为这个唯一的结点是叶子。

### 先序加中序能切开，先序加后序切不开

先序的第一个字符是根。到中序里找到它，左边整段是左子树，右边整段是右子树。左右子树的结点数也就知道了，再按同样的个数去切先序的剩余部分。`ABDECF` 和 `DBEACF`：

```text
split root=A left=DBE right=CF
split root=B left=D right=E
split root=C left=- right=F
```

得到的树后序是 `DEBFCA`。再用这条后序配合同一条中序建回来，先序仍是 `ABDECF`。后序的根在最后，切中序的方法和先序对称。

先序 `AB`、后序 `BA` 有两棵树：`A(,B)` 的中序是 `AB`，`A(B,)` 的中序是 `BA`。先序都是先 A 后 B，后序都是先 B 后 A。差只在 B 挂在左边还是右边，两条序列都看不出来。

结点各不相同、而且每个结点要么是叶子、要么有两个孩子时，先序加后序才唯一。`ABC` 配 `BCA` 只有 `A(B,C)`。满二叉树是这种树的特例，但不是唯一的一类：少掉一些叶子、只要没有度为 1 的结点，也唯一。

### 2011-5：八棵链里没有 3,2,4,1，选 C

先序 `1234` 和后序 `4321` 正好相反，所以这棵树是一条链，每个非叶结点只有一个孩子。三个孩子各有左右两种挂法，一共 `2^3 = 8` 棵。程序把它们都列出来了：

| 挂法 | 中序 |
|---|---|
| 全右 | 1 2 3 4 |
| 只把 4 挂到 3 的左边 | 1 2 4 3 |
| 3 在 2 的左边、4 在 3 的右边 | 1 3 4 2 |
| 3 和 4 都在左边 | 1 4 3 2 |
| 2 在 1 的左边，其余向右 | 2 3 4 1 |
| | 2 4 3 1 |
| | 3 4 2 1 |
| 全左 | 4 3 2 1 |

选项 A、B、D 都在表里。选项 C 的 `3,2,4,1` 不在。它要求 3 在 2 的左边、4 在 2 的右边，也就是结点 2 同时有两个孩子。那样后序不会是 `4321`。`test.c` 用另一套「按位决定左右」的写法生成这 8 个中序，和 `prepost` 的结果对过。

## 2014-41 三段式

**1. 设计思想**

叶子的带权路径长度是「权值 × 从根到该叶子的边数」。根到自己是 0 条边。对树做一次遍历，把边数当作参数传下去，走到叶子就累加，走到空结点就返回 0。非叶结点的 `weight` 题面没有定义，不读进和里。

**2. 结点**

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

**3. 算法实现**

带打印的版本在 `answer/src/wpl.c`，孩子是编号。卷面用指针：

```c
int wpl_at(BiTree t, int edge) {
    if (t == NULL) return 0;
    if (t->lchild == NULL && t->rchild == NULL)  /* 左右都空才是叶子 */
        return t->weight * edge;                 /* edge 是边数，根传入 0 */
    return wpl_at(t->lchild, edge + 1) + wpl_at(t->rchild, edge + 1);
}

int WPL(BiTree root) {
    return wpl_at(root, 0);
}
```

样例 `4 / 2 / 5,1` 和右孩子 `3`：`5*2 + 1*2 + 3*1 = 15`。只有一个结点时边数是 0，积是 0。把根的 4 换成 100，15 不变。

**4. 复杂度**

每个结点进函数一次。时间 O(n)，递归栈深度是树高，最坏 O(n)。

## 2017-41 三段式

**1. 设计思想**

中缀表达式就是表达式树的中序序列。只做中序会丢掉括号，`a+b*c` 和 `(a+b)*c` 的中序都可能写成 `a+b*c`。除了整棵树的根和叶子，每个运算符在自己的左右子树外面加一对括号，运算次序就和树一致。根的层号从 1 记，大于 1 才加括号。单目减号的左孩子是空，中序走左边时自然不输出字符。

**2. 算法实现**

```c
void to_exp(BTree *t, int deep) {
    if (t == NULL) return;
    if (t->left == NULL && t->right == NULL) {   /* 叶子不加括号 */
        printf("%s", t->data);
        return;
    }
    if (deep > 1) printf("(");                  /* 根的 deep 传入 1 */
    to_exp(t->left, deep + 1);                  /* 左空时这里直接返回 */
    printf("%s", t->data);
    to_exp(t->right, deep + 1);
    if (deep > 1) printf(")");
}
```

第一棵树得到 `(a+b)*(c*(-d))`。第二棵树里，单目减号的 deep 是 2，它的右孩子那棵二元减号 deep 是 3，所以是 `(a*b)+(-(c-d))`。最外层没有括号。

**3. 复杂度**

每个结点访问一次，输出长度也是 O(n)。时间 O(n)，递归栈 O(树高)。

## 易错点

1. **`n0 = n2 + 1` 的前提是非空。** 空树两个量都是 0。给出 `n0 = 0` 直接冲突，因为非空树至少有一个叶子。
2. **`n` 和 `n1` 奇偶性相反。** 完全二叉树 `n` 为偶数时 `n1 = 1`，为奇数时 `n1 = 0`。写成「同奇偶」会把 768 的 `n1` 判成 0，叶子就少算或多算一个。
3. **层次从 1 起，WPL 的边数从 0 起。** 王道里根的层次是 1。路径长度是边数，根是 0。单结点若按层次去乘，得到的是权值本身，题意是 0。样例若从 1 起乘，15 会变成每个叶子都多乘一层。
4. **非叶的权值不加。** 题面只保证叶子的 `weight` 有意义。根换成 100，WPL 仍是 15。
5. **叶子是左右都空。** 条件写成「有一个孩子为空」会把度为 1 的结点当成叶子，提前返回，下面的叶子就丢了。
6. **先看下标从几起。** 王道和本关的 `cbt` 从 1 起，孩子 `2i`、`2i+1`。2022-41 从 0 起，孩子 `2i+1`、`2i+2`。`cbt 10 6` 的两行指的是同一个叶子。
7. **顺序存储的空洞要占着。** 右斜三结点用到下标 7，不是紧凑地存在下标 1、2、3。二叉链表才不留空洞。
8. **非递归先序先压右孩子。** 栈顶先弹出的是后压进去的。先压左的话，先序会先走右子树。
9. **后序要记住刚访问的结点。** 从右孩子回来时，栈顶仍是它的双亲。不比较这个记号，右孩子会被再次进入。
10. **完全二叉树要把空孩子入队。** 只把非空孩子入队，队列里永远没有空位，任何树都会被判成完全的。`AB#E##C##` 的空位在 E 前面。
11. **先序加后序看不出唯一的孩子在哪一边。** `AB` 和 `BA` 有两棵树。2011-5 的 `3241` 要求结点 2 有两个孩子，和「先序后序正好相反」矛盾，所以选 C。没有度为 1 的结点时，先序加后序才唯一；满二叉树只是其中一种。
12. **先序等于中序，差的是有没有左孩子。** 度为 1 的左斜链不满足。叶子的度是 0，所以「每个结点的度都是 1」对有叶子的树不成立。
13. **2011-4 的 257 不是叶子总数。** 它只是第 10 层。第 9 层还有 127 个没有孩子的结点。
14. **2009-5 的 39 是最少。** 119 少减了 8。最多是 111。
15. **表达式的根和叶子不加括号。** 评分标准把根的 `deep` 设成 1，`deep > 1` 才加。单目减号不要单独写分支，左孩子为空时左边自然没有字符。给每个操作数也加括号，会和题面的两个式子不一致。

## 概念卡片参考

- **树和二叉树**：树的一个结点可以有任意多个孩子，孩子之间通常不区分次序。二叉树每个结点最多两个孩子，而且左、右是有意义的，只有左孩子和只有右孩子是两棵不同的树。所以「度不超过 2 的树」不等于二叉树。二叉树才有先序、中序、后序这三套走法；普通树说先根、后根。
- **满二叉树和完全二叉树**：高度为 h、结点数正好是 `2^h - 1` 的是满二叉树，每一层都满，没有度为 1 的结点。完全二叉树只允许最下一层的右边缺结点，缺了之后不能在更右边又出现结点，也不能在上面的层缺。满二叉树是完全二叉树；反过来，`ABD##E##C##` 有 5 个结点，是完全的，但三层满了应该是 7 个，所以不满。完全二叉树里度为 1 的结点最多一个，并且只可能有左孩子。
