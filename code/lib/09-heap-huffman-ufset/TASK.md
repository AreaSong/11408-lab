# lib/09 · 堆、哈夫曼树、并查集 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 5 章。有的版次把并查集放在查找那一章，考纲仍把它和堆、哈夫曼树放在树这一部分。堆是一棵完全二叉树，用数组按层存。哈夫曼树是带权路径长度最小的二叉树。并查集用双亲数组表示若干棵树，根就是集合的名字。

## 一、本关任务

- **产出**：小根堆（也要能切换成大根堆）；用堆做优先队列和 Top-K；哈夫曼树、编码和 WPL；并查集（按秩合并 + 路径压缩），以及判断连通、判断无向图有没有环
- **小步骤**：
  ① 建堆、插入、删除。每次筛选都要留下调整过程
  ② 优先队列就是堆的插入和删除堆顶。另写 Top-K：用大小为 k 的小根堆留下最大的 k 个数
  ③ 用反复取两个最小权值的办法构造哈夫曼树，输出编码，并检查前缀性。WPL 用叶子路径算一遍，再用内部结点权值加一遍，两个数必须相同
  ④ 并查集。分别做「总把第一棵树挂到第二棵下面」「按秩合并」「按秩合并并且路径压缩」。合并之后同时打出真实树高和秩。无向图里，一条边的两端已经在同一集合，这条边就成环
- **通过标准**：单元测试通过；2009-9、2018-11、2021-11、2024-9 的堆序列与标准答案一致；2018-5、2021-5、2023-4、2025-5 的编码、WPL 或编码长度与标准答案一致；按秩合并后的树高低于不做优化时的链，路径压缩之后真实高度下降、秩不降

每个项目有两个程序：`main.c` 编出的主程序（与项目同名，如 `heap_huffman_ufset_first`）、`test.c` 编出的单元测试（`heap_huffman_ufset_first_test`）。

约定：

- 堆和并查集的下标都从 1 起，0 不用。堆的父结点是 ⌊i/2⌋，左孩子 2i，右孩子 2i+1
- 大根堆要求父结点不小于孩子，小根堆要求父结点不大于孩子。相等已经算成堆，不要再交换
- 左右孩子一样大时留下边。王道筛选是「右孩子的关键字严格更优，才把下标拨到右边」
- 建堆从最后一个非叶结点 ⌊n/2⌋ 往前，对每个结点向下筛选。这和「从空堆一个一个插进去」不是同一种过程，两种都要实现
- 哈夫曼树：每次在还没有双亲的结点里选权值最小的两个，权值相等时下标小的先选。先选出的做左孩子，后选出的做右孩子。左分支记 0，右分支记 1
- 并查集的 `height` 是边上的条数，单结点是 0，和秩用同一把尺子。路径压缩会把真实高度压低，秩不改
- `plain`：把第一个参数所在的树挂到第二个参数的根下面
- `rank`：秩小的根挂到秩大的根下面。秩相等时，把后一个根挂到前一个根下面，前一个根的秩加 1
- `both`：按秩合并，查找时做路径压缩。`union` 里面的查找也会压缩，但那一行输出不展开查找过程；要看压缩，用 `find`

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（build / insert / push / pop / topk / huff / prefix / decode / uf / cycle / paths / exam，一行一条，Ctrl+D 结束）：`

读到输入结束就退出，退出码 0。参数不对：往标准输出打 `fail format`，继续读下一条。失败时这条命令不再打别的内容。

| 输出 | 含义 |
|---|---|
| `fail format` | 命令、名字或 0/1 串不合法 |
| `fail range` | 个数、删除次数超出范围 |
| `fail heap` | `push` / `pop` 给的序列还不是堆 |
| `fail dup` | 哈夫曼名字重复 |
| `fail prefix` | 译码用的码不是前缀码 |
| `fail decode` | 比特串对不上任何码字，或译完还有剩余 |
| `fail long` | 这一行太长 |
| `fail unknown` | 不认识的命令 |
| `fail unknown exam <题号>` | 不认识的题号 |

关键字的范围是 −1000000 到 1000000。权值是 1 到 1000000。堆、哈夫曼树、并查集的结点都不超过 32 个。哈夫曼叶子不超过 16 个。

### `build max|min <关键字...>`

把这串关键字先按层摆成完全二叉树，再自底向上建成堆。

先打 `build max` 或 `build min`，再打 `start` 和最初的关键字。然后对每个需要筛选的结点打 `sift <下标>`。发生交换时打 `swap <父下标> <孩子下标>`，紧接着 `now` 和交换后的整表。一个结点可能连续交换好几次。最后一行 `heap` 是建完的堆。

**样例**

输入：

```
build max 1 3 3
```

输出：

```
build max
start 1 3 3
sift 1
swap 1 2
now 3 1 3
heap 3 1 3
```

两个孩子都是 3，筛选留在左边，所以根和左孩子交换，结果是 `3 1 3`，不是 `3 3 1`。

### `insert max|min <关键字...>`

从空堆开始，按给出的顺序一个一个插入。先打 `insert max` 或 `insert min`。每个关键字再打一组：`push <关键字>`、`place`（刚放到表尾、还没上浮的整表）、`sift <下标>`、需要时的 `swap` 和 `now`、然后 `heap`。

### `push max|min <已经是堆的关键字...> + <新关键字...>`

`+` 前面的序列必须已经是对应的堆，否则 `fail heap`。`+` 后面的关键字按顺序插入。先打一行 `push max` 或 `push min`，后面每个关键字的格式和 `insert` 里的一组相同。

### `pop <次数> max|min <关键字...>`

序列必须已经是堆，否则 `fail heap`。次数小于 1，或大于当前个数：`fail range`。每次删除堆顶。先打 `pop max` 或 `pop min`。每一次打 `pop <被删的关键字>`。堆里还有元素时，打 `place`（最后一个元素放到堆顶之后、还没下筛的整表），再 `sift 1` 以及交换，最后 `heap`。删成空堆时只打 `heap -`。

### `topk <k> <关键字...>`

用大小为 k 的小根堆保留目前最大的 k 个。堆还没满就插入。满了以后，新关键字不大于堆顶就打 `skip <关键字>`；大于堆顶就打 `replace <关键字>`，再按删除时的格式向下筛选。全部看完后打 `largest`，从大到小列出这 k 个（不足 k 个就全部列出）。

### `huff <叶子...>`

叶子要么全是 `a:6` 这种「一个字母加冒号加权值」，要么全是正整数。全是整数时，名字按顺序写成 A、B、C……两种写法混在一行里是 `fail format`。名字重复是 `fail dup`。

输出：

```text
huff n=<叶子数>
leaf a=6 b=3
pick d:2 + b:3 -> #7:5
code a=00 len=2
wpl=<叶子带权路径长度>
inside=<内部结点权值之和>
total=<叶子权值之和>
avg=<加权平均长度，保留两位小数>
nodes=<结点数>
degree1=<度为 1 的结点数>
prefix=ok
```

`pick` 的左边是左孩子，右边是右孩子，`#7:5` 是新建的 7 号结点、权值 5。内部结点没有字母，用 `#下标:权值`。只有一个叶子时没有 `pick`，编码写成 `-`，`len=0`。`avg` 用四舍五入保留两位，整数除法算，不依赖浮点格式。

### `prefix <码字...>`

码字只含 0 和 1。没有任何一个码字是另一个的前缀时打 `prefix=ok`。否则打 `prefix=bad <较短的> <被它当了前缀的>`，只报告第一对。

### `decode <比特串> <名字:码字...>`

名字是一个字母。先检查这些码字是不是前缀码，不是就 `fail prefix`。然后从左到右唯一译码。译完打 `text=<名字串>`。对不上或最后剩下一截对不上：`fail decode`。

### `uf plain|rank|both <n> <操作...>`

结点编号 1 到 n，一开始每个结点自成一棵树。操作是 `1-2` 这种合并，或 `find 4`。先打 `uf <模式> n=<n>` 和初始状态，每做一次再打一次状态。

```text
parent 1 1 3 4
height 1
rank 1
components 3
```

`parent` 从 1 号报到 n 号，根的双亲是它自己。`plain` 的 `rank` 打 `-`。合并时打 `union <x> <y>`。已经在同一集合打 `same`。否则打 `link <被挂的根> -> <新根> plain|low|tie`。`low` 是秩不同，矮的挂到高的下面。`tie` 是秩相等。

`find` 先打 `find <x>`。不压缩时沿途打 `up <结点> -> <双亲>`，最后 `root <根>`。压缩时先打到 `root`，再对确实改了双亲的结点打 `compress <结点> -> <根>`，然后打压缩之后的状态。

### `cycle <n> <边...>`

无向图，顶点 1 到 n。边写成 `1-2`。用按秩合并。两端已经连通就打 `edge <u> <v> cycle`，这条边不加进去；否则打 `edge <u> <v> add`。最后两行是 `cycle=yes` 或 `cycle=no`，以及 `components <连通块个数>`。

### `paths <权值...> / <权值...>`

两条从根到叶的权值序列，中间用单独的 `/` 分开。能出现在同一棵哈夫曼树上打 `same=yes`，否则 `same=no`。路径上没写出来的那个孩子，按「父亲的权值减去这个孩子」看成一个叶子。

### `exam <题号>`

题号是 `2009-9`、`2014-6`、`2015-3`、`2017-6`、`2018-5`、`2018-11`、`2019-3`、`2020-9`、`2021-5`、`2021-11`、`2022-5`、`2023-4`、`2024-9`、`2025-5`，或者 `all`。每题先打 `exam <题号>`，再把这题的过程打出来，最后两行是 `option` 和 `pick`。`all` 按上面的顺序接起来，题和题之间空一行。
