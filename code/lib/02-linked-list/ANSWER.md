## 思路

### 单链表改的是指针，不是搬元素

头插两句，顺序不能反：

```c
s->next = head->next;   /* 新结点先抓住原来的第一条链 */
head->next = s;         /* 头结点再指向新结点 */
```

先改 `head->next` 的话，原来的链从入口就断了。连续头插得到的顺序和插入顺序相反：`head 1` 再 `head 2` 得到 `[2 1]`。

尾插把新结点接到 `tail` 后面，新结点的 `next` 置 `NULL`，然后 `tail` 自己前进一步。空表时 `tail` 就是头结点，所以第一句 `tail->next = s` 实际上写的是头结点。不维护尾指针、每次从头找到表尾再插，总时间是 O(n²)；建表时留下尾指针，n 次尾插一共 O(n)。

按位插入先走到位序 i−1 的前驱（头结点是位序 0），再做和头插一样的两句。删除是 `pred->next = q->next`，然后 `free(q)`。`q->next` 要在 `free` 之前用掉。

逆置用头插法：原第一个结点留下，`next` 先置 `NULL`，它变成新表尾；后面的结点逐个摘下，插到头结点后面。摘的时候必须先把 `p->next` 存进 `rest`，否则一改 `p->next` 就找不回后半段。`tail` 要改成这个新表尾。`[7 8 9]` 逆置成 `[9 8 7]` 之后，表尾是 7；逆置前的表尾 9 已经到了表头。`tail` 若还指着 9，下一次尾插会改写 9 的后继，把 8 和 7 从链上摘掉。

### 四种判空

| 表 | 空表长什么样 | 判空 | 遍历停在哪 |
|---|---|---|---|
| 带头单链表 | 头结点的 `next` 是 `NULL` | `head->next == NULL` | `p == NULL` |
| 循环单链表 | 头结点的 `next` 指向自己 | `head->next == head` | `p == head` |
| 循环双链表 | `next` 和 `prior` 都指向自己 | `head->next == head` | `p == head` |
| 非循环双链表 | `next` 是 `NULL`，`prior` 也是 `NULL` | `head->next == NULL` | `p == NULL` |

循环链表上没有 `NULL`。遍历条件写成 `p != NULL` 会一直转下去。尾结点的标志是 `p->next == head`，不是 `p->next == NULL`。

循环单链表的 `rear->next` 始终是头结点。删掉尾结点时，`rear` 退回它的前驱；表被删空时，`rear` 退回头结点。

### 双链表的四次赋值

在 p 后面插入 s，王道的顺序是：

```c
s->next = p->next;
p->next->prior = s;   /* 必须在改 p->next 之前，否则原后继丢了 */
s->prior = p;
p->next = s;
```

循环双链表的后继至少是头结点，这四句在表尾也成立，不用单独判断 `NULL`。空表插入第一个结点时，`p` 是头结点，`s->next` 和 `p->next->prior` 写的都是头结点，插完后头尾互相指着。

非循环双链表插在表尾时 `p->next` 是 `NULL`，不能写 `p->next->prior`。删除表尾同样不能写后继的 `prior`。`ndouble` 的样例里这两处打印 `skip`。表中插入和删除则和循环双链表一样，要改后继的 `prior`。

### 静态链表：下标就是指针

容量 8，下标 0 固定当头结点。`next == -1` 表示空。0 不能再拿来当空，因为它是头结点的下标。

初始时下标 1→2→…→7→-1 串成备用链表，`spare = 1`。插入从 `spare` 取下第一个下标，相当于 `malloc`。删除把头插还回备用链表，相当于 `free`：后释放的下标会先被下一次插入拿走。

`practice-reuse` 里先建成 `[10 20 30]`，三个数据分别在下标 1、2、3。删掉位序 2 的 20 之后，逻辑表是 `[10 30]`，但 `dump` 里下标 2 仍是 `data=20 next=4 free`。元素没有像顺序表那样被搬掉，只是游标不再指到它；这个格子重新分配给 99 时，下标还是 2。

表满是 `spare == -1`，不是“下标用完了就把元素往前移”。7 个数据结点占满之后，位序合法的插入也失败，打印 `fail insert full`。

严蔚敏的静态链表用 `0` 表示空，`space[0]` 是备用链表头，数据表的头在最后一个单元。王道的图是 0 号当头结点、链尾用空游标。本关按王道的图，另外用 `spare` 指向备用链表，避免 0 既是下标又是空指针。

### 2009-42 倒数第 k 个

倒数第 k 个就是正数第 n−k+1 个。单链表没有长度字段，可以先走一遍数出 n，再走 n−k 步。那样是两遍，时间和空间都已经是 O(n)、O(1)。

参考答案合成一趟：p、q 都从首元出发。前 k 次只移动 p，用 `count` 数步；`count` 到 k 之后，每次 p、q 一起移动。p 走到 `NULL` 时，q 离链尾还剩 k 个结点，它就是答案。`count` 还没到 k 链表就结束，说明表长小于 k，返回 0。

`1 2 3 4 5`、k = 2 的过程：p 先单独走到 1、再到 2（count = 2），然后 q 依次经过 2、3、4，p 同步经过 3、4、5。p 变空时 q 停在 4。k = 1 时 q 会一直跟到表尾 5；k = 5 时没有 `sync` 行，q 一直停在表头的 1；k = 6 时 count 只到 5，返回 0。做完再把链表打印出来，还是原来的顺序：题目要求不改变链表。

### 2019-41 重排

目标是 a1, an, a2, an−1, …。后半段要按从尾到头的顺序取，单链表做不到随机访问，所以先把后半段原地逆置，再和前半段交叉插接。三步都只改 `next`，不 `malloc` 新结点。

找中间用官方解答的走法：p 每次一步，q 每次两步，q 的 `next` 为空就停。停下来的 p 在位序 ⌈n/2⌉。前半是从首元到 p，后半是 p 后面的结点。前半的结点数是 ⌈n/2⌉，后半是 ⌊n/2⌋，前半不会比后半短。交叉插入时，后半先用完。

n = 6 时 p 在 3，不是在 4：

| 步 | 前半 | 后半 |
|---|---|---|
| 切断 | 1 2 3 | 4 5 6 |
| 后半头插逆置 | 1 2 3 | 6 5 4 |
| 交叉插入 | 1 6 2 5 3 4 | |

n = 5 时 p 在 3，后半是 4 5，逆置成 5 4，结果 1 5 2 4 3。奇数长度的正中间留在前半，最后落在结果的末尾。n = 0、1、2 不用特殊分支：后半为空或只有一个结点，循环自然做完。

把全部结点指针先存进数组、再按下标重接，结果也对，但空间是 O(n)，题干要求 O(1)。每轮都从头找到当前的表尾再摘下来，空间是 O(1)，时间退成 O(n²)。

## 易错点

1. **判空看的是头结点的 `next`，不是头指针自己**。带头结点的空表仍然有头结点。循环表写成 `next == NULL`，或者遍历写成 `p != NULL`，都会死循环。
2. **头插的两句顺序**。先让新结点指向原来的后继，再让头结点指向新结点。尾插在空表上写的是头结点，因为这时 `tail == head`。
3. **头插建表得到逆序**。要保持输入顺序用尾插，并在建表过程中留住尾指针。
4. **逆置之后更新 `tail`**。新表尾是原来的第一个结点。只把 `next` 逆过来、`tail` 还指着旧表尾，下一次 `tail` 会插错位置。
5. **双链表先改 `p->next` 会丢掉原后继**。`p->next->prior = s` 必须用旧的 `p->next`。非循环表的表尾没有后继，这一句要跳过。
6. **`free` 之前先读 `next`**。静态链表把结点还回备用链表时也会改写这个单元的 `next`，后继下标要先存下来。和单链表先保存 `q->next` 再 `free(q)` 是同一件事。
7. **位序、下标、游标是三样东西**。位序从 1 开始，前驱的位序是 i−1。静态链表里前驱的数组下标常常不是 i−1：`practice-reuse` 删位序 2 时，前驱位序是 1，前驱下标也是 1；插回 99 时新结点下标是 2，但它的位序是 2，不是“下标等于位序”这个规律能一直用下去。
8. **空游标是 −1，不是 0**。0 是头结点。严蔚敏用 0 当空指针，数据表头放在数组最后一格；那份代码和本关的 `dump` 对不上。备用链表按头插回收，刚删掉的下标会立刻被复用，不是去找最小的空闲下标。格子里的旧值在再次分配之前还在。
9. **按值查找失败返回 0**。位序 0 是头结点，本来就不能当元素的位序。不要写成 −1。
10. **2009 的 p 要单独走满 k 步**。走成 k−1 步，q 会停在倒数第 k+1 个。k 大于表长时返回 0，这时 q 可能是 `NULL`，不能打印 `q->data`。题面的指针域名是 `link`，本关结点用的是王道的 `next`，走法一样。做完链表必须还是原样。
11. **2019 的切分点是位序 ⌈n/2⌉**。n = 6 时 `mid pos=3`，n = 5 时也是 3。另一种写法用 `fast->next && fast->next->next`，n = 5 时会停在位序 2。后半逆置再交叉合并，两种切分的最终序列一样，但 `cut` 行不一样，本关测试按官方解答的切分。
12. **2019 先把后半从中间结点上摘下来，再逆置**。摘之前不把 `mid->next` 置 `NULL`，逆置会把前半卷进去。交叉插入时也要先保存两个后继，再改 `next`。
13. **同章另外两道题的丢分点**。2012-42 的共同后缀是同一段结点，判断用指针相等，不用 `data` 相等。2015-41 按绝对值去重，删掉当前结点后前驱不能跟着往前走，否则 `|data|` 连续相同的结点会漏删。本关没有为这两题单独做程序。

## 2009-42 三段式

**1. 设计思想**

设两个指针 p、q 都指向首元结点。p 先单独走 k 步；若不到 k 步就走到表尾，说明表长小于 k，返回 0。随后 p、q 同步前进，直到 p 为空。此时 q 与表尾相距 k 个结点，输出 q 的数据并返回 1。算法只读 `link`，不改链表。

**2. 实现步骤**

1. p、q 初始化为 `list->link`，`count = 0`。
2. p 非空时循环：若 `count < k`，则 `count` 加 1；否则 q 沿 `link` 前进一步。然后 p 前进。
3. 循环结束。`count < k` 返回 0；否则输出 `q->data` 并返回 1。

**3. 算法实现**

带过程打印的版本在 `answer/src/kth.c`，字段名是 `next`。卷面按题干写成 `link`：

```c
int Search_k(LinkList list, int k) {
    LNode *p = list->link;             /* p、q 都从首元出发 */
    LNode *q = list->link;
    int count = 0;
    while (p != NULL) {
        if (count < k) count++;        /* 前 k 步只移动 p */
        else q = q->link;              /* 之后 q 与 p 保持距离 k */
        p = p->link;
    }
    if (count < k) return 0;           /* 表长不足 k */
    printf("%d", q->data);
    return 1;
}
```

**4. 复杂度**

- 时间：p 从首元走到表尾，O(n)
- 空间：只用 p、q、count，O(1)

## 2019-41 三段式

**1. 设计思想**

后半段要按从后往前的顺序插到前半段的间隙里。单链表不能直接取表尾，所以分三步，并且不申请新结点：用 p 走一步、q 走两步找到位序 ⌈n/2⌉ 的结点，把链表切成前后两半；后半段头插法原地逆置；再把逆置后的结点依次插入前半段每个结点之后。前半不短于后半，插入时前半不会先被用完。

**2. 算法实现**

带过程打印的版本在 `answer/src/rearrange.c`，三步和下面这段一致。

```c
void change_list(NODE *h) {
    NODE *p = h, *q = h, *r, *s;
    while (q->next != NULL) {          /* p 一步，q 两步，q 到尾时 p 在位序 ceil(n/2) */
        p = p->next;
        q = q->next;
        if (q->next != NULL) q = q->next;
    }
    q = p->next;                       /* q 是后半的第一个结点 */
    p->next = NULL;                    /* 先切断，再逆置，避免两段缠在一起 */
    while (q != NULL) {                /* 后半头插到 p 后面，得到逆序 */
        r = q->next;
        q->next = p->next;
        p->next = q;
        q = r;
    }
    s = h->next;                       /* s 是前半下一个插入点 */
    q = p->next;                       /* q 是逆置后的后半 */
    p->next = NULL;
    while (q != NULL) {
        r = q->next;                   /* 先保存后继，再改 next */
        q->next = s->next;
        s->next = q;
        s = q->next;
        q = r;
    }
}
```

n = 6 的中间结果见上面的表。n = 5 时 p 停在 3，`cut` 是前半 `[1 2 3]`、后半 `[4 5]`，结果 `[1 5 2 4 3]`。

**3. 复杂度**

- 时间：找中间、逆置、交叉插入各走一遍结点，O(n)
- 空间：只用固定个数的指针，O(1)。题面第 3 问只要求写时间；空间 O(1) 是题干的限制，和“用数组记下全部指针”的做法区分开

## 概念卡片参考答案

### 卡片一：顺序表 vs 链表

| | 顺序表 | 链表 |
|---|---|---|
| 按位存取 | O(1)，下标直接算地址 | O(n)，要从头沿 `next` 走 |
| 存储密度 | 高，连续空间里几乎都是元素 | 低，每个结点都带一到两个指针 |
| 插入、删除 | 平均要移动 O(n) 个元素 | 已经知道结点位置时只改指针，O(1)；找到第 i 个仍是 O(n) |
| 容量 | 动态顺序表可以加倍 | 动态链表按结点申请；静态链表容量编译期定死 |

第 01 关插入、删除要搬家，是因为元素挤在一片连续内存里。链表的元素不必相邻，所以没有 `move data[j]` 那种行，改的是 `link ...`。代价是按位取值也要 `walk`。

### 卡片二：带头结点 vs 不带头结点

带头结点：空表也有一个头结点，判空看 `head->next`（循环表则看它是否指回自己）。第一个元素和后面的元素走同一段插入、删除代码，因为第一个元素前面总有头结点当它的前驱。头结点的地址在初始化之后不变，插入删除不用把“头指针”这个变量再写回去。

不带头结点：空表就是空指针。在空表里插入第一个结点，或者删掉仅有的一个结点，都要修改头指针本身，C 里这个参数得是二级指针。表空、表非空要分成两段写。

本关四种表都带头结点，和王道对链表操作的写法一致。王道的 `LinkList &L` 在初始化时会改头指针，C 里写成 `SList *L`；插入、删除只改头结点里的 `next`，头指针的值不动。
