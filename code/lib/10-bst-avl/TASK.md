# lib/10 · 二叉搜索树与 AVL · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 7 章。二叉搜索树（二叉排序树）要求左子树更小、右子树更大，中序就是升序。平衡二叉树（AVL）首先是一棵二叉搜索树，再要求每个结点的平衡因子只能是 −1、0、1。

## 一、本关任务

- **产出**：二叉搜索树的插入、查找、删除；AVL 的插入和 LL、RR、LR、RL 四种旋转
- **小步骤**：
  ① 二叉搜索树的插入和查找。查找路径上每个结点都算一次比较
  ② 删除的三种情况：叶子、只有一棵子树、左右子树都在
  ③ AVL 的旋转。每次旋转都留下旋转前的最小不平衡子树和转完的结果
  ④ 用递推算出高度为 h 的 AVL 最少有多少结点，再按同样的形状把树造出来，两个数必须一样
- **通过标准**：单元测试通过；2010-4 插入 48 之后 37 的左右孩子是 24 和 53；2013-3 平衡因子为 0 的分支结点是 3 个；2013-6 叶子删后再插入树不变，非叶删后再插入树变了；2012-4 高度 6 且非叶平衡因子全是 1 时有 20 个结点；平均查找长度和手算的分子分母一致

每个项目有两个程序：`main.c` 编出的主程序（与项目同名，如 `bst_avl_first`）、`test.c` 编出的单元测试（`bst_avl_first_test`）。

约定：

- 关键字互不相等。左孩子更小，右孩子更大
- 空树高度是 0，叶子高度是 1。结点高度 = 较高的那棵子树的高度 + 1
- 平衡因子 = 左子树高度 − 右子树高度。AVL 里它只能是 −1、0、1
- 失衡时只处理最低的那棵不平衡子树。LL、RR 是单旋，LR、RL 是双旋
  - LL：左孩子更高，而且左孩子的平衡因子 ≥ 0。右旋
  - RR：右孩子更高，而且右孩子的平衡因子 ≤ 0。左旋
  - LR：左孩子更高，而且左孩子的平衡因子 < 0。先对左孩子左旋，再对失衡结点右旋
  - RL：右孩子更高，而且右孩子的平衡因子 > 0。先对右孩子右旋，再对失衡结点左旋
- 插入造成的失衡，转完这一处就停。删除会让子树变矮，祖先还可能接着失衡，一路都要看
- 删除时，较高那一侧孩子的平衡因子可以是 0。0 仍按单旋处理，不要做成双旋
- 双孩子结点用中序前驱顶上：左子树里最右的那个结点。前驱自己没有右孩子；它若还有左子树，那棵左子树接回前驱原来的位置
- 树形写成括号。空孩子是 `#`，叶子不写括号。AVL 在关键字后面加 `[平衡因子]`，例如 `20[0](10[0],30[0])`
- 查找成功的平均查找长度：每个关键字的比较次数等于它所在的层号，根是第 1 层，分子是这些层号之和，分母是结点数
- 查找失败：n 个结点有 n+1 个空孩子，每个空孩子是一种失败。比较次数等于它父结点的层号，不再把空指针本身算一次比较。分母是 n+1
- 小数用四舍五入保留两位。一半向上进。用整数算：`(分子 × 100 + 分母 / 2) / 分母`，不要依赖浮点格式

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（bst / find / del / back / asl / aslw / avl / avldel / avlback / min / exam，一行一条，Ctrl+D 结束）：`

读到输入结束就退出，退出码 0。空行跳过。参数不对：往标准输出打一行失败，继续读下一条。失败时这条命令不再打别的内容。

| 输出 | 含义 |
|---|---|
| `fail format` | 命令或数字不合法，权值不是正整数，`关键字:权值` 写错 |
| `fail range` | 关键字超过 64 个，或者高度不在 1 到 12 |
| `fail dup` | 同一条命令里关键字重复 |
| `fail long` | 这一行超过 1023 个字符 |
| `fail unknown` | 不认识的命令 |
| `fail unknown exam <题号>` | 不认识的题号 |

关键字的范围是 −1000000 到 1000000。权值是 1 到 1000000。

### `bst <关键字...>`

从空树开始，按给出的顺序插入二叉搜索树。先打 `bst`。每个关键字打 `insert <关键字>`，再打 `tree` 和插入后的整棵树。最后一行 `inorder` 是中序，也就是从小到大。

**样例**

输入：

```
bst 50 30 70
```

输出：

```
bst
insert 50
tree 50
insert 30
tree 50(30,#)
insert 70
tree 50(30,70)
inorder 30 50 70
```

### `find <关键字> <建树用的关键字...>`

用后面的关键字建成二叉搜索树，再查找第一个关键字。先打 `find <关键字>`。沿路径每个经过的结点打 `cmp <关键字>`。找到打 `hit`，否则打 `miss`。建树用的关键字可以一个都没有，那就是在空树上查找。

**样例**

输入：

```
find 30 50 30 70
```

输出：

```
find 30
cmp 50
cmp 30
hit
```

### `del <关键字> <建树用的关键字...>`

建成树之后删除第一个关键字。先打 `del <关键字>` 和 `before`（删除前的树）。没有这个关键字就打 `missing`。否则先打情形，再打 `after`。

| 情形 | 含义 |
|---|---|
| `case leaf` | 叶子，直接摘掉 |
| `case left` | 只剩左子树，用左孩子替代 |
| `case right` | 只剩右子树，用右孩子替代 |
| `case two` | 左右都在。下一行 `pred <前驱>`，用前驱的关键字顶上，再摘掉前驱 |

**样例**

输入：

```
del 30 50 30 70
```

输出：

```
del 30
before 50(30,70)
case leaf
after 50(#,70)
```

### `back <关键字> <建树用的关键字...>`

先按 `del` 的格式删除，删除后、还没插回去的树打 `mid`，再把同一个关键字插回去，最后打 `after` 和 `same=yes` 或 `same=no`。没有这个关键字时，打完 `before` 就打 `missing`。

### `asl <关键字...>`

按顺序建成二叉搜索树。打出 `tree`、`level`（中序，`关键字=层号`）、`success=分子/分母 dec=两位小数`、`fail=分子/分母 dec=两位小数`。

### `aslw <关键字:权值...>`

和 `asl` 一样按顺序建树，但查找成功的平均查找长度按权值加权。分母是权值之和。另外打一行 `weight`，顺序和输入一致。不算查找失败。

### `avl <关键字...>`

从空树开始按顺序插入 AVL。每个关键字先打 `insert`。若出现旋转，对每一处失衡打一组：

```text
pivot <失衡结点> bf=<平衡因子> child=<较高的孩子> childbf=<孩子的平衡因子> kind=LL
unbal <旋转前的这棵子树>
balanced <转完的这棵子树>
```

LR、RL 在两行之间多一行 `half`，那是第一次单旋之后、第二次单旋之前的子树。`pivot` 的 `bf` 是失衡时的值，绝对值至少是 2。一组转完再打 `tree`，那是整棵树。没有失衡就只有 `insert` 和 `tree`。

**样例**

输入：

```
avl 30 20 10
```

输出：

```
avl
insert 30
tree 30[0]
insert 20
tree 30[1](20[0],#)
insert 10
pivot 30 bf=2 child=20 childbf=1 kind=LL
unbal 30[2](20[1](10[0],#),#)
balanced 20[0](10[0],30[0])
tree 20[0](10[0],30[0])
```

30 的左子树过高，左孩子 20 的平衡因子是 1，这是 LL，右旋一次。`unbal` 只写最小不平衡子树；这一题它刚好就是整棵树。

### `avldel <关键字> <建树用的关键字...>`

先按顺序插入 AVL（插入过程不打印），再删除第一个关键字，并沿途打印旋转。`before` 是删除前的整棵树，`after` 是删除并重新平衡之后的整棵树。情形和 `del` 相同。没有这个关键字就打 `missing`。

### `avlback <关键字> <建树用的关键字...>`

在 AVL 上先删除再插入。删除后、还没插回去的整棵树打 `mid`，然后打 `insert <关键字>`。插入若引起旋转，格式和 `avl` 一样。最后打 `after` 和 `same=yes` 或 `same=no`。

### `min <高度>`

高度从 1 算到给出的值。每一行是：

```text
h=<高度> recur=<递推结点数> build=<造出来的结点数> height=<实际高度> avl=yes bf1=<平衡因子为 1 的非叶个数>/<非叶个数>
```

`avl=yes` 表示它仍是二叉搜索树，每个平衡因子的绝对值不超过 1，而且存着的高度和结构一致。高度不超过 4 时，最后再打一行 `tree`。

**样例**

输入：

```
min 2
```

输出：

```
min h=2
h=1 recur=1 build=1 height=1 avl=yes bf1=0/0
h=2 recur=2 build=2 height=2 avl=yes bf1=1/1
tree 2[1](1[0],#)
```

高度 1 没有非叶结点，所以 `bf1=0/0`。高度 2 的那一个非叶结点，左子树高 1、右子树高 0，平衡因子是 1。

题号是 `2010-4`、`2012-4`、`2013-3`、`2013-6`、`2013-42`、`2015-4`、`2019-4`、`2020-5`、`2024-7`，或者 `all`。先打 `exam <题号>`。过程沿用上面的格式，再补一行结论：

- 2010-4：按 24、13、53、37、90、48 插入 AVL，最后打 `left=<37 的左孩子> right=<37 的右孩子>`
- 2012-4：`min 6` 的表格，高度 6 不打 `tree`
- 2013-3：按 1 到 7 插入 AVL，最后打 `bf0=<个数> keys=<平衡因子为 0 的分支结点，中序>`
- 2013-6：对关键字 5、3、7、2、4、6 做三次 `back`，三次前面的标记是 `leaf 2`、`one 7`、`two 3`
- 2013-42：打 `half_level`、`half`、`seq`、两棵树的名字和 `for_root`、`repeat_root` 的平均查找长度。关键字按 do=1、for=2、repeat=3、while=4
- 2015-4：先打一组左大右小的 `pair`，再打一组 `triple`。结论行包括 `root_degree`、`min`、`max`、`last`
- 2019-4：四组 `leaf_same`、`leaf_diff`、`inner_diff`、`inner_same`，每组有 `insert`、`del`、`before`、`after`、`same`
- 2020-5：A 到 D 各打一行插入后的树
- 2024-7：打出用 10、30、20、25 建成的树，以及 A 到 D 是否成立

选择题最后两行是 `option` 和 `pick`。`2013-42` 是综合题，没有这两行。`all` 按上面的顺序接起来，题和题之间空一行。

### 2013-6

### 2013-42

设包含 4 个数据元素的集合 S = {"do"，"for"，"repeat"，"while"}，各元素的查找概率依次为：p1 = 0.35，p2 = 0.15，p3 = 0.15，p4 = 0.35。将 S 保存在一个长度为 4 的顺序表中，采用折半查找法，查找成功时的平均查找长度为 2.2。

（1）若采用顺序存储结构保存 S，且要求平均查找长度更短，则元素应如何排列？应使用何种查找方法？查找成功时的平均查找长度是多少？

（2）若采用链式存储结构保存 S，且要求平均查找长度更短，则元素应如何排列？应使用何种查找方法？查找成功时的平均查找长度是多少？

> 概率按百分数 35、15、15、35 计算，避免浮点格式不一致。折半查找的 2.2 用「下标从 0 起、mid = ⌊(low+high)/2⌋、元素按字典序」核对。
