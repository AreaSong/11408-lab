# lib/11 · 红黑树 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 7 章。红黑树首先是一棵二叉搜索树，再给每个结点涂成红或黑。它不要求左右高度差不超过 1，只要求下面五条性质。叶结点指外部空结点 NIL，不是「没有孩子的那个内部结点」。

## 一、本关任务

- **产出**：红黑树的性质校验、黑高，以及插入时的变色和旋转。删除是第 ④ 步，选做；标准答案实现了它，`tests/practice-del` 用来对照
- **小步骤**：
  ① 写校验：二叉搜索树、五条性质、每个结点的黑高。左右贡献不相等就判失败
  ② 插入。新结点先染红。父结点是黑就结束；父结点是红就看叔叔，trace 打出变色和旋转
  ③ 每插完一个关键字就调用第 ① 步。正确的插入，校验必须通过
  ④（选做）删除。双孩子用中序后继顶上。摘掉的结点原来是黑，才做删除修复
- **通过标准**：单元测试通过；`judge` 能分开根红、红红相邻、黑高不等、不是二叉搜索树；`rb 1 2 3 4 5 6 7` 的最终形态和红结点数与 `tests/practice-seq.out` 一致；`rb 30 20 10` 是 LL，`rb 30 10 20` 是 LR；非空树满足 h < 2 log₂(n+1)

每个项目有两个程序：`main.c` 编出的主程序（与项目同名，如 `rbtree_first`）、`test.c` 编出的单元测试（`rbtree_first_test`）。

约定：

- 关键字互不相等。左孩子更小，右孩子更大
- 颜色只有红和黑。输出里红写 `R`，黑写 `B`
- 全树共用一个黑色哨兵表示 NIL。画树时不画它。没有叔叔，就把它当成黑色叔叔
- 新插入的内部结点先染红。若它成为根，再涂成黑色
- 黑高：从该结点出发走到 NIL，**不含该结点、含 NIL**，路径上的黑结点数。NIL 的黑高是 0，它自己是黑的，所以一个 NIL 孩子交给父亲的数是 1。空树黑高是 0。单独一个黑根的黑高是 1
- 高度：根到 NIL 的最长边数，等于这条路上的内部结点数。空树高度 0，单独一个结点高度 1
- 树形写成括号。空孩子是 `#`，叶子不写括号。颜色写在关键字后面，例如 `20[B](10[R],30[R])`
- `judge` 的结点行按后序：先左子树，再右子树，再自己。`L`、`R` 是左右两侧交给本结点的黑结点数。两侧相等时，这个数就是本结点的黑高，写 `bh=`；不相等，或某一侧已经坏了，写 `bh=bad`，坏掉的一侧写 `L=bad` 或 `R=bad`
- 插入的四种调整，字母说的是新结点和父亲在祖父的哪一侧，旋转方向和 AVL 一样：LL 右旋，RR 左旋
  - 叔叔红：父、叔变黑，祖父变红，再把祖父当成新的当前结点继续。不旋转
  - LL：叔叔黑，当前结点和父亲都是左孩子。父变黑，祖父变红，对祖父右旋
  - RR：叔叔黑，当前结点和父亲都是右孩子。父变黑，祖父变红，对祖父左旋
  - LR：叔叔黑，父亲是左孩子，当前结点是右孩子。先对父亲左旋，这一步不改颜色，再按 LL 做
  - RL：叔叔黑，父亲是右孩子，当前结点是左孩子。先对父亲右旋，再按 RR 做
- 变色把根涂红时，循环结束后把根涂回黑色。这一步不是旋转
- 一次插入的旋转次数是 0、1 或 2。只变色是 0，LL/RR 是 1，LR/RL 是 2
- 删除（选做）双孩子用中序后继：右子树里一直向左走到底的结点。真正从树上摘掉的是后继，它的颜色若是红，不必修复；若是黑，按下面四种情形修。一次删除的旋转次数不超过 3
  - 情形 1：兄弟是红。兄弟变黑，父亲变红，对着父亲旋转，然后用新兄弟继续
  - 情形 2：兄弟是黑，兄弟的两个孩子都是黑。兄弟变红，额外的黑上移到父亲
  - 情形 3：兄弟是黑，远离空位的孩子是黑，靠近空位的孩子是红。近孩子变黑，兄弟变红，对着兄弟旋转，进入情形 4
  - 情形 4：兄弟是黑，远离空位的孩子是红。兄弟染成父亲原来的颜色，父亲变黑，远孩子变黑，对着父亲旋转，结束
  - 额外的黑落到一个红结点上时，把这个红结点涂黑。输出 `absorb`
- 比较 2^h 和 (n+1)^2 时用整数。h < 2 log₂(n+1) 就是 2^h < (n+1)^2。不要用浮点

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（rb / judge / del / bound，一行一条，Ctrl+D 结束）：`

读到输入结束就退出，退出码 0。空行跳过。参数不对：往标准输出打一行失败，继续读下一条。失败时这条命令不再打别的内容。

| 输出 | 含义 |
|---|---|
| `fail format` | 命令或数字不合法，关键字超出 −1000000 到 1000000，颜色不是 `B`/`R`，括号不配对 |
| `fail range` | 一条命令里关键字或括号树的内部结点超过 64 个 |
| `fail dup` | 同一条命令的建树关键字重复 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令 |

`judge` 的树形中间不要有空格，它必须是一个词。

### `rb <关键字...>`

从空树开始按顺序插入。先打 `rb`。每个关键字打 `insert <关键字>`。若这一步有调整，在 `tree` 之前按发生的顺序打出来：

```text
uncle <叔叔或#> <R或B> kind=LL
recolor parent <父> B grand <祖父> R
rotate <被旋的结点> right
```

叔叔是 NIL 时，第一项写 `#`，颜色写 `B`。`kind` 是 `recolor`、`LL`、`RR`、`LR`、`RL` 之一。叔红时的变色行是：

```text
recolor parent <父> B uncle <叔> B grand <祖父> R
```

LR、RL 先打第一次 `rotate`，再打 `recolor` 和第二次 `rotate`。根从红被涂成黑时打 `root <关键字> B`，已经是黑就不打。然后打 `tree` 和整棵树，再打：

```text
ok bh=<黑高> reds=<红结点数> height=<高度> spins=<这次旋转次数>
```

全部插完后打 `inorder`，中序关键字用一个空格隔开。一个关键字都没有时，这一行只有 `inorder`。最后一行是 `done n=<结点数> reds=<红结点数> height=<高度> bh=<黑高>`。

**样例**

输入：

```text
rb 30 20 10
```

输出：

```text
rb
insert 30
root 30 B
tree 30[B]
ok bh=1 reds=0 height=1 spins=0
insert 20
tree 30[B](20[R],#)
ok bh=1 reds=1 height=2 spins=0
insert 10
uncle # B kind=LL
recolor parent 20 B grand 30 R
rotate 30 right
tree 20[B](10[R],30[R])
ok bh=1 reds=2 height=2 spins=1
inorder 10 20 30
done n=3 reds=2 height=2 bh=1
```

30 的左孩子 20 也是左孩子 10 的父亲，叔叔是 NIL，按黑色处理，这是 LL，对 30 右旋一次。

### `judge <树形>`

读入一棵已经涂好颜色的树，自底向上核对。先把命令里的树形原样打出来。然后每个内部结点一行：

```text
node <关键字> <R或B> L=<数或bad> R=<数或bad> bh=<数或bad>
```

接着固定这些结论，成立写 `yes`，不成立写 `no`：

```text
bst=yes
color=yes
root=black
nil=black
redred=yes
bh=yes
bh_value=<根的黑高>
rb=yes
```

`root` 还有两种写法：根是红的写 `root=red`，空树写 `root=none`。空树没有结点行，`rb=yes`，`bh_value=0`。出现红父红子时，在 `redred=no` 的下一行打 `pair <父> <子>`，取先序遇到的第一对，先父后子。黑高不相等时不打 `bh_value`。`rb=yes` 表示它是二叉搜索树，并且五条性质都成立。

**样例**

输入：

```text
judge 2[B](1[R],3[R])
```

输出：

```text
judge 2[B](1[R],3[R])
node 1 R L=1 R=1 bh=1
node 3 R L=1 R=1 bh=1
node 2 B L=1 R=1 bh=1
bst=yes
color=yes
root=black
nil=black
redred=yes
bh=yes
bh_value=1
rb=yes
```

1 和 3 是红叶子，左右都是 NIL，各贡献 1 个黑。它们自己是红的，不再加 1，所以根看到的左右都是 1。

### `del <关键字> <建树用的关键字...>`

先按后面的关键字静默建成红黑树，再删除第一个关键字。先打 `del <关键字>` 和 `before`。没有这个关键字就打 `missing`。否则先打情形：

| 情形 | 含义 |
|---|---|
| `case leaf` | 叶子，直接摘掉 |
| `case left` | 只剩左子树 |
| `case right` | 只剩右子树 |
| `case two` | 左右都在。下一行 `succ <后继>` |

然后打 `remove <被摘掉的关键字> color=<摘掉前的颜色>`。双孩子时，被摘掉的是后继，不是命令里那个关键字。需要修复时，按发生的顺序打 `fix`、`recolor`、`rotate`。`side=L` 表示空位在父亲左边、兄弟在右边；`side=R` 相反。`near` 是靠近空位的孩子，`far` 是远离空位的孩子。红结点吸收额外的黑时打 `absorb <关键字> B`。最后打 `after` 和与 `rb` 相同的 `ok` 行，`spins` 是这次删除的旋转次数。

**样例**

输入：

```text
del 7 1 2 3 4 5 6 7
```

输出：

```text
del 7
before 2[B](1[B],4[R](3[B],6[B](5[R],7[R])))
case leaf
remove 7 color=R
after 2[B](1[B],4[R](3[B],6[B](5[R],#)))
ok bh=2 reds=2 height=4 spins=0
```

7 是红叶子。摘掉红结点不改变黑高，也不制造新的红红相邻，所以没有 `fix`。

### `bound <关键字...>`

按顺序静默建成红黑树。先打 `bound` 和 `tree`。然后：

```text
n=<结点数>
height=<高度>
bh=<黑高>
long=<最长边数>
short=<最短边数>
twice=yes
two_h=<2 的 height 次方>
cap=<(n+1) 的平方>
lt=yes
le=yes
reds=<红结点数>
```

`long`、`short` 是根到 NIL 的边数。`twice=yes` 表示 long ≤ 2×short。`lt=yes` 表示 two_h < cap，也就是 h < 2 log₂(n+1)。`le=yes` 表示 two_h ≤ cap。关键字一个都没有时，树是 `#`，高度 0，two_h 和 cap 都是 1，所以 `lt=no`、`le=yes`。

**样例**

输入：

```text
bound 1
```

输出：

```text
bound
tree 1[B]
n=1
height=1
bh=1
long=1
short=1
twice=yes
two_h=2
cap=4
lt=yes
le=yes
reds=0
```

## 三、考法说明

红黑树从 2022 年大纲起列入查找。检索 2022–2026 年数据结构题号和王道笔记，没有见到单独成题的统考原题，所以本关用例都以 `practice-` 开头，不编年份题号。选择题若出现，常见是两问：这棵涂色的树是不是红黑树；按这个顺序插入之后树长什么样、红结点有几个。

下面两题是按这个考法编的练习，不是统考原题。用第二节的命令做，输出要和 `tests/` 里的同名文件一致。

1. 将关键字 1，2，3，4，5，6，7 依次插入初始为空的红黑树。红结点的个数是（ ）。
   A. 1　　B. 2　　C. 3　　D. 4
2. 分别判断：根是红的单结点；一棵黑高相等但有父子都是红的树；一棵没有红红相邻但左右黑结点数不同的树；一棵颜色合法但中序不是升序的树。哪些不是红黑树，分别违反哪一条。
