# code/lib/ · 数据结构通用库

> 数据结构既是 408 的一门课，也是其他三门关卡的工具。这里的每个结构都由用户手写，并被 `co/`、`os/`、`net/` 复用。

## 约定
- 每个结构一对文件：`<name>.h`（接口）+ `<name>.c`（实现），例如 `queue.h` / `queue.c`
- 接口命名：`<结构>_<动作>`，例如 `queue_init`、`queue_push`、`queue_pop`、`queue_free`
- 每个结构配单元测试 `tests/test_<name>.c`；数据结构真题（如算法大题）可作为额外测试
- 手写时对照王道的定义与操作，注明时间复杂度
