# code/lib/ · 数据结构

> 数据结构既是 408 的一门课，也是其他三门关卡的工具库。每个结构由用户手写，并被 `co/`、`os/`、`net/` 复用。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节，不必通读。

## 本科目约定
- **默认「🟢 先学会模式 · 两段式推进」优先（见 [TEACHING.md](../TEACHING.md)）**：
  - **第一段（日常闯关 = 只学基础结构）**：每关只写 `src/` 下的**基础数据结构与基本操作**（建表、增删查、遍历、单趟过程），用 `test.c` 的 `CHECK_EQ` 断言验证返回值 + 1 次总反讲即标 `✅ 基础已通` 过关；**一轮日常默认跳过 🎯 代码算法大题（及 `TASK.md` 中的 `trace` 过程打印、`moves` 统计参数、`main.c` 命令行交互格式）**
  - **第二段（板块刷题节点）**：每学完 1 个大板块（见下方进度表中的 `🎯 板块节点` 分隔行），集中手推本板块 408 选择题；**🎯 代码算法大题统一留到板块节点或学完排序/哈希后，优先用直白好懂的保底高分写法完成三段式**
- **每关一个目录**：`lib/<两位序号>-<英文主题>/`，例如 `lib/02-linked-list/`
- 每个结构一对文件 `<name>.h` + `<name>.c`；接口命名 `<结构>_<动作>`，例如 `queue_push`
- 其他关卡复用时，在该关的 `DEPS` 文件里写一行 `lib/04-queue`（只要部分文件就写 `lib/04-queue queue.h queue.c`），再运行 `./lab.sh sync`：答案项目复制该关 `answer/src`，用户的尝试复制他最新标记完成的那次（没有则用答案），都放进项目的 `deps/`（因此在默认「🟢 先学会模式」下通关只更新下方进度表，**不运行 `./lab.sh done`**，让后续关卡自动复用完整 `answer/src`）
- **trace 模式（仅「🔵 规范化代码模式」启用）**：规范化模式下每个算法打印每一步的中间状态，用来跑通 `ctest`
- **🎯 关卡**的代码算法大题：在阶段刷题节点按"设计思想 + 纯粹 C 核心代码（优先直白保底高分解）+ 复杂度"三段式完成
- 王道的 `LinkList &L` 在 C 中写成 `LinkList *L`（二级指针），函数内用 `*L = ...` 修改头指针；只读不改的参数直接传值 `LinkList L`
- 对照王道的定义与操作；注意下标起点、next 数组起算方式等约定与王道一致
