# code/lib/ · 数据结构

> 数据结构既是 408 的一门课，也是其他三门关卡的工具库。每个结构由用户手写，并被 `co/`、`os/`、`net/` 复用。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节，不必通读。

## 本科目约定
- **每关一个目录**：`lib/<两位序号>-<英文主题>/`，例如 `lib/02-linked-list/`
- 每个结构一对文件 `<name>.h` + `<name>.c`；接口命名 `<结构>_<动作>`，例如 `queue_push`
- 其他科目复用时，在 Makefile 中用相对路径引用，例如 `-I../../lib/04-queue`
- **trace 模式**：每个算法都能打印每一步的中间状态，用来和真题选择题的答案对照
- **🎯 关卡**的最后一步：按"设计思想 + C 代码 + 复杂度"三段式完成 1~2 道真题算法大题
- 王道的 `LinkList &L` 在 C 中写成 `LinkList *L`（二级指针），函数内用 `*L = ...` 修改头指针；只读不改的参数直接传值 `LinkList L`
- 对照王道的定义与操作；注意下标起点、next 数组起算方式等约定与王道一致
