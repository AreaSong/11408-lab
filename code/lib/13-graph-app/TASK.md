>
> 王道第 6 章后半：最小生成树、最短路径、拓扑排序、关键路径。图怎么存、怎么遍历是上一关。

## 一、本关任务

- **产出**：Prim、Kruskal（Kruskal 用第 09 关的小根堆和并查集）；Dijkstra，按轮打印 `dist` 和 `path`；Floyd，打印每一轮的矩阵；拓扑排序，并判断序列是否唯一；关键路径，输出 `ve`、`vl`、每个活动的 `e`、`l`、`slack`，以及关键活动
- **小步骤**：
  ① 最小生成树。Prim 用 `low` / `from` 扫描，不写堆优化版。Kruskal 把边放进小根堆，再用并查集判断会不会成环
  ② Dijkstra。每一轮从未确定的顶点里选一个，再松弛。`dist` 要保留每一轮结束时的样子
  ③ Floyd。`k` 从 0 扫到 n−1，每扫完一个 `k` 把矩阵打出来。对角线上出现负数就是负环
  ④ 拓扑排序。每次取入度为 0 的顶点。某一步候选多于一个，序列就不唯一。顶点排不完，图里有环
  ⑤ 关键路径。先求事件的 `ve`、`vl`，再求活动的最早开始 `e`、最晚开始 `l`。`slack = l - e`。`slack` 为 0 的是关键活动
- **通过标准**：单元测试通过；`tests/2021-8.out` 第 2 轮的 `dist`、`tests/2016-8.out` 的 `order`、`tests/2015-6.out` 里 Prim 的 `alt` 和 Kruskal 的 `open`、`tests/2010-8.out` 的 `count`、`tests/practice-aoe.out` 的 `len` 和 `alone` 与程序一致

每个项目有两个程序：`main.c` 编出的主程序（如 `graph_app_first`）、`test.c` 编出的单元测试（`graph_app_first_test`）。算法都在主程序里，没有第二个带 `main` 的文件。

约定：

- 顶点编号从 0 连续到 n−1。真题若从 1 或字母起，先自己平移再输入。简单图：没有自环，同一条弧不重复加。无向边 `edge 1 0` 和已经加入的 `edge 0 1` 是同一条
- 无向边在矩阵里写成对称的两格，边数只加 1。有向边只写一格
- 没有边的格子打印 `inf`。前驱不存在打印 `-`。权值可以是负数，所以不用 `-` 表示无穷
- Prim、Kruskal 只用于无向图。拓扑排序和关键路径只用于有向图。Dijkstra、Floyd 两种图都可以
- 权值相等时，Prim 和 Dijkstra 都选编号较小的顶点；`low` 或 `dist` 只有严格变小才改前驱。Prim 另有一条同样短的边时，打在 `alt` 后面
- Kruskal 的边序是：权值小的在前；权值相同则较小端点在前，再比另一端。端点在输出里写成小数在前。`open` 是「这一档权值里，现在还不成环、都可能被选作下一条」的边，在这一档还没加入任何边时打印
- Dijkstra 的 `order` 不含源点。`round k` 下面的 `dist` 是第 k 个目标顶点确定并且松弛完之后的数组。问「求出第 k 条最短路径后」就读这一行，不要读最后一轮
- Floyd 的 `path` 里，`path[i][j]` 是从 i 到 j 的路径上 j 的前驱。只有严格变短才改。`k -` 是还没套任何中间点的初值
- 拓扑排序每次在入度为 0 的顶点里取编号最小的。`topo-all` 把全部序列按字典序列出。超过 2000 条就停
- 关键路径的权是活动持续时间，必须 ≥ 0。`alone` 是每一条关键路径都经过的活动
- 比较和计数都用整数。无穷用一个足够大的常数，不要用 `INT_MAX`，松弛时的加法会溢出

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（new / edge / show / prim / kruskal / dijkstra / floyd / topo / topo-all / topo-check / aoe，一行一条，Ctrl+D 结束）：`

读到输入结束就退出，退出码 0。空行跳过。参数不对：往标准输出打一行失败，继续读下一条。失败时这条命令不再打别的内容。还没有 `new` 成功过就执行需要图的命令，打 `fail empty`。失败的 `edge` 不会改掉已经加上的边。

| 输出 | 含义 |
|---|---|
| `fail format` | 命令名对，但参数个数或数字不合法 |
| `fail range` | 顶点数、顶点编号或权值超出下面的限制 |
| `fail loop` | 自环 |
| `fail dup` | 重边 |
| `fail kind` | 这个算法不能用在当前这种图上 |
| `fail empty` | 还没有图 |
| `fail heap` | 无向边多于 32 条，第 09 关的堆放不下 |
| `fail neg` | 关键路径遇到了负权 |
| `fail many` | 拓扑序列超过 2000 条 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令 |

限制：`new` 的 n 是 1 到 12；权值是 −1000000 到 1000000。

### `new U|D n`

建一张空图。`U` 无向，`D` 有向。成功时打一行 `kind=U n=4 e=0`。失败不替换原来的图。

### `edge u v w`

加一条权为 w 的边。成功时不打字。

### `show`

```text
kind=D n=3 e=2 neg=0
mat
0 3 8
inf 0 2
inf inf 0
```

`neg` 是负权边的条数。对角线是 0。

### `prim s`

从顶点 s 长一棵树。`low` 是到树的最小边权，已经在树里的顶点是 0，到不了是 `inf`。`from` 是这条边连回树的哪个顶点，没有则是 `-`。

```text
start 0
low 0 1 inf
from - 0 -
round 1 pick 1 w=1 via 0
low 0 0 inf
from - 0 -
round 2 stop
edges 0-1
cost 1
span no
```

`via` 是选中的那条边。`alt` 是当时另外几条一样短、也可以选的边的另一端，没有就不写。`span yes` 表示 n 个顶点都进来了。`span no` 表示剩下的顶点到不了这棵树。`edges` 按加入顺序列出，端点小数在前；一条都没有时是 `edges -`。

### `kruskal`

```text
heap edges=4
sort 0-3:5 0-2:8 1-2:8 2-3:8
next 5 open 0-3
add 0-3
next 8 open 0-2 1-2 2-3
add 0-2
add 1-2
edges 0-3 0-2 1-2
cost 21
span yes
```

`sort` 是小根堆弹出的次序。`next` 的 `open` 是这一档权值里、此刻还不成环的边。然后按这个次序能加就 `add`，会成环就 `skip`。收够 n−1 条就停，这一档后面还没看的边不再打印。图不连通时 `span no`，`cost` 是生成森林的权。没有边时 `sort -`。

### `dijkstra s`

有负权时第一行是 `warn neg`，后面照样算。`path` 是前驱。`order` 是源点之后依次确定的顶点。`route` 是最终路径；到不了写成 `route 2 -`。

```text
src 0
dist 0 5 inf inf 4 inf
path - 0 - - 0 -
round 1 pick 4 dist=4
dist 0 5 inf 11 4 9
path - 0 - 4 0 4
order 4 1 2 5 3
route 0 0
route 1 0>1
```

`round` 那一行的 `dist=` 是选中它的时候的距离，还没做这一轮的松弛。紧挨着的 `dist` 行才是松弛之后。

### `floyd`

```text
k -
0 3 8
inf 0 2
inf inf 0
k 0
0 3 8
inf 0 2
inf inf 0
k 1
0 3 5
inf 0 2
inf inf 0
path
- 0 1
- - 1
- - -
negcycle no
```

`k -` 是初值。之后每个 `k` 用完打一次距离矩阵。最后的 `path` 是前驱矩阵，对角线固定是 `-`。有负环时 `negcycle yes`，矩阵里的数只是算法跑出来的值。

### `topo` / `topo-all` / `topo-check`

```text
step 0 pick 0 ready 0
step 1 pick 1 ready 1 4
order 0 1 2 4 3
unique no
cycle no
```

`ready` 是这一步入度为 0 的全部顶点，编号从小到大。`unique yes` 表示每一步的 `ready` 都只有一个，并且没有环。有环时 `cycle yes`，`unique no`，再打一行还没输出的顶点 `left 0 1`。一个顶点都没输出时 `order -`。

`topo-all`：

```text
count 3
seq 0 1 2 4 3
seq 0 1 4 2 3
seq 0 4 1 2 3
cycle no
```

没有序列时 `count 0` 且 `cycle yes`。

`topo-check` 后面跟 n 个顶点。是一条拓扑序列打 `yes`，否则打 `no`。个数不对，或某个词不是整数，打 `fail format`。

### `aoe`

```text
ve 0 3 5 7 7 10
vl 0 3 5 7 7 10
len 10
act 0>1 w=3 e=0 l=0 slack=0 key
act 0>3 w=1 e=0 l=6 slack=6
paths 3
path 0>1>2>3>5
path 0>1>2>4>5
path 0>1>4>5
alone 0>1
```

`len` 是工期，等于最大的 `ve`。活动按起点、终点编号排列。`key` 只加在 `slack` 为 0 的活动后面。`path` 是从源点沿关键活动走到汇点的一条关键路径。`alone` 没有时写 `alone -`。有环时只打 `cycle yes`。

**样例**（对应上面 `prim` 的格式，图不连通）：

输入：

```text
new U 3
edge 0 1 1
prim 0
```

输出：

```text
kind=U n=3 e=0
start 0
low 0 1 inf
from - 0 -
round 1 pick 1 w=1 via 0
low 0 0 inf
from - 0 -
round 2 stop
edges 0-1
cost 1
span no
```

### 2009-41
