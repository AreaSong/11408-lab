# lib/14 · 顺序、折半与分块查找 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 7 章前半：顺序查找、折半查找、分块查找。判定树和平均查找长度（ASL）是这三节共用的尺子。二叉搜索树、B 树、散列表在后面几关。

## 一、本关任务

- **产出**：顺序查找（无序、带哨兵、有序）、折半查找（判定树和 ASL）、分块查找（块内顺序、块内折半），都能算出成功和失败的 ASL
- **小步骤**：
  ① 顺序查找。无序表从头扫；无序表从尾扫并在 0 号放哨兵；有序表从头扫，当前元素已经更大就停。分别打出成功、失败的 ASL
  ② 折半查找。按下标取中点，打印判定树，再按层数算 ASL。向下取整和向上取整都要能打
  ③ 分块查找。索引可以顺序或折半，块内可以顺序或折半。等长块还要打出王道的公式值，和按每个关键字真走一遍的结果对照
- **通过标准**：单元测试通过；`tests/2010-9.out` 和 `tests/2023-8.out` 的 `height`、`tests/2013-42.out` 里 `weight=yes` 的 `succ`、`tests/2015-7.out` 每条 `path` 的 `yes`/`no`、`tests/2024-5.out` 的四行 `fit`、`tests/2025-7.out` 的 `pick`，与程序一致
- **概念卡片**（写进 `NOTES.md`）：查找表、静态查找和动态查找、ASL 的定义；成功和失败为什么要分开算

每个项目有两个程序：`main.c` 编出的主程序（如 `search_first`）、`test.c` 编出的单元测试（`search_first_test`）。算法都在主程序里，没有第二个带 `main` 的文件。

约定：

- 关键字、权、`worst` 和 `best` 里的整数，都在 −1000000 到 1000000。查找表的长度是 1 到 64。`worst`、`best` 的 n 是 1 到 100000。`best` 最多 8 个候选块长。分块最多 16 块，每块 1 到 32 个关键字。一行超过 4095 个字符，或一行里的词超过 80 个，拒绝
- 下标从 1 起，和王道的 `ST.elem[1..n]` 一致。0 不是元素，只在带哨兵的顺序查找里当失败位置
- 输出里的 `<` `>` `=` 都是「待查关键字和当前这个数比」。`<` 表示待查的更小。无序顺序查找只分相等和不等，写成 `=` 和 `!=`
- ASL 写成最简分数，后面再跟一个四舍五入到两位的小数，例如 `27/7=3.86`。核对以分数为准。成功的分母是元素个数；给了权就是权的和。失败的分母是失败入口的个数，不受权影响
- `prob` 的权是正整数，个数必须和当前表的长度一样。0 或个数不对，拒绝，原来的权保留
- 有序顺序查找、折半查找的表必须严格升序。块内折半时，这一块也必须严格升序。分块时，后一块的每个关键字都要大于前一块的最大关键字
- 折半的中点：`floor` 是 `(low+high)/2`，`ceil` 是 `(low+high+1)/2`。分块里的折半固定用 `floor`
- 一行一条命令。读到输入结束就退出，退出码 0。空行跳过。失败时这条命令不再打别的内容，已经建好的表保持原样。`blk` 本身成功时会换成一张新的空分块表

| 输出 | 含义 |
|---|---|
| `fail format` | 命令名对，但词的个数、种类不合法，或某个词不是整数 |
| `fail range` | 整数越界，表太长、太空，或权不合法 |
| `fail order` | 该严格升序的地方没有升序，或块和块之间的顺序不对 |
| `fail empty` | 还没有表；分块表还没有块，却要查找或算 ASL |
| `fail kind` | 这条命令不能用在当前这种表上 |
| `fail divide` | `best` 的某个块长不能整除 n |
| `fail full` | 已经有 16 块，还要再加 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令 |

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（seq / bin / blk / add / find / asl / prob / tree / show / worst / path / fit / best，一行一条，Ctrl+D 结束）：`

### `seq plain|guard|order k1 k2 ... kn`

建一张顺序查找表，清掉以前的权，并打出每个位置的比较次数和 ASL。

- `plain`：无序，从下标 1 扫到 n。下标 i 成功要比 i 次。失败比 n 次，只有 1 个入口
- `guard`：无序，从下标 n 扫到 1，最后再和 0 号哨兵比一次。下标 i 成功要比 `n-i+1` 次。失败比 n+1 次
- `order`：升序，从下标 1 扫。相等就成功；当前元素更大就失败停下；扫完也失败。成功次数仍是 i。失败有 n+1 个入口，比较次数依次是 1、2、…、n、n。最后两个都是 n：大于最后一个元素时，扫完表就停，不再多比一次

```text
seq order n=6
cmp 1 2 3 4 5 6
gap 1 2 3 4 5 6 6
asl succ=7/2=3.50 fail=27/7=3.86 weight=no
```

`cmp` 从下标 1 写到 n。`gap` 是每个失败入口的比较次数。`weight=no` 表示成功 ASL 按等概率。

### `prob w1 w2 ... wn`

给当前的顺序表或折半表加权，然后只重打 ASL 那一行。失败入口仍等概率。分块表不能用这条命令。

`tests/2013-42.in`：折半那行的 1、2、3、4 按题面顺序是 do、for、repeat、while，权是 35、15、15、35。顺序那行的 1、4、2、3 是 do、while、for、repeat，权是 35、35、15、15。权是百分数，和为 100。

### `find key`

在当前表里查一个关键字，先打一行 `find 25`，再打比较过程。

有序顺序查找：

```text
find 25
i=1 a=10 >
i=2 a=20 >
i=3 a=30 <
miss cmp=3
```

相等时是 `hit i=4 cmp=4`。带哨兵且失败时，最后多一行 `i=0 sentinel =`，然后 `miss`。无序表的中间行用 `=` 或 `!=`。

折半查找：

```text
find 10
low=1 high=11 mid=6 a=29 <
low=1 high=5 mid=3 a=13 <
low=1 high=2 mid=1 a=7 >
low=2 high=2 mid=2 a=10 =
hit i=2 cmp=4
```

区间空了再打 `low=4 high=3 stop` 和 `miss cmp=3`。`low` 比 `high` 大就是停。

分块查找见下面的 `find`。还没有表，或分块表一块都没有，打 `fail empty`。

### `bin floor|ceil k1 k2 ... kn`

建一张严格升序的折半表，清掉权，打出判定树和 ASL。层数从 1 起，根是第 1 层。成功比较次数就是这个关键字的层数。每个空孩子是一个失败入口，比较次数等于它父结点的层数；`fail` 从左往右写这些次数。n 个结点有 n+1 个空孩子。

`floor` 的 n=5：

```text
bin floor n=5
key 1 2 3 4 5
root=3
depth 2 3 1 2 3
node i=1 key=1 depth=2 left=0 right=2
node i=2 key=2 depth=3 left=0 right=0
node i=3 key=3 depth=1 left=1 right=4
node i=4 key=4 depth=2 left=0 right=5
node i=5 key=5 depth=3 left=0 right=0
fail 2 3 3 2 3 3
height=3
asl succ=11/5=2.20 fail=8/3=2.67 weight=no
```

`left=0` 或 `right=0` 是空孩子。`height` 是最大层数。`ceil` 用同一批关键字再打一遍，层数分布相同，某个下标的层数可能不同。

### `tree`

把当前折半表的 `root`、`depth`、`node`、`fail`、`height` 再打一遍，不打 ASL。当前不是折半表，打 `fail kind`。

### `asl`

把当前表的 ASL 再打一遍。顺序表和折半表只打 `asl` 那一行。分块表打下面三行。一块都没有，打 `fail empty`。

### `worst floor|ceil n`

不建关键字表。按这个 n 造判定树，树高必须和 `floor(log2 n)+1` 相同。

```text
worst floor n=16 height=5 bound=5
```

`height` 是树高，`bound` 是那个公式。两者不一致说明中点取错了。2010 年第 9 题是 `worst floor 16`，2023 年第 8 题是 `worst floor 600`。

### `path k1 k2 ... km`

这串数能不能依次成为某次折半查找比过的关键字。先打 `path`。每个数一行：序号、关键字、当时允许的开区间、`in` 或 `out`。区间一开始是 `(-inf,+inf)`。这个数比前一个小，上界收成前一个；比前一个大，下界收成前一个。落在开区间外就是 `out`，然后打 `no` 并停。全部在区间里，最后打 `yes`。

```text
path
1 500 (-inf,+inf) in
2 200 (-inf,500) in
3 450 (200,500) in
4 180 (200,450) out
no
```

`tests/2015-7.in` 的四条 `path` 依次是 A、B、C、D。

### `fit array|list|static order|chaos`

这种结构能不能直接折半。`array` 能按下标取中点，`list` 和 `static` 不能。`order` 是有序，`chaos` 不是。两个都满足才是 `yes`。缺有序就在 `no` 后面写 `sorted`，缺随机存取就写 `random`，两个都缺就都写。

```text
fit list order no random
fit array chaos no sorted
fit static order no random
fit static chaos no sorted random
```

`tests/2024-5.in` 这四行依次是Ⅰ、Ⅱ、Ⅲ、Ⅳ。两个条件都满足时打 `yes`，例如 `fit array order`。2024 年的四个选项都不是这一行。

### `blk seq|bin seq|bin`

新建一张空的分块表。第一个词是索引怎么查，第二个词是块内怎么查。`seq` 顺序，`bin` 折半。

```text
blk index=seq inner=seq
```

### `add k1 k2 ... ks`

往当前分块表加一块。成功时不打字。块内折半却没有严格升序，或这一块的最小关键字不大于上一块的最大关键字，打 `fail order`，这一块不加。

### `show`

```text
show b=2 n=5 index=seq inner=seq
block 1 n=3 min=1 max=11 11 1 8
block 2 n=2 min=20 max=30 20 30
```

关键字按输入顺序写，不按大小重排。一块都没有时只有第一行，`b=0 n=0`。

### 分块的 `find` 和 `asl`

索引顺序：从第 1 块扫到第 b 块。待查关键字大于这块的最大关键字就 `>`，继续；否则 `<` 或 `=`，进入这块。全部大于，索引失败，不再进块内。

索引折半：在各块最大关键字上做 `floor` 折半。相等就进入这块。`low>high` 时，若 `low` 还在 1 到 b 之间，进入第 `low` 块；`low` 变成 b+1 就是索引失败。

块内顺序：从左到右找相等，不等写 `!=`。块内折半：和整表折半同一套 `low` `high` `mid`，行首加 `inner`。

总比较次数是索引次数加块内次数。索引失败时块内次数是 0。

```text
find 4
index i=1 max=3 >
index i=2 max=6 <
block=2
inner j=1 a=4 =
hit j=1 cmp=3
```

`asl` 打三行：

```text
asl exact=7/2=3.50
parts index=2/1=2.00 inner=3/2=1.50
rough=7/2=3.50 match=yes
```

`exact` 是表里每个关键字按上面的过程真查一遍，再求平均。`parts` 把这些次数拆成索引和块内。`rough` 只在每块个数相同时才有，用王道的等长公式：

- 索引顺序：`(b+1)/2`
- 索引折半：b 个最大关键字做折半查找的成功 ASL。这一块里的每个关键字都按「这块最大关键字的层数」计，不按刚才那条真实路径
- 块内顺序：`(s+1)/2`
- 块内折半：长度为 s 的折半查找成功 ASL

两段相加就是 `rough`。和 `exact` 约分后相同则 `match=yes`，否则 `match=no`。块长不齐时写 `rough=- match=-`。

### `best seq|bin seq|bin n s1 s2 ...`

不建表。n 个元素均匀分成若干块，每块 s 个，b = n/s。某个 s 不能整除 n，整条命令打 `fail divide`，一行结果都不要。ASL 用上面的 `rough`。选最小的那个 s；一样小就留下先出现的，后面的写在 `tie` 里，没有则是 `-`。

```text
best n=4 index=seq inner=seq
s=1 b=4 asl=7/2=3.50
s=4 b=1 asl=7/2=3.50
pick s=1 asl=7/2=3.50 tie=4
```

一样小的块长留在 `tie` 里。`tests/2025-7.in` 的四个 s 依次是 A、B、C、D。
