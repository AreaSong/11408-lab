## 思路

### 中序线索：先递归左边，再改当前，最后递归右边

空的左孩子指向中序前驱，空的右孩子指向中序后继。指针改完之后，单看非空分不清是孩子还是线索，所以每个结点加两位标志：0 是孩子，1 是线索。

线索化要同时知道当前结点和它的前驱。前驱用一个 `pre` 带着走，它始终是中序里刚访问过的结点。访问当前结点时做两件事：自己的左孩子如果空，就指向 `pre`；`pre` 的右孩子如果空，就指向当前结点。后继线索只能由后继来补，因为轮到自己的时候后继还没出现。

递归顺序不能反。先走进左子树，那时左指针还是真正的孩子。改完当前结点再走进右子树，右指针也还没被后继改掉。中序线索化靠这个次序，不会顺着线索转圈。

王道在树的外面加一个头结点。头结点的左标志是 0，左指针指向根；右标志是 1，右指针指向中序最后一个结点。线索化开始前 `pre` 就是头结点，所以第一个结点的前驱线索指向头。结束后，最后一个结点的右指针指向头，头的右指针再指向最后一个结点。空树时头结点的左右都指向自己。

不带头结点的话，这两端是空指针，一共剩 2 个。`plain_null=2` 说的就是这件事。头结点把这两条也接上了，中间结点的线索不变。2014 的 x 不在两端，有没有头结点，它的左右线索都是 b 和 a。

找后继：`rtag` 为 1，右指针就是后继；为 0，后继是右子树里一直向左走到标志为 1 的那个结点。找前驱对称，向右走时必须看 `rtag`。线索化之后右指针非空，可能只是一条回到祖先的线索。写成「指针非空就继续向右」会绕回去。

中序遍历不再要栈。从头结点的左孩子（根）出发，能向左就向左，访问，再按上面的规则取后继，直到回到头结点。`walk` 必须和建树时记下的中序一样，`check=ok`。

`ABD##E##C##` 这棵树是 A 的左孩子 B、右孩子 C，B 的左孩子 D、右孩子 E。中序 `DBEAC`。B 的两个标志都是 0，左右指针仍是 D 和 E。它的前驱是 D，后继是 E，这两个都要靠走到子树尽头才得到，不是 B 自己的线索。E 没有右孩子，`rtag` 为 1，右线索直接是 A。

### 2014-4：中序 edbxac，x 的线索是 b 和 a，选 D

先序串 `abde###x##c##` 对应的树：

```text
      a
     / \
    b   c
   / \
  d   x
 /
e
```

中序是 `edbxac`。x 是叶子，左右指针本来都空，所以两条都会变成线索。x 左边是 b，右边是 a。

四个选项里，e 是 d 的孩子，不是 x 的前驱。c 是 a 的右孩子，中间还隔着 a。d 是 b 的左孩子，中序里 d 在 b 前面。只有 b、a 贴着 x。

b 自己的右指针是孩子 x，`fix=b child`，不能把 b 的右指针也改成线索。d 的右孩子是空的，右线索才是 b。

### 2013-5：后序里，右叶子的右线索是父亲，选 A

后序是「左、右、根」。X 是叶子，又有左兄弟 Y，说明 X 是右孩子，Y 是左孩子。后序先走完 Y 这棵子树，最后一个访问的是 Y 自己，然后访问 X，再访问父亲。所以 X 的后序后继是父亲，右线索指向父亲。X 的后序前驱是 Y，那是左线索，选项 C 看的是左边。

`ayb##c##x##`：

```text
      a
     / \
    y   x
   / \
  b   c
```

后序 `bcyxa`。x 的左线索是 y，右线索是 a。Y 一直向左是 b，一直向右是 c。四个选项分别是 a、b、y、c，只有右线索等于父亲。

若问的是左孩子 b，`ab##c##` 的后序是 `bca`。b 有右兄弟，后继是 c，不是父亲 a。题目里的「有左兄弟」不能省。

### 三种存储看的是不同的指针

同一片森林 `A(B(D,E),C) F(G)`：

```text
    A          F
   / \         |
  B   C        G
 / \
D   E
```

双亲表示每个结点只记父亲，根记 `-1`。找父亲是 O(1)。找孩子要把整张表扫一遍，看谁的父亲是自己。

孩子表示每个结点挂一条孩子链表，从左到右是 B 的 D、E，A 的 B、C。找孩子沿着链表走。找父亲又得去扫别人的链表，除非另外再记父亲。

孩子兄弟表示每个结点只有两个指针：第一个孩子，下一个兄弟。A 的孩子是 B，B 的兄弟是 C，B 的孩子是 D，D 的兄弟是 E，A 的兄弟是下一棵树的根 F。找大儿子和右兄弟都是 O(1)，找父亲仍然不直接。

这三个都不是「更好」，是各管一种操作。要频繁找父亲用双亲表示，要频繁找孩子用孩子链表，要和二叉树的算法共用代码用孩子兄弟。

### 转换只是换一种读法

把 `child` 读成左孩子、`sibling` 读成右孩子，存储一个指针都不用改。

一棵树只有一个根，根没有兄弟，所以根的右指针是空的。`A(B(E,F,G),C,D)` 的 `root_sibling=-`。森林从第二棵树起，根被当成前一棵树根的兄弟，右指针才接上去。`A(B) C` 里 A 的右孩子是 C，`kind=forest`，棵数是 2。

倒过来也一样。二叉树根没有右子树，就还原成一棵树；根有右子树，沿着右孩子数，结点数就是森林的棵数。数的时候不要把右子树里面的左孩子算进去。2021 的右链是 a、c、f 三棵，不是把所有右指针为空的结点都当成树根。

叶子没有孩子，左指针必空。左指针为空的结点也一定没有孩子。所以森林的叶子数等于二叉树中左孩子指针为空的结点数。右指针为空的是「自己是最后一个兄弟」的结点，再加最后一棵树的根，个数是分支结点数加 1，一般不等于叶子数。

`A(B,C,F) D` 有 4 个叶子 B、C、F、D。B 还有兄弟 C，在二叉树里 B 的右指针不空，所以 B 不是二叉树的叶子。二叉树叶子只有 F 和 D，度为 1 的也只有 B 和 C。四个选项里只有「左指针为空」等于 4。这是 2014-5，选 C。用一棵很小的树可能碰巧让几个数相等，要拿有兄弟的叶子去排除。

### 遍历怎么对上

树的先根：根，然后每棵子树的先根。对应二叉树是「根，左子树，右子树」，因为左子树是第一棵子树，右孩子链是其余子树。所以树的先根 = 二叉树的先序。

树的后根：每棵子树的后根，然后根。对应二叉树是「左子树，根，右子树」：先走完第一棵子树和它的兄弟链，再访问根。所以树的后根 = 二叉树的中序。二叉树的后序没有对应的树遍历。

森林就是把每棵树做一遍。先序接起来等于二叉树先序，中序（每棵树的后根）等于二叉树中序。`A(B) C` 的先根是 `ABC`，后根接起来是 `BAC`。二叉树先序 `ABC`，中序 `BAC`，后序 `BCA`。后序已经和森林中序不同。

2019-2 问的就是这件事，选 B。程序用 `A(B(E,F,G),C,D)` 核对：后根 `EFGBCDA` 等于二叉树中序，不等于先序 `ABEFGCD`，也不等于后序 `GFEDCBA` 和层序 `ABECFDG`。

### 2009-6：隔两代可能是父子或兄弟，选 B

孩子兄弟的两条边：

- 左指针：v 是 u 的第一个孩子。森林里 u 是 v 的父亲。
- 右指针：v 是 u 的下一个兄弟。森林里 u 和 v 是兄弟。

u 到 v 走两步，四类里题面问了前两类：

- 第一步左、第二步右：v 是 u 的第二个孩子。森林里是父子。`A(B,C)` 里 A 是 C 的父亲，二叉树里 A 的左孩子 B 的右孩子是 C。
- 两步都向右：u、中间那个、v 是连续三个兄弟。`D(E,F,G)` 里 E 和 G 是兄弟，中间隔着 F。各棵树的根也这样连，`Q R S` 里 Q 和 S 是兄弟。

Ⅲ 说的是 u 的父亲和 v 的父亲彼此是兄弟。程序把 `L(M(N),O(P))` 里的 N 和 P 拿出来：M 和 O 是兄弟，所以 Ⅲ 的那句关系成立，可是 N 的二叉树祖父是 M，不是 N 自己的某个结点去当 P 的祖父。整片例子里，凡是二叉树祖父关系，Ⅲ 的计数都是 0。

还会出现题面没列的关系：u 是 v 父亲的左兄弟。`H(I,J(K))` 里 I 是 K 的二叉树祖父，森林里 I 和 J 是兄弟、K 是 J 的孩子。这不改变选项。Ⅰ 和 Ⅱ 出现过，Ⅲ 在这种祖父关系里不出现，选 B。

### 2010-5、2011-6、2016-5：三条计数

树的边数等于结点数减 1，也等于各结点的度相加。设度为 i 的结点有 nᵢ 个，叶子是 n₀，则

`n0 = 1 + Σ(i-1)·nᵢ`

2010 年 n₄=20，n₃=10，n₂=1，n₁=10：

`n0 = 1 + 3·20 + 2·10 + 1·1 = 82`

度之和是 122，那是边数，选项 D。已给的结点共 41 个，那是分支结点，选项 A。选 B。

2011 年，每个分支结点恰好有一个最右的孩子，这个孩子没有右兄弟。根也没有右兄弟，而且根不是任何人的孩子。无右孩子的结点 = 分支结点数 + 1 = (2011-116)+1 = 1896。有右孩子的是 116-1 = 115，那是选项 A。选 D。

2016 年，每棵树都满足「结点 = 边 + 1」。k 棵树就有 `边 = 结点 - k`，所以 k = 25-15 = 10。一棵树会有 24 条边。选 C。

### 2020-4 和 2021-4：先还原二叉树，再读右链

2020 的先序 `abcdef`、中序 `badfec`。根 a 的左边只有 b，右边是 c，c 的左子树是 d、e、f。按孩子兄弟读回去是两棵树 `a(b)` 和 `c(d,e(f))`。二叉树后序是 `bfedca`，选 C。选项 A 是森林的中序，也就是二叉树的中序，不是后序。

2021 的先序 `abdcegf`、中序 `bdaegcf`。根 a 的右孩子是 c，c 的右孩子是 f，f 没有右孩子。右链三个结点，森林是 `a(b,d)`、`c(e,g)`、`f`，共 3 棵。选 C。b 的右指针指向 d，d 是 b 的兄弟，不是 b 的孩子，不能把 d 算成第三层里的另一棵树。

### 2022-3：右兄弟中间一定夹着父亲，选 B

中序是左子树、根、右子树。左孩子那棵子树的最后一个结点和右孩子那棵子树的第一个结点之间，必定先访问父亲。所以左孩子和右孩子不会在中序里相邻。Ⅲ 不可能。

另外三种都能造出来：

- `qp###` 的中序是 `pq`，q 是 p 的父亲
- `p#q##` 的中序是 `pq`，q 是 p 的右孩子
- `qx#p###` 的中序是 `xpq`，q 是 p 的父亲的父亲

`fp##q##` 的中序是 `pfq`。p 和 q 真是左右兄弟，相邻的却是 (p,f) 和 (f,q)。`sibling_adjacent=0`。选 B。

### 2022-4：244 个结点的三叉树至少 6 层，选 C

叶子高度为 1，高度就是层数，不是边数。高度 h 的满 k 叉树最多 `(k^h - 1) / (k - 1)` 个结点。k=3 时高度 5 是 121，高度 6 是 364。244 在两者之间，最矮是 6。若把叶子高度记成 0，同一棵树的数字会少 1，和题面不符。

### 2024-3：两个孩子把前驱和后继挤到子树边上，选 A

v 有左子树也有右子树。中序里紧挨在 v 前面的 p，是左子树中最靠右的结点，它不能再有右孩子，否则那个右孩子会插在 p 和 v 之间。紧挨在 v 后面的 q，是右子树中最靠左的结点，它不能再有左孩子。

p 可以有左孩子。`va#pb###q##` 的中序是 `abpvq`，v 的前驱 p 左孩子是 b、没有右孩子，后继 q 没有左孩子。选项 C、D 要求 p 有右孩子，和「紧挨着 v」矛盾。选 A。

### 2025-4：森林都能收成一棵二叉树，选 B

- A：两个结点的完全二叉树，根只有左孩子，度是 1
- B：`A B C` 三棵树，根沿右指针串成一棵二叉树
- C：右斜链 `ABC####` 有 1 个叶子、2 个分支结点，分支并不比叶子少。二叉树只保证叶子 = 度为 2 的结点 + 1
- D：表达式树的根是最后才算的那个运算符。先算的是叶子那边的运算

选 B。

## 易错点

1. **线索化之后不能靠指针空不空来判断。** 空指针已经改去指前驱或后继了。向左、向右都要看 `ltag`、`rtag`。
2. **后继线索是后继补上的。** 访问自己时还不知道后继是谁。漏掉「若 pre 的右孩子为空，则指向当前结点」，右线索会少一半。
3. **先递归，再改指针。** 若先把左指针改成线索再递归左边，就会顺着线索走回前驱。
4. **头结点只改变序列两端。** 第一个结点的前驱和最后一个结点的后继指向 `^`。2014 的 x 在中间，线索仍是 b、a。不带头时这两端是空，`plain_null=2`。
5. **有右子树时，后继不是右孩子本人，除非右孩子没有左子树。** B 的右孩子是 E，E 没有左孩子，后继才刚好是 E。右孩子下面还有左子孙时，要走到最左。
6. **树的后根对应二叉树的中序。** 对应后序是 2019-2 的干扰项。`A(B) C` 的森林中序是 `BAC`，二叉树后序是 `BCA`。
7. **根有没有右子树，用来区分树和森林。** 一棵树转换后根的右指针必空。森林的棵数是根的右链长度，不是整棵二叉树里右指针为空的个数。
8. **左指针空 = 原来的叶子。** 右指针空 = 最后一个兄弟，再加 1 个最后的根。2014-5 选 C。有兄弟的叶子在二叉树里不是叶子。
9. **无右孩子 = 分支数 + 1。** 2011-6 的 115 是有右孩子的结点，116 是叶子，1895 是分支结点。
10. **度之和是边数，不是叶子数。** 2010-5 的 122 是边，41 是已经给出的分支结点。叶子要按 `(i-1)·nᵢ` 来加，再加 1。
11. **中序里左右孩子不会相邻。** 父亲夹在中间。2022-3 只有 Ⅲ 不可能，祖父是可能的。
12. **2022-4 的高度按叶子为 1。** 满三叉树高度 5 只有 121 个结点。

## 概念卡片参考

- **双亲表示**：结点里记父亲的下标，根是 `-1`。找父亲 O(1)，找孩子要扫描整表。适合「从孩子问父亲」的题，不适合频繁枚举孩子。
- **孩子表示**：每个结点一条孩子链表。找孩子直接顺着链表走，找父亲要看别人的链表。孩子个数差得很大时，比「每个结点固定留 m 个孩子指针」省空间。
- **孩子兄弟表示**：左指针是第一个孩子，右指针是下一个兄弟。任何树都变成二叉树，森林是多棵树的根互为兄弟。找父亲不直接，适合转换和套用二叉树遍历。
