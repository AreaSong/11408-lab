# lib/17 · 插入与交换排序 · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 8 章前半：直接插入、折半插入、希尔排序、起泡排序、快速排序。简单选择、堆排序、归并和基数在第 18 关。

## 一、本关任务

- **产出**：直接插入、折半插入、希尔、冒泡、快速排序，每种都能按趟打印序列
- **小步骤**：
  ① 直接插入。第 i 趟把下标 i 插进前面已经有序的前缀
  ② 折半插入。用折半找插入位置，移动方式和直接插入相同
  ③ 希尔。默认增量 ⌊n/2⌋、⌊n/4⌋、…、1，也可以自己指定增量。一趟是一个增量
  ④ 冒泡。`rise` 是王道示例代码，最小的换到前面；`sink` 是严蔚敏的起泡，最大的沉到后面
  ⑤ 快排。枢轴取区间第一个元素，trace 打出每一次划分。一趟把当时所有还没就位的区间都划分完
- **通过标准**：单元测试通过；下面这些用例的序列和 `letter` 与程序一致
  - `tests/2009-10.out` 的 `letter=B`
  - `tests/2010-10.out` 的 `order_same=yes`、`data_same=no`、`letter=D`
  - `tests/2010-11.out` 里 `sink` 的前三趟和 `letter=A`
  - `tests/2012-10.out` 的 `letter=A`，`tests/2012-11.out` 的两组 `moves_same=yes`、`cmps_same=no`、`letter=D`
  - `tests/2014-10.out` 的 `letter=B`，`tests/2014-11.out` 的 `letter=C`
  - `tests/2018-10.out` 的 `letter=D`，`tests/2019-10.out` 的 `letter=D`
  - `tests/2023-10.out` 的 `letter=C`，`tests/2023-11.out` 的 `key=81`、`letter=D`
  - `tests/2024-8.out` 的 `letter=A`，`tests/2025-11.out` 的 `gaps 3 2`、`letter=A`
- **概念卡片**（写进 `NOTES.md`）：第 k 趟之后，插入类和交换类各自留下什么外形；稳定性看相等关键字会不会越过；「一趟」对快排是什么意思

每个项目有两个程序：`main.c` 编出的主程序（如 `sort_insert_swap_first`）、`test.c` 编出的单元测试（`sort_insert_swap_first_test`）。算法都在主程序里，没有第二个带 `main` 的文件。

约定：

- 关键字个数 n 是 1 到 16。关键字是 −1000000 到 1000000 的整数，可以重复
- 数组下标从 0 起。王道带哨兵的写法下标从 1 起，A[0] 只做暂存，打出来的关键字序列与这里相同，位置号比这里大 1
- 直接插入、折半插入一共 n−1 趟。第 i 趟（i 从 1 起）处理原来下标为 i 的元素。`head` 是这一趟结束后有序前缀的长度，第 i 趟之后 `head=i+1`
- 折半查找在关键字相等时继续向右，插在已有相等关键字的后面。这样和直接插入落在同一个位置
- 希尔的一趟等于一个增量：按这个步长把序列分成若干组，组内做直接插入。`gap` 不带数字时，后面的 `shell` 用 ⌊n/2⌋、⌊n/4⌋、…、1。指定增量时，每个增量是 1 到 n−1；最后一项不是 1 时结果不一定整体有序，多打一行 `partial=yes`
- `rise` 从右往左比相邻元素，严格大于才交换，最小的冒到当前开头。某一趟交换次数是 0 就停。`head` 是已经就位的前缀长度
- `sink` 从左往右比，较大的换到右边，最大的沉到当前末尾。`tail` 是已经就位的后缀长度。停的规则和 `rise` 相同
- 快排每次取区间最左边的元素做枢轴。右指针遇到小于枢轴的才停，左指针遇到大于枢轴的才停，所以枢轴左边都小于等于它，右边都大于等于它。`cut lo hi` 是这一次划分的闭区间，`at` 是枢轴落下的下标
- 快排的一趟按 2012 年的定义：把当时所有长度至少为 2、还没就位的区间都划分一遍，先左后右。不是「只做一次递归调用」
- 比较次数：每做一次关键字比较记 1。移动次数：每做一次记录赋值记 1。一次交换是 3 次赋值。元素留在原位时，直接插入和折半插入都不计移动，所以两者移动次数相同
- 一行一条命令。读到输入结束就退出，退出码 0。空行跳过。失败时这条命令不再打别的内容
- 一行超过 4095 个字符是 `fail long`。一行里的词超过 80 个，或命令的词个数不对，是 `fail format`

| 输出 | 含义 |
|---|---|
| `fail format` | 词的个数不对，或某个词不是整数，或分段符用错 |
| `fail range` | 关键字个数、关键字、趟数或增量越界 |
| `fail long` | 这一行超过 4095 个字符 |
| `fail unknown` | 不认识的命令 |

## 二、主程序题目（`main.c`）

每次读取前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时不打印）：

`请输入命令（insert / binary / gap / shell / rise / sink / quick / fit / qopt / dorder / shell2 / placed / family / half / calls / fixes / blocks / stable，一行一条，Ctrl+D 结束）：`

直接插入的样例：

```text
insert 49 38 65 97
```

```text
pass 1 head=2
38 49 65 97
pass 2 head=3
38 49 65 97
pass 3 head=4
38 49 65 97
cmp=3
move=3
```

`head` 是有序前缀的长度。65 和 97 本来就比前一个大，所以第 2、3 趟序列不变，但仍然各算一趟。`cmp` 是关键字比较次数，`move` 是记录赋值次数。

快排只示意划分的写法，完整过程见 `tests/practice-quick.out`：

```text
quick 49 38 65 97 76
```

```text
pass 1
cut 0 4 pivot=49 at=1
38 49 65 97 76
```

`cut 0 4` 是下标 0 到 4。枢轴 49 落到下标 1。

### `insert k1 ... kn` / `binary k1 ... kn`

清空计数，做直接插入或折半插入，每一趟打 `pass`、`head` 和整段序列，最后打 `cmp`、`move`。n = 1 时打 `sorted` 和这一个关键字。

### `gap d1 d2 ...` / `gap`

设置后面 `shell` 使用的增量。不带数字时恢复成折半增量，打 `gap=half`。带数字时打 `gap 5 3` 这样的一行。

### `shell k1 ... kn`

按当前增量做希尔排序。每一趟打 `pass`、`gap` 和序列。

### `rise k1 ... kn` / `sink k1 ... kn`

冒泡。有交换的趟打完之后，再遇到全趟没有交换，打出该趟并另起一行 `stop`。

### `quick k1 ... kn`

快排。每一趟先打 `pass`，每次划分打 `cut` 和划分之后的整段序列。

### `fit k a1 ... an`

只看序列的外形，判断它有没有可能是第 k 趟的结果。k 是 1 到 n。

| 行 | 成立的条件 |
|---|---|
| `insert` | 前 k+1 个已经非降 |
| `rise` | 前 k 个是最小的 k 个，并且非降 |
| `sink` | 后 k 个是最大的 k 个，并且非降 |
| `select` | `rise` 或 `sink` 有一个成立 |
| `merge` | 每 2^k 个关键字是一段非降序列，最后一段可以更短 |
| `quick` | 能选出第 k 趟快排的枢轴，使每个当时还没结束的区间里都有一个已经就位的元素 |

不成立打 `no`，不能排除打 `possible`。四个选项按 2009 年第 10 题：A 冒泡，B 插入，C 选择，D 二路归并。只有插入不能排除、另外三个都不成立时打 `letter=B`，否则 `letter=none`。快排不在这四个选项里，只作对照。

### `qopt k n` 后面 4 段、每段 n 个数

四段按 A、B、C、D 的顺序。对每一段判断它是否可能是快排第 k 趟的结果，打 `A=yes` 或 `A=no`。恰好有一段不可能时，`letter` 是那一段的字母，否则 `letter=none`。

### `dorder d1 d2 d3 d4 = a1 ... an`

四个增量按 A、B、C、D 的顺序，`=` 后面是序列。增量 d 成立，是指每个下标 i 都有 a[i] ≤ a[i+d]。恰好一个成立时打出 `gap` 和对应字母。

### `shell2 n` 后面 3 段序列和 8 个增量

三段都是 n 个数：初始序列、第 1 趟、第 2 趟。后面 8 个数是四对增量，顺序是 A、B、C、D。某一对增量依次各做一趟希尔插入，两趟都和给出的序列相同，才算 `yes`。恰好一对成立时打出字母。

### `placed c1 c2 c3 c4 = a1 ... an`

四个候选关键字按 A、B、C、D。`=` 后面是一次划分之后的序列。打出每一个已经就位的下标和关键字。恰好一个就位，并且它等于某个候选时，打出对应字母。

### `family 2010` 或 `family 2025`，后面用 `/` 分段

第一段是初始序列，后面每一段是一趟的结果。段与段之间是单独的一个 `/`。最多 4 趟，每段长度相同。

程序用直接插入、折半插入、希尔（枚举增量）、两种冒泡、快排、一趟趟的两两归并、最低位优先的基数，逐个去对这几趟。对得上打 `yes`。希尔对上时另起一行 `gaps`，写的是找到的第一组增量。

- `2010` 的选项是 A 起泡、B 希尔、C 归并、D 基数。`rise` 或 `sink` 对上，并且希尔、归并、基数都不对，打 `letter=A`
- `2025` 的选项是 A 希尔、B 基数、C 归并、D 折半插入。只有希尔对上时打 `letter=A`

归并和基数在这里只用来排除选项，完整算法在第 18 关。基数遇到负数就认为对不上。

### `half k1 ... kn`

对这一个序列分别做直接插入和折半插入。打出趟数、两种移动次数、两种比较次数。`space=1` 表示两种都只用一个暂存记录。趟数、移动、空间都相同，比较次数不同，按 2012 年第 11 题打 `letter=D`。

### `calls` / `fixes` / `blocks` / `stable`

这四条命令不带参数。

- `calls`：用有序序列 `1..8` 和 `49 38 65 97 76 13 27 49` 各做一次快排。`parts` 的四个数依次是先左、先右、先短、先长的划分次数，`depth` 是对应的最大递归深度。`opt_depth` 是把较长的一边改成循环之后的深度。划分次数与处理顺序无关、但与初始排列有关时，按 2010 年第 10 题打 `letter=D`
- `fixes`：各给一个具体序列，看希尔、归并、简单选择、快排这一趟之后有没有元素就位。堆排序按「根与末尾交换」记为就位，过程在第 18 关。五条判断对应 2012 年第 10 题的 I 到 V
- `blocks`：三组内置序列各做一次划分，看块间是否有序、块内是否有序、两边长度、块内有没有相等关键字。按 2024 年第 8 题，只有「块间有序」总是成立
- `stable`：用带原来次序的关键字看相等元素会不会反序。`key:ord` 里的 `ord` 是排序前的下标。归并、堆、基数的稳定性按定义列出，完整过程在第 18 关。按 2023 年第 10 题，不稳定的是希尔、快排和堆
