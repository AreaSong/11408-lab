# code/net/ · 计算机网络

> 在 MiniMachine 中的角色：**通信**，让两台机器（或两个进程）可靠地交换数据。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节。

## 本科目约定
- **默认「🟢 先学会模式 · 两段式推进」优先（见 [TEACHING.md](../TEACHING.md)）**：
  - **第一段（日常闯关 = 只学单一机制）**：每关只搞懂单一协议机制、拿 1 组简单数字手推算式或状态表，再写 `src/` 下最简写的核心计算/解析/状态转移函数并用 `test.c` 断言验证 + 1 次总反讲即标 `✅ 基础已通` 过关；**`TASK.md` 中的 `trace` 打印格式、`main.c` 命令行壳子及跨关综合真题留到板块节点或「🔵 规范化代码模式」**
  - **第二段（板块刷题节点）**：每学完 1 个大板块（见下方进度表中的 `🎯 板块节点` 分隔行），停下来集中手推本板块的 408 历年选择题与综合组网大题
- **计算器**：手推与推导时**每个数值都带单位**
- **报文用 C 结构体表示**，封装和解析都按字节操作；网络字节序是大端，注意 `htons`/`ntohs`
- 抓包用 macOS 自带的 `tcpdump`（需要 `sudo`），保存为 `.pcap` 供解析器读取
- **协议状态机 trace（仅「🔵 规范化代码模式」要求打印格式）**：默认先手推每一轮状态并用 `test.c` 测核心函数返回值；规范化模式下再补全 `trace` 打印跑 `ctest`

## 考纲约定与易错点（AI 引导时重点核对）
- **设备拆到哪一层的头，就工作在哪一层**：交换机看 MAC（第 2 层），路由器看 IP（第 3 层）
- 带宽、速率中的 k/M/G 是 10³/10⁶/10⁹
- IP 分片的片偏移以 **8 字节**为单位；除最后一片外，数据部分长度必须是 8 的倍数
- 拥塞控制：超时后 ssthresh = cwnd / 2，cwnd 重置为 1；收到 3 个重复 ACK 时快恢复，cwnd = ssthresh（以王道为准）
- GBN 发送窗口 ≤ 2ⁿ − 1；SR 发送窗口与接收窗口之和 ≤ 2ⁿ
- 时延计算分清发送时延、传播时延、排队时延；所有算式带单位
- 零比特填充：发送方每遇到连续 5 个 1 就插入一个 0，接收方反向删除
- 海明码的校验位放在第 1、2、4、8……位（2 的幂次位置），个数由 2ʳ ≥ k + r + 1 决定
- UDP 校验和要加上 12 字节伪首部，按 16 位反码求和
- IPv4 组播地址只把低 23 位映射进以太网组播 MAC 地址，因此 32 个组播 IP 对应同一个 MAC
