## 考纲约定与易错点（AI 引导时重点核对）
- **设备拆到哪一层的头，就工作在哪一层**：交换机看 MAC（第 2 层），路由器看 IP（第 3 层）
- IP 分片的片偏移以 **8 字节**为单位；除最后一片外，数据部分长度必须是 8 的倍数
- 拥塞控制：超时后 ssthresh = cwnd / 2，cwnd 重置为 1；收到 3 个重复 ACK 时快恢复，cwnd = ssthresh
- 时延计算分清发送时延、传播时延、排队时延；所有算式带单位
