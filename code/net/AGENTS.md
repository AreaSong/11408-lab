# code/net/ · 计算机网络

> 在 MiniMachine 中的角色：**通信**，让两台机器（或两个进程）可靠地交换数据。
> **各关的产出、小步骤、通过标准见 [LEVELS.md](LEVELS.md)**，开始或推进某一关时再读对应小节。

## 本科目约定
- **计算器**：所有计算逐步打印推导过程，**每个数值都带单位**
- **报文用 C 结构体表示**，封装和解析都按字节操作；网络字节序是大端，注意 `htons`/`ntohs`
- 抓包用 macOS 自带的 `tcpdump`（需要 `sudo`），保存为 `.pcap` 供解析器读取
- 协议过程用状态机模拟，trace 打印每一轮状态

## 考纲约定与易错点（AI 引导时重点核对）
- **设备拆到哪一层的头，就工作在哪一层**：交换机看 MAC（第 2 层），路由器看 IP（第 3 层）
- 带宽、速率中的 k/M/G 是 10³/10⁶/10⁹
- IP 分片的片偏移以 **8 字节**为单位；除最后一片外，数据部分长度必须是 8 的倍数
- 拥塞控制：超时后 ssthresh = cwnd / 2，cwnd 重置为 1；收到 3 个重复 ACK 时快恢复，cwnd = ssthresh（以王道为准）
- GBN 发送窗口 ≤ 2ⁿ − 1；SR 发送窗口与接收窗口之和 ≤ 2ⁿ
- 时延计算分清发送时延、传播时延、排队时延；所有算式带单位
