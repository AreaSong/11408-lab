### 14 · 电子邮件、FTP 与 P2P
- **产出**：迷你 SMTP 服务器；Base64 编码器（MIME 用它编码非 ASCII 内容）；C/S 与 P2P 文件分发时间计算器
- **小步骤**：① 迷你 SMTP 服务器：用 `nc` 连上去，手动输入 HELO、MAIL FROM、RCPT TO、DATA，服务器把邮件存成文件 ② 用 Base64 编码一段中文，拼成一封带 MIME 首部的邮件，理解 MIME 为什么需要它 ③ C/S 与 P2P：给定文件大小、服务器上传速率、各对等方上下载速率，计算 N 个用户都拿到文件的最短时间，画出 N 增大时两种模型的变化
