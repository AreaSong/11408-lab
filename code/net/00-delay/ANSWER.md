## 思路

### 一条链路

发送时延 = 数据长度 / 带宽，也叫传输时延，是结点把比特推上链路的时间。传播时延 = 距离 / 电磁波速率，是比特已经在路上之后还要走多久。处理时延、排队时延题目经常给 0，总时延仍然把四项都写出来，避免以后漏项。

`link` 打出的 RTT = 2 × 传播时延，只含往返传播。王道里的 RTT 有时指「从发出数据到收到确认」的全部时间，那种 RTT 已经含有发送时延，不能再加一次。

时延带宽积 = 传播时延 × 带宽，单位是比特，表示这段单向链路里同时能容纳多少比特。2023-33 把这句话写进了题干：时延带宽积 = 单向传播时延 × 带宽，所以传播时延 = 时延带宽积 / 带宽，和发送时延是同一个除法，分子换成管道里的比特数。

### 停等利用率

一个周期里，真正在发数据帧的只有 Td。确认帧的发送时延 Ta、去和回的传播都占着信道却没有新数据。

U = Td / (Td + Ta + 2 × 单向传播时延)

2020-36：帧长 1000 B = 8000 bit，速率 10 kbps = 10⁴ bit/s，Td = Ta = 0.8 s = 800 ms。单向传播 200 ms，往返传播 400 ms。周期 = 800 + 800 + 400 = 2000 ms。U = 800 / 2000 = 40%。

确认帧长度填 0 时，Ta 变成 0，公式收成 Td / (Td + 2 × 传播)。发送窗口大于 1 的利用率在可靠传输那一关再算，本关窗口固定是 1。

### 吞吐

多段链路串联时，吞吐量等于最慢的一段。有效吞吐再乘上「数据 / 分组长度」：2010 题每个分组 1000 B 里只有 980 B 是文件，100 Mbps 的链路上有效吞吐是 98 Mbps。总时延那道题仍然按 1000 B 的整分组来除，不能改用 98 Mbps 去除文件，否则把首部开销算了两次。

### 三种交换

设文件 x bit，带宽 R，段数 k，每段传播 d，分组长度 L，分组数 n，一个分组的发送时延 t = L / R。

| 方式 | 总时延 | 原因 |
|---|---|---|
| 电路交换 | 建立 + x/R + k×d | 通路建好后比特直通，中间结点不把整份数据存下来 |
| 报文交换 | k × (x/R + d) | 整份报文每一段都要收完再转发 |
| 分组交换 | n×t + (k−1)×t + k×d | 源端把 n 个分组发完，第一个分组还要在后面 k−1 段上各存一次；传播走 k 段 |

分组交换这行就是流水线。后一个分组不用等前一个走完全程，只比前一个晚一个 t 从目的端出来。k 段链路、n 个等长分组，多出来的发送次数是 k−1，不是 n×k，也不是把每个分组的全程都加一遍。

代码里逐跳模拟是对照：每一跳开始发送的时刻 = max(分组已经整段到达的时刻, 这条链路发完上一个分组的时刻)。各组等长时，模拟结果必须和上面的整式相同，对不上就当计算失败。最后一个分组更短时整式不再成立，只留模拟结果。

首部为 0 且各组等长时，三种方式的 k×d 互相抵消。分组交换短于电路交换，当且仅当建立时延 > (k−1)×t。这是谢希仁习题 1-10 的条件，王道也用这个口径。

### 数据报和虚电路

数据报的每个分组自己带路径，到达 = 发送时刻 + 这条路径的时延，所以后发的分组可以走一条更短的路，先到。虚电路在发送前花一次建立时延，选定一条路，之后全部分组都走它，到达顺序和发送顺序相同。

虚电路仍然是分组交换，链路上不为它留出专用带宽。预分配带宽、独占通路的是电路交换。2020-34 把「需要为每条虚电路预分配带宽」当成正确叙述，这一句是错的。

## 真题对照

| 题 | 结果 | 选项 |
|---|---|---|
| 2010-34 | 1000 个分组，t = 0.08 ms，3 段链路：80 ms + 2×0.08 ms = 80.16 ms | C |
| 2013-35 | 报文 2×800 ms = 1600 ms；分组 800×1 ms + 1 ms = 801 ms | D |
| 2023-33 | 传播 1000 bit / 100 Mbps = 0.01 ms；80 ms + 0.08 ms + 2×0.01 ms = 80.10 ms | D |
| 2020-36 | 800 ms / 2000 ms = 40% | D |
| 2020-34 | 虚电路保证顺序、建立时选路、按虚电路号转发；不预分配带宽 | B |

2013 题问的是报文交换和分组交换，顺序是先报文、后分组，所以是 1600 ms、801 ms。同一组数如果把建立时延填 0，电路交换是 800 ms，比分组交换少的那 1 ms 就是多出来的一次存储转发。题目没有问电路交换。

## 易错点

1. **k、M、G 按 10³、10⁶、10⁹**。1 Mbps = 10⁶ bit/s。2023 的题注是 M = 10⁶；有的转载把指数印成 10⁵，文件会变成 0.1 MB，总时延到不了 80 ms 这一档。1 MB = 10⁶ B = 8×10⁶ bit，发送整份文件是 80 ms，漏掉「1 B = 8 bit」会得到 10 ms。
2. **段数 = 中间结点 + 1**。2010 最短路径是 2 个分组交换机，链路是 3 段。只算源端发送得到 80 ms（选项 A）；把交换机个数当成段数，额外只加 1 个 t，得到 80.08 ms（选项 B）；多算一个交换机得到 80.24 ms（选项 D）。
3. **流水线不是 n×k 个发送时延**。等长分组的发送部分是 (n+k−1)×t。2013 的 801 ms = 800 ms 再加 1 个分组的转发，不是 1600 ms，也不是 800 ms。
4. **2010 先按 980 B 拆文件，再加 20 B 首部**。分组数 = 980000 / 980 = 1000。线上每个分组是 1000 B，t = 8000 bit / 100 Mbps = 0.08 ms。用 1000 B 去除 980000 B 会多出半个分组。
5. **2023 的传播时延不能丢掉**。0.01 ms 很小，但选项就差在这一位：80.08 ms 是忘了传播，80.02 ms 是只加了两段传播、忘了路由器还要再发一次，80.09 ms 是只加了一段传播。
6. **报文交换没有流水线**。整份报文在每一段都发送一次，2013 是 1600 ms。分组短，后面的分组才能和前面的分组待在不同的段上。
7. **停等的分母含确认帧**。2020-36 的 Ta 也是 800 ms。去掉 Ta 得到 800 / 1200 ≈ 66.7%，那是选项 B。
8. **本关 `link` 的 RTT 不含发送时延**。题目若已经把 RTT 定义成往返总时间，确认帧长度填 0，单向传播填题目所给 RTT 的一半，否则发送时延会加两次。
9. **虚电路不预分配带宽**。它保证顺序，是因为分组走同一条已经选好的路，不是因为占了一条专用电路。2020-34 选 B。
10. **存储转发要等整个分组**。同一年的直通交换是另一题：交换机收到目的地址就可以开始转发，模型不同，不能拿来算本关的总时延。

## 概念卡片参考答案

### 卡片一：定义、组成、功能

计算机网络是互连的、自治的计算机的集合。互连指用通信链路连起来；自治指没有主从关系，一台机器不能强制开动或停止另一台。

| 看法 | 分成什么 |
|---|---|
| 组成部分 | 硬件、软件、协议。协议是核心 |
| 工作方式 | 边缘部分：主机，用户直接使用，通信方式有客户/服务器和对等。核心部分：路由器组成的网络，负责连通和交换 |
| 功能组成 | 通信子网负责数据通信，资源子网负责资源共享 |

功能里最基本的是数据通信。此外是资源共享、分布式处理、提高可靠性、负载均衡。

### 卡片二：分类

| 按什么分 | 类别 |
|---|---|
| 分布范围 | 个域网 PAN、局域网 LAN、城域网 MAN、广域网 WAN。因特网是最大的广域网 |
| 使用者 | 公用网、专用网 |
| 拓扑 | 总线、星形、环形、网状、树形 |
| 传输技术 | 广播式网络、点对点网络 |
| 交换方式 | 电路交换、报文交换、分组交换。分组交换再分数据报和虚电路 |

### 卡片三：电路交换、报文交换、分组交换

| | 电路交换 | 报文交换 | 分组交换 |
|---|---|---|---|
| 要不要先建立 | 要，建立专用通路 | 不要 | 数据报不要；虚电路要建立逻辑连接 |
| 传输单位 | 连续比特流 | 整份报文 | 长度有限的分组 |
| 中间结点 | 直通，不存储整份数据 | 存储转发整份报文 | 存储转发每个分组，分组之间可以流水线 |
| 带宽 | 通信期间独占 | 按报文动态占用 | 按分组动态占用。虚电路也不预分配带宽 |
| 顺序 | 沿通路按序到达 | 一份报文 | 数据报可能乱序；虚电路按序到达 |
| 适合 | 连续、大量、实时 | 现在很少用 | 计算机之间突发的数据 |

分组交换比报文交换时延小，是因为流水线，不是因为少走路。电路交换在建立时间很短、数据量很大时可以更短，条件是建立时延 > (k−1)×分组发送时延（首部为 0、各组等长、传播两边相同）。建立时间为 0 时，电路交换比分组交换少的就是那几次额外的存储转发。
