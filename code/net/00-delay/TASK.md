> 王道第 1 章。带宽和数据量里的 k / M / G 是 10³ / 10⁶ / 10⁹。1 B = 8 bit。时间用 `s`、`ms`、`us`、`ns`，`us` 就是微秒 μs。数值和单位之间要有空格，例如 `10 kb`、`8 Mb`、`100 Mbps`、`1 MB`。

## 一、本关任务

- **产出**：带单位的计算器，能算发送时延、传播时延、处理时延、排队时延、往返时间 RTT、时延带宽积、吞吐量、有效吞吐、停等协议的信道利用率；并能比较电路交换、报文交换、分组交换的总时延，以及数据报和虚电路的到达顺序
- **小步骤**：
  ① 一条链路的发送时延和传播时延，加上处理、排队，得到总时延
  ② 时延带宽积；只含往返传播的 RTT
  ③ 分组交换经过若干段链路的总时延（存储转发，分组之间流水线），并和电路交换、报文交换比
  ④ 同一组分组：数据报每个分组自选路径，虚电路先建一条路再全部沿它走，比较到达顺序
- **通过标准**：经过若干路由器的分组交换总时延与真题一致，存储转发和流水线都要体现；每个结果带单位，k / M / G 按 10 的幂
- **概念卡片**（写进 `NOTES.md`）：计算机网络的定义、组成与功能；按范围、拓扑、交换方式分类；电路交换、报文交换、分组交换

每个项目有四个程序：`main.c` 编出的主程序（与项目同名，如 `delay_first`）、`test.c` 编出的单元测试（`delay_first_test`）、`switching.c`（`delay_first_switching`）、`path.c`（`delay_first_path`）。

读入前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。可以连续输入多条命令，Ctrl+D 结束。命令之间的输出空一行。

认这些单位，大小写按下面写，不认识的单位向 stderr 报错并以非 0 退出：

| 量 | 单位 |
|---|---|
| 数据 | `bit` `b` `kbit` `kb` `Mbit` `Mb` `Gbit` `Gb`；字节 `B` `kB` `KB` `MB` `GB` |
| 带宽 | `bps` `kbps` `Mbps` `Gbps`，或写成 `b/s` `kb/s` `Mb/s` `Gb/s`、`bit/s` `kbit/s` `Mbit/s` `Gbit/s` |
| 时间 | `s` `ms` `us` `ns` |
| 距离 | `m` `km` |
| 传播速率 | `m/s` |

`kb` 是千比特，`kB` 是千字节。`Mbps` 是兆比特每秒。`MB/s` 不接受。链路段数记为 k，中间结点数是 k−1：两端是主机，主机之间的每一跳都算一段链路。

## 二、主程序题目（`main.c`）

### 命令

| 命令 | 输入 | 要算的量 |
|---|---|---|
| `link` | 长度、带宽、距离、传播速率、处理时延、排队时延，各带单位 | 四种时延、总时延、RTT、时延带宽积 |
| `util` | 数据帧、确认帧、带宽、单向传播时延，各带单位。确认帧长度可以是 0 | 停等信道利用率 |
| `bottleneck` | 第一行段数 n（1 到 8），接着 n 行「速率 单位」 | 吞吐量 = 最慢一段 |
| `goodput` | 数据、首部、带宽，各带单位 | 有效吞吐 = 数据 / (数据+首部) × 带宽 |

公式（输出里要把代入的数打出来）：

- 发送时延 = 数据长度 / 带宽。发送时延也叫传输时延
- 传播时延 = 距离 / 传播速率
- 总时延 = 发送 + 传播 + 处理 + 排队
- RTT = 2 × 传播时延。这里的 RTT 只含往返传播
- 时延带宽积 = 传播时延 × 带宽，单位是比特
- 停等利用率 U = 数据帧发送时延 / (数据帧发送时延 + 确认帧发送时延 + 2 × 单向传播时延)
- 吞吐量等于各段速率的最小值
- 有效吞吐按上面的比例缩带宽

每一块先写一行单位约定：k、M、G 按 10³、10⁶、10⁹ 计算，1 B = 8 bit。最后一行以 `结果：` 开头。除法要能整除到纳秒或整数比特，不能整除就报错退出，不要四舍五入。

### 样例

输入：

```
link 8000 bit 10 Mbps 1000 km 200000000 m/s 0 ms 0 ms
```

输出：

```
【时延构成】
单位约定：k、M、G 按 10^3、10^6、10^9 计算；1 B = 8 bit。
数据长度 = 8000 bit = 8 kbit（k = 10^3） = 1000 B = 1 kB（k = 10^3）
带宽 R = 10000000 bps = 10 Mbps（M = 10^6）
距离 = 1000000 m = 1000 km
传播速率 = 200000000 m/s
发送时延（传输时延）= 数据长度 / 带宽 = 8000 bit / 10000000 bps = 0.0008 s = 0.80 ms
传播时延 = 距离 / 传播速率 = 1000000 m / 200000000 m/s = 0.005 s = 5 ms
处理时延 = 0 s
排队时延 = 0 s
总时延 = 发送 + 传播 + 处理 + 排队 = 0.0058 s = 5.80 ms
往返时间 RTT = 2 × 传播时延 = 0.01 s = 10 ms
这里的 RTT 只含往返传播。题目若已把发送时延算进 RTT，不能再加一次。
时延带宽积 = 传播时延 × 带宽 = 5000000 ns × 10000000 bps / 10^9 = 50000 bit = 50 kbit（k = 10^3）
时延带宽积的单位是比特，等于这段单向链路同时能容纳的比特数。
结果：总时延 5.80 ms，RTT 10 ms，时延带宽积 50000 bit = 50 kbit（k = 10^3）
```

## 三、交换时延程序（`switching.c`）

各段链路的带宽相同，每段传播时延相同。处理时延和排队时延忽略。分组按存储转发：这一段没收完，下一段不能开始发。文件已经在源主机上，分组一个接一个发。

| 命令 | 输入 |
|---|---|
| `pipe` | `段数 带宽 单位 time或bdp 数值 单位 分组长度 单位 首部 单位 文件 单位` |
| `compare` | `段数 带宽 单位 传播 单位 建立 单位 文件 单位 分组长度 单位 首部 单位` |

- `time` 后面是每段传播时延。`bdp` 后面是时延带宽积（比特），传播时延 = 时延带宽积 / 带宽
- 分组长度是线上整个分组，首部含在里面。分组数据 = 分组长度 − 首部。文件按分组数据来拆
- 段数 k 从 1 到 32。分组个数不超过 1000000
- 电路交换的建立时延只加在电路交换上。报文交换和分组交换不建立电路
- 电路交换：建立 + 文件发送 + k × 传播。发送时延只在源端算一次
- 报文交换：k × (文件发送 + 传播)。报文不拆，长度就是文件，不加分组首部
- 分组交换：各组等长时，总时延 = n×t + (k−1)×t + k×传播。t 是一个整分组的发送时延。最后一个分组更短时，按逐跳模拟，不要再用这个整式

### 样例

输入：

```
compare 3 1 Mbps 1 ms 10 ms 10000 bit 1000 bit 0 bit
```

输出：

```
【电路交换、报文交换、分组交换】
单位约定：k、M、G 按 10^3、10^6、10^9 计算；1 B = 8 bit。
链路段数 k = 3 段，中间结点 = 2 个
段数比中间结点多 1：两端主机之间的每一段链路都要算，主机自己不是中间结点。
带宽 R = 1000000 bps = 1 Mbps（M = 10^6）
分组长度 L = 1000 bit = 1 kbit（k = 10^3） = 125 B
分组首部 = 0 bit
分组数据 = 1000 bit = 1 kbit（k = 10^3） = 125 B
文件 = 10000 bit = 10 kbit（k = 10^3） = 1250 B
分组数 n = 10000 / 1000 = 10 个
每段传播时延 d = 0.001 s = 1 ms
电路建立时延 = 0.01 s = 10 ms
文件发送时延 = 10000 bit / 1000000 bps = 0.01 s = 10 ms
电路交换 = 建立 + 文件发送 + k×传播 = 10 ms + 10 ms + 3 ms = 23 ms
通路建好后比特直通，中间结点不存储整份数据，发送时延只在源端算一次。
报文交换 = k × (文件发送 + 传播) = 3 × (10 ms + 1 ms) = 33 ms
报文不拆开，每一段都要收完整个报文再转发。
分组交换按存储转发，分组之间可以流水线：
单段发送时延 t = L / R = 1000 bit / 1000000 bps = 0.001 s = 1 ms
源端发完 = n × t = 10 × 1 ms = 10 ms
存储转发：一个分组没收完不能转发。流水线：后一个分组不用等前一个走完全程。
额外存储转发 = (k-1) × t = 2 × 1 ms = 2 ms
传播合计 = k × d = 3 ms
分组交换 = n×t + (k-1)×t + k×d = 10 ms + 2 ms + 3 ms = 15 ms
首部为 0 且各组等长时，三种方式的传播都是 k×d，比较时抵消。
分组交换短于电路交换的条件：建立时延 > (k-1)×t，即 10 ms > 2 ms。
本题条件成立。
分组交换仍短于报文交换：报文在每一段都发送整份文件。
结果：电路交换 23 ms，报文交换 33 ms，分组交换 15 ms
```

## 四、路径程序（`path.c`）

读到输入结束。链路是无向的，同一对端点不能写两次。结点名 1 到 15 个字符。

| 关键字 | 输入 | 缺省 |
|---|---|---|
| `interval` | 发送间隔，带单位。只能写一次 | 0 |
| `setup` | 虚电路建立时延，带单位。只能写一次 | 0 |
| `link` | 端点 端点 时延 单位 | |
| `vc` | 结点个数，接着是结点名。只能写一次 | |
| `packet` | 分组编号，然后是结点个数和结点名 | |

分组按输入顺序发送。第 i 个分组（从 0 数）的发送时刻 = i × 发送间隔。

- 数据报：到达时刻 = 发送时刻 + 自己这条路径的时延。不建立连接
- 虚电路：到达时刻 = 建立时延 + 发送时刻 + 虚电路路径的时延。全部分组走 `vc` 那条路

路径时延是沿途各段之和。到达顺序按到达时刻排，同时到达时先发送的在前。结果行写成 `结果：数据报 <编号…>，虚电路 <编号…>`。

### 样例

输入：

```
interval 5 ms
setup 10 ms
link S A 10 ms
link A D 15 ms
link S B 30 ms
link B D 5 ms
vc 3 S A D
packet 1 3 S B D
packet 2 3 S A D
packet 3 3 S B D
```

输出：

```
【数据报与虚电路】
发送间隔 = 5 ms
虚电路建立时延 = 10 ms。建立在发送数据之前，只做一次。
数据报不建立连接，每个分组按自己的路径走。
虚电路建立时选定路径，之后全部分组走同一条路。
虚电路不预分配带宽。预分配带宽、独占通路的是电路交换。
链路 S-A = 10 ms
链路 A-D = 15 ms
链路 S-B = 30 ms
链路 B-D = 5 ms
虚电路路径 S-A-D 时延 25 ms
【数据报】
分组 1 路径 S-B-D 时延 35 ms，发送 0 s，到达 35 ms（发送 + 时延）
分组 2 路径 S-A-D 时延 25 ms，发送 5 ms，到达 30 ms（发送 + 时延）
分组 3 路径 S-B-D 时延 35 ms，发送 10 ms，到达 45 ms（发送 + 时延）
到达顺序：2 1 3
和发送顺序不同。
【虚电路】
分组 1 路径 S-A-D 时延 25 ms，发送 0 s，到达 35 ms（建立 + 发送 + 时延）
分组 2 路径 S-A-D 时延 25 ms，发送 5 ms，到达 40 ms（建立 + 发送 + 时延）
分组 3 路径 S-A-D 时延 25 ms，发送 10 ms，到达 45 ms（建立 + 发送 + 时延）
到达顺序：1 2 3
和发送顺序相同。
结果：数据报 2 1 3，虚电路 1 2 3
```
