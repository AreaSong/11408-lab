### 08 · 分组转发、NAT、ARP 与 IPv6
- **产出**：路由表最长前缀匹配（Trie）；路由器转发函数；NAT 转换表模拟；ARP 过程模拟；IPv6 地址压缩与展开转换器
- **小步骤**：① 用 Trie 实现最长前缀匹配（含默认路由） ② 路由器转发函数：查表得下一跳，TTL 减 1，重算首部校验和，TTL 为 0 时丢弃并产生 ICMP ③ NAT：模拟 NAPT 转换表，内网地址加端口与公网地址加端口的互换 ④ ARP：模拟 ARP 缓存与请求、响应的过程 ⑤ ICMP：用 `ping` 和 `traceroute` 观察，理解 traceroute 怎样利用 TTL ⑥ IPv6：地址的零压缩（`::`）与前导零省略，压缩、展开互转
- **通过标准**：真题考法：给定目的地址的下一跳、NAT 转换后的地址和端口、转发后首部哪些字段改变
- **概念卡片**：网络层的功能（异构网络互连、路由与转发、拥塞控制）；DHCP 的四步过程；ICMP 报文类型；IPv6 的主要特点与首部（与 IPv4 对比）；路由器的组成、路由表 vs 转发表
