## 思路

### 最长前缀匹配

路由表里的每一条是一个前缀。目的地址可能同时落进好几条，转发用最长的那条。默认路由是 `0.0.0.0/0`，长度是 0，什么地址都匹配，但任何更长的前缀都盖过它。

Trie 从地址的最高位往下长。前缀 /n 写在走完高 n 位之后的那个结点上，/0 就写在根上。查找时顺着目的地址走，沿途见到写了前缀的结点就记住，最后留下的是最长的。线性把表扫一遍再比长度，结果一样；Trie 是转发表的查法，表本身仍是插入的那些路由。考场上的「路由表」常常就是这张用来转发的表，控制平面里带度量的路由表要到第 09 关才分开。

直连网络没有下一跳，输出写 `直连`。标准解答的表里这一格是「—」或空着。

### 转发时首部改什么

路由器先查表。没有匹配就丢弃，向源主机发 ICMP 终点不可达，类型 3、代码 0。查到了才转发：TTL 减 1。减完是 0，分组不再往下送，向源主机发 ICMP 时间超过，类型 11、代码 0。代码 1 是分片重组超时，不是这一跳的事。

TTL 变了，首部校验和必须重算。算法和第 07 关一样：校验和字段先当 0，16 位一组做反码求和，进位折回，再按位取反。只改 TTL、而且没有进位时，校验和正好加上 `0x0100`。`tests/practice-ttl` 里 `0x66de` 变成 `0x67de` 就是这个。源地址也改了就不能靠这一下，要整份首部重算。

NAT 在这台路由器上还会改源地址或目的地址。2011 的标准答案改的是源 IP、TTL、首部校验和，不改目的 IP，也不改端口。总长度 495 字节，小于以太网 MTU 1500 字节，所以总长度、标志、片偏移这次不动。分组比 MTU 长时，这三个字段要分片才改，分片在第 07 关。

源 IP 一变，TCP 校验和也要重算，因为伪首部里有源 IP。题目问的是 IP 首部，`pkt` 只重算 IP 首部校验和。

### NAT 和 NAPT

基本 NAT 一对一地换 IP，端口可以不动。2011 和 2016 的问法都是这种：只问源 IP 和目的 IP。NAPT 把「内网地址 + 端口」换成「公网地址 + 端口」，多台内网主机才能共用一个公网地址。回来的分组用目的地址加目的端口查表，再换回内网那一端。所以表的键是地址加端口，用散列，不是最长前缀。

静态 `map` 把一个公网地址加端口固定指到一台内网主机，给外部访问内网服务器用。公网这一侧的地址加端口不能重复，否则回来的分组不知道交给谁。

### ARP

主机要填的是这一跳的 MAC，不是最终目的的 MAC。目的 IP 和本机在同一个网络里，解析目的自己；否则解析默认网关。请求是广播，以太网目的 MAC 为 `ff-ff-ff-ff-ff-ff`，因为这时还不知道对方的 MAC。请求里带着发送方自己的 IP 和 MAC，响应方先把这一对记下来，回程就不用再广播。响应是单播。

ARP 请求出不了本广播域。VLAN 把广播隔开，所以别的 VLAN 里的主机会不进这台主机的 ARP 表。第 06 关用 2024-35 看过这件事，这里把同一张图落到 ARP 上。

### IPv6 的文本写法

8 段，每段 16 位。前导零省略。连续的 0 用 `::` 替换，而且只能替换一次。RFC 5952 还规定：只压最长的那一处；一样长就压最左边；只有一段 0 时不要用 `::`，写成 `0`；字母用小写。王道强调「`::` 只能出现一次」和「省略前导零」，例子多是好几段 0，和这条一致。有的口语和 macOS 的部分显示会把单独一段 0 也压成 `::`，读得回来，但不是 RFC 5952 的推荐写法。本程序不压单独的一段。

## 易错点

1. **同时匹配时留下最长的前缀。** 2013 的 `194.17.20.200` 既在 `/23` 里也在 `/25` 里，走 E0，不走 S1。
2. **默认路由是长度 0，不是「最后一条」。** 先写后写都不改变谁更长。`8.8.8.8` 只有 `/0` 匹配，才用它。
3. **主机路由是 /32。** 2009 的域名服务器要单独一行，掩码全 1，下一跳是 `202.118.2.2`，不是直连。
4. **直连的下一跳是空，不是接口 IP。** 输出里的 `直连` 就是表上的「—」。
5. **到达时的 TTL 要把路径上每一台路由器都减掉。** 2014 是 `64 - 3 = 61`。R1 刚转发出去时是 63，那不是题目要的数。
6. **TTL 减到 0 就不再转发。** 类型 11、代码 0。查不到路由是类型 3、代码 0，不要都写成时间超过。
7. **校验和跟着变过的字段走。** 只减 TTL 时，没有进位的话校验和加 `0x0100`。源地址也改了就必须整份重算，2011 的 `0xba9d` 不是变成 `0xbb9d`，而是 `0x65e8`。
8. **2011 这问不改目的 IP，也不改端口。** 目的已经是公网地址。端口一起变的是 NAPT。
9. **/30 只有两个主机地址。** 2016 里 `.8` 和 `.11` 不能当源地址。R1 占了 `.9`，R2 就是 `.10`。
10. **公网地址加端口不能重复。** 2020 如果两行都写 `203.10.2.6:80`，入站无法区分。和第（2）问一致的发布地址是 `203.10.2.2:80`。
11. **ARP 解析下一跳，不是最终目的。** 2011 的请求找的是 `10.2.128.1`。目的 MAC 是全 1，不是网关的 MAC；网关的 MAC 在响应里才有。
12. **请求是广播，响应是单播。** 请求里要带上自己的映射，响应方才能单播回来，并且顺手缓存。
13. **别的 VLAN 进不了 ARP 表。** 2024 的 D 被 VLAN 隔开。第 06 关已经用这道题说明 VLAN 切的是广播域。
14. **`::` 只压一次，而且至少两段。** `2001:db8:ffff:0:123:4567:89ab:cdef` 中间那个 0 留着。一样长时压最左边，所以是 `2001::ffff:0:0:1:2`，不是把后面那段 0 压掉。
15. **IPv6 地址空间不是 IPv4 的 96 倍。** 是 2^96 倍。基本首部固定 40 字节，没有首部校验和；Hop Limit 对应 TTL。

## 概念卡片

**网络层的功能**

异构网络互连：不同数据链路用 IP 连成一个逻辑网络，路由器拆到 IP 首部。路由是控制平面算出到各网络的路径；转发是数据平面按最长前缀把分组从入接口送到出接口。拥塞控制在网络层的手段是 ICMP 源点抑制（类型 4，已经废弃，王道仍列入）和丢弃，真正把发送速率压下来的是传输层的拥塞窗口，第 12 关再做。

**DHCP 的四步**

客户还没有地址，发现报文是广播。服务器 67、客户 68，都走 UDP。

| 步骤 | 报文 | 谁发 |
|---|---|---|
| 1 | DHCP DISCOVER | 客户广播，找服务器 |
| 2 | DHCP OFFER | 服务器提供一个地址 |
| 3 | DHCP REQUEST | 客户广播，表示选用哪一个 |
| 4 | DHCP ACK | 服务器确认，地址可以开始用 |

发现报文过不了路由器。别的网段上的服务器要靠中继代理，中继用单播把发现报文转给服务器。本关没有模拟这四步。

**ICMP 报文类型**

ICMP 装在 IP 里，协议号 1。本关转发实际产生的是类型 3 和类型 11。

| 类型 | 名字 | 本关里的代码 |
|---|---|---|
| 0 | 回显应答 | `ping` 的应答 |
| 3 | 终点不可达 | 代码 0 网络不可达；UDP traceroute 到终点时常是代码 3 端口不可达 |
| 4 | 源点抑制 | 已废弃，王道仍写 |
| 5 | 重定向 | 告诉主机一条更好的下一跳 |
| 8 | 回显请求 | `ping` 发出的 |
| 11 | 时间超过 | 代码 0 是 TTL 到 0；代码 1 是分片重组超时 |
| 12 | 参数问题 | 首部字段有错 |

traceroute 从 TTL = 1 开始送探测。每一台中间路由器减到 0 就回类型 11，从而暴露自己的地址。TTL 加到能到达终点时，终点对 ICMP 探测回类型 0，对 UDP 探测回类型 3 代码 3。本机隧道上的实际输出见 `EXPERIMENTS.md`，和这条理想路径不完全一样。

**IPv6 和 IPv4**

| | IPv4 | IPv6 |
|---|---|---|
| 地址 | 32 位 | 128 位，是 IPv4 的 2^96 倍 |
| 基本首部 | 20～60 字节，可变 | 固定 40 字节，扩展首部另接 |
| 校验和 | 首部有 | 基本首部没有，改由上层负责 |
| 跳数 | TTL | Hop Limit，含义相同 |
| 广播 | 有 | 没有，用组播代替 |
| 分片 | 路由器可以切 | 只在源主机切，路径 MTU 发现 |

过渡用双协议栈和隧道。隧道是把 IPv6 分组装进 IPv4，第 10 关的移动 IP 也用 IP-in-IP。

**路由器的组成**

路由选择部分是控制平面：跑路由协议，维护带度量的路由表。分组转发部分是数据平面：转发表、输入端口、交换结构和输出端口。转发表来自路由表，但查的是最长前缀到出接口、下一跳，转发时不再跑路由协议。本关的数组是写进去的路由，Trie 是按它建成的转发表。考试表格里的「路由表」多数时候就是要你填的这张转发表。
