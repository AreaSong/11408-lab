## 一、本关任务

- **产出**：CDMA 码片计算器；CSMA/CD 的争用期、最短帧和二进制指数退避；多站点冲突模拟；令牌传递模拟，并和 CSMA/CD 在同一负载下比利用率
- **小步骤**：
  ① 信道划分：检查码片是否两两正交；由叠加信号求各站发送的比特
  ② 争用期与最短帧：由距离求最短帧，由最短帧求最远距离或单向传播上限；帧长变化时距离怎么变
  ③ 二进制指数退避：打印每次冲突后的退避范围，以及选中的时隙
  ④ 多站点 CSMA/CD：站点数从 2 增加到 20，统计信道利用率
  ⑤ 令牌传递：令牌在环上轮转，持有令牌才能发送，和第 ④ 步用同一负载比较利用率
- **通过标准**：CDMA 求某站发送的数据；最短帧或最远距离；冲突后的退避时间范围。结果与真题一致
- **概念卡片**（写进 `NOTES.md`）：FDM、TDM、WDM、CDMA；ALOHA、CSMA 的三种坚持、CSMA/CD、CSMA/CA；802.11 的 RTS/CTS

## 二、主程序题目（`main.c`，CDMA）

码片的每个分量只能是 `1` 或 `-1`。各站码片等长。一次运行里，已经写入的码片和收到的信号会保留，下一条命令接着用。

发比特 1 时发原码片，发比特 0 时每位取反，`x` 表示这一位不发（信道上是全 0）。规格化内积 = 这一段与码片的内积 / 码片长度。结果是 +1 表示比特 1，-1 表示比特 0，0 表示没发。不是这三个数就报错。

| 命令 | 作用 |
|---|---|
| `chip <站名> <1 或 -1> ...` | 登记一个站的码片。站名以字母开头 |
| `ortho` | 检查目前所有站是否两两正交 |
| `recv <整数> ...` | 写入信道上的叠加信号。长度必须是码片长度的整数倍 |
| `send <站名> <比特串>` | 记下这一站要发的比特。比特串只含 `1` `0` `x` |
| `mix` | 按各站的 `send` 算出叠加信号，并当成随后 `decode` 的输入。各站比特数要相同 |
| `decode` | 解出每一个站 |
| `decode <站名>` | 只解这个站 |

`decode` 不带站名时，每个站各有一段过程，最后一行把各站的比特串写在一起，例如 `结果：A=101，B=110，C=xxx`。`x` 是没发，不是比特 0。

### 样例

输入：

```
chip A 1 1 1 1
chip B 1 -1 1 -1
ortho
recv 2 0 2 0
decode A
```

输出：

```
【码片 A】
发比特 1 时发出这串，发比特 0 时每位取反，不发则是全 0。
A：1 1 1 1
结果：站 A，码片长度 4

【码片 B】
发比特 1 时发出这串，发比特 0 时每位取反，不发则是全 0。
B：1 -1 1 -1
结果：站 B，码片长度 4

【正交】
码片长度 4。不同站内积为 0，各自和自己的内积等于码片长度。
A·A = 1×1 + 1×1 + 1×1 + 1×1 = 4
B·B = 1×1 + -1×-1 + 1×1 + -1×-1 = 4
A·B = 1×1 + 1×-1 + 1×1 + 1×-1 = 0
结果：两两正交

【叠加信号】
共 4 个数，码片长度 4，所以是 1 个比特。
结果：收到 1 个比特

【解码 A】
规格化内积 = 内积 / 码片长度。+1 是比特 1，-1 是比特 0，0 是没发。
第 1 位 (2 0 2 0) · (1 1 1 1) = 2×1 + 0×1 + 2×1 + 0×1 = 4，4 / 4 = 1，发送 1
结果：1
```

`tests/2014-37` 是三个站、三个比特的真题，只解 A。`tests/practice-stations` 把同一段信号三个站都解出来。`tests/practice-mix` 先正交，再由各站的比特叠加，然后解回去。

## 三、争用期程序（`csma.c`）

最短帧的发送时间要盖住争用期。争用期 = 2 × 单程预算。单程预算 = 单程传播 + 单程经过的设备时延。`dev` 不写就是没有设备。设备时延先从单程预算里扣，剩下的才用来算距离；不要先从整个争用期里扣一次再除以 2。

10 Mbps 以太网的标准最短帧是 64 B（512 bit），争用期 51.2 us。题目写了不考虑前导码，就不要再加 8 字节前导码。给了别的帧长，就按给的算，不要改成 64 B。

二进制指数退避按王道，并且和 2023 年的题一致：已经连续冲突 n 次时，k = min(n, 10)，退避时隙数 r 从 0～2ᵏ−1 里取，等待 r 个争用时间片。n = 16 时不再重传，放弃这一帧。

| 命令 | 作用 |
|---|---|
| `frame bw <速率> dist <距离> speed <速度> [dev <时间>]` | 由距离求最短帧 |
| `reach frame <帧长> bw <速率> speed <速度> [dev <时间>]` | 由最短帧求最远距离 |
| `tau frame <帧长> bw <速率>` | 单向传播最多多久 |
| `delta less\|more <帧长变化> bw <速率> speed <速度>` | 帧变短或变长时，最远距离减少或增加多少 |
| `backoff n <次数> slot <时间>` | 这一次冲突之后，退避范围和最长等待 |
| `picks slot <时间> r <整数>...` | 按给出的 r 逐次打印范围和等待。r 必须落在当次范围内，最多 15 个 |
| `detect dist <距离> speed <速度>` | 两台主机都检测到冲突的最短时间和最长时间 |
| `goodput frame <帧长> data <有效数据> ack <确认帧> bw <速率> dist <距离> speed <速度>` | 一个周期里的有效数据速率。分子用 `data`，分母含整帧发送、确认帧发送和往返传播 |

关键字顺序不能换。`less` 表示帧变短，`more` 表示帧变长。

### 样例

输入：

```
frame bw 10 Mbps dist 2500 m speed 200000 km/s
```

输出：

```
【最短帧】
带宽 10 Mbps（M = 10^6），距离 2500 m，速度 200000000 m/s = 200000 km/s = 200 m/us。
单程传播 = 距离 / 速度 = 12.5 us。
争用期 = 2 × 单程传播 = 25 us。
最短帧 = 争用期 × 带宽 = 250 bit。
帧的发送时间至少要盖住争用期，否则发完了才发现冲突。
结果：250 bit
```

`tests/csma/practice-cable` 在这一问之后，再问 64 B、10 Mbps、没有设备时延时的最远距离。`tests/csma/2009-37`、`2016-36`、`2019-36`、`2023-36`、`2010-47` 是真题。`tests/csma/practice-picks` 自己指定每次抽中的 r。`tests/csma/practice-cap` 看 k 封顶和放弃。

## 四、模拟程序（`sim.c`）

时间分成时隙，1 个时隙 = 1 个争用期。这里比的是时隙数，不换算成比特。

CSMA/CD 按 1-坚持：

- 退避减到 0 的站，信道一空闲就发送
- 只有一个站发送：成功，占用 `length` 个时隙，这些时隙算有用
- 两个及以上站同时发送：冲突，只浪费这 1 个时隙。强化冲突的干扰信号已经算在这个争用期里，不再单列
- 没参与这次发送的站，退避照样减。减到 0 时如果信道还忙，就等到空出来再抢
- 大家都还在退避：信道空等

选中的时隙不用真随机数，否则每次结果不一样，没法对测试。公式是

r = (17 × 站号 + 29 × 冲突次数 + 3) mod 2ᵏ

站号从 0 起。k = min(这一站已经发生的冲突次数, 10)。第 16 次冲突放弃这一帧，放弃的帧不算有用。冲突次数按站分开计，发送成功后清零。

令牌从站 0 开始，沿 0、1、2……转：

- 持有令牌且还有帧：发 1 帧，占用 `length` 个时隙
- 然后把令牌交给下一站，走过 `walk` 个时隙。最后一帧发完就停，不再多走一次
- 没有帧的站也要把令牌传下去，同样走 `walk` 个时隙

利用率 = 有用时隙 / 总时隙，百分数保留两位小数，四舍五入。`compare` 里每站的帧数和帧长相同，这就是两边的同一负载。令牌多出来的是 `walk`，总线上没有这一项。

| 命令 | 作用 |
|---|---|
| `trace csma stations <n> frames <每站帧数> length <帧长>` | 打印 CSMA/CD 的每一次冲突、空等和成功 |
| `trace token stations <n> frames <每站帧数> length <帧长> walk <时隙>` | 打印令牌的发送和传递 |
| `compare from <n1> to <n2> frames <每站帧数> length <帧长> walk <时隙>` | 站点数从 n1 到 n2，每档都打 CSMA/CD 和令牌 |

站点数 1～32。本关要看的实验是 2 到 20。

### 样例

输入：

```
trace csma stations 2 frames 1 length 4
```

输出的结果行是：

```
结果：8/9 = 88.89%
```

前面要有规则，以及每次冲突的 k、范围和选中的 r。`tests/sim/practice-trace` 是 3 个站的 CSMA/CD 和令牌。`tests/sim/practice-compare` 是 2～20 站的对照。
