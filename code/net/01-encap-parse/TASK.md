### 01 · 分层封装与报文解析
- **产出**：把一句 HTTP 请求逐层封装为 TCP 报文段 → IP 数据报 → 以太网帧，并逐字节打印；再写解析器把帧一层层拆开
- **小步骤**：① 用 C 结构体定义以太网头、IP 头、TCP 头 ② 封装 ③ 解析 ④ 用 `tcpdump -w` 抓一个真实的包，让解析器解析它（`.pcap` 文件格式很简单）
- **通过标准**：能说出每层头部的关键字段及长度；真题考法：给出一段以太网帧的十六进制，求源/目的 IP、端口、TTL、协议类型等
- **概念卡片**：分层结构；协议、接口、服务的关系（协议是水平的、服务是垂直的）；OSI 七层 vs TCP/IP 四层与五层模型；各层 PDU 的名称
