> 王道第 2 章 物理层。带宽、速率里的 k / M / G 是 10³ / 10⁶ / 10⁹。频率用 Hz，码元速率用 Baud（波特），数据率用 bps。数值和单位之间要有空格，例如 `3 kHz`、`24 kbps`、`1200 Baud`。

## 一、本关任务

- **产出**：奈奎斯特定理与香农定理计算器；码元、波特与比特率的换算；用字符画出 NRZ、曼彻斯特、差分曼彻斯特，并能从波形读回比特串
- **小步骤**：
  ① 码元速率、比特率、状态数三者换算。调制时，码元状态数 = 相位种数 × 振幅种数
  ② 无噪声时用奈奎斯特。题目没写理想带通，最高码元速率按理想低通的 2W
  ③ 有噪声时用香农，分贝先换成功率比。两个极限都给出时取较小值
  ④ 用字符画打印 NRZ、曼彻斯特、差分曼彻斯特，并按波形判断比特串
- **通过标准**：给定带宽和码元状态数或信噪比，最大数据传输速率与真题一致；给出波形时能读出比特串
- **概念卡片**（写进 `NOTES.md`）：信道、信号、带宽、码元、信源与信宿；单工、半双工、全双工；编码和调制（调幅、调频、调相、QAM）；传输介质；物理层接口的四个特性；中继器和集线器能不能隔离冲突域

每个项目有三个程序：`main.c` 编出的主程序（与项目同名，如 `physical_first`）、`test.c` 编出的单元测试（`physical_first_test`）、`wave.c`（`physical_first_wave`）。

读入前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，用法同 `printf`，跑测试时自动不打印）。一行一条命令，可以连续输入，Ctrl+D 结束。空行跳过。命令之间的输出空一行。算不出来时向 stderr 写原因，并以非 0 退出，不要四舍五入。

认这些单位，大小写按下面写：

| 量 | 单位 |
|---|---|
| 频率带宽 | `Hz` `kHz` `MHz` `GHz` |
| 数据率 | `bps` `kbps` `Mbps` `Gbps`，或 `b/s` `kb/s` `Mb/s` `Gb/s`、`bit/s` `kbit/s` `Mbit/s` `Gbit/s` |

## 二、主程序题目（`main.c`）

每一块先写一行单位约定：k、M、G 按 10³、10⁶、10⁹ 计算。最后一行以 `结果：` 开头。速率能被 1000、10⁶、10⁹ 整除时，结果里同时写出 `kbps` / `Mbps` / `Gbps`，波特和频率同样处理。

### 命令

| 命令 | 输入 |
|---|---|
| `convert` | `bits` 或 `baud`，接着是数值和单位；然后 `states <V>`，或 `phase <p> amp <a>`，或 `code manchester` / `code nrz` |
| `nyquist` | 带宽和单位，然后 `states <V>`，或 `phase <p> amp <a>`，或 `rate <数据率> <单位>` |
| `shannon` | 带宽和单位，信噪比数值，`dB` 或 `ratio`。可以再写 `actual <百分比>` |
| `bound` | `states <信噪比> dB或ratio`，求最少状态数；或者 `带宽 单位 states <V> <信噪比> dB或ratio`，两个极限取较小值 |

`V = 相位 × 振幅`。只写 `states` 时，V 就是这个数，不要再乘一次。V 必须是 2 的幂，并且至少为 2，这样每个码元的比特数 `log2(V)` 才是整数。

公式：

- 比特率 = 波特率 × log2(V)。已知比特率时，波特率 = 比特率 / log2(V)，必须整除
- NRZ：一个比特一个码元，码元速率 = 比特率
- 曼彻斯特：一个比特切成前后两半，码元速率 = 2 × 比特率。从码元速率反推比特率时必须整除
- 奈奎斯特（无噪声、理想低通）：最高码元速率 = 2W，最大数据率 = 2W × log2(V)。`nyquist ... rate` 是反求 V：比特数 = 数据率 / 2W，必须整除，V = 2 的这个比特数次方。V ≥ 4 时结果写成 `QAM-<V>`
- 香农（有噪声）：C = W × log2(1 + S/N)。注意是 W，不是 2W
- `dB`：S/N = 10^(dB/10)。`ratio` 后面的数本身就是 S/N
- log2(1+S/N) 正好是整数时，照整数算，结果不加「约」
- 否则看 1+S/N 和离它最近一侧的 2^k：较大者 × 100 ≤ 较小者 × 103 时，把 log2 收成这个 k，输出里写明这道整数比较，结果加「约」。30 dB 时 1+S/N = 1001，2^10 = 1024，1024×100 ≤ 1001×103，所以收成 10。这条 3% 的线就是为了接住这个考法
- 超过 3% 就不收成单个整数，写出 W×下整 和 W×上整 两个严格界，结果行是 `不是整数比特，不给单值`
- `actual` 是 1 到 100 的百分比，实际速率 = 百分比 × 香农极限，乘完必须是整数 bps。log2 还没收成整数时不能再乘百分比
- `bound` 带带宽时，两个极限都算出来，取较小值。较小值落在近似过的香农一侧（或两边相等且香农是近似）时，结果加「约」
- `bound states`：最小的整数 V 满足 V² ≥ 1+S/N，再把这个 V 向上补成 2 的幂。log2(1+S/N) 能收成偶数 k 时，再写一遍 2×log2(V) ≥ k

### 样例

输入：

```
convert baud 1200 Baud phase 4 amp 1
```

输出：

```
【码元速率与比特率】
单位约定：k、M、G 按 10^3、10^6、10^9 计算。
比特率 = 波特率 × 每个码元的比特数。波特率就是码元速率。
相位 = 4，每种相位的振幅 = 1
码元状态数 V = 相位 × 振幅 = 4 × 1 = 4
每个码元携带 log2(4) = 2 bit
波特率 = 1200 Baud
数据传输速率 = 波特率 × 每码元比特数 = 1200 × 2 = 2400 bps
结果：2400 bps，1200 Baud
```

`tests/practice-bound` 是两个极限谁更小。`tests/practice-code` 是曼彻斯特的码元速率。`tests/practice-range` 是 log2 不能收成整数。`tests/practice-states` 是最少状态数本身不是 2 的幂。

## 三、波形程序（`wave.c`）

电平：`-` 为高，`_` 为低。每个比特占前后两格。表格用 `bit`、`NRZ`、`MAN`、`DIFF` 对齐，竖线隔开比特；规则用中文写在表的上面。

本关固定用这套约定（谢希仁、王道做题时没另给约定就用它；题目声明相反时，0 和 1 对调）：

- NRZ（不归零）：两格都高是 1，两格都低是 0。整个比特电平不变
- 曼彻斯特：正中间一定跳变。高到低（` -_`）是 1，低到高（`_-`）是 0。这一跳既是时钟也是数据，所以每个比特是 2 个码元
- 差分曼彻斯特：正中间一定跳变，只做同步，不表示 0 或 1。这一格开头和上一格末电平相同是 1，不同是 0。必须知道前一比特的末电平，缺省是低

| 命令 | 输入 |
|---|---|
| `draw` | 只含 0 和 1 的比特串，1 到 32 位。后面可以写 `low` 或 `high`，缺省 `low` |
| `read nrz` | 若干格，每格两个字符 |
| `read man` | 若干格 |
| `read diff` | 先写 `low` 或 `high`，再写若干格 |

`draw` 三种编码都画。`read` 读回比特串。对不上这种编码就报错退出：NRZ 的两半必须相同，曼彻斯特和差分曼彻斯特的正中间必须跳变。

### 样例

输入：

```
draw 10 low
```

输出：

```
【编码波形】
电平：- 为高，_ 为低。每个比特占前后两格，竖线把比特隔开。
NRZ（不归零）：整格不变，高为 1，低为 0。连续相同比特时没有跳变，不能自同步。
曼彻斯特：正中间一定跳变。高到低（-_）是 1，低到高（_-）是 0。
这一跳既是时钟也是数据，所以每个比特是 2 个码元，码元速率是比特率的 2 倍。
差分曼彻斯特：正中间的跳变只做同步。开头不跳变是 1，跳变是 0。
前一比特末电平：低。差分解码必须先有这个参考，缺省按低。
两格长得一样也可以是不同的比特，因为比的是和上一格末电平，不是这一格的形状。
bit  | 1 | 0 |
NRZ  | --| __|
MAN  | -_| _-|
DIFF | _-| _-|
结果：10
```

`tests/wave/2013-34` 是按上面的曼彻斯特约定写成的字符波形。`tests/wave/2015-34` 画比特串 `01100111`。`tests/wave/practice-diff` 读差分曼彻斯特。`tests/wave/practice-nrz` 读 NRZ。
