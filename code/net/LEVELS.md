# 计算机网络 · 关卡任务详情

> 考查范围以 **2027 年 408 统考大纲**为准（与 2026 版无变动），逐条对照见文末「大纲覆盖对照」；具体约定以王道为准。
> 每关不超过 6 个小步骤，约 3~4 次学习完成。

## 贯穿全程的设计

### 1. 「计算器」对接计算题
时延、信道利用率、最短帧长、子网划分、IP 分片、TCP 序号与窗口……计网大题几乎都要算。
→ 每关写**带单位的计算器**，逐步打印推导过程，拿真题数据直接对答案。

### 2. 「报文解析」对接分层理解
**设备拆到哪一层的头，就工作在哪一层。**
→ 从第 01 关开始，你会亲手把数据一层层封装成帧，再一层层拆开；后面几关再用 `tcpdump` 抓真实的包来解析。书上的报文格式图会变成你自己写过的结构体。

### 3. 「状态机」对接协议过程
TCP 三次握手与四次挥手、拥塞控制、滑动窗口、距离向量的收敛……
→ 用状态机模拟，trace 打印每一轮的状态（cwnd、窗口边界、路由表），和真题逐步对照。

### 4. 「概念卡片」对接无法动手的概念
只有定义、分类这类真正写不成代码的内容，才用卡片。
→ 每关列出的**概念卡片**写进该关 `NOTES.md` 的「概念卡片」一节：一张卡片 = 一张对比表或一张图。

## 各关详情

### 00 · 时延与性能计算器
- **产出**：计算发送时延、传播时延、往返时间 RTT、时延带宽积、吞吐量、信道利用率；数据报与虚电路的转发模拟
- **小步骤**：① 发送时延与传播时延 ② 时延带宽积 ③ 分组交换与电路交换、报文交换的总时延对比 ④ 数据报 vs 虚电路：同一组分组经过多条路径的网络，数据报方式每个分组独立选路，虚电路方式先建路再沿同一条路走，比较到达顺序
- **通过标准**：真题考法：经过若干路由器的分组交换总时延（**注意存储转发与流水线效应**）；所有结果带单位（**带宽的 k/M 是 10³/10⁶**）
- **概念卡片**：计算机网络的定义、组成与功能；网络的分类（按范围、拓扑、交换方式）；电路交换 vs 报文交换 vs 分组交换

### 01 · 分层封装与报文解析
- **产出**：把一句 HTTP 请求逐层封装为 TCP 报文段 → IP 数据报 → 以太网帧，并逐字节打印；再写解析器把帧一层层拆开
- **小步骤**：① 用 C 结构体定义以太网头、IP 头、TCP 头 ② 封装 ③ 解析 ④ 用 `tcpdump -w` 抓一个真实的包，让解析器解析它（`.pcap` 文件格式很简单）
- **通过标准**：能说出每层头部的关键字段及长度；真题考法：给出一段以太网帧的十六进制，求源/目的 IP、端口、TTL、协议类型等
- **概念卡片**：分层结构；协议、接口、服务的关系（协议是水平的、服务是垂直的）；OSI 七层 vs TCP/IP 四层与五层模型；各层 PDU 的名称

### 02 · 物理层：信道容量与编码
- **产出**：奈奎斯特定理与香农定理计算器；码元、波特与比特率换算；曼彻斯特编码、差分曼彻斯特编码的波形打印
- **小步骤**：① 码元、波特、速率的换算（含调制：码元状态数 = 相位数 × 振幅数） ② 奈奎斯特（无噪声） ③ 香农（有噪声，分贝换算），两个极限同时给出时取较小值 ④ 用字符画打印 NRZ、曼彻斯特、差分曼彻斯特波形
- **通过标准**：真题考法：给定带宽和码元状态数或信噪比，求最大数据传输速率；根据波形判断比特串
- **概念卡片**：信道、信号、带宽、码元、信源与信宿等基本概念；单工、半双工、全双工；编码 vs 调制（调幅、调频、调相、QAM）；传输介质（双绞线、同轴电缆、光纤、无线）；物理层接口的四个特性；中继器 vs 集线器（能否隔离冲突域）

### 03 · 组帧与差错控制
- **产出**：组帧器（字符计数、字节填充、零比特填充）；奇偶校验；CRC 计算器，trace 打印模 2 除法的每一步；海明码编码与纠错器
- **小步骤**：① 组帧：字符计数法；字节填充（以 PPP 的 0x7E、0x7D 转义为例）；零比特填充（连续 5 个 1 后插 0）及接收端删除 ② 奇偶校验 ③ CRC 发送端：求余数并拼接 ④ CRC 接收端：校验 ⑤ 海明码：由海明不等式求校验位个数，确定校验位位置并编码；人为翻转一位，接收端定位并纠正
- **通过标准**：真题考法：零比特填充后的比特串；给定生成多项式和数据，求 CRC 校验码或实际发送的比特串；海明码的校验位个数与出错位置
- **概念卡片**：数据链路层的功能；四种组帧方法对比；检错编码 vs 纠错编码

### 04 · 可靠传输：停等、GBN、SR
- **产出**：滑动窗口模拟器：停等协议、后退 N 帧（GBN）、选择重传（SR），可模拟丢包和超时；信道利用率计算器
- **小步骤**：① 停等协议与信道利用率 ② GBN（累计确认、超时后重传窗口内全部帧） ③ SR（逐个确认、只重传出错帧） ④ 窗口大小与序号位数的关系
- **通过标准**：真题考法：要使信道利用率最大，发送窗口至少多大；n 位序号时 GBN、SR 的最大窗口；丢失某帧后需要重传哪些帧
- **概念卡片**：流量控制 vs 可靠传输；停等、GBN、SR 对比

### 05 · 介质访问控制
- **产出**：CDMA 码片计算器；CSMA/CD 最短帧长计算器与二进制指数退避模拟；多站点冲突模拟器；令牌传递模拟器
- **小步骤**：① 信道划分：CDMA 码片序列的正交验证，由叠加信号求各站发送的比特 ② 争用期与最短帧长 ③ 二进制指数退避：trace 打印每次冲突后的退避范围与选中的时隙 ④ 多站点 CSMA/CD 冲突模拟：站点数从 2 增加到 20，统计信道利用率的变化 ⑤ 令牌传递：令牌在环上轮转，持有令牌才能发送，与第 ④ 步在相同负载下比较利用率
- **通过标准**：真题考法：CDMA 求某站发送的数据；最短帧长或最远距离计算；冲突后的退避时间范围
- **概念卡片**：FDM、TDM、WDM、CDMA 的原理对比；ALOHA、CSMA（三种坚持策略）、CSMA/CD、CSMA/CA；802.11 的 RTS/CTS

### 06 · 局域网与交换机
- **产出**：以太网帧构造器；集线器与交换机模拟器（MAC 地址自学习与转发）；802.1Q 标签插入；802.11 地址字段推演
- **小步骤**：① 以太网（IEEE 802.3）帧：构造各字段，数据不足 46 字节时填充 ② 集线器 vs 交换机：同一组主机分别接在集线器和交换机上，统计冲突域和广播域的个数 ③ 交换机：自学习、转发、泛洪 ④ VLAN：给以太网帧插入 4 字节的 802.1Q 标签，交换机只在同一 VLAN 内转发和泛洪 ⑤ 802.11：给定站点、AP 和目的主机，推出帧中地址 1、2、3 各填什么（**以王道为准**）
- **通过标准**：真题考法：给定一串帧的收发，求交换机地址表的变化以及哪些端口能收到帧；冲突域与广播域的个数；802.11 帧的地址字段
- **概念卡片**：局域网的体系结构（LLC 与 MAC 子层）；VLAN 的作用；广域网与 PPP 协议

### 07 · IPv4 编址与分片
- **产出**：IPv4 头部解析器；CIDR 计算器；子网划分与聚合计算器；IP 分片模拟器
- **小步骤**：① IPv4 头部字段 ② CIDR：网络地址、广播地址、可用主机数 ③ 子网划分与路由聚合 ④ IP 分片：片偏移、MF 标志
- **通过标准**：真题考法：划分子网后各子网的地址范围、路由聚合结果、某数据报分片后各片的长度和偏移
- **概念卡片**：IPv4 地址分类与私有地址

### 08 · 分组转发、NAT、ARP 与 IPv6
- **产出**：路由表最长前缀匹配（Trie）；路由器转发函数；NAT 转换表模拟；ARP 过程模拟；IPv6 地址压缩与展开转换器
- **小步骤**：① 用 Trie 实现最长前缀匹配（含默认路由） ② 路由器转发函数：查表得下一跳，TTL 减 1，重算首部校验和，TTL 为 0 时丢弃并产生 ICMP ③ NAT：模拟 NAPT 转换表，内网地址加端口与公网地址加端口的互换 ④ ARP：模拟 ARP 缓存与请求、响应的过程 ⑤ ICMP：用 `ping` 和 `traceroute` 观察，理解 traceroute 怎样利用 TTL ⑥ IPv6：地址的零压缩（`::`）与前导零省略，压缩、展开互转
- **通过标准**：真题考法：给定目的地址的下一跳、NAT 转换后的地址和端口、转发后首部哪些字段改变
- **概念卡片**：网络层的功能（异构网络互连、路由与转发、拥塞控制）；DHCP 的四步过程；ICMP 报文类型；IPv6 的主要特点与首部（与 IPv4 对比）；路由器的组成、路由表 vs 转发表

### 09 · 路由算法与 SDN
- **产出**：链路状态（Dijkstra，对应 OSPF）与距离向量（Bellman-Ford，对应 RIP）模拟器；一个迷你 SDN 控制器
- **小步骤**：① Dijkstra 求最短路径树（可复用数据结构第 13 关） ② 距离向量：trace 打印每一轮交换后各路由器的路由表 ③ 模拟链路断开，**亲眼看到"坏消息传得慢"** ④ RIP 更新：给定邻居发来的距离向量，trace 打印本路由表的更新（距离加 1、16 表示不可达） ⑤ SDN：控制器掌握全网拓扑，集中算出路径，给每台交换机下发"匹配-动作"流表；数据平面只查流表转发，链路断开时由控制器重新下发
- **通过标准**：真题考法：给定拓扑和链路代价，求某路由器的路由表；RIP 收到邻居路由表后的更新结果；SDN 中数据平面和控制平面各做什么
- **概念卡片**：静态路由 vs 动态路由；层次路由与自治系统

### 10 · 路由协议、组播与移动 IP
- **产出**：BGP 路径向量模拟；组播地址映射计算器；移动 IP 转发模拟
- **小步骤**：① BGP：自治系统之间交换完整 AS 路径，收到包含自己 AS 号的路径就丢弃，trace 打印环路如何被避免 ② 组播：把 IP 组播地址映射为以太网组播 MAC 地址（01-00-5E 加低 23 位），算出多少个组播 IP 会映射到同一个 MAC ③ 移动 IP：主机移到外地网络后获得转交地址，归属代理截获发往它的数据报，用 IP-in-IP 隧道封装后发往转交地址（复用第 01 关的封装函数），trace 打印每一跳的外层和内层地址
- **通过标准**：真题考法：组播地址映射；移动 IP 中归属代理、外地代理、转交地址的作用
- **概念卡片**：域内路由 vs 域间路由；RIP vs OSPF vs BGP（算法、封装、度量，以及 OSPF 的分区）；组播的概念与 IGMP

### 11 · UDP 与 TCP 连接管理
- **产出**：UDP 校验和计算器；TCP 连接状态机（三次握手、四次挥手）；序号与确认号计算器
- **小步骤**：① UDP 首部；带伪首部的 16 位反码求和校验，接收端验证 ② 三次握手、四次挥手的状态与序号变化，trace 打印双方每一步的状态 ③ 序号、确认号与数据长度的计算
- **通过标准**：真题考法：UDP 校验和；握手或挥手过程中的序号和确认号、某时刻双方所处的状态
- **概念卡片**：传输层的功能；端口与熟知端口号；无连接服务 vs 面向连接服务；UDP vs TCP

### 12 · TCP 可靠传输、流量与拥塞控制
- **产出**：超时重传时间计算器；流量控制模拟；拥塞控制模拟器，trace 打印每个 RTT 的 cwnd 与 ssthresh
- **小步骤**：① 超时重传：加权平均往返时间与超时重传时间的计算（公式以王道为准） ② 流量控制（接收窗口），含零窗口与持续计时器 ③ 拥塞控制：慢开始、拥塞避免、超时、3 个重复 ACK 与快恢复 ④ 发送窗口 = min(接收窗口, 拥塞窗口)
- **通过标准**：真题考法：某时刻 cwnd 的值、经过多少个 RTT 发送窗口达到某值、超时重传时间

### 13 · Socket、HTTP 与 DNS
- **产出**：用 Socket 写 TCP 回声服务器，再升级为极简 HTTP 服务器，用浏览器或 `curl` 访问；DNS 解析过程模拟
- **小步骤**：① TCP 回声服务器与客户端 ② 极简 HTTP 服务器，返回一个网页，并用 `Set-Cookie` 记住访问次数 ③ 用 `curl -v` 对比持久连接与非持久连接：同一页面的多个对象各需要几次 TCP 连接 ④ 用 `tcpdump` 抓自己服务器的包，看三次握手 ⑤ DNS：用 `dig +trace` 观察从根域名服务器开始的迭代解析（**开着代理软件的 TUN 模式时 DNS 会被截获，trace 不完整，先关掉再做**），再写一个模拟器对比递归与迭代查询的报文个数
- **通过标准**：真题考法：访问一个网页总共需要多少个 RTT（含 DNS、TCP 连接、HTTP 请求）；DNS 查询的报文个数
- **概念卡片**：层次域名空间与域名服务器的种类；WWW 的组成（URL、HTTP、HTML）；HTTP 报文结构

### 14 · 电子邮件、FTP 与 P2P
- **产出**：迷你 SMTP 服务器；Base64 编码器（MIME 用它编码非 ASCII 内容）；C/S 与 P2P 文件分发时间计算器
- **小步骤**：① 迷你 SMTP 服务器：用 `nc` 连上去，手动输入 HELO、MAIL FROM、RCPT TO、DATA，服务器把邮件存成文件 ② 用 Base64 编码一段中文，拼成一封带 MIME 首部的邮件，理解 MIME 为什么需要它 ③ C/S 与 P2P：给定文件大小、服务器上传速率、各对等方上下载速率，计算 N 个用户都拿到文件的最短时间，画出 N 增大时两种模型的变化
- **通过标准**：真题考法：电子邮件发送和读取各用什么协议；FTP 的连接个数；C/S 与 P2P 的分发时间
- **概念卡片**：电子邮件系统的组成、SMTP vs POP3、邮件格式；FTP 的控制连接与数据连接、主动与被动模式；C/S 模型 vs P2P 模型
