# 计算机网络 · 关卡任务详情

## 贯穿全程的设计

### 1. 「计算器」对接计算题
时延、信道利用率、最短帧长、子网划分、IP 分片、TCP 序号与窗口……计网大题几乎都要算。
→ 每关写**带单位的计算器**，逐步打印推导过程，拿真题数据直接对答案。

### 2. 「报文解析」对接分层理解
**设备拆到哪一层的头，就工作在哪一层。**
→ 从第 01 关开始，你会亲手把数据一层层封装成帧，再一层层拆开；后面几关再用 `tcpdump` 抓真实的包来解析。书上的报文格式图会变成你自己写过的结构体。

### 3. 「状态机」对接协议过程
TCP 三次握手与四次挥手、拥塞控制、滑动窗口、距离向量的收敛……
→ 用状态机模拟，trace 打印每一轮的状态（cwnd、窗口边界、路由表），和真题逐步对照。

## 各关详情

### 00 · 时延与性能计算器
- **产出**：计算发送时延、传播时延、往返时间 RTT、时延带宽积、吞吐量
- **小步骤**：① 发送时延与传播时延 ② 时延带宽积 ③ 分组交换与电路交换、报文交换的总时延对比
- **通过标准**：真题考法：经过若干路由器的分组交换总时延（**注意存储转发与流水线效应**）；所有结果带单位（**带宽的 k/M 是 10³/10⁶**）

### 01 · 分层封装与报文解析
- **产出**：把一句 HTTP 请求逐层封装为 TCP 报文段 → IP 数据报 → 以太网帧，并逐字节打印；再写解析器把帧一层层拆开
- **小步骤**：① 用 C 结构体定义以太网头、IP 头、TCP 头 ② 封装 ③ 解析 ④ 用 `tcpdump -w` 抓一个真实的包，让解析器解析它（`.pcap` 文件格式很简单）
- **通过标准**：能说出每层头部的关键字段及长度；真题考法：给出一段以太网帧的十六进制，求源/目的 IP、端口、TTL、协议类型等

### 02 · 物理层：信道容量与编码
- **产出**：奈奎斯特定理与香农定理计算器；曼彻斯特编码、差分曼彻斯特编码的波形打印
- **小步骤**：① 奈奎斯特（无噪声）② 香农（有噪声，分贝换算） ③ 用字符画打印编码波形
- **通过标准**：真题考法：给定带宽和码元状态数或信噪比，求最大数据传输速率；根据波形判断比特串

### 03 · 差错控制：奇偶校验与 CRC
- **产出**：奇偶校验；CRC 计算器，trace 打印模 2 除法的每一步
- **小步骤**：① 奇偶校验 ② CRC 发送端：求余数并拼接 ③ CRC 接收端：校验
- **通过标准**：真题考法：给定生成多项式和数据，求 CRC 校验码或实际发送的比特串

### 04 · 可靠传输：停等、GBN、SR
- **产出**：滑动窗口模拟器：停等协议、后退 N 帧（GBN）、选择重传（SR），可模拟丢包和超时；信道利用率计算器
- **小步骤**：① 停等协议与信道利用率 ② GBN（累计确认、超时后重传窗口内全部帧） ③ SR（逐个确认、只重传出错帧） ④ 窗口大小与序号位数的关系
- **通过标准**：真题考法：要使信道利用率最大，发送窗口至少多大；n 位序号时 GBN、SR 的最大窗口；丢失某帧后需要重传哪些帧

### 05 · 以太网与交换机
- **产出**：CSMA/CD 最短帧长计算器与二进制指数退避模拟；交换机模拟器（MAC 地址自学习与转发）
- **小步骤**：① 争用期与最短帧长 ② 指数退避 ③ 交换机：自学习、转发、泛洪 ④（理解层面）VLAN 与 802.11 的 CSMA/CA
- **通过标准**：真题考法：最短帧长或最远距离计算；给定一串帧的收发，求交换机地址表的变化以及哪些端口能收到帧

### 06 · IP、子网划分与转发
- **产出**：子网划分与聚合计算器；IP 分片模拟器；路由表最长前缀匹配（Trie）；ARP 过程模拟
- **小步骤**：① IPv4 头部字段 ② CIDR：网络地址、广播地址、可用主机数 ③ 子网划分与路由聚合 ④ IP 分片：片偏移、MF 标志 ⑤ 用 Trie 实现最长前缀匹配 ⑥（理解层面）NAT、DHCP、ICMP
- **通过标准**：真题考法：划分子网后各子网的地址范围、路由聚合结果、给定目的地址的下一跳、某数据报分片后各片的长度和偏移

### 07 · 路由算法
- **产出**：链路状态（Dijkstra，对应 OSPF）与距离向量（Bellman-Ford，对应 RIP）模拟器
- **小步骤**：① Dijkstra 求最短路径树（可复用数据结构第 10 关） ② 距离向量：trace 打印每一轮交换后各路由器的路由表 ③ 模拟链路断开，**亲眼看到"坏消息传得慢"** ④（理解层面）RIP、OSPF、BGP 的对比
- **通过标准**：真题考法：给定拓扑和链路代价，求某路由器的路由表；RIP 收到邻居路由表后的更新结果

### 08 · TCP
- **产出**：TCP 连接状态机（三次握手、四次挥手）；序号与确认号计算；拥塞控制模拟器，trace 打印每个 RTT 的 cwnd 与 ssthresh
- **小步骤**：① 三次握手、四次挥手的状态与序号变化 ② 序号、确认号与数据长度的计算 ③ 流量控制（接收窗口） ④ 拥塞控制：慢开始、拥塞避免、超时、3 个重复 ACK 与快恢复 ⑤ 发送窗口 = min(接收窗口, 拥塞窗口)
- **通过标准**：真题考法：某时刻 cwnd 的值、经过多少个 RTT 发送窗口达到某值、握手或挥手过程中的序号和确认号

### 09 · 应用层与 Socket 编程
- **产出**：用 Socket 写 TCP 回声服务器，再升级为极简 HTTP 服务器，用浏览器或 `curl` 访问；DNS 解析过程模拟
- **小步骤**：① TCP 回声服务器与客户端 ② 极简 HTTP 服务器，返回一个网页 ③ 用 `tcpdump` 抓自己服务器的包，看三次握手 ④ DNS 递归与迭代查询的过程模拟 ⑤（理解层面）HTTP 持久连接与非持久连接、FTP、SMTP
- **通过标准**：真题考法：访问一个网页总共需要多少个 RTT（含 DNS、TCP 连接、HTTP 请求）；DNS 查询的报文个数
