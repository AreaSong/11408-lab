# 计算机网络 · 关卡任务详情

> 考查范围以 **2027 年 408 统考大纲**为准（与 2026 版无变动），逐条对照见文末「大纲覆盖对照」；具体约定以王道为准。

## 贯穿全程的设计

### 1. 「计算器」对接计算题
时延、信道利用率、最短帧长、子网划分、IP 分片、TCP 序号与窗口……计网大题几乎都要算。
→ 每关写**带单位的计算器**，逐步打印推导过程，拿真题数据直接对答案。

### 2. 「报文解析」对接分层理解
**设备拆到哪一层的头，就工作在哪一层。**
→ 从第 01 关开始，你会亲手把数据一层层封装成帧，再一层层拆开；后面几关再用 `tcpdump` 抓真实的包来解析。书上的报文格式图会变成你自己写过的结构体。

### 3. 「状态机」对接协议过程
TCP 三次握手与四次挥手、拥塞控制、滑动窗口、距离向量的收敛……
→ 用状态机模拟，trace 打印每一轮的状态（cwnd、窗口边界、路由表），和真题逐步对照。

### 4. 「概念卡片」对接概念题
传输介质、SDN、移动 IP、协议对比这类内容写不成代码。
→ 每关列出的**概念卡片**写进该关 `NOTES.md` 的「概念卡片」一节：一张卡片 = 一张对比表或一张图。

## 各关详情

### 00 · 时延与性能计算器
- **产出**：计算发送时延、传播时延、往返时间 RTT、时延带宽积、吞吐量、信道利用率
- **小步骤**：① 发送时延与传播时延 ② 时延带宽积 ③ 分组交换与电路交换、报文交换的总时延对比
- **通过标准**：真题考法：经过若干路由器的分组交换总时延（**注意存储转发与流水线效应**）；所有结果带单位（**带宽的 k/M 是 10³/10⁶**）
- **概念卡片**：计算机网络的定义、组成与功能；网络的分类（按范围、拓扑、交换方式）；电路交换 vs 报文交换 vs 分组交换；数据报 vs 虚电路

### 01 · 分层封装与报文解析
- **产出**：把一句 HTTP 请求逐层封装为 TCP 报文段 → IP 数据报 → 以太网帧，并逐字节打印；再写解析器把帧一层层拆开
- **小步骤**：① 用 C 结构体定义以太网头、IP 头、TCP 头 ② 封装 ③ 解析 ④ 用 `tcpdump -w` 抓一个真实的包，让解析器解析它（`.pcap` 文件格式很简单）
- **通过标准**：能说出每层头部的关键字段及长度；真题考法：给出一段以太网帧的十六进制，求源/目的 IP、端口、TTL、协议类型等
- **概念卡片**：分层结构；协议、接口、服务的关系（协议是水平的、服务是垂直的）；OSI 七层 vs TCP/IP 四层与五层模型；各层 PDU 的名称

### 02 · 物理层：信道容量与编码
- **产出**：奈奎斯特定理与香农定理计算器；码元、波特与比特率换算；曼彻斯特编码、差分曼彻斯特编码的波形打印
- **小步骤**：① 码元、波特、速率的换算（含调制：码元状态数 = 相位数 × 振幅数） ② 奈奎斯特（无噪声） ③ 香农（有噪声，分贝换算），两个极限同时给出时取较小值 ④ 用字符画打印 NRZ、曼彻斯特、差分曼彻斯特波形
- **通过标准**：真题考法：给定带宽和码元状态数或信噪比，求最大数据传输速率；根据波形判断比特串
- **概念卡片**：信道、信号、带宽、码元、信源与信宿等基本概念；单工、半双工、全双工；编码 vs 调制（调幅、调频、调相、QAM）；传输介质（双绞线、同轴电缆、光纤、无线）；物理层接口的四个特性；中继器 vs 集线器（能否隔离冲突域）

### 03 · 组帧与差错控制
- **产出**：组帧器（字符计数、字节填充、零比特填充）；奇偶校验；CRC 计算器，trace 打印模 2 除法的每一步；海明码编码与纠错器
- **小步骤**：① 组帧：字符计数法；字节填充（以 PPP 的 0x7E、0x7D 转义为例）；零比特填充（连续 5 个 1 后插 0）及接收端删除 ② 奇偶校验 ③ CRC 发送端：求余数并拼接 ④ CRC 接收端：校验 ⑤ 海明码：由海明不等式求校验位个数，确定校验位位置并编码；人为翻转一位，接收端定位并纠正
- **通过标准**：真题考法：零比特填充后的比特串；给定生成多项式和数据，求 CRC 校验码或实际发送的比特串；海明码的校验位个数与出错位置
- **概念卡片**：数据链路层的功能；四种组帧方法对比；检错编码 vs 纠错编码

### 04 · 可靠传输：停等、GBN、SR
- **产出**：滑动窗口模拟器：停等协议、后退 N 帧（GBN）、选择重传（SR），可模拟丢包和超时；信道利用率计算器
- **小步骤**：① 停等协议与信道利用率 ② GBN（累计确认、超时后重传窗口内全部帧） ③ SR（逐个确认、只重传出错帧） ④ 窗口大小与序号位数的关系
- **通过标准**：真题考法：要使信道利用率最大，发送窗口至少多大；n 位序号时 GBN、SR 的最大窗口；丢失某帧后需要重传哪些帧
- **概念卡片**：流量控制 vs 可靠传输；停等、GBN、SR 对比

### 05 · 介质访问控制与局域网
- **产出**：CDMA 码片计算器；CSMA/CD 最短帧长计算器与二进制指数退避模拟；以太网帧构造器；交换机模拟器（MAC 地址自学习与转发）；802.1Q 标签插入；802.11 地址字段推演
- **小步骤**：① 信道划分：CDMA 码片序列的正交验证，由叠加信号求各站发送的比特 ② 争用期与最短帧长 ③ 指数退避 ④ 以太网（IEEE 802.3）帧：构造各字段，数据不足 46 字节时填充 ⑤ 交换机：自学习、转发、泛洪 ⑥ VLAN：给以太网帧插入 4 字节的 802.1Q 标签 ⑦ 802.11：给定站点、AP 和目的主机，推出帧中地址 1、2、3 各填什么（**以王道为准**）
- **通过标准**：真题考法：CDMA 求某站发送的数据；最短帧长或最远距离计算；给定一串帧的收发，求交换机地址表的变化以及哪些端口能收到帧；802.11 帧的地址字段
- **概念卡片**：FDM、TDM、WDM、CDMA 的原理对比；ALOHA、CSMA（三种坚持策略）、CSMA/CD、CSMA/CA；令牌传递协议；局域网的体系结构（LLC 与 MAC 子层）；802.11 的 RTS/CTS；VLAN 的作用；广域网与 PPP 协议；集线器 vs 交换机（冲突域与广播域）

### 06 · IPv4、IPv6 与分组转发
- **产出**：子网划分与聚合计算器；IP 分片模拟器；路由表最长前缀匹配（Trie）；NAT 转换表模拟；ARP 过程模拟；IPv6 地址压缩与展开转换器
- **小步骤**：① IPv4 头部字段 ② CIDR：网络地址、广播地址、可用主机数 ③ 子网划分与路由聚合 ④ IP 分片：片偏移、MF 标志 ⑤ 用 Trie 实现最长前缀匹配（含默认路由） ⑥ NAT：模拟 NAPT 转换表，内网地址加端口与公网地址加端口的互换 ⑦ ARP：模拟 ARP 缓存与请求、响应的过程 ⑧ ICMP：用 `ping` 和 `traceroute` 观察，理解 traceroute 怎样利用 TTL ⑨ IPv6：地址的零压缩（`::`）与前导零省略，压缩、展开互转
- **通过标准**：真题考法：划分子网后各子网的地址范围、路由聚合结果、给定目的地址的下一跳、某数据报分片后各片的长度和偏移、NAT 转换后的地址和端口
- **概念卡片**：网络层的功能（异构网络互连、路由与转发、拥塞控制）；SDN 的基本概念（数据平面与控制平面分离）；IPv4 地址分类与私有地址；DHCP 的四步过程；ICMP 报文类型；IPv6 的主要特点与首部（与 IPv4 对比）；路由器的组成和功能、路由表 vs 转发表

### 07 · 路由算法、路由协议与组播
- **产出**：链路状态（Dijkstra，对应 OSPF）与距离向量（Bellman-Ford，对应 RIP）模拟器；组播地址映射计算器
- **小步骤**：① Dijkstra 求最短路径树（可复用数据结构第 10 关） ② 距离向量：trace 打印每一轮交换后各路由器的路由表 ③ 模拟链路断开，**亲眼看到"坏消息传得慢"** ④ RIP 更新：给定邻居发来的距离向量，trace 打印本路由表的更新（距离加 1、16 表示不可达） ⑤ 组播：把 IP 组播地址映射为以太网组播 MAC 地址（01-00-5E 加低 23 位），算出多少个组播 IP 会映射到同一个 MAC
- **通过标准**：真题考法：给定拓扑和链路代价，求某路由器的路由表；RIP 收到邻居路由表后的更新结果；组播地址映射
- **概念卡片**：静态路由 vs 动态路由；层次路由与自治系统；域内路由 vs 域间路由；RIP vs OSPF vs BGP（算法、封装、度量）；组播的概念、IP 组播地址与 IGMP；移动 IP 的概念与通信过程（归属代理、外地代理、转交地址）

### 08 · 传输层：UDP 与 TCP
- **产出**：UDP 校验和计算器；TCP 连接状态机（三次握手、四次挥手）；序号与确认号计算；超时重传时间计算器；拥塞控制模拟器，trace 打印每个 RTT 的 cwnd 与 ssthresh
- **小步骤**：① UDP 首部；带伪首部的 16 位反码求和校验，接收端验证 ② 三次握手、四次挥手的状态与序号变化 ③ 序号、确认号与数据长度的计算 ④ 超时重传：加权平均往返时间与超时重传时间的计算（公式以王道为准） ⑤ 流量控制（接收窗口） ⑥ 拥塞控制：慢开始、拥塞避免、超时、3 个重复 ACK 与快恢复 ⑦ 发送窗口 = min(接收窗口, 拥塞窗口)
- **通过标准**：真题考法：UDP 校验和；某时刻 cwnd 的值、经过多少个 RTT 发送窗口达到某值、握手或挥手过程中的序号和确认号
- **概念卡片**：传输层的功能；端口与熟知端口号；无连接服务 vs 面向连接服务；UDP vs TCP

### 09 · 应用层与 Socket 编程
- **产出**：用 Socket 写 TCP 回声服务器，再升级为极简 HTTP 服务器，用浏览器或 `curl` 访问；DNS 解析过程模拟；Base64 编码器（MIME 用它编码非 ASCII 内容）
- **小步骤**：① TCP 回声服务器与客户端 ② 极简 HTTP 服务器，返回一个网页 ③ 用 `tcpdump` 抓自己服务器的包，看三次握手 ④ DNS 递归与迭代查询的过程模拟 ⑤ 用 Base64 编码一段中文，理解 MIME 为什么需要它
- **通过标准**：真题考法：访问一个网页总共需要多少个 RTT（含 DNS、TCP 连接、HTTP 请求）；DNS 查询的报文个数
- **概念卡片**：C/S 模型 vs P2P 模型；层次域名空间与域名服务器的种类；FTP 的控制连接与数据连接；电子邮件系统的组成、SMTP vs POP3、邮件格式与 MIME；WWW 的组成（URL、HTTP、HTML）；HTTP 报文结构、持久连接 vs 非持久连接、Cookie

## 大纲覆盖对照（2027 年 408 大纲 · 计算机网络）

> 每个条目后面是落在哪一关；「卡片」表示以概念卡片为主。

- **一、计算机网络概述**：（一）网络的定义、组成与功能、分类 → 00 卡片，主要性能指标 → 00；（二）分层结构，协议、接口、服务，OSI 与 TCP/IP 参考模型 → 01 卡片 + 01
- **二、物理层**：（一）基本概念 → 02，奈奎斯特定理与香农定理、编码与调制 → 02，电路交换、报文交换与分组交换 → 00，数据报与虚电路 → 00 卡片；（二）传输介质、物理层接口的特性 → 02 卡片；（三）中继器、集线器 → 02 卡片
- **三、数据链路层**：（一）功能 → 03 卡片；（二）组帧 → 03；（三）检错编码、纠错编码 → 03；（四）流量控制与可靠传输、停等、GBN、SR → 04；（五）信道划分 → 05（CDMA 计算）+ 05 卡片，随机访问（ALOHA、CSMA、CSMA/CD、CSMA/CA） → 05，轮询访问 → 05 卡片；（六）局域网体系结构 → 05 卡片，以太网与 802.3、802.11、VLAN → 05；（七）广域网、PPP → 05 卡片，PPP 的字节填充 → 03；（八）以太网交换机 → 05
- **四、网络层**：（一）异构网络互连、路由与转发、SDN、拥塞控制 → 06 卡片；（二）静态与动态路由、层次路由 → 07 卡片，距离-向量、链路状态 → 07；（三）IPv4 分组、地址与 NAT、子网划分与 CIDR、ARP、DHCP、ICMP → 06；（四）IPv6 的特点与地址 → 06；（五）自治系统、域内与域间路由 → 07 卡片，RIP → 07，OSPF、BGP → 07 卡片；（六）IP 组播 → 07；（七）移动 IP → 07 卡片；（八）路由器的组成和功能 → 06 卡片，路由表与分组转发 → 06
- **五、传输层**：（一）传输层的功能、寻址与端口、无连接与面向连接服务 → 08 卡片；（二）UDP 数据报、UDP 校验 → 08；（三）TCP 段、连接管理、可靠传输、流量控制、拥塞控制 → 08
- **六、应用层**：（一）C/S 与 P2P → 09 卡片；（二）DNS → 09；（三）FTP → 09 卡片；（四）电子邮件 → 09 卡片 + 09（Base64）；（五）WWW 与 HTTP → 09
