# net/10 · 路由协议、组播与移动 IP · 题目

> 本文件只写题目，不含思路和代码，做题前可以放心看；答案讲解在 `ANSWER.md`，做完再看。
>
> 王道第 4 章。BGP 是自治系统之间的路径向量：通告里带着整条 AS 路径，路径中出现自己的 AS 号就丢弃。eBGP 通告时把自己的 AS 加在最前面，iBGP 不再加。无策略时先比 AS 个数，再比本 AS 内到出口的 IGP 距离。IPv4 组播 MAC 是 `01-00-5e` 再接组播 IP 的低 23 位，第 25 位写成 0。移动 IP 里，通信对端只认归属地址；归属代理把原数据报装进新的 IP 数据报，外层目的是转交地址。

## 一、本关任务

- **产出**：BGP 路径向量模拟；组播地址映射；移动 IP 的隧道转发
- **小步骤**：
  ① 自治系统之间交换完整 AS 路径。收到的路径里已有自己的 AS 号就丢弃，trace 里要看得出环路停在哪里
  ② 把 IPv4 组播地址映射成以太网组播 MAC，并算出多少个组播 IP 落到同一个 MAC
  ③ 移动节点到了外地网络后向归属代理登记转交地址。通信对端仍发往归属地址，归属代理用 IP-in-IP 隧道转发。内层数据报用第 01 关的封装函数生成。trace 打印每一跳的外层地址和内层地址
- **通过标准**：组播映射和「多少个 IP 对应一个 MAC」与下面的规则一致；移动 IP 里说得清归属代理、外地代理、转交地址各做什么；2024-47 的（4）（5）和 2017-37 的封装与标准答案一致
- **概念卡片**（写进 `NOTES.md`）：域内路由和域间路由；RIP、OSPF、BGP 的算法、封装、度量，以及 OSPF 的分区；组播和 IGMP

每个项目有四个程序：`main.c`（如 `bgp_multicast_mip_first`）、`test.c`（`bgp_multicast_mip_first_test`）、`mcast.c`（`bgp_multicast_mip_first_mcast`）、`mip.c`（`bgp_multicast_mip_first_mip`）。

读入前用 `prompt(...)` 打印提示（`prompt` 在 `deps/prompt.h`，跑测试时自动不打印）。一行一条命令，可以连续输入，Ctrl+D 结束。空行跳过。会出内容的命令之间空一行。输入不合法时向 stderr 写原因，并以非 0 退出。每条会出内容的命令，最后一行以 `结果：` 开头。

## 二、主程序题目（`main.c`，BGP）

AS 编号是 1～65535。前缀写成 `a.b.c.d/长度`，长度 0～32，主机位必须是 0。路由器名字以字母开头，后面可以是字母或数字，最长 7 个字符。

`step` 按这一轮开始时的路由表生成通告，本轮刚收下的路由要等下一轮才继续往外传。通告对象包括刚才把路由学过来的那个邻居。比较时，AS 个数少的留下；一样少就留先收到的。自己始发的前缀不改成学来的路径。

`offer` / `pick` 不看上面的拓扑。一条通告里的 AS 路径从左到右写，至少 1 个、最多 12 个 AS。IGP 距离是 0～255 的整数，单位是跳。同一台路由器、同一个前缀、同一个下一跳不能记两次。

| 命令 | 作用 |
|---|---|
| `as <编号>` | 加入一个自治系统 |
| `peer <AS> <AS>` | 建立一条 eBGP 邻接 |
| `origin <AS> <前缀>` | 这个 AS 始发该前缀 |
| `step` | 所有 AS 同步交换一轮 |
| `encap` | 打印 RIP、OSPF、BGP 报文的直接封装 |
| `session <名字> <AS> <名字> <AS>` | 判断 eBGP 还是 iBGP，以及通告用哪种报文 |
| `offer <路由器> <前缀> via <下一跳> igp <距离> path <AS>...` | 记下一条候选 |
| `pick <路由器> <前缀>` | 在无策略约束下选出下一跳 |
| `reset` | 清空拓扑和候选 |

结果行：

| 命令 | 结果行 |
|---|---|
| `as` | `结果：已加入 AS 1` |
| `peer` | `结果：已连接 AS 1 和 AS 2` |
| `origin` | `结果：AS 1 始发 10.0.0.0/8` |
| `step` | `结果：本轮收下 2 条`。路径里有自己时要写出「丢弃」 |
| `encap` | `结果：UDP、IP、TCP` |
| `session` 两个 AS 不同 | `结果：eBGP，报文 UPDATE` |
| `session` 两个 AS 相同 | `结果：iBGP` |
| `offer` | `结果：已记录 R14 经 R11` |
| `pick` | `结果：下一跳 R11` |
| `reset` | `结果：已清空` |

### 样例

输入：

```
as 1
as 2
as 3
peer 1 2
peer 2 3
peer 3 1
origin 1 10.0.0.0/8
step
step
```

输出与 `tests/practice-loop.out` 一致。第 2 轮里 AS 2、AS 3 把带有 AS 1 的路径送回 AS 1，AS 1 丢弃。

## 三、组播程序（`mcast.c`）

只接受 D 类地址，也就是 224.0.0.0～239.255.255.255。MAC 用小写、字节之间用 `-`。`same` 要给出 2^5 的个数，并各举一个「只改没被映射的位」和「改了已被映射的位」的地址。

| 命令 | 作用 |
|---|---|
| `map <组播 IP>` | 打印二进制，并给出 MAC |
| `same <组播 IP>` | 说明有多少个组播 IP 映射到同一个 MAC |

结果行是 `结果：01-00-5e-00-01-01` 或 `结果：32 个`。

### 样例

输入：

```
map 224.0.1.1
```

输出：

```
【组播映射】224.0.1.1
D 类地址。前 4 位是 1110，后面 28 位是组标识。
二进制：11100000 00000000 00000001 00000001
以太网组播 MAC 的前 24 位固定为 01-00-5e，第 25 位固定为 0，再接 IP 的低 23 位。
第 2 个字节 00000000 去掉最高位 0，低 7 位是 0x00。
丢掉的 5 位是第 1 个字节的低 4 位（0）和第 2 个字节的最高位（0）。
主机加入这个组用 IGMP 告诉本地路由器。组播 MAC 不能靠 ARP 问出来。
结果：01-00-5e-00-01-01
```

`tests/mcast/practice-map` 还有 224.0.0.5 和 224.215.145.230。`tests/mcast/practice-same` 看 32 这个数，以及 224.128.1.1、225.0.1.1 是否和 224.0.1.1 共用 MAC。

## 四、移动 IP 程序（`mip.c`）

先写归属地址和归属代理，再写转交地址，再写通信对端。`foreign` 和 `colocated` 只能设一次。转交地址不能等于归属地址或归属代理。`away` 之前节点在归属网络，归属代理不截获。`send` 的载荷是一个不含空格的词，1～32 字节。`reply` 要在 `away` 而且已经 `send` 之后。

内层是普通的 IPv4 数据报。节点在外地时，归属代理再套一层 IP：外层源是归属代理，外层目的是转交地址，外层协议号是 4。沿途只改外层的 TTL 和首部校验和，内层不动。`foreign` 的隧道终点是外地代理；`colocated` 的隧道终点是移动节点自己。回程的源地址用归属地址。

| 命令 | 作用 |
|---|---|
| `home <归属地址> agent <归属代理>` | 登记归属网络 |
| `foreign <外地代理>` | 转交地址用外地代理的地址 |
| `colocated <转交地址>` | 同址转交地址，没有外地代理 |
| `cn <通信对端>` | 通信对端的地址 |
| `away` | 移到外地并向归属代理登记 |
| `back` | 回到归属网络并注销 |
| `send <载荷>` | 通信对端发给归属地址 |
| `reply` | 移动节点直接回给通信对端 |

人在归属网络时，结果行是 `结果：直接交付，目的 10.0.0.8`。隧道转发的结果行是 `结果：隧道交付，外层目的 30.0.0.1，内层目的 10.0.0.8`。回程是 `结果：直接发送，源 10.0.0.8，目的 20.0.0.2`。

`tests/mip/practice-triangle` 用外地代理转交地址，先在家发一次，再 `away` 后发送和回程。`tests/mip/practice-colo` 用同址转交地址 30.0.0.50。
