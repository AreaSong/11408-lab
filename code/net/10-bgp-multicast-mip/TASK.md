### 10 · 路由协议、组播与移动 IP
- **产出**：BGP 路径向量模拟；组播地址映射计算器；移动 IP 转发模拟
- **小步骤**：① BGP：自治系统之间交换完整 AS 路径，收到包含自己 AS 号的路径就丢弃，trace 打印环路如何被避免 ② 组播：把 IP 组播地址映射为以太网组播 MAC 地址（01-00-5E 加低 23 位），算出多少个组播 IP 会映射到同一个 MAC ③ 移动 IP：主机移到外地网络后获得转交地址，归属代理截获发往它的数据报，用 IP-in-IP 隧道封装后发往转交地址（复用第 01 关的封装函数），trace 打印每一跳的外层和内层地址
- **通过标准**：真题考法：组播地址映射；移动 IP 中归属代理、外地代理、转交地址的作用
- **概念卡片**：域内路由 vs 域间路由；RIP vs OSPF vs BGP（算法、封装、度量，以及 OSPF 的分区）；组播的概念与 IGMP
