## 学习理念

硬看视频、硬啃书，知识是被动灌进来的，学完也说不清自己到底懂没懂。这里把顺序倒过来：

```
定一个要做出来的东西
  → 做到一半卡住，因为缺某个知识
  → 带着问题去翻书、看视频
  → 把它写成代码，亲手实现一遍
  → 用真题数据跑通 = 真的懂了
```

**掌握的标准**：我能把它写出来，并且用真题的数据跑，结果和标准答案一致。
